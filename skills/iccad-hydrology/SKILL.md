# 水文、规模与调节计算辅助审查

水文是后面一切的输入。这里错一个参数，规模、建筑物、投资全跟着错。

## 输入与边界

水文站与实测资料、暴雨与洪水参数、产汇流参数、径流调节计算、库容曲线、特征水位表、工程规模与任务指标、泥沙与冰情资料。

只核对**链条与一致性**，不重算全套水文（除非用户明确要求）。需要重算时另开专项，并记录方法与参数来源。

## 审查方式

沿「资料 → 设计洪水 → 调节 → 特征水位 → 规模」逐环节追，每一环都要能回到上游数据。

| 环节 | 核对什么 |
|---|---|
| 基本资料 | 站名、集水面积、系列年限、插补延长方法与误差、历史洪水调查 |
| 设计洪水 | 频率曲线线型与适线、经验频率公式、参数合理性、成果地区对照 |
| 洪水组合 | 同频率/同倍比、分期洪水、入库洪水与坝址洪水的转换 |
| 产汇流 | 参数取值与下垫面、模型选择、参数率定与检验 |
| 调节计算 | 调节性能判定、损失水量、生态与供水优先序、多年调节 |
| 特征水位 | 死水位、正常蓄水位、设计/校核洪水位是否成套且各有出处 |
| 泥沙与冰情 | 淤积年限与库容损失；北方河流的冰盖、冰塞壅高 |
| 规模与指标 | 库容、灌溉面积、供水量、装机与前述成果对应 |

## 常见误判

| 现象 | 为什么是问题 |
|---|---|
| 特征水位表与调洪演算成果对不上 | 水位是结论，必须有演算过程支撑 |
| 库容曲线与地形图/断面数据不一致 | 调节计算用的库容不可靠 |
| 施工期用全年洪水、运行期用分期洪水（或反之） | 口径错位，导流标准随之错 |
| 调节计算不计蒸发渗漏损失 | 多年调节与供水保证率失真 |
| 设计洪水成果只有一个点值，无适线图与参数 | 无法复核，也无法判断地区合理性 |
| 上游已建水库的调蓄影响未计入 | 来水条件与实际不符 |
| 冰情区不设冰盖/冰塞工况 | 北方河流的典型漏项 |

## 输出与交接

将本专业结果写成 `discipline=hydrology` 的 checks/findings；特征水位与规模的结论供 `$iccad-dam`、`$iccad-gate-pump`、`$iccad-cost` 引用。

- 数值比较记录对象、原值、单位、换算与前提（如「P=1% 设计洪水」）。
- 「无资料无法判断」记 `insufficient_input`，不要用相邻工程的参数替代后当作已核实。
- 跨章节矛盾（如第 2 章与第 5 章水位不同）交 `$iccad-coordination` 统一记账，避免重复计数。
