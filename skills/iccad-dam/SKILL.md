# 挡水与泄水建筑物辅助审查

坝工审查的关键不是「算得对不对」，而是**前提说清了没有、结论有没有被沿用到别处**。

## 输入与边界

坝型比选、坝体断面、筑坝材料与填筑标准、防渗体系、稳定与渗流计算书、溢洪道与泄水建筑物、下游消能防冲、大坝安全监测、除险加固的鉴定问题清单。

不替代坝工计算与安全鉴定；无断面几何或计算书时，几何类检查记 `unsupported`。

## 审查方式

1. 先定**坝型与级别**：工程等别、坝级别、洪水标准，三者决定后面所有阈值。
2. 再查**断面成套性**：坝顶高程 = 静水位 + 波浪爬高 + 安全加高；三个要素各有出处，缺一个就不能判。
3. 再查**防渗与排水**：防渗体型式与地质条件、渗流计算的水力比降、反滤与排水能力、渗流出逸条件。
4. 再查**稳定**：工况组合（正常蓄水、设计洪水、校核洪水、水位骤降、地震）、抗剪强度指标与工况匹配、最不利滑弧位置。
5. 最后查**泄水**：泄流能力、消能型式、下游冲刷、闸门与启闭机、超标准洪水应对。

## 关键核对项

| 项 | 判据要点 | 典型问题 |
|---|---|---|
| 坝顶高程 | 三要素各有依据，且与计算书一致 | 直接用「设计洪水位 + 0.5m」 |
| 填筑标准 | 控制值与规范下限比较；压实度与渗透系数分列 | 用实测值替代控制标准 |
| 防渗体尺寸 | 厚度、坡度、水力比降 | 只有型式，无尺寸依据 |
| 稳定工况 | 逐工况列安全系数与允许值 | 只给一个工况的结论 |
| 渗流控制 | 出逸比降、排水体能力 | 只算单宽渗流量 |
| 溢洪道泄量 | 堰型、净宽、堰顶高程与调洪成果对应 | 泄量与调洪演算脱节 |
| 消能防冲 | 消能型式与下游水位、地质对应 | 海漫长度无计算 |
| 除险加固 | 逐条回应安全鉴定提出的问题 | 只列加固措施，不建对应关系 |

## 常见误判

- **只比数值不看前提**：压实度 96% 是否合规，取决于部位（培厚段/原坝体/反滤层）与工程等别。
- **一个断面的结论覆盖全坝段**：不同坝段地质、坝高、填筑料不同，须分别核对或明确说明代表性。
- **把规范推荐值当强条**：SL/T 类推荐性条文不能作为「违反强制性条文」的依据。
- **水位骤降工况缺失**：土石坝上游坡的常见控制工况，漏了稳定结论就不完整。

## 输出与交接

写成 `discipline=dam` 的 checks/findings，逐条带断面/章节定位与依据条号。

- 与 `$iccad-geotech`（参数取值）、`$iccad-calc`（计算一致性）、`$iccad-hydrology`（洪水与水位）交界处注明主责，不重复计数。
- 几何或计算能力不足时明确记 `unsupported`，不凭经验补一个结论。
