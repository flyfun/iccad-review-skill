# 防洪评价（洪水影响评价）专项辅助审查

防洪评价的结论必须**收得住**：每一个「影响很小」都要有对应的计算和工况支撑。

## 输入与边界

建设项目概况与涉河布置、河道与水文资料、设计洪水与水位、壅水与阻水计算、冲刷与淤积分析、施工期影响、防汛抢险、第三人合法水事权益、补救措施、结论与建议。

适用于 M6 专项报告；不代替行政审批，也不代替水行政主管部门的技术审查。

## 审查链条

```
涉河布置 → 设计洪水/水位 → 阻水与壅水 → 冲刷与基础埋深 → 施工期 → 防汛与应急 → 第三方权益 → 补救措施 → 结论
```

链条上每一环都要能回到上一环的数据。常见断点在「壅水 → 结论」和「冲刷 → 基础埋深」两处。

## 关键核对项

| 项 | 核对什么 | 典型问题 |
|---|---|---|
| 涉河布置 | 位置、尺寸、与治导线及管理范围关系 | 只给坐标，无与治导线的距离 |
| 设计洪水 | 频率、成果来源、与所在河段一致性 | 各频率成果不成套 |
| 水位 | 设计洪水位、建站前后水位变化 | 用上游站水位直接替代 |
| 阻水比 | 阻水面积/过水面积，各工况分别计算 | 只给一个频率的阻水比 |
| 壅水 | 公式与参数来源、工况组合、最不利工况选择 | 参数无出处，或只算平均工况 |
| 冲刷 | 一般冲刷 + 局部冲刷，与基础埋深比较 | 把一般冲刷当总冲刷 |
| 施工期 | 围堰/便桥阻水、拆除与度汛 | 只评运行期，不评施工期 |
| 防汛抢险 | 通道、监测、预案、物资 | 泛泛写「加强管理」 |
| 第三方权益 | 上下游取水口、排水口、堤防、耕地 | 一句「无影响」无支撑 |
| 结论 | 是否与前述计算一致，措施是否可落地 | 结论强度超过计算能力 |

## 常见误判

- **只算一个频率**：防洪评价至少覆盖设计洪水与校核（或更高）工况，并说明最不利工况选择理由。
- **阻水比达标即结论安全**：阻水比是过程指标，壅高与冲刷才是影响结论。
- **基础埋深与冲刷深度不比较**：这是最实质的一条，缺了整份评价就落空。
- **把规范推荐公式当唯一解**：公式适用条件（河道类型、宽深比、有无导流建筑物）不满足时，结果不可用。
- **结论超出计算范围**：没有算的工况不能写「均满足要求」。

## 输出与交接

写成 `discipline=flood_eval` 的 checks/findings，每条带章节/表号定位与依据（导则条文、批复要求）。

- 水文成果交 `$iccad-hydrology` 复核，结构埋深交 `$iccad-gate-pump` 或 `$iccad-dam`。
- 与规划同意书论证（M12）不得互相替代：本报告评影响，M12 论证规划符合性，两类结论不能混写。
