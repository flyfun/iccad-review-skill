# 各模块候选检查项

候选范围，不是规范库，也不是法定审查要点。按项目等别、类型、阶段与单位内控增删；
每条只有在挂上**已核验依据**后才是可执行的审查项，否则只作为观察点。

## 通用项（全部模块、全部阶段）

| 编号 | 检查项 | 能力前提 |
|---|---|---|
| U01 | 责任表：编制/校核/审查/批准人齐全并签署 | text；扫描页须目视 |
| U02 | 设计单位资质与证号在有效期内 | text 或 image |
| U03 | 单位章、注册执业章齐全有效 | image |
| U04 | 目录与正文章节、页码对应 | text |
| U05 | 正文引用的附图、附表、附件齐全 | text + drawing_list |
| U06 | 版本标识一致（封面/页眉/修订记录） | text |
| U07 | 工程等别、建筑物级别全文一致 | text |
| U08 | 计量单位与量纲统一，表格内外一致 | text + tables |
| U09 | 引用规范号带年份且现行有效 | text |
| U10 | 结论章节与各章结论不矛盾 | text |

## M1 土石坝 / 水库

坝型与断面、防渗体系、坝料与填筑标准、边坡与稳定、渗流与排水、溢洪道与泄水、放水与引水、大坝安全监测、除险加固针对性（针对鉴定问题逐条落实）。

- [ ] 工程等别与坝级别是否与规模、库容、保护对象匹配
- [ ] 特征水位（正常/设计/校核/死水位）成套，且有调洪演算支撑
- [ ] 坝顶超高、波浪爬高、风浪要素取值与计算书一致
- [ ] 填筑压实度、渗透系数等控制指标与规范下限比较
- [ ] 上下游边坡稳定工况齐全（正常、设计洪水、校核洪水、骤降、地震）
- [ ] 防渗型式（心墙/斜墙/土工膜/垂直防渗）与地质条件对应
- [ ] 渗流控制与排水设施（贴坡排水、棱体、褥垫）与渗流计算对应
- [ ] 溢洪道泄流能力、消能型式、下游冲刷论证
- [ ] 除险加固报告是否逐条回应安全鉴定提出的问题
- [ ] 大坝安全监测设施与新老坝体衔接

## M2 混凝土坝 / 拱坝

体型与分缝、材料分区、温控与浇筑、坝基处理、泄洪与消能、应力与稳定、坝体排水、接缝灌浆。

- [ ] 坝体断面与非溢流/溢流段划分
- [ ] 应力与稳定分析工况、荷载组合、材料参数来源
- [ ] 温控标准与浇筑分层分块、冷却措施
- [ ] 坝基开挖、固结灌浆、帷幕灌浆参数与地质建议对应
- [ ] 泄洪表孔/深孔布置与下游消能防冲
- [ ] 分缝分块与接缝灌浆、止水构造
- [ ] 与 M1 共用项：水文、泄流能力、监测

## M3 堤防 / 河道治理（含山洪沟、侵蚀沟两子类）

堤线布置、堤型断面、护岸与护坡、险工处理、穿堤建筑物、河道整治、清淤疏浚、防汛道路。

- [ ] 堤线布置与河道治导线、行洪断面的关系
- [ ] 堤顶高程 = 设计水位 + 波浪爬高 + 安全加高，三要素是否各有出处
- [ ] 堤身填筑标准、防渗与减压、堤基处理
- [ ] 护岸型式的抗冲流速与河床组成对应
- [ ] 穿堤建筑物（涵闸、泵站）与堤身的结合部防渗
- [ ] 疏浚范围、深度与弃土处置
- [ ] 山洪沟子类：防御标准、沟道卡口与滞洪、预警非工程措施
- [ ] 侵蚀沟子类：分级依据、措施配置、措施投资占比

## M4 水闸 / 泵站 / 输水建筑物

闸孔规模与过流、消能防冲、闸基与防渗、结构稳定、金属结构与启闭机、泵站选型与进出水、隧洞/渡槽/倒虹吸/管道的水力与结构。

- [ ] 闸孔总净宽与过流能力计算（设计/校核工况）
- [ ] 消能型式、海漫长度、下游冲刷
- [ ] 闸基抗滑、抗倾、地基承载力与地质参数对应
- [ ] 防渗长度与渗流稳定（出口段、侧向绕渗）
- [ ] 闸门型式、启闭机容量与运行工况对应
- [ ] 泵站：设计扬程/流量、机组选型、进出水条件、断流设施
- [ ] 输水建筑物：过流能力、水头损失、结构受力、伸缩缝与止水
- [ ] 与灌区渠系的水位衔接（跨 M5 时互引证据）

## M5 灌区 / 农田水利

灌溉制度与需水、水土资源平衡、渠系布置与建筑物、渠系水利用系数、节水措施、管理设施。

- [ ] 灌溉设计保证率与灌溉制度参数来源
- [ ] 供需平衡：来水、需水、调蓄能力三者口径一致
- [ ] 渠系分级、控制面积与设计流量逐级推算
- [ ] 渠道纵横断面与不冲不淤流速
- [ ] 渠系建筑物（分水闸、量水、跌水、渡槽）配套完整性
- [ ] 渠系水利用系数取值依据与节水措施对应
- [ ] 与水源工程（M1/M4）的水量与水位衔接

## M6 防洪评价（洪水影响评价）

建设项目概况、河道与水文、洪水计算、阻水与壅水、冲刷与淤积、防汛抢险、第三人合法水事权益、补救措施、结论。

- [ ] 涉河建筑物位置、尺寸、与治导线及管理范围的关系
- [ ] 设计洪水与相应水位的来源与频率一致性
- [ ] 壅水计算：公式、参数、工况组合、最不利工况选择
- [ ] 一般冲刷与局部冲刷深度、基础埋深比较
- [ ] 施工期影响与临时设施（围堰、便桥）的阻水与拆除
- [ ] 防汛抢险通道、监测与应急预案
- [ ] 对第三人合法水事权益的影响分析
- [ ] 结论是否与前述计算一致，补救措施是否可落地

## M7 水土保持方案

项目与项目区概况、水土流失预测、防治目标与标准、措施布局与设计、监测、投资、效益。

- [ ] 防治责任范围与项目征占地一致
- [ ] 扰动面积、弃渣量、预测流失量与主体工程量对应
- [ ] 防治标准等级与项目所在区域、行业对应
- [ ] 措施体系（工程/植物/临时）无缺项、与主体工程衔接
- [ ] 弃渣场选址合规性与防护设计
- [ ] 水保投资与主体工程投资口径不重复计算

## M8 水资源论证

水资源条件、取用水合理性、水源可靠性、取退水影响、节水与保护措施。

- [ ] 取水水源来水量与保证率、特枯年应对
- [ ] 用水定额与行业标准、节水水平对比
- [ ] 取退水口位置与河段功能区的相符性
- [ ] 河道内生态流量保障
- [ ] 取退水影响分析与第三方权益

## M9 环境影响评价

工程分析与污染源、环境现状、影响预测、保护措施、监测与管理、结论。

- [ ] 工程分析与主体工程规模、施工组织一致
- [ ] 环境保护目标与敏感区位置关系
- [ ] 施工期与运行期影响分别评价
- [ ] 生态流量、鱼类保护、下泄水温等措施与设计衔接
- [ ] 环保投资与概算口径一致

## M10 安全鉴定

现状调查、质量检测、复核计算、运行管理评价、类别判定、处理建议。

- [ ] 鉴定范围与建筑物清单完整
- [ ] 检测项目、数量、方法与结论可追溯
- [ ] 复核计算采用的实际断面、材料参数、运行工况
- [ ] 防洪能力、结构安全、渗流安全、抗震安全分项结论
- [ ] 类别判定（一类/二类/三类）与分项结论逻辑自洽
- [ ] 处理建议与所判问题逐条对应，并给出实施紧迫性

## M11 重大设计变更 / 建设方案复核

变更缘由、变更内容、必要性与合理性、对已批方案的影响、投资变化、实施安排。

- [ ] 变更是否属于重大变更的判定依据
- [ ] 变更前后技术方案对比（数量、位置、结构、标准）
- [ ] 对已批规模、任务、效益的影响
- [ ] 投资变化幅度与资金来源
- [ ] 是否触发重新报批或专项论证

## M12 规划同意书论证

规划符合性、工程建设必要性、方案合理性、对规划实施的影响、结论。

- [ ] 与流域/区域规划、河湖岸线规划的符合性
- [ ] 工程任务与规模在规划中的定位
- [ ] 对规划确定的防洪、供水、生态目标的影响
- [ ] 是否与洪水影响评价重复或遗漏（两者不能互相替代）

## M13 河湖健康评价

指标体系、数据来源、赋分、分级、问题与对策。

- [ ] 评价范围与河湖分段是否合理
- [ ] 指标数据年份、来源、监测点位
- [ ] 赋分标准与权重是否引用现行技术文件
- [ ] 分级结果与各指标得分一致
- [ ] 问题识别与对策的对应关系

## M14 幸福河湖建设实施方案 / 自评估

建设目标、任务措施、投资与进度、评估指标、成效自评。

- [ ] 目标指标可量化、可考核
- [ ] 任务措施与目标逐项对应
- [ ] 投资与进度匹配，来源明确
- [ ] 星级/评分依据与得分明细一致
- [ ] 不把景观提升替代防洪、供水、生态等核心任务

## 使用提示

- 上表用于**生成 `planned_check_ids`**，不是结论模板。每项在记录里必须有状态，不能只记命中。
- 同一事实被多个模块覆盖时，确定主责模块，其余模块引用主责证据，避免重复计数。
- 表中未列但项目特有的关键问题，用 `origin=manual` 补充进计划，并说明补充理由。
