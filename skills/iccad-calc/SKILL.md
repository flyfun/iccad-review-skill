# 水力与结构计算书一致性审查

不是重算，是**追**：这个数从哪来、用什么公式、在哪个工况下成立、被谁引用。

## 输入与边界

计算书（含电子表格）、参数表、公式与适用条件、成果汇总、正文引用处、图纸标注。

只核对一致性与可追溯性。需要重算时另开专项，记录工具、方法、参数版本；**不得用估算结果冒充复核结果**。

## 四条追溯线

1. **工况线**：计算工况是否覆盖规范要求的组合（正常、设计、校核、骤降、地震、施工期）。
2. **参数线**：计算书参数 ← 地质建议值 / 水文成果 / 材料试验值，是否与来源篇章一致。
3. **公式线**：公式形式、适用条件（堰流/孔流、宽顶堰/实用堰、有无侧收缩）、量纲是否与参数匹配。
4. **引用线**：正文、附表、图纸标注的数值是否与计算书**最终版**一致。

## 常见问题

| 现象 | 后果 |
|---|---|
| 正文数值与计算书最后一版不一致 | 读者按错误值理解方案 |
| 同一参数在三个篇章取三个值 | 结论不可复现 |
| 单位换算错（万 m³ ↔ m³、L/s ↔ m³/s、cm/s ↔ m/d） | 量级错，判断全错 |
| 公式套用条件不符（如侧收缩未考虑） | 结果偏差无说明 |
| 只给一个工况的成果 | 无法判断最不利 |
| 有效数字与修约不一致（96.5% 写成 97%） | 阈值比较结论翻转 |
| 计算书无编制/校核签署 | 无法追溯责任 |
| 引用他册计算书但未附成果表 | 无法核对 |

## 数值比较的规矩

- 记录对象、原值、单位、归一值、阈值与阈值单位、前提条件是否已核验。
- 未知值记 `insufficient_input`，**不用 0 或经验值代替**。
- 只支持脚本 `UNITS` 表内的单位与精确十进制换算；复合单位、含修约规则的口径交专项工具，并在记录里写清方法。

## 输出与交接

写成 `discipline=hydraulic` 或 `structure` 的 checks/findings：

- `kind=calculation_inconsistency` 时给出**两侧定位**（计算书表号/公式号 + 正文/图纸位置）与两个数值。
- 结论只写事实：「计算书成果 328 m³/s，正文引用 245 m³/s」，不写「计算错误」。
- 与 `$iccad-dam`、`$iccad-gate-pump` 的数值判断合并时，以本条提供的两侧定位为准，避免同一问题被两处各记一次。
