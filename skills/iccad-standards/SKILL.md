# 规范依据核验与检索

审查意见的分量取决于依据。**没核验过的编号不是依据，是猜**。

## 三类依据

| kind | 内容 | 效力 |
|---|---|---|
| `standard` | 国家标准（GB/GB/T）、水利行标（SL）、推荐性行标（SL/T）、地标（DB）、团体标准（TB） | 按层级与强制性属性 |
| `regulation` | 法律、行政法规、部委规章与规范性文件（如水利部办公厅通知、稽察整改要求） | 不得与现行规范抵触；放宽要求时以规范为准 |
| `approval` | 批复、审查意见、项目专用技术要求 | 仅对本项目有效，**不能升格为国家规范** |

`drawing`、`project` 作为依据时，只用于图文一致性与合同条件类判断。

## 每张依据卡必须回答

1. **编号与年份**：完整写 `SL/T 619-2021`，不写「619 规程」。
2. **现行性**：现行 / 已被替代 / 尚未实施 / 未收录。被替代的写明替代标准与过渡规则。
3. **实施日期与基准日**：有效区间 `[effective_from, effective_to)`；`effective_to` 为空表示**未记录终止日**，不是永久有效。
4. **强制性属性**：`mandatory=true` 必须能定位到具体条文，并注明是全文强制还是条文强制。
5. **适用条件**：工程等别、建筑物级别、工程类型、地区、阶段——不满足条件就不是本项目依据。
6. **可追溯来源**：公告号、正文页、受控副本编号。**`authority=official` 不能凭标准名称认定。**

## 检索条文原文

条号凭记忆写是最容易出错的一环。有 ima 知识库时按四步走：**检索 → 开原文核对 → 核官方来源 → 写依据卡**。
接入方式、凭据配置与错误码见 [ima 接入说明](../iccad-review/references/ima-integration.md)。

- 检索用规范术语（如「土石坝 压实度」「消能防冲」），**不要把项目名、地名写进检索词**——检索词会外发。
- 命中结果是**线索**：高亮片段可能截断或跨段拼接，必须打开原文核对条号与文字。
- 同一规范在库里可能有多个年份，以基准日适用的那一版为准，不跨版本混用。
- 没有可用检索源时，依据写 `status=unknown` 并记检索缺口；**不要凭印象补一个条号**。

## 常见陷阱

| 陷阱 | 后果 | 处理 |
|---|---|---|
| 只写编号不写年份 | 无法判断版本，换版后意见失效 | 一律带年份 |
| 把 SL/T、GB/T 的条文当强制性条文 | 意见被驳回，损害审查权威 | 推荐性标准判违规只能作为「建议」或「不符合约定」 |
| 用已废止版本判违规 | 结论错误 | 先查替代关系，再看过渡规则 |
| 地方标准与国标冲突 | 口径分裂 | 从严者执行，并说明冲突点 |
| 引用部委文件但文件已修订 | 依据失效 | 核对文号与发布日期，保留现行版本 |
| 工程等别未定就套阈值 | 阈值取错档 | 等别未知时该检查项记 `insufficient_input` |

## 效力层级与冲突

1. 强制性条文 > 一般条文；国标/行标 > 地标 > 团体标准 > 单位内部要求 > 合同技术要求。
2. 外部依据（内部审查要点、上级通知、批复意见）**低于国家与行业规范**：与规范冲突或放宽要求时以规范为准，**从严者优先**。
3. 每条引用外部依据的意见必须标注「依据来源：文件 § 定位」，**不得伪装成规范条文**。
4. 冲突无法消解时，登记为疑点交由专业责任人判断，不由 AI 自行取舍。

## 输出与交接

写入 `bases`：`identifier`、`clause`、`level`、`mandatory`、`status`、`applicability`、`effective_from/to`、`source_ref`、`verified_by/at`、`transition_ref`、`rights_basis`、`summary`。

- **核不实就保留 `status=unknown`**：未知字段填 null，写清检索缺口。不得为通过格式检查编造元数据。
- `unknown` 依据不得支撑 `evaluated` 的检查项；相关规则保持 `draft`，检查记 `unverified_basis`。
- 只摘要，不分发授权不明的标准全文。
- 交接给 `$iccad-rule-author`（转规则）与 `$iccad-report`（依据清单）。

不做什么：不判断设计是否满足条文（那是各专业与 `$iccad-calc` 的事），只回答「这条依据是否成立、是否适用、写在哪」。
