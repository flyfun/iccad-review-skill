# 水保、水资源与环评专项篇章辅助审查

专项篇章的通病是**自成一套数**：自己一套工程量、自己一套投资、自己一套结论，与主体工程对不上。

## 输入与边界

水土保持方案（M7）、水资源论证（M8）、环境影响评价（M9）、征地移民篇章，以及对应的主体工程规模、施工组织、概算。

按专项规程核对要素完整性与衔接；不代替行政审查，不判定是否批准。

## 一、水土保持（M7）

| 核对项 | 要点 |
|---|---|
| 防治责任范围 | 与征占地、施工布置、弃渣场范围一致 |
| 流失预测 | 扰动面积、弃渣量、预测方法与参数 |
| 防治标准 | 等级与项目所在区域、行业对应 |
| 措施体系 | 工程/植物/临时三类无缺项，与主体工程衔接 |
| 弃渣场 | 选址合规性、堆置稳定、防护与排水 |
| 监测与投资 | 监测点布设；水保投资不与主体重复计列 |

常见问题：责任范围小于实际扰动；弃渣量取自可研而施组已变；措施投资按比例估算。

**水保方案 12 块**：编制依据/水平年/方案深度 → 项目组成与项目区概况 → 水土保持评价（含措施界定）→
防治责任范围与防治目标 → 水土流失分析与预测 → 措施总体布局与分区措施 →
**弃渣场与取土场专项（最高频判定块）** → 表土保护与土石方平衡 → 监测 → 投资概（估）算与效益 →
水土保持管理 → 附件、附图与方案变更。

逐条判定标准见 [水保清单](../domain-packs/soil-conservation/references/checklist.md)，
限值见 [水保表](../domain-packs/soil-conservation/references/swc_tables.md)，
分区与行业指标见 [行业与区域](../domain-packs/soil-conservation/references/industry-region.md)。

## 二、水资源论证（M8）

| 核对项 | 要点 |
|---|---|
| 水源可靠性 | 来水量、保证率、特枯年应对 |
| 用水合理性 | 用水定额、行业对标、节水水平 |
| 取退水 | 取水口位置、退水口与水域功能区 |
| 生态流量 | 河道内生态流量保障与下泄措施 |
| 影响分析 | 对上下游用水户、地下水的影响 |

常见问题：定额无来源；生态流量只写数字不给保障方式；取水规模与设计供水规模不一致。

**水资源论证 12 块**：项目概况与取用水方案 → 工作等级与论证范围 → 水平年与基本资料 →
**水资源量** → **开发利用与潜力** → **用水合理性：工艺与水量平衡** → **用水水平与节水潜力** →
**核定取水量** → **取水水源论证—地表水** → **取水水源论证—地下水/公共供水/再生水** →
**取水影响** → **退水影响 + 措施与结论**。

标 ★ 的 9 块是论证的主体，报告若把「核定取水量」写成结论而无水量平衡支撑，整章即不成立。
逐条判定标准见 [水资源清单](../domain-packs/water-resources/references/checklist.md)，
表与限值见 [水资源表](../domain-packs/water-resources/references/wr_tables.md)。

## 三、环境影响评价（M9）

| 核对项 | 要点 |
|---|---|
| 工程分析 | 与主体规模、施组、运行方式一致 |
| 环境现状 | 监测点位、时段、因子 |
| 敏感目标 | 保护区、饮用水源、鱼类「三场」 |
| 影响预测 | 施工期与运行期分开；水文情势变化 |
| 保护措施 | 生态流量、鱼类过鱼、下泄水温、增殖放流 |
| 环保投资 | 与概算口径一致 |

常见问题：生态流量与设计下泄设施脱节；鱼类保护措施无设施支撑；施工期影响只写一句。

## 四、征地移民

| 核对项 | 要点 |
|---|---|
| 征地范围 | 与工程布置、淹没线一致 |
| 实物指标 | 人口、房屋、耕地、专项设施，调查与公示 |
| 补偿标准 | 依据现行文件，与地方标准一致 |
| 安置方案 | 生产安置与搬迁安置的可行性 |
| 投资 | 与概算中的移民投资一致 |

常见问题：实物指标用旧年份数据；补偿标准引用已废止文件；移民投资与概算两套数。

## 输出与交接

写成对应 `discipline`（`soil_water`/`water_resource`/`environment`/`resettlement`）的 checks/findings。

- 与主体工程的数据不一致，属 `document_conflict`，须给两侧定位；主责交 [跨篇章接口与图文一致](../disciplines/coordination.md) 统一记账。
- 专项报告未随主体报告提供时记 `insufficient_input`，写明影响范围。
- 专项投资与概算的对应关系交 [施工组织与概算](../disciplines/cost.md) 核对，避免重复计列或漏计。
