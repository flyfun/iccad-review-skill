# 工程地质与基础处理辅助审查

地质篇章最常见的两种病：**参数没有出处**，和**设计用了另一套参数**。

## 输入与边界

勘察报告与工作量、钻孔与剖面、地层描述、物理力学指标统计表、地下水与渗透性、标准贯入/动力触探、天然建筑材料、地基处理与边坡建议、设计采用的地质参数。

不做岩土计算；核对「试验/经验 → 建议值 → 设计采用值」这条链是否可追。

## 关键核对项

| 项 | 核对什么 | 典型问题 |
|---|---|---|
| 勘察工作量 | 钻孔间距、深度、试验组数是否满足阶段深度 | 初设阶段工作量按可研配置 |
| 地层与剖面 | 剖面与钻孔柱状、地质图一致 | 剖面层位与文字描述矛盾 |
| 参数统计 | 样本数、剔除异常、平均值/标准值/小值平均 | 只给一个数，无统计口径 |
| 参数取值 | 建议值有试验依据或明确的经验依据 | 经验值冒充试验区值 |
| 强度指标 | 与工况匹配（不排水/固结不排水/排水） | 全篇只用一个 c、φ |
| 地下水 | 水位、腐蚀性、渗透系数与抽水试验 | 抗浮/基坑降水未考虑 |
| 天然建材 | 储量、质量、运距与用量对应 | 储量小于需求量 |
| 地基处理 | 处理方案与地层、承载力、沉降对应 | 方案无计算，只有构造要求 |
| 边坡 | 建议坡比与岩土条件、地下水 | 建议值与设计采用值不一致 |

## 常见误判

- **「地区经验」当依据**：无试验、无引用出处的经验参数，只能记为观察点，不能用来判违规。
- **参数搬家**：第 4 章建议值、第 5 章设计值、计算书参数三处不同，是最容易被漏掉也最影响结论的一类。
- **把勘察结论当设计结论**：地质说「建议采用 X 处理」，不代表设计已按 X 设计。
- **渗透系数单位混乱**：cm/s 与 m/d 混用，直接导致渗流判断错档。

## 依据库能提供什么

地质勘察**没有**独立的已校准依据库。可用的是各专业包里与地层、参数相关的判定口径：

| 需要什么 | 去哪找 |
|---|---|
| 坝基处理、帷幕、固结灌浆的判定口径 | `domain-packs/gravity-dam/references/checklist.md` 块 8 |
| 土石坝坝基处理与坝体连接 | `domain-packs/earth-dam/references/checklist.md` 块 8 |
| 堤基处理、渗透变形判别 | `domain-packs/river-channel/references/checklist.md` 块 7、块 10 |
| 闸基承载力与地基处理 | `domain-packs/sluice/references/checklist.md` 块 7 |
| 参数取值与稳定安全系数的对应关系 | 各包的 `*_tables.md`、`limits.md` |

（路径相对 `references/` 目录。）

这些包只覆盖「地质条件如何影响设计判断」，**不覆盖勘察工作量、钻孔间距、试验项目与成果精度**——
那部分须由 [规范依据核验](../workflow/02-standards.md) 现场核验勘察规范后判定，不要用设计清单替代勘察审查。

## 输出与交接

写成 `discipline=geotech` 的 checks/findings，写明参数名称、建议值、设计采用值、两侧定位。

- 参数传递到 [挡水与泄水建筑物](../disciplines/dam.md)、[水闸泵站与输水](../disciplines/gate-pump.md)、[计算书一致性](../disciplines/calc.md) 的，须在该处再次核对采用值，不能假定已传递。
- 勘察报告未随审查材料提供时记 `insufficient_input`，并在缺口清单写明影响哪些检查项。
