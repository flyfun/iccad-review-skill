# 水闸、泵站、渠系与输水建筑物辅助审查

这类建筑物的问题多出在**接口**：水力给了流量，结构按另一个流量配筋，金结又按第三种尺寸订闸门。

## 输入与边界

闸孔规模与过流计算、消能防冲、闸基与防渗、结构稳定、金属结构与启闭机、泵站选型与进出水、渠道纵横断面、渡槽/倒虹吸/隧洞的水力与结构。

不做水力计算与结构验算；只核对同一参数在不同篇章、图表之间是否一致，以及论证链条是否闭合。

## 关键核对项

| 对象 | 核对什么 | 常见问题 |
|---|---|---|
| 水闸 | 闸孔总净宽与过流能力（设计/校核工况） | 只给单孔尺寸，无总净宽与过流验算 |
| 水闸 | 消能型式、海漫长度、下游冲刷 | 消能型式与下游水位不匹配 |
| 水闸 | 抗滑、抗倾、地基承载力 | 基底压力与地基允许承载力不比较 |
| 水闸 | 防渗长度与侧向绕渗 | 只算正向渗流 |
| 金结 | 闸门型式、孔口尺寸、启闭力与运行工况 | 闸门尺寸 ≠ 闸孔尺寸 |
| 泵站 | 设计/最高/最低扬程与流量、机组选型 | 只给设计扬程，缺最高/最低工况 |
| 泵站 | 进出水流态、断流设施、拦污 | 前池尺寸无依据 |
| 渠道 | 分级流量逐级推算、不冲不淤流速 | 末级渠道流量与灌溉面积不匹配 |
| 输水建筑物 | 过流能力、水头损失、结构受力、伸缩缝止水 | 水头损失与总水头不闭合 |
| 交叉 | 与渠系水位衔接、与道路/河道的净空 | 各篇章各写一套水位 |

## 水闸 10 块

设计标准与特征水位 → 闸址与总体布置 → 过流能力与闸孔规模 → 消能防冲 → 防渗排水 →
稳定分析 → 结构设计与地基处理 → 闸门、启闭机与金属结构 → 安全监测 → 施工组织与温度控制。

稳定与防渗两块最容易只算正向：侧向绕渗、基底压力与地基承载力比较、抗浮在检修工况下是否成立，逐项确认。
详见 [水闸清单](../domain-packs/sluice/references/checklist.md)、
[水闸表](../domain-packs/sluice/references/sluice_tables.md)。

## 泵站 12 块

概述与设计依据 → 基本资料 → 工程规模与等别 → **特征水位（本域命门）** → **特征扬程与水泵选型** →
**水泵安装高程与汽蚀** → 总体布置与站址 → 泵房（布置/高程/防渗/稳定/结构）→
**进出水建筑物（引渠/前池/进水池/出水池/管道/流道）** → 机电设备与金属结构 → 自动化与安全监测 → 结论、措施与附表附图。

泵站的三处高频错：特征水位不成套（设计/最高/最低缺一）、选型只按设计扬程、安装高程没做汽蚀校核。
详见 [泵站清单](../domain-packs/pump-station/references/checklist.md)、
[泵站表](../domain-packs/pump-station/references/ps_tables.md)。

## 水运工程 12 块

前置条件与设计基础 → 设计船型与泊位等级 → 总平面布置 → 码头前沿高程与水深 → 航道与通航尺度 →
荷载 → 码头结构选型与稳定 → 桩基与地基处理 → 防波堤与护岸 → 航道整治与疏浚 → 耐久性防腐与附属设施 → 报告完整性与附图附件。

详见 [水运清单](../domain-packs/port-waterway/references/checklist.md)、
[水运表](../domain-packs/port-waterway/references/pw_tables.md)。

## 常见误判

- **把设备参数当论证**：写了「选用 X 型启闭机」不等于论证了启闭力。
- **扬程口径混用**：设计扬程、平均扬程、最高/最低扬程不可互相替代，选型须按最不利工况。
- **流量传递断链**：水源—干渠—支渠—田间，任一级流量与面积、灌水率不自洽。
- **图纸与计算书不同版**：过流尺寸、孔数、高程不一致，须回到两侧定位。
- **闸孔总净宽只按设计流量定**：校核工况过流能力与消能都要复核，否则汛期靠超蓄兜底。

## 输出与交接

写成 `discipline=gate_pump` 的 checks/findings，注明对象（哪座闸/哪台机组/哪段渠）、工况与两侧定位。

- 水力计算依据交 [计算书一致性](../disciplines/calc.md)，地质参数交 [工程地质与基础](../disciplines/geotech.md)，与水源工程的水位衔接交 [跨篇章接口与图文一致](../disciplines/coordination.md)。
- 设备铭牌参数、厂家资料未提供时记 `insufficient_input`，不按经验值判定合格。
