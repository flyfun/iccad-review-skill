# 防洪评价（洪水影响评价）专项辅助审查

防洪评价的结论必须**收得住**：每一个「影响很小」都要有对应的计算和工况支撑。

## 输入与边界

建设项目概况与涉河布置、河道与水文资料、设计洪水与水位、壅水与阻水计算、冲刷与淤积分析、施工期影响、防汛抢险、第三人合法水事权益、补救措施、结论与建议。

适用于 M6 专项报告；不代替行政审批，也不代替水行政主管部门的技术审查。

## 前置判定（先定这六样，再翻正文）

| 判定项 | 取值 | 判错的后果 |
|---|---|---|
| 报告类型 | 涉河建设项目 / 蓄滞洪区非防洪建设项目 | 走错附录 B 的目录，整份对照失效 |
| 跨越型式 | 跨河 / 穿河穿堤 / 临河临堤 / 蓄滞洪区内 | 用错技术要求章节 |
| 河流特性 | 山区 / 半山区 / 平原 / 低洼 | 影响分析范围与壅水系数取错 |
| 设防标准与堤防级别 | 按防护对象等级查 | **标准定错则全篇连锁错** |
| 影响分析范围 | 山区 3B / 丘陵 (3~5)B / 平原 (5~10)B | B 为**两堤之间河宽**，无堤段取历史最高洪水位河宽 |
| 报告目录归属 | SL/T 808 附录 B 的 B.1 综合 / B.2 河道 / B.3 蓄滞洪区 | 章节比对全部对不上 |

工程等别、堤防级别判不出来，本身就是一条资料缺口，不要猜一个值往下走。

## 审查链条

```
涉河布置 → 设计洪水/水位 → 阻水与壅水 → 冲刷与基础埋深 → 施工期 → 防汛与应急 → 第三方权益 → 补救措施 → 结论
```

链条上每一环都要能回到上一环的数据。常见断点在「壅水 → 结论」和「冲刷 → 基础埋深」两处。

## 十二块骨架

| 块 | 审什么 | 主要依据 |
|---|---|---|
| 1 | 概述与评价依据（目录、依据现行性、影响范围） | 附录 B、影响范围表 |
| 2 | 建设项目基本情况（与河道/堤防空间关系、施工方案） | 报告编制章节 |
| 3 | 流域（河湖/蓄滞洪区）基本情况（河段参数、水工程、水文站、规划） | — |
| 4 | 河道演变分析（历史/近期/趋势；重要河段须数值模拟或河工模型） | 演变分析条款 |
| 5 | **洪水影响分析计算**（工况、水文、阻水、壅水、冲刷） | 计算章节（★核心） |
| 6 | 技术要求符合性（阻水比、夹角、净空、埋深、跨越方式） | 技术要求章节（★核心） |
| 7 | 河势稳定与冲刷淤积 | 河势与冲淤条款 |

## 关键判定锚点

| 项 | 锚点 | 典型问题 |
|---|---|---|
| 阻水比 | 跨河与临河分别有上限；须**总阻水比 + 河槽 + 滩地 + 占用行洪面积**四项齐备 | 只给总数；某项填「/」＝该算未算 |
| 壅水 | ΔZ_M = η(V_M² − V²)，η 与 V_M 按表分类取值；须给出壅水高度**与**壅水长度 | η 拍脑袋；V_M 无依据 |
| 冲刷 | 一般冲刷 + 局部冲刷分别计算，与基础埋深比较 | 把一般冲刷当总冲刷 |
| 净空与夹角 | 桥下净空按表查；桥轴与水流夹角有上限 | 夹角超限仍写「满足要求」 |
| 工况 | 现状/规划防洪标准工况、项目设计防洪标准工况、施工期工况 | 只算一个工况，漏施工期 |
| 施工期 | 围堰/便桥阻水、拆除与度汛 | 只评运行期 |

具体数值限值见 [限值表](../domain-packs/flood-impact/references/flood_tables.md)，
章节结构与附录 B 三套目录见 [结构与目录](../domain-packs/flood-impact/references/flood_works_tables.md)。
**限值随工程等别、河段类型变化，抄表前先确认前提成立。**

## 引用纪律

- **SL/T 808-2025 本身不在强条汇编里**。洪评的法定强条落在其引用规范上（首要 GB 50286 关于堤防的规定），
  判强条前先查 [强制条文清单](../domain-packs/flood-impact/references/compulsory-clauses.md)，
  不要把推荐性条文写成「违反强制性条文」。
- 取条文用该规范自己的术语（「阻水比」是洪评导则的词，拿去查别的规范是 0 命中）；
  查条号别带「表」字。完整纪律见 [norms](../domain-packs/flood-impact/references/norms.md)。
- 取不到条文就记 `unverified_basis`，只出疑点不出结论。

## 常见误判

- **只算一个频率**：至少覆盖设计洪水与校核（或更高）工况，并说明最不利工况的选择理由。
- **阻水比达标即结论安全**：阻水比是过程指标，壅高与冲刷才是影响结论。
- **基础埋深与冲刷深度不比较**：这是最实质的一条，缺了整份评价就落空。
- **把推荐公式当唯一解**：公式适用条件（河道类型、宽深比、有无导流建筑物）不满足时结果不可用。
- **结论超出计算范围**：没有算的工况不能写「均满足要求」。
- **工程量与投资不落地**：措施写得再好，没有工程量和投资概算，附录 B 的对应章节就缺。

## 输出与交接

写成 `discipline=flood_eval` 的 checks/findings，每条带章节/表号定位与依据（导则条文、批复要求）。

- 水文成果交 [水文与规模](../disciplines/hydrology.md) 复核，结构埋深交 [水闸泵站与输水](../disciplines/gate-pump.md) 或 [挡水与泄水建筑物](../disciplines/dam.md)。
- 与规划同意书论证（M12）不得互相替代：本报告评影响，M12 论证规划符合性，两类结论不能混写。

```bash
python <本Skill目录>/scripts/engine_run.py 洪评报告.docx --engine-root <引擎根目录> --out review/imported.json
```

导入后「覆盖」≠「符合」，须按 [口径对照](../status-mapping.md) 人工复核。
