# 施工组织、导流与概算辅助审查

概算的问题几乎都来自上游：工程量变了、施组变了，概算没跟上。

## 输入与边界

施工条件、导流标准与方式、围堰与基坑、料场与弃渣场、施工进度、主要工程量表、单价分析、费用构成（建筑工程/机电设备/金属结构/临时工程/独立费用/预备费）。

核对口径与守恒关系，不重编概算，不替代造价专业审核。

## 一、施工组织与导流

| 核对项 | 要点 | 典型问题 |
|---|---|---|
| 导流标准 | 与保护对象、工程等别、施工时段匹配 | 全年一个标准，不分时段 |
| 导流方式 | 明渠/隧洞/涵管/分期，与地形地质匹配 | 方式与枢纽布置冲突 |
| 围堰 | 断面、防渗、稳定、超高、拆除 | 有围堰无稳定计算 |
| 基坑排水 | 初期与经常排水量、设备配置 | 只写「配置水泵」 |
| 料场 | 储量、质量、运距与用量 | 储量小于需求 |
| 进度 | 关键线路、度汛节点、冬雨季措施 | 总工期与节点矛盾 |
| 北方河流 | 冰期施工、导冰排冰 | 完全不提冰情 |

## 二、工程量与概算

关键在**守恒**：图纸 → 工程量表 → 概算工程量 → 单价分析，四级数量应能对上。

| 核对项 | 要点 |
|---|---|
| 工程量来源 | 与图纸、断面、清单对应；注明计算式或软件 |
| 土石方平衡 | 挖方 = 回填 + 弃方 + 利用方，不得重复计列 |
| 混凝土与钢筋 | 分部位工程量与配筋量对应 |
| 单价 | 定额子目、人工材料机械消耗、取费 |
| 临时工程 | 导流、施工交通、营地、供电，是否与施组一致 |
| 独立费用 | 建设管理、勘测设计、监理、科研等计费基数 |
| 预备费 | 基本预备费率与阶段对应 |
| 投资对比 | 与可研/估算的差异说明 |

## 常见误判

- **只核总价不核数量**：总价看起来合理，单项数量错得很远。
- **土石方重复计列**：利用方既算挖运又算购买。
- **临时工程与施组脱节**：施组写隧洞导流，概算按明渠导流。
- **单价分析套错定额**：定额子目适用条件（部位、工艺）不符。
- **预备费率按旧阶段取**：初设套可研费率。

## 依据库能提供什么

施工导流与概算**没有**独立的已校准依据库。可用的只有两处间接材料：

- 各专业包的限值表里有工程量和构造尺寸的直接依据（如堤防/护岸的量、弃渣场防护量），
  但**取哪个定额、怎么组价不在包里**；
- `domain-packs/report-builder/references/calc-conventions.md` 里有计算书与成果表的书写约定，
  可用于核对「工程量表—概算表—正文数字」三者是否同一版。

不要借用洪评或水保的清单来审概算：它们的「工程量与投资」块只核对章节是否存在与投资栏是否填写，
不核对单价与定额组价。概算口径的实质核对须由院内定额库 + 本次批复文件支撑，记 `unverified_basis` 或
`insufficient_input`，不要凭经验判「偏高/偏低」。

## 输出与交接

写成 `discipline=cost` 的 checks/findings，带表号与数值：

- 数量类问题记录两侧数值与差异（如「图纸量 1.2 万 m³，概算量 1.8 万 m³」）。
- 导流标准与围堰问题与 [挡水与泄水建筑物](../disciplines/dam.md) 交叉时，主责归本条（施工期），运行期归坝工。
- 专项投资（水保、环保、移民）与 [水保水资源环评移民](../disciplines/special.md) 对账，避免重复或漏计。
