# 水土保持工程报告审查

## 这个 Skill 是什么

**审查编排层**，不是设计知识卡。回答：拿到一份水土保持方案报告，**按什么顺序查、查哪些点、
每条怎么判、依据谁、怎么输出**。条款号、限值一律从条文库 / 固化表核对，**不硬编码**。
库内**无水土保持设计领域技能可路由** → 判据全落在规范库 + 固化限值表 + 复算脚本上。

## 何时用 / 不适用

- **用**：有一份水土保持方案报告（报告书 / 报告表 / 变更方案），可从合规性、防治目标、措施体系出发现。
- **不用**：防洪评价 / 洪水影响评价、环境影响评价、纯设计问题、纯条文查询、非生产建设项目方案。

## 审查总流程

```
报告文本 (docx/pdf)
 ├─[0]   前置判定 ── 类型 / 项目 / 区划 / 等级 / 敏感区（+行业）
 ├─[0.5] 取判据 ── spec_lookup 调条文 + 限值表 + calc_*.py 复算
 ├─[1]   分块审查（12 块）── 查什么 → 判定标准 → 依据
 ├─[2]   跨专业一致性 ── 等级↔指标↔时段↔责任范围↔弃渣场链↔土石方↔投资
 └─[3]   结构化发现 ── 位置 / 问题 / 依据 / 严重度 / 建议
```

**每一步该翻哪一册，见该步末尾的 ▶ 载入。**

## 第 0 步：前置判定

**先定这五样，再翻正文。**

| 判定项 | 常见取值 | 对审查的影响 |
|---|---|---|
| **报告类型** | 报告书 / 报告表 / 变更方案 | 决定深度要求与章节完整性 |
| **项目类型** | 点型 / 线型；建设类 / 建设生产类 | 线型分段指标；建设生产类另设生产期指标 |
| **水土流失类型区** | 东北黑土区…青藏高原区（八区） | **六项指标值全随区划变化** |
| **防治标准等级** | 一级 / 二级 / 三级（4.0.1） | **等级定错则六项指标全错** |
| **敏感区** | 重点预防区 / 重点治理区 / 水源保护区… | 决定是否执行一级标准、提高工程级别 |

> 判不出这五样 → 报告基本资料有缺项，本身就是一条 ○ 级发现。
> ▶ **载入**：`references/industry-region.md`（177 号 附件 1~7：8 类型区 22 条 + 6 行业 40 条特别要求）。
> 定完区划 / 行业后**先查这里**，看有无"必须提高标准 / 必须补做"的特别条款。

## 第 0.5 步：取判据（别跳过）

**报告是 docx → 先用 `scripts/extract_docx_tables.py <报告> --keyword <词>` 把表格还原成网格**
（判据多藏在土石方平衡表 / 弃渣场特性表 / 工程量表里，顺序拼字会错行）。

三个来源，**不可混用**：

| 来源 | 怎么取 | 怎么写进意见 |
|---|---|---|
| **规范条文** | `python scripts/spec_lookup.py --spec "GB 51018" --q 关键词` | 引条款号（如"违反 GB 51018 12.2.2"） |
| **固化限值表** | `swc_tables.md`（八区指标 / 弃渣场 / SL 190）+ `swc_works_tables.md`（GB 51018 §5） | 引条款号 + 表号 |
| **强制性条文** | `compulsory-clauses.md`（11 条 + 配套） | 写"**违反强制性条文**"，最高严重级 |

> GB 50433 / GB/T 50434 **已入库**，可 `--spec` 直取条文（与固化表互校）。取不到条文的判定项 → 标"依据待核"，只出疑点不出结论。

**能算的不要只靠看** —— 凡报告给出数值结论，用复算脚本自己过一遍：

| 脚本 | 覆盖 |
|---|---|
| `calc_swc_targets.py` | **六项防治指标达标**（GB/T 50434 表 4.0.2-1~8；含 4.0.6~4.0.10 调整提示） |
| `calc_dregs.py` | **弃渣场级别 + 拦挡级别 + 防洪标准 + 抗滑/抗倾覆**（GB 51018 表 5.7.1~5.7.5） |
| `calc_soil_loss.py` | **土壤流失量预测复核**（W=ΣF·M·T；施工期 + 自然恢复期；容许流失量判级） |
| `calc_drainage.py` | **排洪 / 截排水水力复核**（曼宁均匀流反求水深；过流能力 / 超高 / 流速） |

> ▶ **载入**：`references/norms.md` §一（取条文方法、数据源、脚本用法与限制）。

## 第 2 步：跨专业一致性（最容易被漏的一层）

单块各自正确 ≠ 报告正确。共 **8 对交叉校验**（等级↔指标↔时段、责任范围↔占地↔分区、
弃渣场级别↔拦挡↔防洪↔抗滑、选址↔强条↔勘察、土石方↔表土↔取弃场、预测↔措施↔指标、
界定↔投资↔措施、内部数值一致）。> ▶ **载入**：`references/checklist.md` §第 2 步。自洽性优先用复算脚本验算，不靠眼看。

## 引用纪律（硬规则）

**下判断前先读** `references/norms.md` §五（引用纪律 7 条）+ §六（易踩的坑）——唯一权威定义，本入口不重复。

## 边界

- 无水土保持设计领域技能可路由——只给**条文级判据 + 固化限值表 + 复算**（详见 `limits.md`）。
- 防洪评价 / 洪水影响评价、环评不在范围；产出为**审查发现**非审批结论，责任在人。

> ▶ **载入**：`references/limits.md`（边界与已知局限）。
