# 水土保持报告审查 — 完整检查项清单

配套 `SKILL.md` 第 1 步"分块审查"使用。按 12 块展开，每条含 **判定标准** 与 **失败模式**。

> **引用约定见 `norms.md`**（条款号取法、限值出处、强条处置、版本声明）。本文件不再重复。
> 骨架来源：**办水保〔2023〕177 号《生产建设项目水土保持方案审查要点》**（35 条重点 + 分区/分行业特别要求）。
> 标 **★强条** 者为 `compulsory-clauses.md` 所列强制性条文。
> **分区 / 分行业特别要求** → 见 `industry-region.md`（177 号 附件 1~7：8 类型区 + 6 行业）：
> 前置判定定完区划 / 行业后**先查它**，再进各块（它是对 12 块的补充，不重复）。

## 块 1　编制依据、设计水平年与方案深度

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 编制依据现行性 | 列出的法律法规、技术标准应为**现行有效版本**（GB 50433-2018、GB/T 50434-2018、GB 51018-2014、SL 575-2012 等） | 引用已废止规范（如 GB 50433-2008、GB 50434-2008、SL 204-98） |
| 方案阶段 | 报告书/报告表与项目阶段匹配；可研/初设水深与附录 B/C 要求一致 | 阶段错配、深度不足 |
| **设计水平年** | 一般为主体工程**完工当年或后一年**（4.1.3） | 设计水平年定错 → 六项指标时段全错 |
| 项目组成一致性 | 项目组成及建设内容应与**立项文件或主体设计文件一致**（177 号-1） | 与批复/主体设计不符 |
| 依托/改扩建衔接 | 有依托工程应明确依托工程立项、建设内容、水保开展情况；改扩建分期应明确各阶段衔接（177 号-3） | 漏交代依托/分期衔接 |

## 块 2　项目组成与项目区概况

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 总体与竖向布置 | 明确总布置与各组成平面布置；竖向布置明确原地面标高、设计标高及防洪排水、边坡防护（177 号-2） | 竖向交代不清 |
| **工程占地** | 占地**性质、类型、面积**列全，并按**县级行政区**统计（177 号-4；GB 50433 4.2.1-4） | 只给总面积、不分类不分区 |
| **土石方平衡** | 明确**挖方/填方/借方/弃方/调配**；**表土应单独平衡**；借方来源、弃方去向明确（177 号-5；GB 50433 4.2.1-5） | 表土未单列；借方/弃方去向不明 |
| 拆迁安置与专项设施 | 明确拆迁（移民）规模、安置方式、专项设施改（迁）建方式及水保责任（177 号-6） | 漏水保责任界定 |
| 自然概况 | 地形地貌、地质、气象、水文、土壤、植被、水土流失现状、**水土保持敏感区**（GB 50433 4.2.5；4.2.6） | 气象水文系列 <30 年；缺敏感区 |
| 施工组织 | 施工生产生活区、施工道路、施工用水电、场地平整/基础开挖/路基修筑等土石方工艺（GB 50433 4.2.1-3） | 施工布置缺、扰动范围不清 |

## 块 3　水土保持评价（含措施界定）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **选址（线）避让** | 依法严格避让**水土流失重点预防区/重点治理区**；确实无法避让的应论证，执行**一级标准**、拦挡与截排水**提高一级**、林草覆盖率**提高 1~2 个百分点**（177 号-8；GB 50433 3.2.1/3.2.7） | 未避让又无论证 |
| 禁止性区域 | 禁止在水土流失严重、生态脆弱区开展可能造成水土流失的生产建设活动；确需建设的须依法审批（177 号-7） | 违规占用且无审批 |
| 建设方案与布局 | 符合绿色设计要求；主体应减少征占地与土石方；临时占地避免占耕地/林地/草地；从水保角度比选论证（177 号-9） | 无比选、临时占地林草地 |
| 工程占地评价 | 符合节约用地、减少扰动；临时占地满足施工要求（GB 50433 4.3.5） | 占地冗余、扰动超范围 |
| 土石方平衡评价 | 挖填数量最优化、调运节点适宜时序可行运距合理、余方优先综合利用（177 号-10；GB 50433 4.3.6） | 同时存在弃方和借方未论证 |
| **弃渣综合利用** | 开展弃渣综合利用调查，制定综合利用方案，明确途径与方向；需设堆存场地的应布防护（177 号-11） | 未做综合利用论证 |
| **表土剥离利用** | 开展**表土资源调查**（土壤类型及分布、表层土厚度、可剥离范围及面积、利用途径）；表土不足应明来源或土壤改良方案（177 号-12） | 表土资源调查缺、剥离量无依据 |
| **取土（石、砂）场** | 位置明确；**禁止在崩塌滑坡危险区、泥石流易发区**设置（★强条 3.2.3）；涉河湖管理范围须合规；要素信息全面准确（177 号-13） | 落入禁区、要素缺失 |
| **弃渣场选址** | 经管理部门及权属单位确认、落实用地可行性；**禁止在河湖管理范围（含水库淹没区）内**设置；**禁止在对公共设施/基础设施/工业企业/居民点有重大影响区域**设置（★强条 3.2.5、GB 51018 12.2.2）；**4 级及以上弃渣场应勘察**（177 号-14） | 落禁区、未勘察、用地未确认 |
| 施工方法与工艺评价 | 符合减少水土流失要求（GB 50433 4.3.9） | 工艺加剧流失 |
| **措施界定** | 按 GB 50433 **附录 D** 界定主体工程设计中水土保持措施（表土剥离保护、土地整治、植被建设、防风固沙、弃渣场挡渣墙/拦渣坝/拦渣堤、集蓄水池、透水硬化等） | 该界定未界定 / 重复计列 / 措施漏项 |

## 块 4　防治责任范围与防治目标

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **防治责任范围** | = 永久征地 + 临时占地（含租赁）+ 其他使用与管辖区域（GB 50433 4.4.1）；据项目组成、建设内容、施工组织确定（177 号-15） | **误把"直接影响区"划入**（2018 版已取消）；范围不完 |
| **防治标准等级** | 按 4.0.1 依水土保持敏感程度 + 水土流失影响程度定一级/二级/三级（177 号-16） | 等级定低 → 六项指标全错 |
| **六项指标值** | 按**区划 + 等级 + 时段**取 GB/T 50434-2018 表 4.0.2-1~8；涉及调整的应合理论证（177 号-16；4.0.6~4.0.10） | 取值不查表、调整无依据 |
| 指标口径 | 施工期只对渣土防护率/表土保护率有要求；风沙区表土保护率不作要求 | 给施工期硬套设计水平年指标 |
| 复算 | 用 `calc_swc_targets.py` 逐项核达标 | 报告称达标而实际不达 |

> **复算工具**：`python scripts/calc_swc_targets.py --region <八区> --level <1|2|3> --period design
> --governed … --ratio … --dregs … --topsoil … --veg-restore … --veg-cover …`

## 块 5　水土流失分析与预测

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 预测范围 | = 水土流失防治责任范围（GB 50433 4.5.2） | 范围小于责任范围 |
| **预测单元/时段** | 单元按地形地貌、扰动方式、扰动后地表物质组成等划分；时段分**施工期 + 自然恢复期**（4.5.4/4.5.6） | 漏自然恢复期、单元划分过粗 |
| **土壤流失量预测** | **W = Σ Fᵢ·Mᵢ·Tᵢ**（4.5.3）；扰动后侵蚀模数用数学模型/试验观测/类比确定；**新增** = 扰动后 − 原地貌；恢复至原地貌以下时不再计 | 只给总量不给方法、参数无依据 |
| 自然恢复期长度 | 湿润区 2 年、半湿润区 3 年、干旱半干旱区 5 年（4.5.6） | 恢复期取错 |
| **危害分析** | 分析对当地、周边、下游及工程本身可能造成的危害形式、程度、范围，以及滑坡/泥石流风险（4.5.8；177 号-17） | 只报土壤流失量、不做危害分析 |

> **复算工具**：`python scripts/calc_soil_loss.py --region <湿润|半湿润|干旱半干旱>
> --unit "名称:面积hm²:原地貌M:扰动后M:时段a[:阶段]"`
> （按 4.5.3 复算 W=ΣF·M·T，新增量 = 扰动后 − 原地貌；`--allowable` 给容许流失量出控制比，`--grade` 按 SL 190 判侵蚀强度级）。

## 块 6　水土保持措施总体布局与分区措施

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **防治区划分** | 按地貌类型、水土流失类型及强度、工程布局、施工组织划分（177 号-18；4.4.2） | 分区不当/层次混乱 |
| **措施总体布局** | 覆盖防治责任范围与施工全过程，与主体施工时序匹配、与周边环境协调（177 号-19；4.6.3） | 措施不覆盖全过程 |
| **工程措施** | 明确工程级别与设计标准；**截排水工程水文及水力计算准确**、排水顺接；土地整治满足复耕/植被恢复（177 号-20） | 无级别标准、无水力计算 |
| **植物措施** | 明确级别与设计标准；据立地条件配置；优先**乡土树（草）种**；与植被恢复与建设工程级别匹配（177 号-21；5.8） | 选外来种、级别不匹配 |
| **临时措施** | 明确布设位置、面积、实施时段；超过一个生长季的项目应增加植物防护（177 号-22） | 临时措施缺失/时段不清 |
| **边坡防护** | 保证安全前提下采用**生态防护型式**、与周边协调；制定**防止边坡溜渣**措施（177 号-24；SL 575 4.1.1-4） | 只做硬护坡不做生态 |
| 降水蓄渗 | 干旱缺水/城市地区布设蓄水池、渗井、透水铺装、下凹式绿地（5.6/4.6.9） | 漏蓄渗措施 |
| 防风固沙 | 风沙区/戈壁风蚀区设沙障、植物固沙、砾石压盖（5.10/4.6.13） | 漏固沙措施 |
| 施工要求 | 明确施工方法、时序；弃渣场"**先拦后弃**"；临时堆土"拦挡、苫盖、排水、沉沙"（4.6.15/3.2.8） | 违反先拦后弃 |

## 块 7　弃渣场与取土场专项　（★本技能最高频判定块）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **弃渣场级别** | 按堆渣量 V、最大堆渣高度 H、失事危害程度查 GB 51018 **表 5.7.1**；三者不一致**就高不就低**（5.7.1） | 级别定低 → 后续标准全低 |
| **拦挡工程级别** | 查 **表 5.7.2**（拦渣堤/拦渣坝/挡渣墙/排洪）；拦渣高度 ≥15m 且渣场 1、2 级时挡渣墙可提高 1 级 | 级别与渣场不匹配 |
| **防洪标准** | 查 **表 5.7.3**（山区丘陵/平原滨海；设计+校核）；拦渣堤/坝**不设校核**；失事重大危害时可提高 1 级；临时拦挡 3~5 年一遇（5.7.3） | 校核标准乱套、临时拦挡无标准 |
| **抗滑稳定** | 查 **表 5.7.4-1**（毕肖普）/ **-2**（瑞典）；非常运用工况含 **≥Ⅶ度地震**（★强条 SL 575 10.5.2） | 只算一种工况、漏地震工况 |
| 排洪与截排水 | 傍山设截水天沟；上游洪水集中设排洪沟/涵洞；进出水口设导流翼墙、消能防冲；暗沟每 50~100m 设检查井、净空 ≥15%（12.4） | 无排洪设计、无消能 |
| 选址禁区 | 见块 3（★强条 3.2.5 / GB 51018 12.2.2 / SL 575 4.1.5） | 落禁区 |
| 稳定性结论 | 稳定性结论应明确可靠（177 号-23） | 只给结论无计算 |

> **复算工具**：`python scripts/calc_dregs.py --volume <万m³> --height <m> --region 山区丘陵|平原滨海
> [--hazard 严重|较严重|不严重|较轻|无危害] [--method bishop|swedish] [--case normal|abnormal] [--calc-k <值>]`
> **复算工具（水力）**：`python scripts/calc_drainage.py --shape trap --b <底宽> --m <边坡> --n <糙率> --i <坡降>
> --q <设计流量>`（曼宁均匀流反求水深，核过流能力 / 流速 / 超高；允许流速与超高按 GB 51018 §5.6）。

## 块 8　表土保护与土石方平衡

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **表土剥离** | 施工前剥离；扰动深度 <20cm 的表土可不剥离，宜采取**铺垫保护**（4.6.5）；剥离量无依据即问题 | 该剥离未剥离、剥离量拍脑袋 |
| 表土存放与防护 | 剥离表土集中存放、采取临时拦挡/苫盖/排水防护；施工结束回覆绿化或复耕（4.6.5；5.2） | 表土散堆无防护 |
| 表土利用方向 | 明确利用方向（复耕/植被恢复/其他区域）；工程余方优先综合利用（4.6.5） | 表土去向不明 |
| 高寒草甸 | 应对**表层草甸剥离**，采取专门养护措施（5.2.2-4） | 高寒区草甸未剥离 |
| **土石方平衡表** | 分区（及县级）统计并复核挖填借弃；**表土单独平衡**；绘制流向框图（4.2.1/4.2.4） | 土石方不平、表土未单列 |

## 块 9　水土保持监测

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **监测范围与时段** | 范围 = 防治责任范围；时段从**施工准备期开始至设计水平年结束**，施工准备期前做**本底值监测**（4.7.2/4.7.3） | 时段起止错、漏本底值 |
| **内容与方法** | 扰动土地、取土/弃渣、水土流失、措施实施及效果；调查监测 + 定位观测；大面积/长距离增遥感（4.7.4/4.7.5） | 内容不全、方法单一 |
| **频次** | 取土/弃渣、扰动面积等**至少每月 1 次**；施工进度、植物生长等**至少每季度 1 次**；灾害事件后 **1 周内**（4.7.6） | 频次不足 |
| **点位布设** | 每个监测区至少 1 个点；>100km 监测区每 100km 宜加 2 个点；代表性、方便性、少干扰（4.7.7） | 点位不足、代表性差 |
| **弃渣场视频监控** | **3 级及以上弃渣场应采取视频监控**（177 号-26） | 高等级弃渣场无监控 |
| 实施条件与成果 | 明确人员、设施、设备；成果含监测报告、数据、图件、影像（4.7.8/4.7.9） | 无设备/成果要求 |

## 块 10　投资概（估）算与效益分析

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 编制原则与依据 | 价格水平年、人工单价、主要材料价格、机械台时费、定额与取费**应与主体工程/同阶段设计一致**（4.7.1；177 号-27） | 依据与本工程不符 |
| 费用构成 | 工程措施 + 植物措施 + 临时措施 + 独立费用（含监测费、监理费）+ 水土保持补偿费（4.7.1） | 漏列独立费用/补偿费 |
| **单价分析** | 措施单价分析应齐全准确，投资应满足防治工作需要（177 号-28） | 单价缺失/明显偏低 |
| **效益分析** | 生态效益为主，量化**六项指标达标情况** + 可减少水土流失量、渣土挡护量、表土剥离保护量（4.7.2；177 号-29） | 只定性、不列指标达标 |
| 概算一致性 | 水保投资概算与同阶段设计文件水保内容一致（177 号附件3-8） | 两处投资对不上 |

## 块 12　附件、附图与方案变更

|---|---|---|

## 第 2 步　跨专业一致性校验（8 对）

**单块各自正确 ≠ 报告正确。** 逐对交叉校验，最容易被漏的一层。

| # | 交叉对 | 校验要点 / 典型错 |
|---|---|---|
| 1 | **防治标准等级 ↔ 六项指标值 ↔ 时段** | 等级是全部指标限值的基准；等级定错或时段用错（施工期套设计水平年值）→ 全篇目标判据连锁错 |
| 2 | **防治责任范围 ↔ 工程占地 ↔ 防治分区** | 责任范围 = 永久征地 + 临时占地 + 其他使用与管辖区域；**不应含已取消的"直接影响区"**；分区应落在责任范围内 |
| 3 | **弃渣场级别 ↔ 拦挡级别 ↔ 防洪标准 ↔ 抗滑允许值** | 渣场级别一错，拦挡级别/防洪标准/抗滑允许值全错（表 5.7.1→5.7.2→5.7.3/5.7.4 是链式取值） |
| 4 | **弃渣场选址 ↔ 强条禁区 ↔ 勘察结论** | 弃渣场不得落于行洪/重要设施重大影响区、河湖管理范围、崩塌滑坡泥石流易发区；4 级及以上须勘察支撑 |
| 5 | **土石方平衡 ↔ 表土平衡 ↔ 取土场/弃渣场规模** | 弃方量应与弃渣场容量对应；借方量与取土场规模对应；表土应单独平衡，不得混入一般土石方 |
| 6 | **土壤流失量预测 ↔ 措施规模 ↔ 六项指标达标** | 预测的流失量应能被措施体系有效控制；措施量应支撑六项指标（尤其渣土防护率、林草覆盖率）达标 |
| 7 | **措施界定（附录D）↔ 投资概算 ↔ 措施体系** | 界定为水保的措施才进投资；同一条措施不得既算主体又算水保（重复计列） |
| 8 | **报告内部同一参数前后一致** | 正文 / 表格 / 图 / 计算书 中的同一数值是否一致（防治责任范围面积、弃渣量、指标值、投资额） |

> 自洽性优先用复算脚本验算，不靠眼看。凡报告给出数值结论（六项指标、弃渣场级别、防洪标准、抗滑安全系数），
> 用 `calc_swc_targets.py` / `calc_dregs.py` 把关键中间量自己过一遍再判。
