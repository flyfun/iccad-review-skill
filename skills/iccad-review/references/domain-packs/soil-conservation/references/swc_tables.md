| 条 | 内容 |
|---|---|
| **4.0.1** | 等级判定：① 位于重点预防区/重点治理区、饮用水水源保护区、水功能一级区保护区与保留区、自然保护区、世界文化和自然遗产地、风景名胜区、地质公园、森林公园、重要湿地**且不能避让**，或位于**县级及以上城市区域** → **一级标准**；② 位于湖泊和已建成水库周边、四级以上河道两岸 3km 汇流范围内，或周边 500m 内有乡镇/居民点，且不在一级标准区域的 → **二级标准**；③ 其余 → **三级标准**。 |
| 4.0.3 | 生产期新增扰动范围指标 ≥ 施工期值；其他区域 ≥ 设计水平年值。 |
| 4.0.4 | 涉及两个以上等级区域时，**分区段**确定指标值。 |
| 4.0.5 | 矿山开采露天采区面积、水工程水域面积可在防治责任范围面积中**扣除**；恢复耕地面积在算林草覆盖率时可扣除。 |
| **4.0.6** | 极干旱地区：植被恢复率、覆盖率可不作定量要求，治理度可降 **5%~8%**；干旱地区：治理度/恢复率/覆盖率可降 **3%~5%**。（干旱程度按 GB/T 17297 多年平均年干燥度：≥16 极干旱，≥3.5 且 <16 干旱） |
| **4.0.7** | 轻度侵蚀为主区域，土壤流失控制比**不应小于 1.0**；中度以上侵蚀为主可降低 **0.1~0.2**。 |
| **4.0.8** | 中山区项目渣土防护率可减 **1%~3%**；极高/高山区可减 **3%~5%**。 |
| **4.0.9** | 城市区项目渣土防护率、林草覆盖率可提高 **1%~2%**。 |
| 4.0.10 | 对林草植被有限制的项目，林草覆盖率可按相关规定适当调整。 |

## 四、GB 50433-2018 核心条文（库外，原文摘录）

### 4.1 水土流失防治基本目标（3.1.2）

> 1 项目建设范围内的新增水土流失应得到有效控制，原有水土流失得到治理；
> 2 水土保持设施应安全有效；
> 3 水土资源、林草植被应得到最大限度的保护与恢复。

六项防治指标（水土流失治理度、土壤流失控制比、渣土防护率、表土保护率、林草植被恢复率、林草覆盖率）
应符合 GB/T 50434 的规定（3.1.3）。**"原有水土流失得到治理"指**：部分项目征占地范围大于扰动范围，
未扰动地表的水土流失也应治理，使其土壤流失强度达到**土壤容许流失量以下**。

### 3.2 项目约束性规定（节选）

- **3.2.1 主体工程选址（线）应避让**：水土流失重点预防区和重点治理区；河流两岸、湖泊和水库周边的植物保护带；
  全国水土保持监测网络中的监测站点、重点试验区及国家确定的水土保持长期定位观测站。
- **3.2.3（★强条）** 严禁在崩塌和滑坡危险区、泥石流易发区内设置取土（石、砂）场。
- **3.2.4** 取土（石、砂）场：不得设置在河道、湖泊和建成水库管理范围内；山丘区宜选荒沟、凹地、支毛沟，平原区宜选凹地、荒地；风沙区宜避开风口。
- **3.2.5（★强条）** 严禁在对公共设施、基础设施、工业企业、居民点等有重大影响的区域设置弃土（石、渣、灰、矸石、尾矿）场。
- **3.2.6** 弃渣场：应结合结束后的土地利用；充分利用取土场/废弃采坑/沉陷区；**先拦后弃**（施工组织 3.2.8）。
- **3.2.2** 建设方案：公路、铁路高填深挖路段应加大桥隧比（填高 >20m、挖深 >30m 应做桥隧替代方案论证）；
  管道穿越宜用隧道/定向钻/顶管；山丘区输电塔基用不等高基础、经林区加高杆塔跨越。
- **无法避让重点预防区/重点治理区时**：执行**一级标准**；截排水与拦挡工程级别、防洪标准**提高一级**；
  林草覆盖率**提高 1~2 个百分点**（3.2.7）。

### 4.4 防治责任范围（4.4.1）

> 应包括项目**永久征地、临时占地（含租赁土地）以及其他使用与管辖区域**。
> （"直接影响区"在 2018 版**已取消**，不再划入责任范围。）

### 4.5 水土流失预测（4.5.3 公式）

> 土壤流失量预测：**W = Σ Fᵢ · Mᵢ · Tᵢ**
> 式中：W——土壤流失量(t)；Fᵢ——第 i 单元的预测面积(km²)；Mᵢ——第 i 单元扰动后土壤侵蚀模数〔t/(km²·a)〕；
> Tᵢ——第 i 单元的预测时段长(a)。**预测时段分施工期（含施工准备期）和自然恢复期**；
> 当土壤侵蚀强度恢复到原地貌水平以下时不再计算。各单元**新增**土壤流失量 = 扰动后 − 原地貌。

### 4.7 水土保持监测（4.7.3 / 4.7.6）

- **时段**：从**施工准备期开始，至设计水平年结束**；各类项目均应在施工准备期前进行**本底值监测**。
- **频次**：取土（石、砂）/弃土（石、渣）情况、水土流失情况、措施实施情况及效果、扰动地表面积等
  **至少每月 1 次**；施工进度、措施实施、植物生长情况**至少每季度 1 次**；水土流失灾害事件发生后 **1 周内**完成监测。
- **方法**：调查监测 + 定位观测相结合；大面积、长距离项目尚应增加**遥感监测**。
- **点位**：每个监测区至少 1 个监测点，长度超 100km 的监测区每 100km 宜增加 2 个点。
- （水保方案另按**办水保〔2023〕177 号**：**3 级及以上弃渣场应采取视频监控**。）

### 附录 D　主体工程设计中水土保持措施界定（择要）

| 界定为水土保持的措施 | 不界定为水土保持的措施 |
|---|---|
| 表土剥离和保护；土地整治；植被建设；防风固沙；植物护坡 | 主体工程稳定边坡上以稳定功能为主的工程护坡（锚杆护坡、抗滑桩、抗滑墙、挂网喷混等） |
| 弃渣场/取土场挡渣墙、拦渣坝、拦渣堤 | 江河湖海的防洪堤、防浪堤（墙）、抛石护脚 |
| 集蓄降水的蓄水池；透水形式场地硬化 | 路面排水、工业场地雨水排水管（以主体功能为主者） |

> 界定原则：假定没有该工程，主体功能仍能发挥但会产生较大水土流失 → 界定为水保措施；反之不界定。
