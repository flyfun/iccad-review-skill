# 技能边界与已知局限

> **本文件是"边界 / 局限"的唯一权威源**。入口 `SKILL.md` 只给指针，不再重复正文。

---

## 一、数据覆盖边界

- **自带条文库覆盖 8 部规范（6 部水保规范 + 强条汇编 + 2 部核心国标），共 4,013 块**（其中 2,830 块带条号）。清单见 `norms.md` 第二节，`--list-specs` 可复现。
- ✅ **两部核心标准已入库**：**GB 50433-2018**（198 块）、**GB/T 50434-2018**（31 块，含八区指标值表全表）
  已从库外原件解析并收入本库，`spec_lookup.py` 可直接取条文（与 `swc_tables.md` 固化副本互为校验）。
  > 这是相较早期版本的关键升级——此前两部标准"块库未收录"，只能查固化表。
  > ⚠ 因来自 PDF/docx 解析，正文偶有 OCR 噪声（如"取土(石、砂〉场"），**引条号 / 限值前先与固化表互校**。
- **仍未入库、只能标"须查原件 / 现行版"的**：
  - **GB/T 22490-2025** 验收技术规程（本机仅低质 txt，小数点位丢失，如 5.1.3→"513"，**不可用**）；
  - **SL 289-2003** 治沟骨干工程、**SL 302-2004** 水坠坝（强条已录 `compulsory-clauses.md`，正文未入库）；
  - **SL 718-2015** 水土保持工程概（估）算编制规定。
  - 要查这些需本机存在 hydro_reviewer 源码树，用 `--pkl` 读块库（全库 62 部）；**多数块库也没有**。
- **管理性文件不是标准**：水利部令第 53 号、水保〔2019〕160 号、办水保〔2023〕177 号等**未入库**，
  其要求已择要固化进 `checklist.md` / `error-patterns.md` / **`industry-region.md`**；
  引用时写文件名 + 条号（如"办水保〔2023〕177 号 附件 3 第 x 条"），不写"某标准"。

## 二、输入 / 解析边界

- **docx 表格可自助提取**：`scripts/extract_docx_tables.py`（**网格重建**，正确处理横向 gridSpan / 纵向 vMerge 合并单元格）
  ——把土石方平衡表 / 弃渣场特性表 / 工程量表 / 排水沟断面表还原成可核对的二维表；正文段落用 `--text-only`。
  **PDF / 扫描件不在本技能内**，须另用 OCR / PDF 工具。
- **报告没写的，判不了**：缺防治责任范围、缺土石方平衡、缺弃渣场参数 → 只能出"深度不足"的发现，判不了对错。
- **附图/影像无法自动审**：地理位置图、一场一图、监测点布置图须**人工看图**核对。

## 三、公式与表格来源边界

- **限值 / 指标值实测自原始文件**（GB/T 50434 表 4.0.2-1~8、GB 51018 表 5.7.1~5.7.5 与 §5.1~5.11、SL 190 表 4.1.1）
  ——可靠，与本技能复算脚本内联值一致。
- **部分原文公式为嵌入图片**（GB 50433、GB 51018、SL 190 均如此），条文库只存符号说明文字。
  已固化为文字的：水土流失量预测 `W=Σ F·M·T`（GB 50433 4.5.3）。其余取公式须回原文。
- **SL 190 侵蚀强度分级**（表 4.1.2-1 水力侵蚀、4.1.2-2 面蚀、4.1.2-3 沟蚀、4.1.3 重力侵蚀、4.2.2 风力侵蚀）
  已固化进 `swc_tables.md` §三；**微度 / 轻度阈值随侵蚀类型区变化**，用前须对区。

## 四、版本边界

- 库内版本：**GB 51018-2014、SL 575-2012、SL 190-2007、SL/T 277-2024、SL/T 879**，
  以及**已入库的 GB 50433-2018、GB/T 50434-2018**。
- 有新版时以**现行版**为准；引用时**必须声明版本**（见 `norms.md` §五.5）。
- 标准更名/换号须辨明：GB 50433 2008 版名《开发建设项目水土保持技术规范》，2018 版更名《生产建设项目水土保持技术标准》。
  汇编 6-2-1 行仍写旧名 + 新号，**以 2018 版为准**。

## 五、复算脚本的能力边界（4 个）

1. `calc_swc_targets.py` 只做**指标值 vs 限值**的机械比对 + 调整情形提示；
   **指标实测值、区划、等级仍须人工从报告摘取**——报告没写就还是"判不了"。
2. 调整情形（4.0.6~4.0.10）为**规则提示**，脚本不自动改限值（避免改错）；
   是否适用、取上/下限，须专业判断并在意见中写明。
3. `calc_dregs.py` 按 GB 51018 表 5.7.1~5.7.5 机械定级与查标准；
   **弃渣场级别"就高不就低"的最终取舍、抗滑计算方法选用（毕肖普/瑞典）是否合理，仍须专业判断**。
4. `calc_soil_loss.py` 按 GB 50433 4.5.3/4.5.6 复算 `W=ΣF·M·T`（施工期 + 自然恢复期，恢复年数默认湿润 2 / 半湿润 3 / 干旱半干旱 5）；
   **侵蚀模数 M、预测单元划分、时段取值仍须人工从报告摘取**；容许流失量判级按 SL 190 表 4.1.1。
5. `calc_drainage.py` 按**曼宁均匀流**复算排洪 / 截排水（矩形 / 梯形断面，反求水深或正算过流）；
   粗糙系数 n 用参考值（脚本内 `N_REF`，**非规范强制**），实际取值须依报告 / 专业判断；
   允许流速与超高按 GB 51018 §5.6 表。
6. 脚本不代算：拦渣坝断面结构、挡渣墙结构配筋、边坡稳定——这些需专业软件 / 人工计算。

## 六、判定责任边界

- 本技能产出的是**审查发现**，不是审批结论；最终判定责任在人，**AI 结论须经复核**。
- 水保方案审查涉**行政审批**（水利部令第 53 号），本技能只提供技术审查辅助，**不替代行政审查程序**。
