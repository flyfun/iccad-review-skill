# 分区 / 分行业特别要求（办水保〔2023〕177 号 附件 1~7）

> **来源**：水利部办公厅《生产建设项目水土保持方案审查要点》（**办水保〔2023〕177 号**，2023-07-04）**附件 1~7**，
> 原文实测自本机 `specs_db/specs/00-17 …（办水保[2023]177号）.txt`。**非记忆**。
>
> **怎么用**（这是本册唯一的用法）：
> 1. 在第 0 步"前置判定"里先定两样——**项目所在水土流失类型区**（可能跨区）与**项目所属行业**；
> 2. 再翻本册对应段落，**逐条**核报告是否落实；
> 3. 每条都挂在通用 12 块之外，**只加分不减分**——通用要求先满足，特别要求再叠加。
>
> 类型区（附件 1）：东北黑土区 / 北方风沙区 / 西北黄土高原区 / 南方红壤区 / 西南岩溶区 / 青藏高原区 / 平原地区 / 城市区域。
> 行业（附件 2~7）：铁路公路 / 水利水电 / 管道 / 核电 / 煤炭 / 输变电。

## 一、不同水土流失类型区特别要求（附件 1，22 条）

### 东北黑土区

| # | 要求 | 核什么 |
|---|---|---|
| 1 | 合理利用和保护黑土资源；依法占用黑土地的，**表土应能剥尽剥**，按规定标准剥离，就近用于新开垦耕地、劣质耕地改良、被污染耕地治理、高标准农田建设、土地复垦 | 表土剥离是否"能剥尽剥"；利用去向是否逐项对应 |
| 2 | 丘陵漫岗区宜布设**坡面径流排导工程**，做好排导工程两端防护及与自然沟道顺接 | 有无排导；顺接是否交代 |
| 3 | 防护措施应**考虑冻害影响** | 措施设计是否含防冻（尤其砌体、混凝土） |

### 北方风沙区

| # | 要求 | 核什么 |
|---|---|---|
| 4 | 保护**地表结皮层、沙壳、砾幕**；裸露地表和堆土区应及时防护、减少裸露时间，采取**苫盖和洒水降尘**等临时措施 | 结皮层保护措施；临时防护时长 |
| 5 | 干旱缺水地区**植物措施应配套灌溉设施** | 有无灌溉配套 |

### 西北黄土高原区

| # | 要求 | 核什么 |
|---|---|---|
| 6 | **禁止违法占用淤地坝** | 是否占压淤地坝；占用有无审批 |
| 7 | 开挖或填筑边坡应采取**削坡开级、挡土墙、工程护坡**等措施，保持安全坡度，并布设截（排）水、排水顺接、消能 | 边坡措施型式与坡比；截排水顺接与消能 |
| 8 | 沟坡施工道路应设**排水沟、消力池**，并顺接至自然沟道 | 施工道路排水设施 |

### 南方红壤区

| # | 要求 | 核什么 |
|---|---|---|
| 9 | 坡面应根据**汇水情况**布设径流排导工程 | 是否按汇水计算布设 |

### 西南岩溶区

| # | 要求 | 核什么 |
|---|---|---|
| 10 | 应避免**破坏、堵塞地下暗河和溶洞等地下水系** | 有无岩溶水系保护措施；弃渣/取土是否影响暗河 |

### 青藏高原区

| # | 要求 | 核什么 |
|---|---|---|
| 11 | 应布设**围挡措施**，严格控制施工范围，保护原有地表植被 | 围挡与施工范围界定 |
| 12 | **高原草甸区应严格实施草皮的剥离、保护和利用** | 草甸剥离量、养护与回铺（呼应块 8 高寒草甸） |
| 13 | 植物措施应**优先使用乡土树种草种**，合理配置乔灌草 | 树种草种是否乡土 |
| 14 | 防护措施应**考虑冻害影响** | 同黑土区 |

### 平原地区

| # | 要求 | 核什么 |
|---|---|---|
| 15 | 应采取**沉沙措施**，防止河网、水系、渠道淤积 | 沉沙池/沉沙设施 |
| 16 | 取土场宜以**宽浅式**为主，注重取土后的**恢复利用** | 取土场型式与后期利用 |
| 17 | 应优化场地、路面设计标高，或采取其他措施，**减少外借土石方量** | 竖向优化论证（呼应块 2 竖向布置） |

### 城市区域

| # | 要求 | 核什么 |
|---|---|---|
| 18 | 应采用**下凹式绿地和透水材料铺装**等措施，增加降水入渗 | 蓄渗措施（呼应块 6 降水蓄渗） |
| 19 | 应**综合利用地表径流**，设置蓄水池等雨洪利用和调蓄设施 | 雨洪利用 |
| 20 | 按当地弃渣收集、清运、集中堆放管理规定做好**弃渣处置** | 弃渣处置合规性 |
| 21 | 裸露面应及时**洒水、苫盖**；运输渣土车辆**车厢全密闭遮盖**、车轮冲洗，防止扬尘和泥沙进入市政管网 | 扬尘与泥浆防控 |
| 22 | 应**提高林草植被建设标准**，注重景观效果，配套灌溉、排水和雨水利用设施 | 植被标准与景观 |

## 二、分行业特别要求（附件 2~7）

### 2.1　铁路、公路建设项目（附件 2，7 条）

| # | 要求 | 核什么 |
|---|---|---|
| 1 | 平面与竖向布置介绍应含**路线走向及平纵断面缩图、路基标准断面图、高填深挖路段典型断面图** | 图件齐备性 |
| 2 | **特殊路基处理**应明确分布位置、处理方案及工程量 | 特殊路基是否交代 |
| 3 | **表土堆放场、临时堆土场、隧道施工平台**等设置情况明确 | 临时场地 |
| 4 | 高填深挖路段应开展**桥隧替代方案论证**，结论支撑推荐方案 | 比选论证（呼应 GB 50433 3.2.2 填高>20m/挖深>30m） |
| 5 | 制（存）梁场、预制场、拌和站等**优先利用既有场地**；施工便道**永临结合**；铁路铺轨基地应做既有与相邻基地综合利用比选 | 永临结合、利用既有 |
| 6 | 山丘区、临河段道路和隧道洞口施工平台**下边坡**应采取拦挡、护坡等工程与植物相结合的综合防护，**防止坡面溜渣** | 下边坡防护与溜渣防治 |
| 7 | 制（存）梁场、铺轨基地、预制场、拌和站、施工生产生活区、施工便道等应开展**水土保持措施典型设计** | 典型设计 |

### 2.2　水利、水电建设项目（附件 3，8 条）

| # | 要求 | 核什么 |
|---|---|---|
| 1 | 通过优化设计最大限度提高永久征地范围内**林草覆盖率**，原则上不低于按标准确定的指标值 | 覆盖率不低于限值 |
| 2 | 防治责任范围以**工程建设征用地面积为基础**，结合工程及施工布置、移民安置规划确定；**防洪工程、改扩建、除险加固等无需征收/征用但扰动的土地应纳入责任范围** | 责任范围完整性（呼应块 4） |
| 3 | 开展**阶段验收**的，应明确相应的防治指标值 | 阶段验收指标 |
| 4 | 水电工程应开展**弃渣场选址及多方案比选论证**；**堆渣量超 300 万 m³ 或最大堆渣高度超 100 m 的弃渣场应专门论证** | 高等级弃渣场专门论证（硬指标） |
| 5 | 根据复耕、植被恢复的**表土资源需求**分析确定表土剥离量；涉水库/水电站的应结合**淹没区表土资源调查**充分利用 | 表土剥离量依据（呼应块 8） |
| 6 | 水利工程水土保持工程设计深度应符合**主体工程设计阶段**的深度要求 | 深度匹配 |
| 7 | **4 级及以上弃渣场**的拦挡、排洪工程**选型和结构应比选论证**，并根据**地质勘察成果**做好基础处理设计 | 比选 + 勘察 + 基础处理（呼应块 7/12） |
| 8 | 水利工程水保投资概（估）算的**依据、原则、方法、成果**应与同阶段设计文件的**水保投资内容一致** | 投资一致性（呼应块 10） |

### 2.3　管道建设项目（附件 4，6 条）

| # | 要求 | 核什么 |
|---|---|---|
| 1 | 按地形地貌明确**线路长度、作业带宽度、施工道路数量**；明确横坡/顺坡敷设长度、穿越山体和水体方式及数量；分类型明确**管沟开挖断面图** | 参数与断面图 |
| 2 | 涉施工导流的，明确**导流方式、结构型式、挖填土石方量及来源** | 导流 |
| 3 | 优先采用**隧道、定向钻、顶管**穿越水体山体，穿水体优先**钢板桩围堰**；大开挖穿越须充分论证并附支撑材料；涉重点预防区/治理区的须**减少作业带宽度** | 穿越方式比选 |
| 4 | **管沟开挖面和局部场平机械作业区应剥离表土**；堆土及无开挖填筑的机械作业区宜**铺垫保护** | 表土剥离与铺垫 |
| 5 | 横坡回填应设**合理排水**，不能形成**拦水堤**；顺坡应**分台阶回填** | 回填排水 |
| 6 | 作业带应**恢复原土地利用类型**；线路中心线两侧各 **5 m 范围内禁止种植深根植物** | 复垦 + 禁植范围 |

### 2.4　核电建设项目（附件 5，6 条）

| # | 要求 | 核什么 |
|---|---|---|
| 1 | 海工工程、海域航道、港池等**清淤物海抛**的不计入土石方平衡，但应明确数量及处置方式；作为**场地填筑或陆上设弃渣场（中转场）的应计入** | 土石方口径 |
| 2 | 最后一期工程应明确**临时用地利用方向**；需恢复植被或复耕的应明确**硬化地面拆除数量及去向、覆土数量和来源** | 临时用地与覆土来源 |
| 3 | 施工布置应**充分利用预留场地** | 场地利用 |
| 4 | 厂区林草覆盖率应考虑**核电行业规范**要求，并结合各期场地布设与后期利用确定 | 覆盖率取值依据 |
| 5 | **海岛区**水保措施应考虑**防台风**要求 | 防台风 |
| 6 | 海堤等临海坡面**自然海蚀线以上**边坡，应结合坡面类型合理考虑**植物防护** | 临海坡面植物防护 |

### 2.5　煤炭建设项目（附件 6，8 条）

| # | 要求 | 核什么 |
|---|---|---|
| 1 | 煤矿地面总布置、**开拓开采方案与开采接续计划**、施工组织与建设计划应明确 | 开采方案 |
| 2 | 井工矿建设期**井巷工程量、排矸量与利用、堆弃方案**，及生产期年排矸量、综合利用方案应明确；**禁止设置永久性煤矸石堆放场**；**临时排矸场规模不应超过 3 年储矸量** | 排矸场（禁止永久性 + ≤3 年储矸量） |
| 3 | 露天矿**内排、外排土计划**与排土场设置、排土工艺应明确；**采掘场占地按初期征地范围或设计水平年地表境界范围**计列 | 排土计划与占地口径 |
| 4 | 井工矿井下或露天矿采掘场**排水量、排水去向与综合利用**应明确 | 矿坑排水 |
| 5 | 露天矿采区接续与排土计划应满足**尽快实现内排**的要求 | 内排时序 |
| 6 | 明确**施工期、设计水平年和生产期**防治目标；计算指标时**露天矿采区面积可在责任范围中扣除**；生产期新增扰动范围指标**不低于施工期**，其他区域**不低于设计水平年** | 三期目标 + 扣除口径（呼应块 4 4.0.3/4.0.5） |
| 7 | 采掘场、排土场应制定**表土（或戈壁砾石）剥离计划** | 表土剥离 |
| 8 | 应充分利用**煤矿排水**保障绿化生态用水 | 生态用水来源 |

### 2.6　输变电建设项目（附件 7，5 条）

| # | 要求 | 核什么 |
|---|---|---|
| 1 | 按地形地貌明确**线路长度、塔基、牵张场、施工道路数量**；按塔基根开及基础型式明确**永久征地、临时占地及土石方挖填**；大跨越应明确施工场地布置 | 参数与占地 |
| 2 | 变电站（含换流站、开关站）**逐一**明确建设内容、规模、平竖向布置、征占地、土石方挖填、进站道路、站外供排水 | 逐站交代 |
| 3 | 新建变电站满足防洪下应做到**自身土石方平衡**；**山丘区塔基应采用不等高基础**，优先**索道施工** | 土石方平衡 + 塔基型式 |
| 4 | **塔基区拦挡弃渣的措施应界定为水土保持措施** | 措施界定（呼应附录 D） |
| 5 | 变电站应优先采用**植草防护**；**干旱区可采用碎石压盖** | 植物措施型式 |
