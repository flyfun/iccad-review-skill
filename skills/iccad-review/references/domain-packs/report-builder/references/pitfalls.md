# 建技能踩过的坑（pitfalls）

> 全部是**实测踩过**的，不是推测。按"类别 → 症状 → 根因 → 对策"记。

---

## 一、工具/环境类

### P1　同一文件禁止并行 Edit
- **症状**：改动**静默丢失**（如 `choices=[...,"regime"]` 没了 → `invalid choice: 'regime'`）。
- **根因**：把同一文件的**多处 Edit 放进同一条消息**并行执行 → 各自"读原文件 → 写回整份"，后写覆盖先写。
- **对策**：**同一文件多次改一律串行**（一次一个 Edit，等结果再下一个）；或干脆整份 `Write`。

### P2　package_skill 输出落点是 cwd
- **症状**：zip 里套着 zip；或 zip 落在技能目录内。
- **根因**：`package_skill.py` 把输出写到**当前工作目录**。
- **对策**：固定 `cwd = 源根`；打包后检查 `nested zip` 与技能目录内有无杂散 zip。

### P3　本机 bash 不稳 / PowerShell stdout 被吞
- **症状**：`head`/`ls`/`grep`/`curl` 报 "not found"、管道不可用、PS 无输出。
- **对策**：**统一用 managed python 直跑**（`…\.workbuddy\binaries\python\versions\3.13.12\python.exe`）；
  需要看输出就 `python -c "…"` 里 `sys.stdout.reconfigure(encoding='utf-8')` 后 `print`，
  **不要**依赖 shell 的 `head/tail`。

### P4　`__pycache__` 混进交付
- **症状**：打包/同步后多出 `.pyc`。
- **对策**：打包与同步前清 `__pycache__`；`copytree` 加 `ignore_patterns('__pycache__','*.pyc')`。

## 二、条文库/检索类

### P5　OCR 空格让关键词查不到关键条
- **症状**：`--q 阻水比` 0 命中，而条文里明明有。
- **根因**：库内写作"阻 水 比"。
- **对策**：`spec_lookup.match_dict` 对 query 与 text **同时去空白 + 大写**（`_norm`）后再包含判定。**勿改回裸 `in`**。

### P6　`--q` 不是语义检索
- **症状**：查"桥墩"返回不了只写"支墩"的条。
- **对策**：同一概念多试几个词；优先**词组**、少用单字；命中数看 stderr 的 `matched: N (of M)`。

### P7　块库 `table_text` 时有时无
- **症状**：以为某规范的限值表在库里，实际 `table_text` 为空。
- **对策**：限值一律以 `<prefix>_tables.md` **固化值**为准；**不要假设**块库有表体。

### P8　公式本体是嵌入图片
- **症状**：块库只有符号说明，取不到公式。
- **对策**：能还原的按"符号定义 + 通用式"还原并**标"待核"**；还原不了的**不复算**，只核报告是否给计算书。

### P9　主规范不在强条汇编内
- **症状**：`--spec "GB-强条汇编" --q "<主规范>"` 0 命中，误以为"无强条约束"。
- **根因**：新规范（如 SL/T 808-2025）**晚于**汇编。
- **对策**：强条约束落在**其引用规范**上（如洪评首推 GB 50286 10.1.3）；写"无强条"前先查引用规范。

### P10　`level=mandatory` ≠ 强制性条文
- **根因**：入库启发式按"含'应'字"打标。
- **对策**：判"违反强制性条文"**必须**回强条汇编核原文，不可据 `level` 字段写。

## 三、写作/结构类

### P11　SKILL.md 正文超 5,000 字符
- **对策**：入口只放"四步流程 + ▶载入 + 分册索引"；域内容移到分册。改完**实测**字符数（frontmatter 不计）。

### P12　分册漏进索引 / 漏 ▶载入
- **症状**：新加了分册但入口没列 → "渐进披露"断链。
- **对策**：交付前对照 `family-spec.md` 第一节目录树逐册核对。

### P13　条目/表号凭记忆写错
- **对策**：所有条号、限值**先从库/固化表取**再写；引表号前先 `spec_lookup` 核。

### P14　复算器判据方向判反
- **对策**：见 `calc-conventions.md` 第二节；上限型用 `_check_max`，区间型取**下限**。

## 四、记忆类

### P15　工作区 MEMORY.md 超 3,000 字符
- **症状**：被截断。
- **对策**：合并去重成表；技能总表用一行一技能；超限就压，别删关键约定。
