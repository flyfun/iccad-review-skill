# 复算器约定（判据方向 / 退出码 / 三方比对）

> 复算器的价值是**不采信报告结论**：自己算一遍，再和"规范限值""报告值"对三方。
> 本册是该族的**统一约定**，新脚本照此实现（`templates/calc_script.py.tmpl` 已内置）。

---

## 一、退出码语义（统一，勿改）

| rc | 含义 | 触发 |
|---|---|---|
| **0** | 满足 | 复算值在限值内，且与报告值不矛盾 |
| **1** | 不满足 | 超限 / 违反强条 / 与报告**显著不符** |
| **2** | 输入错 | 参数缺失或取值不在表中 |
| **3** | 仅参考 | 公式本体为图片等，**不作硬判定**，只给参考值 |

脚本末尾 `sys.exit(main())`；`main()` 返回 `1`（bad 非空）或 `0`。批量审查靠 rc 汇总。

---

## 二、判据方向（★最容易判反，判反即错情）

| 类型 | 方向 | 助手 | 典型判据 |
|---|---|---|---|
| **下限型** | 越大越好，要求 **≥** | `_check_min` / `_check_report_min` | 安全系数、净空、超高/加高、埋深、防洪标准、压实度、相对密度 |
| **上限型** | 越小越好，要求 **≤** | `_check_max` / `_check_report_max` | 阻水比、基底应力比 σmax/σmin、桥墩夹角、σmax vs 允许承载力、超深超宽 |
| **严格大于型** | 越大越好，要求 **>**（**等于不放行**） | 专用 `_gt`（**勿用 `≥`**） | 条文写「**应大于**」类：立式泵基准面淹没 >0.5 m（GB 50265 10.1.7-2）、穿堤泵站防洪标准 vs 堤防（GB 50201 11.8.3★ 留安全裕度） |

**实例教训（洪评）**：`calc_stability` 的**基底应力比**是**上限型**（σmax/σmin ≤ 表值）。
最初误用下限助手 → 实测 2.12 > 2.00 竟判"满足"。改用 `_check_max` 后正确判不满足。
同理 `σmax ≤ 允许承载力`、`σmax ≤ 1.2×允许承载力` 都是上限型。

**实例教训（泵站）**：GB 50265 10.1.7-2「基准面最小淹没深度**应大于**0.5 m」最初写 `≥0.5`
→ 实测 0.50 竟判"满足"。**「应大于」必须用 `_gt` 严格 `>`**（等于即不满足）。

## 三、区间型判据怎么取

规范给"区间"时（如 SL/T 386 表 3.3.7 边坡抗滑 1.15~1.25）：
- **作最低要求**取**下限**（偏安全）→ 用 `_check_min(val, 区间下限)`。
- 若报告按上限设计且无说明 → 出提示（不一定 rc=1，视是否影响安全）。

**教训**：曾误取**上限**当要求 → 3 级正常工况把 1.15 的要求写成 1.20，偏严误报。

---

## 四、"应/不应" vs "宜"（决定 rc 是否置 1）

- **应 / 不应 / 不应大于 / 应进行** → 硬约束，进 `bad`（rc=1）。
- **宜 / 宜采用 / 不宜 / 可 / 可按** → 推荐，**只出 ▲ 提示**，不置 rc（避免假错情）。

**强度由动词定，不由量值词定**：量值词只表方向——「大于」→ `>`、「至少/不小于」→ `≥`；
但**是否硬判**看动词（应/宜/可）：

| 条文措辞 | 判定 | 助手 |
|---|---|---|
| **应大于** | 严格 `>`，等于不满足 | `_gt` |
| **至少 / 不应小于** | `≥`，硬（rc=1） | `_check_min` |
| **宜不小于 / 可按** | `≥`，但仅 **▲** | `_soft_ge`（软判定，进 warn 不进 bad） |

**教训（洪评）**：`calc_geometry` 里"承台顶 ≤ 规划河底"是**不应**（硬），
"跨堤梁底 ≥ 规划堤顶"是**宜**（▲）—— 两者混用会把推荐项误报成硬错情。

**教训（泵站）**：GB 50265 8.3.3「出水管出口上缘**宜**不小于0.3 m」、8.2.7「进水池容积**可**按秒换水系数30~50」
最初都写硬判 → 改 `_soft_ge` 只出 ▲；而 10.2.2-5「进口上缘**至少**0.5 m」是应级 → 保留硬判。
**同一册里 5 条淹没/容积判据，措辞不同强度就不同** —— 取到条文后必须逐条读动词。

## 五、三方比对与容差

```python
if args.report is not None:
    # 与复算值比较；偏离超阈值 → 提示"须核对参数取值与来源"
    if abs(val - args.report) > tol:   # tol 如 0.05 m / 0.6 个百分点
        print("★ 复算与报告差 > 阈值 —— 须核对 <哪几个参数> 的取值与来源")
        return 1
```
- **不复算的量**（如稳定系数）→ 用 `--report` 只做"**报告值 vs 规范限值**"两方比对。
- **近似公式**（如壅水长度 L_Y≈2ΔZ_M/I₀）→ **只出 ▲ 提示，不作硬判定**，
  正式判定要报告给出的值（`--ly` 传入），否则近似值算出的 702 m 会把 10 m 间距误报成违反。

## 六、参数量纲与用法（写进 `--help` 与 docstring）

- 长度 m、面积 m²、流速 m/s、流量 m³/s、应力 kPa、比降无量纲 —— **统一在 docstring 声明**。
- 报告只给结论值时用 `--report`；能拆中间量时优先拆（如壅水给 `--v/--vm/--eta` 而非只给 ΔZ）。
- 每个复算器都要在 docstring 写**依据（规范号 + 条号/表号）**与**不代算什么**。
