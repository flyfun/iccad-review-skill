# 土石坝工程报告审查

## 这个 Skill 是什么

**审查编排层**，不是设计知识卡。它回答：拿到一份土石坝报告，**按什么顺序查、查哪些点、
每条怎么判、依据谁、怎么输出**。

本技能**不硬编码条文** —— 条款号、限值一律从自带条文库 / 限值表核对。

> **与水闸版的关键差别**：手册第六卷「土石坝」缺失 → **无土石坝设计领域技能可路由** →
> 判据全落在规范库 + 复算脚本上，**复算脚本权重更高**。

## 何时用 / 不适用

- **用**：手里有一份土石坝工程报告（可研 / 初设 / 施设 / 安全评价 / 除险加固 / 蓄水安全鉴定），
  要从设计合理性、规范合规性、专业间一致性三个角度出审查发现。
- **不用**：混凝土坝 / 拱坝 / 浆砌石坝；纯水闸报告（走 `sluice-report-review`）；单点设计问题；纯条文查询。
- 报告主体不是土石坝（河道整治、灌区、供水）→ 本技能不覆盖。

## 审查总流程

```
报告文本 (docx/pdf)
   │
   ├─[第0步]   前置判定 ── 报告类型 / 坝型 / 坝基类型 / 工程等级与洪水标准
   │
   ├─[第0.5步] 取判据 ── spec_lookup.py 调条文 + dam_tables.md 查限值 + calc_dam_*.py 复算
   │
   ├─[第1步]   分块审查（12 块）── 每块：查什么 → 判定标准 → 依据
   │
   ├─[第2步]   跨专业一致性 ── 布置↔坝料↔分区↔超高↔防渗↔渗流↔稳定 数值是否自洽
   │
   └─[第3步]   结构化发现 ── 位置 / 问题 / 依据 / 严重度 / 修改建议
```

**每一步该翻哪一册，见该步末尾的 ▶ 载入。**

## 第 0 步：前置判定

**先定这四样，再翻正文。** 同一处做法在不同前提下判定不同——同一安全系数，
级别或运用条件不同，允许值就不同。

| 判定项 | 常见取值 | 对审查的影响 |
|---|---|---|
| **报告类型** | 可研 / 初设 / 施工图 / 安全评价 / 除险加固 / 蓄水安全鉴定 | 可研重方案比选；初设重设计深度与计算书；安全评价重现状复核；除险加固重病害成因与措施 |
| **坝型** | 均质坝 / 土质防渗体分区坝（心墙、斜墙）/ 非土质材料防渗体坝（面板堆石、沥青心墙、土工膜） | 决定稳定计算方法（8.3.9）、防渗体顶部超高取值（表 5.5.3）、材料要求（强条 4.1.5） |
| **坝基类型** | 砂砾石层 / 岩石 / 软粘土 / 湿陷性黄土 / 可液化土 | 决定坝基处理方案（6.2/6.3/6.4）、沉降与稳定计算要求 |
| **等级与洪水标准** | 工程级别（SL 252）+ 洪水标准（GB 50201） | **允许安全系数、安全加高全随级别变化**，级别定错则后续判据全错 |

> 判不出这四样 → 报告基本资料有缺项，本身就是一条 ○ 级发现。

## 第 0.5 步：取判据（别跳过）

判定标准有三个来源，**不可混用**：

| 来源 | 怎么取 | 怎么写进意见 |
|---|---|---|
| **规范条文** | `python scripts/spec_lookup.py --spec "SL 274" --q 关键词` | 引条款号（如"违反 SL 274 8.3.10"） |
| **规范限值表** | `references/dam_tables.md`（SL 274 原文表） | 引条款号 + 表号 |
| **强制性条文** | `references/compulsory-clauses.md`（SL 274 共 15 条） | 写"**违反强制性条文**"，最高严重级 |

取不到条文的判定项 → 标"依据待核"，只出疑点、不出结论。

**能算的不要只靠看** —— 凡报告给出数值结论，用复算脚本把关键中间量自己过一遍：

| 脚本 | 覆盖 |
|---|---|
| `scripts/calc_dam_crest.py` | **坝顶高程/超高 + 防渗体顶高程**（5.3.1 `y=R+e+A`、查表 5.3.1、5.3.3 四工况；**分「A 无防浪墙 / B 有防浪墙」两方案**——B 含 5.3.4 静水位限值 + 5.4.4 墙高；**5.5.3 防渗体顶高 + 5.5.4 保护层**） |
| `scripts/calc_dam_slope.py` | **坝坡抗滑稳定**（表 8.3.10 允许值；8.3.11 瑞典圆弧法 ×0.92；8.3.12 滑楔法） |

> ▶ **载入**：`references/norms.md` §一（取条文方法、数据源、脚本用法与限制）。

## 第 2 步：跨专业一致性（最容易被漏的一层）

单块各自正确 ≠ 报告正确。共 **8 对交叉校验**（级别↔洪水标准↔允许值、坝顶↔特征水位↔R+e+A、
防渗体顶高↔5.5.3、坡率↔K↔方法、抗剪指标↔时期↔试验方法、分区↔渗透↔反滤、坝基↔渗控、内部数值一致）。

> ▶ **载入**：`references/checklist.md` §第 2 步（8 对逐条展开）。
> 自洽性优先用复算脚本验算，不靠眼看。

---

## 第 3 步：结构化发现

| 序号 | 位置 | 问题描述 | 判定依据 | 严重度 | 修改建议 |
|---|---|---|---|---|---|
| 1 | 第X章 X.X 节 | …… | SL 274 第x.x条 / 表x.x.x / 复算结果 | ★/●/○ | …… |

**严重度分级**
- **★ 严重**：违反**强制性条文**（15 条），或影响工程安全
- **● 重要**：不符合规范推荐做法、或明显不合理（漏算水位降落期工况、坝料分区反序）
- **○ 一般**：表述不清、深度不足、专业间不一致、图文不符

## 引用纪律（硬规则）

**下判断前先读** `references/norms.md` §五（引用纪律 7 条）+ §六（易踩的坑）——唯一权威定义，本入口不重复。

> 唯一不能忘的一条：**条款号与限值一律取自工具 / 固化表，不凭记忆写**。

## 边界

- **无土石坝设计领域技能可路由**——只给**条文级判据 + 复算**（详见 `limits.md` §五）。
- 安全监测类深挖 → `monitoring-focus-derivation` / `monitoring-point-layout` /
  `instrument-selection-range-precision` / `monitoring-frequency-patrol` /
  `seepage-monitoring-design` 等。
- 混凝土坝 / 拱坝 / 浆砌石坝 → 不在本技能范围。
- 本技能产出的是**审查发现**，不是设计成果；最终判定责任在人。

> ▶ **载入**：`references/limits.md`（边界与已知局限）。
