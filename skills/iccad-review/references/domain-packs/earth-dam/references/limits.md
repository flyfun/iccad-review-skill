# 技能边界与已知局限

> **本文件是"边界 / 局限"的唯一权威源**。入口 `SKILL.md` 只给指针，不再重复正文。

---

## 一、数据覆盖边界

- **自带条文库覆盖 19 部 / 13,480 块**（其中 10,595 块带条号）。清单见 `norms.md` 第二节，`--list-specs` 可复现。
- 要查这 **19 部之外**的规范（如 SL 189 小型土石坝、SL 228 混凝土面板堆石坝、
  SL 551 土石坝安全监测、GB/T 45530 土石坝安全监测），需本机存在 hydro_reviewer 源码树，
  用 `--pkl` 读块库（全库 62 部）；也可 `--export` 追加固化后并入 JSON。
- **未入库的规范**：审到相关条款时，标 **"未入库，须查现行有效版本"**，不要凭印象编号。

## 二、输入 / 解析边界

- **解析层不在本技能内**：技能假设已拿到报告文本；审 docx 需先自行解析。
- **报告没写的，判不了**：缺水位、缺地质参数、缺计算书 → 只能出"深度不足"的发现，判不了对错。

## 三、公式来源边界

- SL 274 附录 A（波浪爬高、风壅高度）、附录 D（稳定计算）的**公式本体在原文中为嵌入图片**，
  机器提取不到文字。
- **限值 / 系数实测自原文表格（可靠）**；公式本体按条文符号定义 + 水力学 / 土力学通用形式还原，
  **使用前须与原文核对**。
- 取公式须回原始 docx 提图识读，**不能凭"公式编号"猜形式**。（另见 `norms.md` §六.6）

## 四、版本边界

- 库内 SL 274 为 **2001 版**（docx 1.0.2 引 `GB50201—94` / `SL252—2000`，据此判为 2001 版）；
  现行 **SL 274-2020** 若有修订，以现行版为准。
- 本机另有 `碾压式土石坝设计规范 SL 274-2020.pdf`，但其**数字/点号经自定义字体编码（如 `/G22C`）、
  "防浪墙"等字未映射**，机抽文本不可读 → **2020 版条文须人工打开 PDF 核对**，不得据抽取文本下结论。
  （已抽出的 2020 §5.3.1 正文与 2001 **一致**：`y=R+e+A`、表 5.3.1 同值。）
- **防浪墙墙高 1.00~1.20m 系 SL 274-2001 §5.4.4 即有的规定**（实测自 2001 docx），**非** 2020 版新增——
  勿因版本存疑而不敢用；但引用时仍须声明所用版本。
- 用本库判据前须先确认项目适用版本。（另见 `norms.md` §三 / §六.2）

## 五、无手册经验值可引

- 《水工设计手册》（第二版）**第六卷「土石坝」缺失** —— 无土石坝设计领域技能可路由。
- 审查意见中**不得出现"手册推荐 XX"**；坝坡稳定、坝料分区、反滤设计等，只能给
  **规范条文级判据 + 复算**。（另见 `norms.md` §六.7）

## 六、复算脚本的能力边界

1. 稳定试算用**均质坝简单条分**，非均质 / 复杂坝型须专业软件；
2. 参数（坝料强度、水位、扬压力…）仍需人工从报告摘取，报告没写就还是"判不了"；
3. 脚本只做机械验算，**坝料选用、工况组合、计算假定是否合理，仍须专业判断**；
4. 防渗体顶部高程（5.5.3）的 hc **只按表 5.5.3 取值，不代算风浪爬高 R**（规范要求"核算 R 影响"须人工核）；
   有/无防浪墙分支按 `--parapet` 判定，**须先确认报告实际是否设墙**。

## 七、判定责任边界

- 本技能产出的是**审查发现**，不是设计成果；最终判定责任在人，**AI 结论须经复核**。
