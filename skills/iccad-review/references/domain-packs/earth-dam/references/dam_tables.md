## 一、坝顶超高（核心判定，对应强条 5.3.1）

**第 5.3.1 条**：坝顶在水库静水位以上的超高应按式(5.3.1)确定：

```
y = R + e + A                                   (5.3.1)
```

- `y` —— 坝顶超高，m
- `R` —— 最大波浪在坝坡上的爬高，m（按附录 A 计算）
- `e` —— 最大风壅水面高度，m（按附录 A 计算）
- `A` —— 安全加高，m（按**表 5.3.1** 确定）

**表 5.3.1　安全加高 A 值（单位：m）**

| 运用情况 | | 1级 | 2级 | 3级 | 4、5级 |
|---|---|---|---|---|---|
| **设计** | | 1.50 | 1.00 | 0.70 | 0.50 |
| **校核** | 山区、丘陵区 | 0.70 | 0.50 | 0.40 | 0.30 |
| **校核** | 平原、滨海区 | 1.00 | 0.70 | 0.50 | 0.30 |

> 校核一栏**分山区丘陵区 / 平原滨海区**取值——报告用错分区即取值错。

**第 5.3.3 条（坝顶高程取最大值）**：坝顶高程 = 水库静水位 + 坝顶超高，应按以下**四种运用条件**计算，**取最大值**：

1. 设计洪水位 + 正常运用条件的坝顶超高；
2. 正常蓄水位 + 正常运用条件的坝顶超高；
3. 校核洪水位 + 非常运用条件的坝顶超高；
4. 正常蓄水位 + 非常运用条件的坝顶超高，再按 5.3.2 加地震安全加高。

> **只算工况 1、3 而漏掉 2、4 是最常见的错**——正常蓄水位往往控制。

**第 5.3.4 条（设防浪墙时）**：坝顶上游侧设防浪墙时，坝顶超高可改为对**防浪墙顶**的要求；但此时：

- 正常运用条件下，**坝顶应高出静水位 0.5 m**（静水位含**正常蓄水位**与**设计洪水位**两支）；
- 非常运用条件下，**坝顶应不低于静水位**。

**第 5.4.4 条（防浪墙墙高，属 5.4「坝顶构造」）**：坝顶上游侧**宜**设防浪墙，
**墙顶应高于坝顶 1.00～1.20 m**。防浪墙必须与防渗体紧密结合，坚固不透水，
结构尺寸按稳定、强度计算确定，并设伸缩缝、做好止水。

> 由此派生：**有防浪墙时 坝顶 = 防浪墙顶 − (1.00~1.20 m)**。
> 与 5.3.4 合看，有防浪墙方案下坝顶须**同时**满足两条：
> ① 由墙顶反推（墙顶 − 墙高）；② 不低于静水位限值（正常运用 静水位＋0.5、非常运用 静水位）。
> 复算见 `scripts/calc_dam_crest.py`（自动分「A 无防浪墙 / B 有防浪墙」两方案）。

**第 5.3.5 条（设计风速取值）**：

| 运用条件 / 级别 | 设计风速 |
|---|---|
| 正常运用 · 1级、2级坝 | 多年平均年最大风速的 **1.5～2.0 倍** |
| 正常运用 · 3级、4级、5级坝 | 多年平均年最大风速的 **1.5 倍** |
| 非常运用条件 | 多年平均年最大风速 |

**第 5.3.6 条**：坝顶应预留竣工后**沉降超高**（按 8.4.3 确定），各坝段按其坝高变化；
**预留沉降超高不应计入坝的计算高度**。

**第 5.3.2 条**：地震区的安全加高尚应增加**地震沉降和地震壅浪高度**（按抗震规范确定）。

## 二、防渗体顶部超高（对应强条 5.5.3）

**第 5.5.3 条**：土质防渗体顶部在正常蓄水位或设计洪水位以上的超高，按**表 5.5.3** 取值；
非常运用条件下，**防渗体顶部不应低于非常运用条件的静水位**，并应核算风浪爬高影响。

**表 5.5.3　正常运用情况下防渗体顶部超高（单位：m）**

| 防渗体结构形式 | 超高 | 防渗体结构形式 | 超高 |
|---|---|---|---|
| **斜墙** | 0.80～0.60 | **心墙** | 0.60～0.30 |

> 当防渗体顶部设有防浪墙时，防渗体顶部高程可不受上述限制，但**不得低于正常运用的静水位**。
> 防渗体顶部应预留竣工后沉降超高。

**防渗体顶部高程计算（据 5.5.3）**

- **无防浪墙**：正常运用 `∇心顶 ≥ max(∇正, ∇设) + hc`（hc 查表 5.5.3）；非常运用 `∇心顶 ≥ ∇校`；**取大值**。
- **有防浪墙**：`∇心顶 ≥ max(∇正, ∇设)`（可不受超高限制，但不得低于正常运用的静水位）。
- **预留竣工后沉降超高**：竣工填筑高程 ＝ 运行期所需高程 ＋ 沉降量（与坝顶预留沉降同等要求）。
- 尚应**核算风浪爬高 R** 的影响（当 R 大于表值 hc 时应由 R 控制）。

**第 5.5.4 条（保护层）**：土质防渗体顶部和土质斜墙上游应设保护层，保护层厚度（含上游护坡垫层）
应**不小于该地区的冻结和干燥深度**，还应满足施工机械的需要。
—— 派生判据：`坝顶高程 − 防渗体顶高程 ≥ 冻结/干燥深度`。

## 三、坝坡抗滑稳定安全系数（对应强条 8.3.10 / 8.3.11 / 8.3.12）

**第 8.3.10 条**：采用**计及条块间作用力**的计算方法时，坝坡抗滑稳定安全系数应不小于表 8.3.10 的规定。

**表 8.3.10　坝坡抗滑稳定最小安全系数**

| 运用条件 | 1级 | 2级 | 3级 | 4、5级 |
|---|---|---|---|---|
| **正常运用条件** | 1.50 | 1.35 | 1.30 | 1.25 |
| **非常运用条件 I** | 1.30 | 1.25 | 1.20 | 1.15 |
| **非常运用条件 II** | 1.20 | 1.15 | 1.15 | 1.10 |

> 混凝土面板堆石坝用非线性抗剪强度指标计算坝坡稳定时，安全系数可**参照**表 8.3.10 取值。

**第 8.3.11 条（瑞典圆弧法折减）**：采用**不计条块间作用力**的瑞典圆弧法计算时：

- **1 级坝正常运用条件**：最小安全系数 **≥1.30**；
- **其他情况**：比表 8.3.10 规定的数值**减小 8%**（即 ×0.92）。

**第 8.3.12 条（滑楔法）**：

- 假定滑楔之间作用力**平行于坡面和滑底斜面的平均坡度** → 按表 8.3.10；
- 假定滑楔之间作用力为**水平方向** → 按 8.3.11（×0.92）。

**第 8.3.9 条（计算方法选型）**：坝坡抗滑稳定应采用**刚体极限平衡法**。

- 均质坝、厚斜墙坝、厚心墙坝 → 宜用**简化毕肖普法**（计及条块间作用力）；
- 有软弱夹层、薄斜墙、薄心墙坝 → 可用**摩根斯顿—普赖斯法**等方法；
- 非均质坝体和坝基 → 须考虑**安全系数的多极值特性**，在不同土层分析比较，求得**最小**安全系数。

**第 8.3.1 条（必须计算的四种工况）**：

1. 施工期的上、下游坝坡；
2. 稳定渗流期的上、下游坝坡；
3. **水库水位降落期**的上游坝坡；
4. 正常运用遇地震的上、下游坝坡。

> **漏算"水库水位降落期"是最常见错**——该工况常是上游坝坡的控制工况。

## 四、筑坝材料与填筑标准（对应强条 4.1.5 / 4.1.15 / 4.2.3 / 4.2.5）

**第 4.1.5 条（防渗土料要求，强制）**：

1. **渗透系数**：均质坝 **≤1×10⁻⁴ cm/s**；心墙和斜墙 **≤1×10⁻⁵ cm/s**；
2. **水溶盐含量**（易溶盐和中溶盐，按质量计）**≤3%**；
3. **有机质含量**（按质量计）：均质坝 **≤5%**，心墙和斜墙 **≤2%**，超过需论证。

**第 4.1.15 条（反滤料、过渡层料、排水体料要求，强制）**：

1. 质地致密，抗水性和抗风化性能满足运用条件要求；
2. 具有要求的级配；
3. 具有要求的透水性；
4. **反滤料和排水体料中粒径小于 0.075 mm 的颗粒含量应不超过 5%**。

**第 4.2.3 条（粘性土压实度，强制）**：

1. **1 级、2 级坝和高坝**：压实度应为 **98%～100%**；
2. **3 级中、低坝及 3 级以下的中坝**：压实度应为 **96%～98%**。

**第 4.2.5 条（砂砾石和砂的填筑标准，强制）**：以**相对密度**为设计控制指标。

1. **砂砾石相对密度 ≥0.75**；**砂相对密度 ≥0.70**；**反滤料宜为 0.70**；
2. 砂砾石中粗粒料含量 **<50%** 时，应保证细料（<5 mm 颗粒）的相对密度也符合上述要求。

**第 4.1 节（不宜用作防渗土料，定性）**：塑性指数 >20 和液限 >40% 的冲积粘土、膨胀土、
开挖压实困难的干硬粘土、冻土、分散性粘土——**不宜**用作防渗体土料。

## 五、反滤层设计（附录 B）

**第 5.6.2 条（强制）**：土质防渗体（心墙、斜墙、铺盖、截水槽等）与坝壳和坝基透水层之间、
以及下游渗流出逸处，**如不满足反滤要求，均必须设置反滤层**。

| 被保护土类别 | D₁₀ (mm) | D₉₀ (mm) |
|---|---|---|
| 所有类别 | <0.5 | 20 |
| | 0.5～1.0 | 25 |
| | 1.0～2.0 | 30 |
| | 2.0～5.0 | 40 |
| | 5.0～10 | 50 |
| | >10 | 60 |

> 反滤层三项基本要求（5.6.1）：① 使被保护土**不发生渗透变形**；② 渗透性**大于**被保护土，
> 能通畅排出渗透水流；③ 不致被细粒土**淤塞**失效。

**第 1.0.5 条 运用条件划分（原文）**：

- **正常运用条件**：① 水库水位处于正常蓄水位和设计洪水位与死水位之间的各种水位的稳定渗流期；
  ② 水库水位在上述范围内**经常性的正常降落**；
- **非常运用条件 I**：① 施工期；② 校核洪水位有可能形成稳定渗流的情况；③ 水库水位**非常降落**；
- **非常运用条件 II**：① 正常运用条件下遇地震；② 其他非常运用情况。
