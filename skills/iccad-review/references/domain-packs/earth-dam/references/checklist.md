# 土石坝工程报告审查 — 完整检查项清单

配套 `SKILL.md` 第 1 步"分块审查"使用。按 12 块展开，每条含 **判定标准** 与 **失败模式**。

> **引用约定见 `norms.md`**（条款号取法、限值出处、强条处置、版本声明、无手册可引）。
> 本文件不再重复；标 **★强条** 者为 SL 274-2001 的 15 条强制性条文之一。

## 块 1　设计标准与洪水

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 工程级别 | 按 SL 252 依工程规模（库容、装机）+ 效益 + 重要性综合定 | 级别定低 → 后续所有允许值用错 |
| 洪水标准 | 按 GB 50201 依级别 + 坝型取设计/校核标准 | 土石坝与混凝土坝标准混用 |
| **土石坝校核洪水标准** | 失事将造成**特别重大灾害**时，**1 级建筑物校核洪水标准应采用可能最大洪水（PMF）或 10000 年一遇**（SL 252 强条） | 用低标准校核 |
| 特征水位齐备性 | 正常蓄水位 / 设计洪水位 / 校核洪水位 / 死水位 列全 | 缺水位 → 坝顶超高四工况算不全 |

## 块 3　筑坝材料与填筑标准

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **防渗土料**（★强条 4.1.5） | 渗透系数：均质坝 ≤1×10⁻⁴ cm/s，心墙斜墙 ≤1×10⁻⁵ cm/s；水溶盐 ≤3%；有机质：均质坝 ≤5%、心墙斜墙 ≤2% | 指标超限未论证 |
| **反滤料/过渡层料/排水体料**（★强条 4.1.15） | 质地致密、级配与透水性满足要求；**<0.075 mm 颗粒含量 ≤5%** | 细粒含量超限 → 反滤失效 |
| **粘性土压实度**（★强条 4.2.3） | 1、2 级坝和高坝 **98%~100%**；3 级中低坝及 3 级以下中坝 **96%~98%** | 压实度标准偏低 |
| **砂砾石/砂填筑标准**（★强条 4.2.5） | 砂砾石相对密度 **≥0.75**、砂 **≥0.70**、反滤料宜 **0.70**；粗粒料 <50% 时细料也须达标 | 用压实度替代相对密度 |
| 不宜作防渗土料 | 塑性指数 >20 且液限 >40% 的冲积粘土、膨胀土、干硬粘土、冻土、分散性粘土**不宜**用 | 选了不宜土料未论证 |
| 石料开采 | 分区开采、软岩边采边填、宜爆破设计（4.1） | — |

## 块 4　坝体分区与坝坡构造

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 坝体分区 | 防渗体 / 反滤过渡 / 坝壳 / 排水体 分区合理，渗透性沿渗流方向**递减**（5.1） | 分区渗透性反序 → 内部渗透破坏 |

| 防渗体厚度 | 厚度与坝高、渗透比降、施工条件匹配；8、9 度区适当加厚（5.5） | 防渗体过薄 → 渗透比降超限 |

## 块 5　坝顶高程与超高　（★本技能最高频判定块）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **坝顶超高**（★强条 5.3.1） | `y = R + e + A`；A 查**表 5.3.1**（按级别 + 运用情况；校核还分山区丘陵/平原滨海） | 漏 R 或 e；A 用错行/错分区 |
| **四工况取最大值**（5.3.3） | ①设计洪水位+正常运用；②**正常蓄水位+正常运用**；③校核洪水位+非常运用；④正常蓄水位+非常运用+地震 —— **四项分别算，取最大** | **只算①③，漏②（正常蓄水位常控制）** |
| **防浪墙**（5.3.4 ＋ 5.4.4） | 设防浪墙时超高改对防浪墙顶；但 **①正常运用时坝顶应高出静水位 0.5 m**（含正常蓄水位、设计洪水位两支）、非常运用不低于静水位；**②墙顶应高于坝顶 1.00~1.20 m**（5.4.4）→ 坝顶 = 墙顶 −(1.0~1.2) | 只算防浪墙顶、漏坝顶自身限值；或墙顶−坝顶不在 1.00~1.20 |
| 设计风速（5.3.5） | 正常运用：1、2 级坝取多年平均年最大风速 **1.5~2.0 倍**；3、4、5 级取 **1.5 倍**；非常运用取**多年平均年最大风速** | 全工况用同一风速 |
| 预留沉降超高（5.3.6） | 坝顶应预留竣工后沉降超高（按 8.4.3）；**不计入坝的计算高度** | 漏预留、或把预留计入计算高度 |
| 地震加高（5.3.2） | 地震区安全加高增加**地震沉降 + 地震壅浪**高度 | 地震区未加 |
| **防渗体顶部高程**（★强条 5.5.3） | **无防浪墙**：正常运用 `max(∇正,∇设)＋hc`（斜墙 0.80~0.60 / 心墙 0.60~0.30）、非常运用 `≥∇校`，**取大值**；**有防浪墙**：`≥max(∇正,∇设)`（不受超高限制，但不得低于正常运用静水位）。均应**预留竣工后沉降超高**、并**核算风浪爬高** | 斜墙/心墙取值混用；有防浪墙仍套超高；**漏预留沉降超高** |
| **防渗体保护层**（5.5.4） | 上游保护层厚度（含护坡垫层）**≥ 冻结/干燥深度**，即 `坝顶高程 − 防渗体顶高程 ≥ 冻结/干燥深度` | 保护层厚度小于冻结/干燥深度 |

> **复算工具**：`python scripts/calc_dam_crest.py --level 2 --region mountain
> --zw-normal 100.0 --zw-design 101.2 --zw-check 102.0 --R 1.2 --e 0.15 --dam-crest 103.5`
> （自动按 5.3.3 取四工况大值、查表 5.3.1，出「A 无防浪墙 / B 有防浪墙」两方案建议值；
> 有防浪墙时传 `--parapet --wall-crest <墙顶> --dam-crest <坝顶>`，脚本自动复核 5.3.4 静水位限值
> 与 5.4.4 墙高 1.00~1.20；`--wall-height <h>` 可指定墙高）
>
> **防渗体（5.5）**：加 `--core-type inclined|central --core-top <防渗体顶高程>` 触发防渗体顶部高程复核，
> 输出「C-A 无防浪墙 / C-B 有防浪墙」两方案；`--core-hc <hc>` 指定超高（默认取表 5.5.3 下限）；
> `--settlement <m>` 或 `--settlement-ratio <比例> --dam-height <坝高>` 计预留沉降超高；
> `--freeze-depth <m>` 触发 5.5.4 保护层校核（坝顶−防渗体顶 ≥ 冻结/干燥深度）

## 块 6　防渗体、反滤层与坝体排水

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **反滤层设置**（★强条 5.6.2） | 土质防渗体与坝壳、坝基透水层之间及下游渗流出逸处，**不满足反滤要求必须设反滤层** | 防渗体与坝壳直接接触、漏反滤层 |
| 反滤层三项要求（5.6.1） | ① 使被保护土不发生渗透变形；② 渗透性大于被保护土；③ 不被细粒土淤塞 | 只满足级配、未验渗透性 |
| 反滤层级配（附录B） | 按**表 B.0.6**（D₉₀ 下包线 / D₁₀ 上包线）与滤土排水要求反算 | 级配不满足滤土或排水任一侧 |
| 排水体型式（5.7） | 棱体排水（滤水坝趾）/ 贴坡排水 / 褥垫排水 / 坝体内排水，按坝型与坝基条件选；**棱体上游坡脚避免锐角** | 排水体出口高于下游水位不足 |
| 过渡层 | 防渗体与坝壳刚度相差悬殊时设过渡层（5.6） | 漏过渡层 |

## 块 8　坝基处理与坝体连接

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 坝基分类处理（6.1） | 深厚砂砾石层 / 软粘土 / 湿陷性黄土 / 疏松砂土 / 喀斯特 / 断层破碎带 各自对应措施 | 坝基问题未识别 |
| **砂砾石坝基渗流控制**（6.2） | 方案：① 垂直防渗（混凝土防渗墙 / 灌浆帷幕）；② 上游防渗铺盖；③ 下游排水设备及盖重。**砂砾石层 ≤80 m 可用混凝土防渗墙；很深时用灌浆帷幕** | 深覆盖层误用浅防渗墙 |
| 灌浆帷幕（6.2.12） | 帷幕厚度 `T = H/J`；灌浆方法宜用套阀花管法 | — |
| 岩石坝基（6.3） | 帷幕灌浆、固结灌浆、断层处理 | 岩基未做防渗 |
| 覆盖层防渗范围（6.3） | 防渗体延伸至：正常蓄水位与地下水位相交处 / 与相对不透水层相交处 / 按渗流计算确定 | 防渗范围不足 |
| 特殊土坝基（6.4） | 易液化土、软粘土、湿陷性黄土 分别处理 | 未处理可液化土 |
| **坝体与岸坡连接**（7.1） | **土质岸坡不宜陡于 1:1.5**；岸坡清理、结合面处理 | 岸坡过陡未削坡 |
| 坝体与其他建筑物连接（7.2） | 土质防渗体与坝下涵管连接处应**扩大防渗体断面** | 连接处防渗削弱 |

## 块 9　渗流与渗透稳定

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 渗流计算工况（8.1） | ① 上游正常蓄水位与下游相应最低水位；② 上游设计洪水位与下游相应水位；③ 上游校核洪水位与下游相应水位；④ **库水位降落时上游坝坡稳定最不利情况** | 漏水位降落工况 |
| 渗透稳定计算（8.2） | 判明坝和坝基土体的渗透稳定、下游渗流出逸段的渗透稳定 | 只算渗流量、不判稳定性 |
| 渗透变形类型 | 无粘性土可能**管涌 + 流土**；黏性土只可能**流土** | 判错类型 → 反滤设计方向错 |
| 浸润线与孔隙压力（附录C） | 稳定渗流期按流网确定；施工期按 u=γhB 估算（B 按附录C） | 不区分工况统一取值 |
| 反滤/盖重 | 下游渗流出逸段设反滤或盖重 | 漏设 |

## 块 10　坝坡稳定与应力变形

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 方法选型（8.3.9） | 均质坝、厚斜墙坝、厚心墙坝宜用**简化毕肖普法**；有软弱夹层/薄斜墙/薄心墙可用摩根斯顿—普赖斯法 | 方法选用与坝型不匹配 |
| **必须计算的工况**（8.3.1） | ① 施工期上、下游坝坡；② 稳定渗流期上、下游坝坡；③ **水库水位降落期上游坝坡**；④ 正常运用遇地震 | **漏算水位降落期**（常为控制工况） |
| **允许安全系数**（★强条 8.3.10） | 表 8.3.10：正常 1.50/1.35/1.30/1.25；非常 I 1.30/1.25/1.20/1.15；非常 II 1.20/1.15/1.15/1.10 | 计算值 < 允许值 |
| **瑞典圆弧法折减**（★强条 8.3.11） | 不计条块间作用力时：1 级坝正常运用 ≥1.30；其他 = 表值 **×0.92** | 用瑞典法却套表值原数（判据偏松） |
| 滑楔法（★强条 8.3.12） | 作用力平行坡面 → 表 8.3.10；作用力水平 → ×0.92 | — |
| 多极值特性（8.3.9） | 非均质坝体/坝基须在不同土层比较滑面，取**最小**安全系数 | 只算一个滑面 |
| **抗剪强度**（8.3.2 / 8.3.5 / 表 D.1.1） | 有效应力法 `τ=c′+(σ-u)tanφ′`；粘性土施工期与水位降落期**同时**用总应力法；指标应按 8.3.5 用三轴仪（3 级以下中坝可直剪慢剪） | 试验方法与控制时期不匹配 |
| 指标取值 | 粘性土抗剪指标 >11 组宜用**小值平均值**（D.1.3） | 用大值平均值 |
| **沉降**（8.4 / 附录E） | 竣工后坝顶沉降量 / 坝高 **>1%** → 应论证填筑标准合理性与工程措施（8.4.8） | 沉降过大未论证 |
| 不均匀沉降与裂缝（8.4.4） | 推算不均匀沉降量与梯度，判断裂缝可能性；分析塑性区、拉应力区、水力劈裂 | 只报总沉降、不判裂缝 |
| 有限元要求（8.4.2） | 1、2 级高坝及复杂软弱地基坝应采用**有限元**计算应力变形 | 该类坝仅用简化法 |
| 分期施工（9.1） | 均质坝、厚心墙坝应核算**合龙段施工期稳定性** | 漏合龙段 |

> **复算工具**：`python scripts/calc_dam_slope.py --level 2 --case normal --method bishop --calc 1.28`
> （自动查表 8.3.10、按 8.3.11 处理瑞典法折减，判满足/不满足）；
> 查抗剪强度试验方法：`python scripts/calc_dam_slope.py --mode test --stage drawdown --stress total --soil cohesive`

## 第 2 步　跨专业一致性校验（8 对）

**单块各自正确 ≠ 报告正确。** 逐对交叉校验，最容易被漏的一层。

| # | 交叉对 | 校验要点 / 典型错 |
|---|---|---|
| 1 | **工程级别 ↔ 洪水标准 ↔ 允许安全系数 ↔ 安全加高** | 级别是全部允许值的基准；级别与洪水标准不对应、或允许值用错行 → 全篇判据连锁错 |
| 2 | **坝顶高程 ↔ 设计/校核洪水位 ↔ 正常蓄水位 ↔ R+e+A** | 是否**四工况分别算、取最大值**（漏"正常蓄水位"工况最常见）；防浪墙顶与坝顶关系（5.3.4） |
| 3 | **防渗体顶部高程 ↔ 正常蓄水位 ↔ 表 5.5.3 超高** | 斜墙 / 心墙取值不同，混用即错 |
| 4 | **坝坡坡率 ↔ 稳定安全系数 ↔ 计算方法** | 坡率改了 K 未重算即不自洽；用瑞典圆弧法却套表 8.3.10 原值（未 ×0.92）即取值错 |
| 5 | **抗剪强度指标 ↔ 控制稳定时期 ↔ 试验方法** | 施工期 / 稳定渗流期 / 水位降落期各用哪套指标（表 D.1.1），用错即计算无效 |
| 6 | **坝体分区 ↔ 渗透系数 ↔ 反滤层设置** | 分区渗透性反序；防渗体与坝壳之间漏反滤层 |
| 7 | **坝基处理型式 ↔ 砂砾石层深度 ↔ 渗流控制效果** | 如深覆盖层误用浅防渗墙 |
| 8 | **报告内部同一参数前后一致** | 正文 / 表格 / 图 / 计算书 中的同一数值是否一致（最常见的低级错） |

> 自洽性优先用复算脚本验算，不靠眼看。凡报告给出数值结论（坝顶超高、坝坡安全系数、防渗体顶高…），
> 用 `calc_dam_crest.py` / `calc_dam_slope.py` 把关键中间量自己过一遍再判。
