# 河道工程报告审查 — 完整检查项清单

配套 `SKILL.md` 第 1 步"分块审查"使用。按 12 块展开，每条含 **判定标准** 与 **失败模式**。

> **引用约定见 `norms.md`**（条款号取法、限值出处、强条处置、版本声明）。本文件不再重复。
> 标 **★强条** 者为 `compulsory-clauses.md` 所列强制性条文。
> 数值限值见 `rc_tables.md`；章节结构见 `rc_works_tables.md`。

## 块 1　编制依据、工程任务与规模

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 编制依据现行性 | 法律法规、技术标准应为**现行有效版本**（GB 50707-2011、GB 50286-2013、SL 252-2017、GB 50201-2014、SL 17-2014 等） | 引用已废止版本 |
| 报告阶段 | 可研/初设/施工图/安全评价 与设计深度匹配（SL/T 618/619 编制规程） | 阶段错配、深度不足 |
| **工程任务** | 明确防洪、排涝、灌溉、航运、生态等**任务与主次** | 任务含混、遗漏 |
| **工程规模** | 整治河段起讫、长度、水面宽、设计流量、设计水位等**规模指标**完备 | 规模指标缺失 |
| 与规划一致性 | 与经审批的**防洪规划、排涝规划、航运规划、岸线利用规划**一致（★强条 GB 50707 4.1.3） | 与规划冲突 / 无规划依据 |
| 与主体/批复一致性 | 项目组成、规模与立项批复、流域规划一致 | 与批复不符 |

## 块 2　基本资料

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 气象水文 | 降水、蒸发、水位、流量、潮流；**水文系列**（一般 ≥30 年）代表性、可靠性、一致性 | 系列过短、资料缺失 |
| **设计洪水** | 按 SL 44 计算（或据经审批成果）；分河段/分频率给出 | 设计洪水无依据、频率混乱 |
| 工程地质 | 堤基分层、物理力学指标（c/φ、承载力、渗透系数）、**地质剖面**完整 | 地质剖面缺层、指标不足 |
| **河床演变** | 按 GB 50707 §6 + 附录 A 分析**冲淤变化趋势**、稳定性 | 无河床演变分析（整治方案的依据缺失） |
| 地形测量 | 带状地形图、横断面图，比例尺与间距满足（GB 50707 表 1/2） | 断面间距过大、比例尺不够 |
| 社会经济 | 保护对象（人口、耕地、城镇、重要设施）统计用于定防洪标准 | 未统计保护对象 → 判不了防洪标准 |
| 现有工程状况 | 现有堤防/护岸/建筑物状况、险工险段、历史险情 | 遗漏现有工程与险情 |

## 块 3　河道整治规划与治导线（GB 50707 核心块）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **整治原则** | 按 GB 50707 §7"典型河段整治原则"（顺直/弯曲/分汊/游荡河段各有原则） | 原则错配河型 |
| **治导线制定** | 宜分段制定；洪水治导线据设计泄洪流量，**有堤河段以堤线作为洪水治导线**；中水/枯水治导线合理（4.2） | 治导线与河势不符、与堤线矛盾 |
| **设计标准** | 防洪/排涝/灌溉/航运/岸线 标准**各有依据且相互协调**（★强条 4.1.3） | 标准间矛盾 / 无规划支撑 |
| 岸线利用 | 与岸线控制线、功能区一致（SL/T 826） | 侵占岸线功能区 |
| 整治方案比选 | 对上、下游、左右岸影响统筹；方案技术经济比选 | 无比选、顾此失彼 |

## 块 4　工程等别、建筑物级别与防洪标准

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **工程等别** | 按 SL 252 **表 3.0.1**（规模/效益/重要性）；综合利用取**最高等别**（★强条 3.0.1/3.0.2） | 等别定低 → 全篇连锁错 |
| **堤防级别** | 按保护对象防洪标准查 SL 252 **表 4.4.1** / GB 50286 **表 3.1.3**（★强条 SL 252 4.4.1） | 级别定低 |
| **防洪标准** | 城市/乡村/工矿分别按 GB 50201 防护等级取；涉行蓄滞洪区/重要设施按强条 5.0.4/6.x | 入口混用、标准偏低 |
| 其他建筑物级别 | 排水渠沟/渠系建筑物/泵站按 SL 252 表 4.5.1~4.5.3 | 级别与规模不匹配 |
| 洪水标准 | 设计/校核洪水按 SL 252 取值 | 校核标准乱套 |
| 复算 | 关键等别/级别用条文库表核对 | 报告称某级别而表不支持 |

## 块 5　河道水力计算与行洪能力

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 计算断面 | 断面选取代表性、间距合理、糙率有依据 | 糙率拍脑袋、断面不足 |
| **水面线** | 按 SL 104 / 能量方程推算，设计与校核工况齐全 | 只算一个工况、成果反常 |
| **行洪能力** | 整治前后各频率**过流能力**复核（用 `calc_channel_capacity.py` 曼宁复算） | 整治后行洪能力下降而未说明 |
| 河势与流速 | 流速是否在河床/护岸抗冲允许范围 | 流速过大冲刷、过小淤积 |
| 顶托/壅水 | 涉河建筑物壅水高度、回水长度 | 漏壅水分析 |
| 数值自洽 | 断面面积、水力半径、流量 前后一致 | 表与图/正文数值矛盾 |

## 块 6　堤线布置与堤型选择（GB 50286 §5）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **堤线布置** | 与河势流向、洪水主流线相适应；堤线**平顺连接**，不应采用折线或急弯；利用现有堤防和有利地形，留有滩地；两岸堤距按防洪规划分河段确定、上下游左右岸统筹（GB 50707 5.x） | 堤线折急弯、压缩行洪断面 |
| **堤型选择** | 按筑堤材料、地形地质、施工条件选土堤/防洪墙等 | 堤型与地质/材料不符 |
| 与治导线关系 | 堤线符合治导线与岸线控制线 | 与治导线矛盾 |

## 块 7　堤基处理（GB 50286 §6）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 堤基分类与处理 | 按清水/透水/多层/岩石堤基分别采取处理措施 | 处理措施与堤基类型不符 |
| **渗流控制** | 透水堤基渗流稳定、出口无管涌（允许水力比降 表 3.2.2） | 未做渗流稳定验算 |
| **垂直防渗** | 渗径不足时垂直防渗有效性（6.6） | 防渗设计缺依据 |
| 软弱层处理 | 软土/液化层处理（回填/加固） | 漏软基处理 |

## 块 8　堤身设计（GB 50286 §7，★含强条）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **堤顶高程** | = 设计洪水位(潮位) + 波浪爬高 R + 安全加高 A（7.3）；用 `calc_levee_crest.py` 复核 | 漏波浪爬高 / 安全加高取值错 |
| **安全加高 A** | 按表 3.2.1（不允许/允许越浪分列）；1 级重要堤段经论证可加大但 ≤1.5m | 越浪与否取值混用 |
| **堤顶宽度** | 1 级≥8m、2 级≥6m、3 级及以下≥3m（7.4.1） | 堤顶过窄，不满足防汛抢险 |
| **填筑标准** | 黏性土压实度（★7.2.4）/ 无黏性土相对密度（★7.2.5） | 压实度/相对密度低于强条值 |
| 堤坡与戗台 | 堤身较高时设戗台；坡率与堤高/土质/渗流匹配（7.5） | 未设戗台、坡率过陡 |
| **护坡与坡面排水** | 护坡型式与水流/风浪匹配；坡面排水（7.6） | 护坡型式不当、无排水 |
| **防渗与排水设施** | "上防下排"：临水侧防渗、背水侧导渗（7.7） | 防渗与排水脱节 |
| 防洪墙 | 墙型/稳定/基底处理（7.8），稳定见块 10 | — |

## 块 9　护岸与防护工程设计（GB 50286 §8 + GB 50707 §8.2）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **防护型式选择** | 按水流、波浪、潮汐特性及地形地质、施工、运用要求选**坡式/墙式/其他**（GB 50707 8.2.1/8.2.2） | 型式与水流条件不符 |
| **结构材料要求** | 坚固耐久、抗冲刷磨损；适应河床变形；便于施工修复；就地取材（8.2.3） | 材料抗冲不足 |
| **防护长度** | 据水流/波浪/潮汐及地形地质，在**河床演变分析**基础上定（8.2.4） | 长度拍脑袋、覆盖不足 |
| **稳定安全系数** | 按 GB 50707 **表 8.2.5**（坡式1.25/1.20、墙式1.25/1.50）；窄滩/无滩段按 GB 50286 取值（8.2.5） | 安全系数不足 |
| **护岸挡墙级别** | 按 SL/T 386 按所属建筑物级别 + 危害程度定 | 挡墙级别定低 |
| 生态护坡 | 在保证安全前提下采用生态型式（SL/T 879） | 只做硬防护不做生态 / 只做生态不做稳定 |
| 复算 | 用 `calc_revetment.py` 复核稳定安全系数与护面块体 | 报告称满足而实际不足 |

## 块 10　稳定与渗流计算（GB 50286 §9）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **边坡抗滑** | 瑞典圆弧法/简化毕肖普法；正常/非常I/非常II 三工况（表 3.2.3） | 只算一种工况、漏地震（非常II） |
| **防洪墙抗滑** | 岩基/土基 × 级别 × 工况（表 3.2.5） | 地基性质与取值不匹配 |
| **地基承载力** | 松软/中等坚实/坚实 × 基本/特殊组合（表 3.2.6） | 承载力验算缺失 |
| **抗倾覆** | 岩基防洪墙抗倾覆（表 3.2.7） | 漏抗倾覆（GB 50286 §9 新增内容） |
| **非常运用条件** | 非常I=施工期；非常II=多年平均水位遭遇地震（9.2.2） | 工况定义错 |
| 软弱地基降值 | 需**论证并报行业主管部门批准**（3.2.4） | 自行降值无说明 |
| 渗流稳定 | 出口渗透稳定、允许水力比降（表 3.2.2） | 未做渗流验算 |

## 块 11　清淤疏浚（SL 17）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 疏浚范围与断面 | 平面位置、开挖边线、**坡比按土质类别**（SL 17 表 4） | 坡比与土质不符、边坡过陡 |
| **超深超宽** | 按船型查 SL 17 表 23（计算/最大允许值） | 超深超宽超限 |
| 工程量与弃土 | 断面法/平均高程法计量；**弃土去向**明确、合规 | 弃土去向不明/乱抛 |
| 吹填（如涉） | 吹填区围堰、排水沟渠**超高**（表 10）、流失率、固结沉降 | 无围堰/超高不足 |
| **施工安全环保** | 安全护栏/警示（★5.7.6）、油污防护预案（★5.7.7）、船机证书与作业条件（★5.7.9）、**严禁垃圾油水直排**（★5.7.13） | 违反环保/安全强条 |
| 复算 | 用 `calc_dredge.py` 复核断面工程量与超深超宽 | — |

## 块 12　工程管理、监测与生态护坡

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **管理范围** | 护堤地宽度（GB 50286 表 13.2.2）+ 保护范围宽度；与 SL/T 852 划界一致 | 管理范围不足 |
| **安全监测** | 按 GB 50286 §12 设必要监测设施（原则：有效、可靠、牢固、方便、经济） | 漏监测设计 |

## 第 2 步　跨专业一致性校验（8 对）

**单块各自正确 ≠ 报告正确。** 逐对交叉校验，最容易被漏的一层。

| # | 交叉对 | 校验要点 / 典型错 |
|---|---|---|
| 1 | **保护对象 ↔ 防洪标准 ↔ 工程等别/级别** | 防洪标准由保护对象（人口/耕地/城镇/设施）定 → 堤防级别 → 断面/加高/稳定取值；标准定错则全篇连锁错 |
| 2 | **设计洪水 ↔ 水面线 ↔ 堤顶高程** | 设计洪水位是堤顶高程的基础；水位算错 → 堤顶高程、超高、越浪判断全错 |
| 3 | **治导线 ↔ 堤线布置 ↔ 护岸布置** | 堤线与岸线控制线应服从治导线；三者矛盾必有一错 |
| 4 | **堤防级别 ↔ 安全加高 ↔ 堤顶宽度 ↔ 稳定安全系数** | 级别是这些取值的共同基准（表 3.2.1/3.2.3/3.2.5/3.2.7 链式取值） |
| 5 | **堤基类型 ↔ 处理措施 ↔ 渗流计算 ↔ 防渗排水布置** | 堤基分类 → 处理措施 → 渗流验算 → 上防下排，须一条链自洽 |
| 6 | **断面几何 ↔ 坡率 ↔ 稳定安全系数** | 报告给的断面/坡率应能算出其声称的安全系数（用复算脚本验算） |
| 7 | **河床演变 ↔ 冲刷深度 ↔ 护岸/护脚基础埋深** | 演变分析的冲淤结论应支撑护岸基础埋深，不能各说各话 |
| 8 | **报告内部同一参数前后一致** | 正文 / 表格 / 图 / 计算书 中同一数值（设计水位、流量、堤顶高程、级别、工程量）是否一致 |

> 自洽性优先用复算脚本验算，不靠眼看。凡报告给出数值结论（安全系数、堤顶高程、过流能力、工程量），
> 用 `calc_levee_crest.py` / `calc_channel_capacity.py` / `calc_revetment.py` / `calc_dredge.py` 把关键中间量自己过一遍再判。
