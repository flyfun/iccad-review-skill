## 二、输入 / 解析边界

- **docx 表格可自助提取**：`scripts/extract_docx_tables.py`（**网格重建**，正确处理横向 gridSpan / 纵向 vMerge 合并单元格）
  ——把堤防断面表 / 工程量表 / 疏浚断面表 / 稳定计算成果表还原成可核对的二维表；正文段落用 `--text-only`。
  **PDF / 扫描件不在本技能内**，须另用 OCR / PDF 工具。
- **报告没写的，判不了**：缺设计洪水、缺堤基地质、缺断面/坡率、缺稳定计算 → 只能出"深度不足"的发现，判不了对错。
- **附图/影像无法自动审**：带状地形图、横断面图、地质剖面图、治导线图、总体布置图须**人工看图**核对。
- **报告是"堤防"还是"小流域治理方案"要先判**：若报告的实质是**水土保持重点工程实施方案**（小流域综合治理），
  属水土保持技能范围，本技能只对其中的 GB 50286/GB 50707 技术模块可用（见"边界"）。

## 五、复算脚本的能力边界（4 个）

1. `calc_levee_crest.py`：按 `堤顶高程 = 设计水位 + 波浪爬高 R + 安全加高 A` 复算。
   **安全加高 A 按 GB 50286 表 3.2.1**（按级别 + 越浪/不越浪）；**波浪爬高 R** 可直接输入，或用简化式（需 H/R0 等参数）；
   `R0` 无风爬高若缺参数须查附录 C 图/公式——脚本给出提示而不臆造。
2. `calc_channel_capacity.py`：按**曼宁均匀流**复算过流能力 / 反求水深。
   **糙率 n 用参考值（脚本内 `N_REF`，非规范强制）**，实际取值须依报告 / 专业判断。
3. `calc_revetment.py`：按 GB 50286 表 3.2.3/3.2.5/3.2.6/3.2.7 与 GB 50707 表 8.2.5 **机械比对**报告给出的稳定安全系数；
   并可按 Hudson 公式算护面块体重量/粒径（`K_D` 按表 27）。**主动土压力、结构配筋、边坡内部稳定**需专业软件/人工。
4. `calc_dredge.py`：按 SL 17 复算疏浚断面面积与工程量、超深超宽允许值、坡比建议。
   **断面几何、土质类别、弃土去向仍须人工从报告摘取**。
5. 脚本不代算：二维水流/泥沙数学模型、河床演变定量预测、三维渗流、结构有限元——这些需专业软件。

## 六、判定责任边界

- 本技能产出的是**审查发现**，不是审批结论；最终判定责任在人，**AI 结论须经复核**。
- 河道整治工程涉**行政审批/规划符合性**（★强条 4.1.3 即要求"符合经审批的规划"），
  本技能只提供技术审查辅助，**不替代规划符合性审查与行政审批程序**。
