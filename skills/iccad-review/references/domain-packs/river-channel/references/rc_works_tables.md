## 二、关键构造与设计要求（正文条文索引，用关键词召回）

| 主题 | 出处 | 要点 |
|---|---|---|
| **堤顶高程** | GB 50286 7.3 | = 设计洪水位(潮位) + 波浪爬高 + 安全加高；**不允许越浪**按此；**允许越浪**须验算越浪量并防护 |
| **波浪爬高** | GB 50286 附录 C.3 | m=1.5~5.0 且 H/L≥0.025 用公式；m≤1.0 用 `Rp=KΔ·Ky·Kp·R1%·H`；爬高累积频率：**不允许越浪取 1%**，允许越浪宜取 2% |
| **堤顶宽度/堤顶结构** | GB 50286 7.4 | 1级≥8m、2级≥6m、3级及以下≥3m；堤顶横坡 2%~3%；防浪墙净高≤1.2m |
| **堤坡与戗台** | GB 50286 7.5 | **1、2 级土堤堤坡不宜陡于 1:3**；堤高>6m 背水侧宜设戗台、宽≥1.5m；消浪平台宽=1~2 倍设计浪高且≥3m |
| **护坡与坡面排水** | GB 50286 7.6 | 砂石垫层≥0.1m；排水孔 50~100mm、孔距 2~3m；基座埋深≥0.5m、封顶宽 0.5~1.0m |
| **防渗与排水设施** | GB 50286 7.7 | "上防下排"；临水侧防渗、背水侧导渗 |
| **筑堤材料与填筑** | GB 50286 7.2 | **压实度（★强条 7.2.4）**：1级≥0.95 / 2级及堤高≥6m的3级≥0.93 / 堤高<6m的3级及以下≥0.91；**相对密度（★强条 7.2.5）**：同上口径 ≥0.65 / ≥0.60；石渣料固体体积率>76% |
| **护岸工程设计** | GB 50286 8 | 坡式护岸：砌石厚 0.25~0.30m、抛石护脚坡度缓于 1:1.5、枯水平台高 0.5~1.0m；坝式（丁坝）：顶宽/坡度/间距见 `rc_tables.md` 五；墙式变形缝 10~20m |
| **堤防稳定计算** | GB 50286 9 | 渗流与渗透稳定（9.1）、抗滑与抗倾（9.2）、沉降（9.3）；三工况见 `rc_tables.md` 二 |
| **交叉建筑物** | GB 50286 10.1.3（★强条） | 与堤防交叉/连接的各类建筑物应做**洪水影响评价**，不得影响堤防管理运用和防汛安全 |
| **治导线** | GB 50707 4.2 | 宜分段制定；洪水治导线据设计泄洪流量，有堤河段**以堤线作为洪水治导线** |
| **防护工程型式** | GB 50707 8.2 | 坡式/墙式/其他；**坚固耐久、抗冲刷磨损、适应河床变形、便于施工修复、就地取材** |
| **防护工程长度** | GB 50707 8.2.4 | 据水流、波浪、潮汐特性及地形地质，在**河床演变分析**基础上确定 |
| **河床演变分析** | GB 50707 6 + 附录 A | 冲淤变化过程分析（整治工程规模依据） |
| **疏浚断面与坡比** | SL 17 §4 | 土质类别定坡比（见 `rc_tables.md` 八） |
| **岸坡生态治理** | SL/T 879 | 生态护坡型式、植物措施；兼顾稳定与生态 |
| **管理范围与保护范围** | GB 50286 13.2 / SL/T 852 | 护堤地宽度 + 保护范围宽度 |

## 三、河道整治工程典型审查主线（判据落点）

```
河道整治工程报告
 ├─ 工程规模/等别 ── SL 252 表3.0.1（防洪保护人口/农田/治涝面积…）
 ├─ 建筑物级别 ── SL 252 表4.2.1/4.4.1（堤防级别按防洪标准）
 ├─ 防洪标准 ── GB 50201（城市/乡村/工矿防护等级）＋ GB 50707 4.1.3（须符合经审批防洪规划）
 ├─ 治导线/整治原则 ── GB 50707 §4.2/§7（典型河段整治原则）
 ├─ 水面线/行洪能力 ── SL 104 ＋ calc_channel_capacity.py（曼宁）
 ├─ 堤顶高程 ── GB 50286 7.3 ＋ calc_levee_crest.py（设计水位+爬高+安全加高）
 ├─ 断面/边坡/护坡 ── GB 50286 §7.5/7.6 + SL 17 坡比
 ├─ 稳定 ── GB 50286 表3.2.3/3.2.5/3.2.6/3.2.7 ＋ calc_revetment.py
 ├─ 护岸/防护工程 ── GB 50707 8.2 表8.2.5
 ├─ 清淤疏浚 ── SL 17 断面/超深超宽 ＋ calc_dredge.py
 └─ 生态护坡 ── SL/T 879
```
