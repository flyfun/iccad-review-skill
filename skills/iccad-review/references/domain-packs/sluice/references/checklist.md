## 块 1　设计标准与特征水位

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 工程级别 | 按 SL 252 依规模、效益、重要性综合定，不得只按单一指标 | 级别定低 → 后续所有容许安全系数用错 |
| 洪水标准 | 按 GB 50201 依级别 + 工程类型取设计/校核标准 | 混用"设计"与"校核"标准 |
| 特征水位齐备性 | 正常蓄水位/设计洪水位/校核洪水位/检修水位/最低运行水位/最高（通航）水位 等按功能列全 | 缺检修水位 → 抗浮工况漏算 |
| **闸顶高程**（SL 265 **4.2.4**） | 挡水：≥ 正常蓄水位/最高挡水位 + 波浪计算高度 + 安全加高；泄水：≥ 设计/校核洪水位 + 安全加高；**两工况取大值**。配套 **4.2.5**（防洪挡潮堤上水闸 ≥ 堤顶高程）、**4.2.6**（软基沉降等） | 单工况取值、漏波浪或超高 → 高程不足 |
| 挡潮闸特殊项 | 潮位组合、**双向水头**（挡潮 + 排涝/引水） | 只按单向算 → 反向工况失稳 |

> **复算工具**：`python scripts/calc_crest.py`。命令行给水位，脚本按 **4.2.4** 取挡水/泄水两工况大值、
> 查**表 4.2.4** 取安全加高，并叠加 **4.2.5**（堤顶高程）/ **4.2.19**（露顶闸门门顶 +0.3m）/
> **4.2.22**（桥梁梁底 ≥ 最高洪水位 +0.5m）约束后取大值；传 `--reported` 自动判满足/不满足。
> 例：`--level 1 --zw-design 123.0 --zw-check 123.4 --bridges "工作桥:1.10,交通桥:0.90" --reported 125.0`
> （2013C5 真题，标准答案 125.00m，脚本实测一致）。
> **4.2.6** 的软弱地基沉降、河道变化、堤顶加高为定性因素，须人工判断，脚本不量化。

## 块 2　闸址与总体布置　（深挖 → `sluice-layout-and-flow`）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 闸址比选 | 地形/地质/水流/潮汐/冻土/冰情/施工/管理/环境 多维技术经济比较，**不得单因子拍板** | 只比地形或只比造价 |
| 闸址硬约束 | 河床稳定、河岸坚固；拦河闸宜在河道直线段 | 选在弯道/冲刷段 |
| 拦河闸走向 | 中心线与河道**中泓线吻合**；上下游直线段均不宜短于 5 倍进口水面宽 | 斜交 → 偏流 |
| 排水闸交角 | 中心线与下游排水河道中泓交角为锐角，宜 <60° | 交角过大 → 下游淤积/冲刷 |
| 引水闸引水角 | 当过闸落差 >0.2m 时引水角 ≤30° | 引水角过大 → 入流不平顺 |
| **闸孔数** | <8 孔宜取**奇数**，中泓居中；多孔均匀对称开启 | 偶数孔且不对称开启 → 偏流 → 局部冲刷 |
| 翼墙角度 | 上游收缩角每侧 ≤18°；下游扩散角每侧 7°~12° | 超限 → 水流脱壁、折冲 |
| 结构型式 | 开敞式/涵洞式按挡水高度与运用条件；整体式/分离式按地基（中等密实/软弱宜整体式，坚实或桩基大中小型宜分离式） | 软基误用分离式 |
| 成套布置 | 消能、防渗、排水、连接建筑物**成套**，不能只画闸室 | 只画闸室、缺连接段 |

## 块 3　过流能力与闸孔规模　（深挖 → `sluice-layout-and-flow`）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 流态判别 | 按闸门开度与上下游水位关系判别堰流/孔流，不得混用公式 | 用堰流公式算孔流工况 |
| 过流能力 | 各工况（设计、校核、非常运用）过流能力 ≥ 要求泄量 | 只算设计工况 |
| 单宽流量 | 不超限；**消力池出口单宽流量 ≤1.5 倍渠道平均单宽流量**（手册经验值） | 出口单宽流量过大 → 下游冲刷 |
| 复算 | `python scripts/calc_hydraulics.py --mode q --Q <流量> --B <宽度>` 或 `--mode outlet --q-outlet <出口> --q-channel <渠道均值>` | 只照抄报告结论不复算 |
| 底板横向宽度 | 垂直水流向宽度：**土基 ≤35m、岩基 ≤20m**（超限须分块并说明） | 超限未分块 |
| 规模匹配 | 闸孔规模与下游河道/渠道输水能力、上游来水相匹配 | 闸大渠小 → 下游冲刷 |

## 块 4　消能防冲　（深挖 → `sluice-layout-and-flow` / `energy-dissipation-design`）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 消能方式 | 默认**底流式**；尾水深且变化小 + 河床岸坡抗冲强 → 面流式；高水头 + 坚硬岩体 → 挑流 | **脱离下游尾水/地质谈消能方式** → 消能失败 |
| 消力池型式 | 尾水深 < 跃后水深 → 下挖式；略小 → 突槛式；远小且池深大 → 综合式 | 型式与尾水条件不匹配 |
| 消力池尺寸 | 深度一般 1.0~3.0m；连接斜坡 1:3~1:5（手册经验值） | 池深不足 → 二次冲刷 |
| 共轭水深核算 | 必须给出计算过程，检验是否满足。复算：`python scripts/calc_hydraulics.py --mode jump --q <单宽流量> --h1 <收缩水深>`（矩形断面 h2=h1/2·(√(1+8Fr1²)−1)）；消力池深 `--mode pool`、海漫长度 `--mode apron` | 只给结论无计算；梯形断面误用矩形公式 |
| 辅助消能工 | **Fr > 4.5 且 流速 > 16 m/s 时不得设消能墩**（手册经验值） | 超限仍设墩 → 空蚀/破坏 |
| 下游防冲 | 海漫、防冲槽、护坡长度与下游流速匹配 | 海漫过短 |

## 块 5　防渗排水　（深挖 → `sluice-seepage-stability-structure`）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 地下轮廓 | 是**折线路径（"线"不是"面"）**：铺盖 + 底板 + 板桩 + 齿墙构成 | 当"面"处理 → 渗流计算错 |
| 防渗长度 | **折算总长 ≠ 铺盖长度**（水平段/垂直段折算系数不同） | **拿铺盖长度当防渗长度 → 抗渗误判** |
| 布置原则 | **上防下排**：上游铺盖/板桩/齿墙/帷幕；下游排水孔/减压井/反滤 | 排水口置于上游 → 扬压力偏大 |
| 铺盖尺寸 | 长 = 2~4 倍水头；厚按 ΔH/J（黏土 J=4~8、壤土 3~5），前端 ≥0.5m、向闸室加厚至 1.0~1.5m（手册经验值） | 铺盖过短 |
| 渗流校核 | 求渗透压力/坡降/流速；**实际坡降 ≤ 容许坡降**，出口设反滤盖重 | 坡降超限未改轮廓 |
| 渗透变形 | 非黏性土可能管涌 + 流土；**黏性土只可能流土** | 判错变形类型 → 反滤设计错 |
| 分缝止水 | 沉降不同处设缝；防渗缝设止水；铅直止水距临水面 0.2~0.5m | 止水位置不当 |
| 侧向绕渗 | 挡潮/排涝闸须考虑**侧向绕渗与双向排水** | 只算纵向渗流 |

## 块 6　稳定分析　（深挖 → `sluice-seepage-stability-structure`）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 荷载组合 | 基本组合 / 特殊组合，**以水位为组合条件取最不利**；双向水头取最不利组合 | 组合漏工况（检修、校核、地震） |
| 抗滑 | **表层滑动控制**；容许 K 按**表 7.3.13（土基）/ 表 7.3.14（岩基）**依级别 + 组合取——**此两条均为强制性条文**。土基：基本组合 **1.35/1.30/1.25/1.20**（1/2/3/4·5 级）、特殊组合I **1.20/1.15/1.10/1.05**、特殊组合II **1.10/1.05/1.05/1.00**；岩基（按 7.3.6-1）**1.10/1.08/1.05**，岩基抗剪断（按 7.3.8）**3.00/2.50/2.30**。公式分**抗剪（f 法）**与**抗剪断（φ、C 按表 7.3.11 折算）** | 用错公式 / 用错级别或组合；岩基用土基容许值（**违反强条**） |
| **抗浮**（SL 265 **7.3.16**） | 基本组合 **≥1.10**、特殊组合 **≥1.05**，**与级别和地基无关**；检修抽空工况常控制 | **漏算检修抽空工况 → 上浮破坏** |
| 基底应力 | 最大/最小应力、不均匀系数在容许范围 | 应力不均导致倾斜 |
| 抗滑不足措施 | 移闸门位置 / 增大结构尺寸 / 加深齿墙 / 加阻滑板 | **只加长铺盖** → 未触及滑动面，抗滑仍不足 |

> 抗滑与抗浮是**两个不同的验算**，分母不同（抗滑含扬压力削减的有效重量），**不可混算**。
>
> **复算工具**：`python scripts/calc_stability.py`（`--mode sliding / float / bearing`）。
> 例：`--mode sliding --level 3 --combo basic --sum-g 60000 --sum-h 15000 --f 0.35`（土基抗剪）；
> `--mode float --sum-v 38000 --sum-u 33000`（抗浮）。限值由脚本按级别/组合内联查表，
> 与 `references/sluice_tables.md` 一致。

## 块 7　结构设计与地基处理　（深挖 → `sluice-seepage-stability-structure`）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 底板内力算法 | 横向截条 + 弹性地基梁；**砂土相对密度 ≤0.50 → 反力直线分布法**；**黏性土或砂土 >0.50 → 弹性地基梁法** | 算法与地基类型不匹配 |
| 闸墩应力模型 | 平面闸门按固结底板悬臂梁；弧形闸门按三边自由弹性板；大型宜有限元 | 模型选错 |
| 有限元 | 岩基线弹性；土基/深厚覆盖层弹塑性（D-P 或 M-C）；底板—地基用接触单元 | 土基用线弹性 |
| 地基设计 | 整体稳定 + 沉降计算（**岩石/砾石卵石/中粗砂免算沉降**）；走**"天然地基→适应性措施→地基处理"三级递进** | 直接上桩 |
| 桩型 | 土基桩基**一般摩擦型优先** | **端承型桩 → 底板脱空 → 接触冲刷** |

## 块 8　闸门、启闭机与金属结构　（深挖 → `gate-*`）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 门型与工况 | 工作门（动水启闭）/事故门（动闭静启）/检修门（静水启闭）分工明确 | 门型与运用方式错配 |
| 启闭力 | **必须同时算闭门力、持住力、启门力三项**；结果为正要加重、为负靠自重关闭 | 只算启门力 → 启闭机选型错 |
| 启闭机选型 | 与启启闭力/行程/扬程匹配 | 容量不足 |
| 支承与止水 | 支承型式、止水装置与门型匹配 | — |
| 耐久性 | 防腐蚀按环境分区选方案；防冰冻；抗震；拦污栅（过栅流速一般 0.8~1.2 m/s，一栅一槽） | 漏环境防护 |
| 孔口尺寸联动 | 闸门孔口尺寸 ↔ 闸孔尺寸 ↔ 启闭力 三者一致 | 改动未回溯 |

## 块 9　安全监测　（深挖 → `rubber-dam-and-special-sluice` / `monitoring-*`）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 项目齐备性 | 由"结构特点 → 失稳模式 → 控制因素 → 必测项目"反推，不缺项（变形/渗流/应力/扬压力/水位等） | 只做变形，漏渗流/扬压力 |
| 测点布置 | 关键/重要/一般三层，冗余集中关键部位；用代表性断面而非等间距铺开 | 平均用力、关键部位欠布 |
| 仪器选型 | 过四条硬门槛（耐久性一般 ≥15 年、可靠性、适用性、经济性）；量程与精度量级配对 | 量程/精度不匹配 |
| 频次 | 跟随**变化速率**（阶段 + 触发式加密：高水位、骤降、地震、异常） | 固定周期不加密 |
| 巡视检查 | 与仪器监测并重的独立通道 | 只依赖仪器 |
| 自动化 | 首要判据是"**有没有让异常更快被发现**"，不是省人 | 为自动化而自动化 |

## 第 2 步　跨专业一致性（最容易被漏的一层）

单块各自正确 ≠ 报告正确。**逐对交叉校验**，共 7 对：

| # | 校验对 | 怎么校 | 失败模式 |
|---|---|---|---|
| 1 | **闸孔总宽 ↔ 底板分块 ↔ 单宽流量限值** | 总宽 / 块数 是否落在限值内（土基底板横宽 ≤35m、岩基 ≤20m） | 总宽超限未分块，或分块后单块仍超限 |
| 2 | **消力池尺寸 ↔ 下游水位-流量关系 ↔ 共轭水深** | 复算 `calc_hydraulics.py --mode jump/pool`；消力池选型与出口单宽流量（≤1.5 倍渠道均值）是否自洽 | 池深与尾水条件矛盾 |
| 3 | **防渗长度 ↔ 水头差 ↔ 出口坡降** | 判据用"防渗长度"（折算总长）还是"铺盖长度"（会误判）；出口坡降 ≤ 表 6.0.4 容许值 | 拿铺盖长度当防渗长度 |
| 4 | **抗滑安全系数 ↔ 扬压力 ↔ 有效重量** | 复算 `calc_stability.py --mode sliding`；抗滑不足时报告措施是"加长铺盖"（只控渗流）还是"加深齿墙/加阻滑板"（触及滑动面） | 抗滑不足却只加长铺盖 |
| 5 | **闸顶高程 ↔ 设计/校核水位 + 浪高 + 超高** | 复算 `calc_crest.py`；挡水/泄水两工况是否分别取、取大值；并核 4.2.5 堤顶 / 4.2.19 露顶闸门 / 4.2.22 桥梁附加约束 | 单工况取值、漏波浪或超高 |
| 6 | **闸门孔口尺寸 ↔ 闸孔尺寸 ↔ 启闭力** | 三者联动核对；任一处改动未回溯另两处 | 提资错误 |
| 7 | **报告内部同一参数前后一致** | 正文 / 表格 / 图 / 计算书 中同一数值比对（闸顶高程、底板宽、孔数、特征水位、安全系数） | 最常见的低级错 |

> 自洽性**优先用复算脚本验算，不靠眼看**。校验所需的限值查 `sluice_tables.md`，
> 条款号走 `spec_lookup.py`，纪律见 `norms.md` §四。
