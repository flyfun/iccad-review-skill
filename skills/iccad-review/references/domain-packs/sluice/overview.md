# 水闸工程报告审查

## 这个 Skill 是什么

**审查编排层**，不是设计知识卡。

- 它不解释"水闸怎么设计"——那是 `sluice-*` / `gate-*` 领域技能的职责。
- 它回答的是：拿到一份水闸报告，**按什么顺序查、查哪些点、每条怎么判、依据谁、怎么输出**。
- 它也不替代规范库：**任何条款号都必须从规范库核对**，本技能不硬编码条文。

## 何时用 / 不适用

**用**：手里有一份水闸工程报告（可研 / 初设 / 施设 / 安全评价），要从设计合理性、规范合规性、专业间一致性三个角度出审查发现。

**不用**：单点设计问题（直接调 `sluice-layout-and-flow` 等设计技能）；纯条文查询（走规范库）；
报告主体不是水闸（纯坝工、灌区、河道整治）；土石坝专项（走 `earth-dam-report-review`）。

## 审查总流程

```
报告文本 (docx/pdf)
   │
   ├─[第0步]   前置判定 ── 报告类型 / 水闸功能 / 地基类型 / 工程等级与洪水标准
   │
   ├─[第0.5步] 取判据 ── spec_lookup.py 调条文 + sluice_tables.md 查限值 + calc_*.py 复算
   │
   ├─[第1步]   分块审查（10 块）── 每块：查什么 → 判定标准 → 依据技能
   │
   ├─[第2步]   跨专业一致性 ── 布置↔过流↔消能↔防渗↔稳定↔结构 数值是否自洽
   │
   └─[第3步]   结构化发现 ── 位置 / 问题 / 依据 / 严重度 / 修改建议
```

**每一步该翻哪一册，见该步末尾的 ▶ 载入。**

---

## 第 0 步：前置判定

**先定这四样，再翻正文。** 同一处做法在不同前提下判定完全不同——软基上"底板分块"是必需，岩基上就未必。

| 判定项 | 常见取值 | 对审查的影响 |
|---|---|---|
| **报告类型** | 可研 / 初设 / 施工图 / 安全评价 / 蓄水安全鉴定 | 可研重方案比选；初设重设计深度与计算书；施设重构造与施工；安全评价重现状检测与复核 |
| **水闸功能** | 拦河 / 进水 / 排水 / 挡潮 / 引水 / 分洪 | 挡潮闸必查**双向水头与双向排水**；排水闸查与下游中泓交角（宜 <60°）；引水闸查引水角（落差 >0.2m 时 ≤30°） |
| **地基类型** | 土基 / 软基（淤泥、粉砂）/ 岩基 | 软基必查地基处理、抗滑、底板分块；岩基查帷幕灌浆与抗剪断指标 |
| **等级与洪水标准** | 工程级别（SL 252）+ 洪水标准（GB 50201） | **容许安全系数随级别变化**，级别定错则后续判据全错 |

> 判不出这四样 → 报告基本资料有缺项，本身就是一条 ○ 级发现。

## 第 0.5 步：取判据（别跳过）

判定标准有三个来源，**不可混用**：

| 来源 | 怎么取 | 怎么写进意见 |
|---|---|---|
| **规范条文** | `python scripts/spec_lookup.py --spec "SL 265" --q 关键词` | 引条款号（如"违反 SL 265 4.2.4"） |
| **规范限值表** | `references/sluice_tables.md`（SL 265 原文表） | 引条款号 + 表号 |
| **手册经验值** | `hydro-design-handbook` / `references/checklist.md` | 写"手册推荐"，**不写"违反规范"** |

取不到条文的判定项 → 标"依据待核"，只出疑点、不出结论。

**能算的不要只靠看** —— 凡报告给出数值结论（抗滑 K、抗浮 Kf、基底应力、共轭水深、消力池深、单宽流量…），用复算脚本把关键中间量自己过一遍：

| 脚本 | 覆盖 |
|---|---|
| `scripts/calc_stability.py` | 抗滑 / 抗浮 / 基底应力（按级别·组合查表判定） |
| `scripts/calc_hydraulics.py` | 单宽流量 / 共轭水深 / 消力池深 / 海漫 / 出口流量判据 |
| `scripts/calc_crest.py` | **闸顶高程**（挡水·泄水取大值 + 安全加高查表 4.2.4 + 桥梁 4.2.22 / 堤顶 4.2.5 / 露顶闸门 4.2.19） |

> ▶ **载入**：`references/norms.md` §一（取条文方法、数据源、脚本用法）。
> 公式来源与脚本限制见 `references/limits.md` §三 / §六。

## 第 1 步：分块审查（10 块）

**深挖时不要在本技能里硬推，转到对应领域技能。**

| # | 审查块 | 重点查什么 | 依据技能 |
|---|---|---|---|
| 1 | **设计标准与特征水位** | 工程级别、洪水标准、特征水位（正常/设计/校核/检修）、闸顶高程 | SL 252 / GB 50201 |
| 2 | **闸址与总体布置** | 闸址比选、中心线与中泓关系、交角、闸孔数奇偶与对称开启、翼墙收缩/扩散角 | `sluice-layout-and-flow` |
| 3 | **过流能力与闸孔规模** | 堰流/孔流判别、各工况过流能力、单宽流量限值、底板横宽限值 | `sluice-layout-and-flow` |
| 4 | **消能防冲** | 消能方式与下游条件绑定、消力池型式选型、共轭水深核算、辅助消能工上限、下游防冲 | `sluice-layout-and-flow` / `energy-dissipation-design` |
| 5 | **防渗排水** | 地下轮廓（线不是面）、防渗长度折算 ≠ 铺盖长度、上防下排、出口坡降与反滤、分缝止水 | `sluice-seepage-stability-structure` |
| 6 | **稳定分析** | 荷载最不利组合、抗滑（按级别取容许值）、抗浮（≥1.10/1.05）、基底应力 | `sluice-seepage-stability-structure` |
| 7 | **结构设计与地基处理** | 底板内力算法选型、闸墩应力模型、地基三级递进、桩型选择 | `sluice-seepage-stability-structure` |
| 8 | **闸门、启闭机与金属结构** | 门型与工况匹配、启闭力三项、启闭机选型、支承止水、防腐蚀 | `gate-*` 系列 |
| 9 | **安全监测** | 项目齐备性、测点布置、仪器选型、频次、自动化 | `rubber-dam-and-special-sluice` / `monitoring-*` |
| 10 | **施工组织与温度控制** | 施工导流、基坑排水、温控（最大拉应力 ≤ 容许抗拉强度）、分块分缝 | `sluice-seepage-stability-structure` |

> ▶ **载入**：`references/checklist.md` §第 1 步（10 块逐条展开：判定标准 + 失败模式）。
> **动手查之前先读它**，可按块号只读当前块。

## 第 2 步：跨专业一致性（最容易被漏的一层）

单块各自正确 ≠ 报告正确。共 **7 对交叉校验**（闸孔总宽↔底板分块↔单宽流量、
消力池尺寸↔下游水位-流量↔共轭水深、防渗长度↔水头差↔出口坡降、抗滑↔扬压力↔有效重量、
闸顶高程↔设计/校核水位+浪高+超高、闸门孔口↔闸孔↔启闭力、报告内部数值一致）。

> ▶ **载入**：`references/checklist.md` §第 2 步（7 对逐条展开）。
> 自洽性优先用复算脚本验算，不靠眼看。

---

## 第 3 步：结构化发现

| 序号 | 位置 | 问题描述 | 判定依据 | 严重度 | 修改建议 |
|---|---|---|---|---|---|
| 1 | 第X章 X.X 节 | …… | SL 265 第x.x条 / 表x.x.x / 复算结果 | ★/●/○ | …… |

**严重度分级**
- **★ 严重**：违反**强制性条文**、或影响工程安全（抗浮漏算检修工况、防渗长度误判）
- **● 重要**：不符合规范推荐做法、或明显不合理（偶数闸孔未论证、桩型误选端承）
- **○ 一般**：表述不清、深度不足、专业间不一致、图文不符

## 引用纪律（硬规则）

**下判断前先读** `references/norms.md` §四（引用纪律 7 条）+ §五（易踩的坑）——唯一权威定义，本入口不重复。

> 唯一不能忘的一条：**条款号与限值一律取自工具 / 固化表，不凭记忆写**。

## 边界

- 单点设计问题 → 直转对应设计技能，别绕本技能。
- 橡胶坝 / 立交涵闸 / 翻板闸等特殊闸型 → `rubber-dam-and-special-sluice`。
- 土石坝 → 走 `earth-dam-report-review`（本技能不含）。
- 本技能产出的是**审查发现**，不是设计成果；最终判定责任在人，AI 结论须经复核。

> ▶ **载入**：`references/limits.md`（边界与已知局限：覆盖、解析、公式来源、版本、脚本能力、判定责任）。
