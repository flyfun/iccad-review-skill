# 水资源论证报告审查

## 这个 Skill 是什么

**审查编排层**，不是设计知识卡。回答：拿到一份水资源论证报告，**按什么顺序查、查哪些点、
每条怎么判、依据谁、怎么输出**。条款号、限值一律从条文库 / 固化表核对，**不硬编码**。

## 何时用 / 不适用

- **用**：有一份**建设项目水资源论证报告书**（申请取水的新建/改建/扩建项目；可研、初设、取水许可阶段）。
- **不用**：洪水影响评价（`flood-impact-report-review`）、水闸（`sluice-report-review`）、
  泵站（`pump-station-report-review`）、河道堤防（`river-channel-report-review`）、
  土石坝（`earth-dam-report-review`）、水土保持方案（`soil-conservation-report-review`）、
  规划水资源论证、水资源评价（非取水许可）、纯水质监测、纯供水工程设计。

## 审查总流程

```
水资源论证报告 (docx)
 ├─[0]   前置判定 ── 报告类型 / 水源 / 行业 / 规模 / 等级 / 水平年
 ├─[0.5] 取判据 ── spec_lookup 调条文 + 固化限值表 + calc_*.py 复算
 ├─[1]   分块审查（12 块）── 查什么 → 判定标准 → 依据
 ├─[2]   跨结构一致性（9 对）── 数值链自洽
 └─[3]   结构化发现 ── 位置 / 问题 / 依据 / 严重度 / 建议
```

**每步该翻哪册见该步末尾 ▶ 载入。**

## 第 0 步：前置判定

| 判定项 | 取值 | 判错会怎样 |
|---|---|---|
| **报告类型** | 建设项目水资源论证 / 规划论证 / 水资源评价 | 章节结构与判据不同，**判错全走错章** |
| **取水水源** | 地表水 / 地下水 / 公共供水 / 再生水 / 多水源 | 决定用 9.3 / 9.4 / 9.5 / 9.6 哪套判据 |
| **项目行业** | 农业灌溉 / 工业 / 生活 / 发电 | 决定是否触发 5.2.2b 提级、用哪套定额 |
| **规模与取水量** | 万m³/d 或 m³/s | 定表1 等级；**地表水农业用 m³/s，其余用万m³/d** |
| **论证等级** | 一级 / 二级 / 三级 | 决定分级深度（表4~表6） |
| **水平年** | 现状 + 规划 | 缺规划年 → 供需平衡无从核 |

> 判不出这些 → 报告基本资料有缺项，本身就是一条 ○ 级发现。

## 第 0.5 步：取判据（别跳过）

**报告是 docx → 先用 `scripts/extract_docx_tables.py <报告> --keyword <词>` 把表格还原成网格**
（判据多藏在**工作等级表、水资源量汇总表、水量平衡表、供需平衡表、退水与污染物表**里，顺序拼字会错行）。

三个来源，**不可混用**：

| 来源 | 怎么取 | 怎么写进意见 |
|---|---|---|
| **规范条文** | `python scripts/spec_lookup.py --spec "GB/T 35580" --q 关键词或条号` | 引条号（如"不符合 8.5.3"） |
| **固化限值表** | `wr_tables.md` + `numeric-checks.md` | 引表号 + 数值 |
| **硬约束** | `compulsory-clauses.md` | 写"不符合 9.2.6" |

> **本域没有强制性条文** —— GB/T 35580 是推荐性国标，强条汇编（1,139 块）实测零命中。
> 任何"违反强制性条文"的表述都是错的。

> **查条文三条纪律**（详见 `norms.md` §一）：① 用规范自己的术语，同义词 0 命中；
> ② 条号写纯号 `8.5.3`，带"表""条"字 0 命中；③ 优先词组、少用单字。

**能算的不要只靠看** —— 凡报告给出数值结论，用复算脚本自己过一遍：

| 脚本 | 覆盖 |
|---|---|
| `calc_water_balance.py` | 取/用/耗/退四量闭合 + 输水损失 + 重复利用率 + 多单元汇总 |
| `calc_water_resources.py` | 总量扣重 + 可利用量 + 开发利用程度分级 |
| `calc_demand_supply.py` | 可供 vs 需水 + 定额反算 + 生态流量余量 |
| `calc_withdrawal_std.py` | 表1 分级 + 退水/入河量 + 纳污能力 + 总量余量 |

> ▶ **载入**：`references/norms.md` §一（取条文方法、脚本用法与限制）。

## 第 2 步：跨结构一致性（最容易被漏的一层）

单块各自正确 ≠ 报告正确。共 **9 对**：
① 规模 ↔ 表1 等级 ↔ 论证深度　② 取 ↔ 用 ↔ 耗 ↔ 退 闭合　③ 定额 ↔ 规模 ↔ 需水 ↔ η
④ 取水 ↔ 保证率 ↔ 来水频率 ↔ 可供　⑤ 地表 + 地下 − 重复 = 总量　⑥ 供水 ↔ 资源量 ↔ 开发程度
⑦ 下泄 ↔ 生态流量　⑧ 退水量 × 浓度 ↔ 入河量 ↔ 纳污能力　⑨ 取水 ↔ 总量控制指标

> ▶ **载入**：`references/checklist.md` §第 2 步。自洽性优先用复算脚本验算，不靠眼看。

## 边界

- 只覆盖**建设项目水资源论证（取水许可）**；规划水资源论证、水资源评价、纯供水工程设计不在范围。
- 条文库为**精编 228 条**（表2/3/5/6 未收录）→ 涉及时查原件并标"依据待核"。
- 产出为**审查发现**非审批结论，责任在人。
