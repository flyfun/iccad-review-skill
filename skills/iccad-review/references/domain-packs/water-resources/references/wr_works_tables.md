# 水资源论证报告 — 规范章节结构 与 报告目录对照

> 给"报告章节 ↔ 规范章节 ↔ 审查块号"做对照，并固化**非数值类**的结构性要求。
> 数值限值见 `wr_tables.md`；本册只放结构与完整性。

## 一、GB/T 35580-2017 的论证内容主线（§4.2 + §6—§13）

标准的**论证内容**（4.2）只有六项，但**报告章节**按 §6—§13 展开为八章：

```
4.2 论证内容                    对应章节
a) 建设项目概况分析          →   §6  建设项目概况分析
b) 水资源及其开发利用状况分析 →   §7  水资源及其开发利用状况分析
c) 用水合理性分析            →   §8  用水合理性分析
d) 取水水源论证              →   §9  取水水源论证
e) 取水影响和退水影响论证    →   §10 取水影响论证 + §11 退水影响论证
f) 水资源节约、保护及管理措施 →   §12 水资源节约、保护及管理措施
                                  §13 综合评价（结论与建议）
```

> 附录A（工作大纲提纲）与附录B（报告书编制提纲）为**资料性附录**，本技能**未收原文**。
> 用附录B 逐条对照目录时，须查标准正文，**不得凭经验编提纲条目**。

## 二、报告章节 ↔ 审查块号映射

| 报告常见章名 | 标准章节 | 审查块 | 该章必有的"硬内容" |
|---|---|---|---|
| 第一章 总论 / 综合说明 | §6 + §5 | 块 1 + 块 2 | 取水规模、水源类型、**设计保证率**、工作等级、四类论证范围 |
| 第二章 区域水资源 / 水资源及其开发利用 | §7 | 块 4 + 块 5 | **重复计算量**、可利用量、开发利用程度、三条红线指标落实情况 |
| 第三章 用水合理性 / 需水预测 | §8 | 块 6 + 块 7 + 块 8 | 定额出处、**水量平衡图/表**、效率指标、核定取水量（含输水损失） |
| 第四章 水资源量（部分报告提前） | §7.2 | 块 4 | 降水蒸发折算、地表/地下/总量、水质达标 |
| 第五章 取水水源论证 / 取水可靠性 | §9 | 块 9 + 块 10 | **可供水量调节计算**、保证率、取水口高程、水质、可靠性 |
| 第六章 取水影响 / 取用水影响 | §10 | 块 11 | 最不利时段、生态流量、纳污能力、其他用水户与补偿 |
| 第七章 退水影响 | §11 | 块 12 | 退水量与污染物核定、叠加累积、入河排污口、接纳协议 |
| 第八章 供需平衡（部分报告单列） | §7.3.4 + §9.3 | 块 5 + 块 9 | 不同保证率的可供 vs 需水、缺口与替代水源 |
| 第九章 水资源节约保护措施 | §12 | 块 12 | 取/用/耗/退四环节措施 + 投资估算 |
| 第十章 结论与建议 | §13 | 块 12 | 取水量、可行性、**前置条件** |

> **顺序不固定，章节名也不统一**——判"报告缺章"时按**内容**核，不按章号核。
> 例如"供需平衡"有的单列一章、有的并入取水水源章，都算齐备。

## 五、审查"翻页路径"（按报告翻，不按块翻）

拿到一份报告，**先按这个顺序翻 8 处**，5 分钟能定性：

1. **第一章找工作等级表** → 表1 三类指标齐不齐、单位对不对、有没有提级（★4）
2. **水资源量章找"重复计算量"这一行** → 在不在（★1）
3. **水量平衡表看四列** → 取/用/耗/退能不能相加对上（★3 ★2）
4. **需水预测表反算** → 定额 × 规模 = 需水？η 是否 >1（★11）
5. **供需平衡表看缺口** → 缺口怎么补、有没有落实（★13）
6. **取水水源章找"调节计算"** → 有没有过程，还是直接给个可供水量（★10）
7. **取退水影响章找两个数** → 生态流量、纳污能力（★9 ★7）
8. **结论章看前置条件** → 有没有把"建议"当"已落实"（★13 ○5）

> 这 8 处命中 3 处以上 ★，基本可以判定"报告需退回补正"，无需逐条读完。

## 六、与"建设项目水资源论证管理办法"的程序衔接（本技能只作提示）

| 程序节点 | 谁做 | 报告里应体现什么 |
|---|---|---|
| 论证工作大纲 | 编制单位 | 一级论证或水源复杂时必须有 |
| 报告书（送审稿） | 编制单位 | 本技能审查对象 |
| 技术审查 | 水行政主管部门组织专家 | 审查意见（报告应附前次审查意见及修改说明） |
| 报告书（报批稿） | 编制单位 | 按审查意见修改后的版本 |
| 取水许可申请 | 业主 | 取水量须与报批稿一致 |

> 审查报批稿时，**必须同时看送审稿的审查意见与修改说明**——否则无法判断"意见是否逐条落实"。
> 这一步属程序性核查，不属技术判据，但漏了会得出错误结论。
