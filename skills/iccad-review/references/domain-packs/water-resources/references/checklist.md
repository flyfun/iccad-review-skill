# 水资源论证报告审查 — 完整检查项清单

配套 `SKILL.md` 第 1 步"分块审查"使用。按 **12 块**展开，每条含 **判定标准** 与 **失败模式**。

> **引用约定见 `norms.md`**（条款号取法、限值出处、强条处置、版本声明）。本文件不再重复。
> 数值限值见 `wr_tables.md`；报告章节结构见 `wr_works_tables.md`；52 项数值速查见 `numeric-checks.md`。
> 本域**没有强制性条文汇编条目**（GB/T 35580 为推荐性国标），因此★标记表示**命门项**（错了直接推翻结论），不表示强条。

## 块 1　项目概况与取用水方案（GB/T 35580 §6）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **产业政策相符性** | 6.1.1：从行业、规模、技术工艺设备、产品四方面分析与国家产业准入政策、行业发展规划的**相符性** | 只写"符合国家产业政策"一句，无对照依据 |
| **多方案比选** | 6.1.2：存在多个建设方案时，应**重点从水资源条件方面**比选 | 只比投资/占地，不比水源可靠性 |
| **三区管控** | 6.1.3：严格控制**缺水地区、水污染严重地区、敏感区域**的高耗水、高污染项目 | 项目位于超采区/缺水区却不论证 |
| **改扩建关系** | 6.1.4：说明改扩建与已建项目**取用退水之间**的关系 | 只写新增规模，不写与老系统如何衔接 |
| **取水方案六要素** | 6.3.1：水源类型、取水方式、取水工程位置、取水规模、取水过程、取水水质、**设计保证率** | 缺设计保证率 → 后文可供水量无从判定 |
| **用水工艺与节水** | 6.3.2：主要用水环节工艺/设备/技术、用水量、水质要求、循环回用，附**用水工艺流程图** | 无流程图，环节水量无法核 |
| **退水方案** | 6.3.4：退水地点、方式、水量、水质、过程 | 退水只写"达标排放"，无水量与去向 |
| **施工期** | 6.3.5：施工期需取水的，应说明施工期取水、用水、污水处理和退水方案；4.4.3 论证应**涵盖施工期和运行期** | 全篇只算运行期，施工期取水漏项 |
| **改扩建现状** | 6.3.6：已建项目的原水资源论证、取水验收、取水许可、**水平衡测试**、节水设施运行情况 | 改扩建项目不附原取水许可 |

## 块 2　工作等级与论证范围（§5）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **等级取值规则** | 5.2.1：工作等级由**分类等级中的最高级别**确定；分类等级分别由取水水源、取水影响、退水影响三类指标的最高级别确定 | 三类各取"平均"或只按取水量定级 |
| **表1 单位陷阱** | 表1：地表水**农业**取水量单位为 **m³/s**；其余（工业/生活/地下农业）为 **万m³/d** | 把 m³/s 当 万m³/d 套 → 等级差 2 级 |
| **开发利用程度** | 表1 注1：地表 = 供水量/地表水资源量；地下 = 供水量/**地下水可开采量**；阈值 地表 30/10、地下 70/50（%） | 两个分母互换；用"水资源总量"做分母 |
| **提级/降级** | 5.2.2b：火(核)电、石化、化工、纺织、造纸、钢铁、食品中**高耗水或重污染**项目应提高一级（最高一级）；5.2.2a 丰水区小型灌区可降一级（最低三级） | 钢铁项目按表1 算出二级就定二级，漏提级 |
| **多水源/线性工程** | 5.2.3 多水源按各水源分别定深度；5.2.4 铁路公路等线性工程按各取水水源分别定 | 多水源取最严一级一刀切，或反过来全按最松 |
| **四类范围** | 5.1.1：分析范围、取水水源论证范围、取水影响范围、退水影响范围 —— **四个都要有**，分别见 5.3.1（3 条）/5.3.2（6 条，按水源分列）/5.3.3（2 条）/5.3.4（2 条） | 只写"论证范围 XX 河段"，四类混为一谈 |
| **范围成图** | 5.1.2 + 5.3.1.3 + **5.3.2.6**（四类水源各自的底图与标注要求）+ **5.3.3.2** + **5.3.4.2**：每种范围图都须说明底图类型与标注要素，并附表说明主要取用水户取退水情况 | 有文字无图；或缺取水影响范围图/退水影响范围图（最常见只画了水源论证范围图） |
| **水源论证范围定法** | 5.3.2.1 地表水：流域面积 ≤3000km² 且取水口以上无水文站 → 论证范围须为**整个流域**；5.3.2.2 地下水：以**完整或相对独立的水文地质单元**为范围；5.3.2.3/4/5 公共供水/再生水/多水源各自定法 | 小流域无站却只取局部河段；地下水按行政区划而非水文地质单元定范围 |
| **分级深度匹配** | 9.1.7：按等级确定分级论证深度（表4 地下水部分：水文地质图 1:1万/1:2.5万~1:5万/1:5万~1:10万；钻孔密度 1眼/10km²、1眼/25km²、1眼/50km² 等） | 一级论证却只有 1 个单孔抽水试验 |

## 块 3　水平年与基本资料（§4.5/4.6）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **现状水平年** | 4.6.1：应具代表性，**宜取最近年份**，避免特枯年与特丰年 | 取一个特枯年做现状 → 可利用量被低估/高估 |
| **规划水平年** | 4.6.2：蓄水、公共供水、引调水等工程应确定规划水平年，并与相关规划水平年**协调** | 规划年与国民经济规划、水资源规划不一致 |
| **资料清单齐备** | 4.5.1：按工作等级开展资料收集，七类缺一不可——a) 规划与区划、水量分配方案；b) 项目前期成果与审批文件；c) 项目概况与取退水方案；d) 自然地理/水文气象/水文地质/社会经济及水资源开发利用、连续枯水年特枯年资料；e) 水源论证范围现状水质与取水量、已有水源地；f) 影响范围水功能区、代表断面水质、已审批取水与入河排污口；g) 从已有工程或管网取水的，须有供水能力、用水户与实际供水量 | 只列水文资料，缺水量分配方案与已审批取水户清单（→ 总量控制无从核） |
| **资料三性** | 4.5.4：水文与地下水动态资料应做**可靠性、一致性、代表性**分析；人类活动明显影响一致性时应**修正** | 直接用 1980 年代径流系列算现状可供水量，不做一致性修正 |
| **资料年限** | 7.3.2：供用水统计资料**宜不少于 5 年**（本条为"宜"，不足时写 ▲ 提示，不判硬错） | 只给 1 年数据就下"变化趋势"结论 |
| **补充监测** | 4.5.2：资料不能满足论证要求时，应补充调查和监测；9.3.2.2 水质资料不足应监测并将报告作**附件** | 水质结论无监测报告支撑 |
| **现场查勘** | 4.5.3：应开展现场查勘，重点查取水水源、取水口位置、入河排污口位置及现有水利工程 | 全篇二手资料，无查勘记录 |

## 块 4　★水资源量（§7.2）

> 本块是全篇的**分母**。分母错了，后面开发利用程度、可利用量、供需平衡全错。

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **总量扣重** | 水资源总量 = 地表水资源量 + 地下水资源量 − **重复计算量**（7.2.2 要求给出水资源数量；重复量为地表与地下相互转化部分） | **地表+地下直接相加**，漏扣重复量 → 总量虚高（最常见的硬错） |
| **降水蒸发** | 降水、蒸发须同系列同口径；蒸发皿（20cm）与 E601 之间须**折算**，不得混用 | E601 蒸发值直接当水面蒸发用（或反之），不写折算系数 |
| **地表水资源量** | 与水文站控制断面、集水面积对应；跨分区时不得重复计入 | 分析范围与水文站集水面积不对应，量直接搬用 |
| **地下水资源量** | 按补给量、排泄量、储存量做**水均衡**（9.4.1.2）；山丘区与平原区分别计算再合并 | 只给一个"补给量"就作地下水资源量 |
| **可开采量** | 9.4.1.2/9.4.1.5：在地下水资源量基础上结合开采方案确定可开采量，并扣除**已有与规划用户开采量** | 把"地下水资源量"当"可开采量"用 |
| **可利用量** | 7.2.2：应给出水资源**可利用量**；等于总量扣除河道内生态需水与汛期不可控弃水 | 用"水资源总量"直接当可供水量 |
| **水质达标** | 7.2.4：说明河流、水功能区、水源地水质及达标情况；地表水按 GB 3838、评价按 SL 395 | 只给一个"Ⅲ类"结论，无断面、无月份、无达标率 |
| **超采区** | 7.2.5：地下水超采地区应说明超采区类型、分布、数量、面积、超采程度及治理状况（划分参见 SL 286） | 项目在超采区却不提超采，直接论证新增取水 |

## 块 5　★开发利用与潜力（§7.3/7.4）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **供用水统计** | 7.3.2：按 SL 429 分析工业、农业、生活及生态环境的供水与用水，统计用水指标，资料宜不少于 5 年 | 只给"总用水量"，不分行业、不分水源 |
| **供需现状** | 7.3.4：做**现状水平年不同来水情况**下的供需平衡，评价紧缺程度 | 只做 P=50% 一种来水 |
| **用水水平评价** | 7.3.5：对照国内外先进水平、地区与行业**用水定额**、节水减排要求评价（指标见表2） | 自定"先进值"，不引定额出处 |
| **问题识别** | 7.3.6：结合开发利用、水质达标、生态保护，分析存在的主要问题 | 问题写成"水资源管理有待加强"的套话 |
| **近海区域** | 7.3.7：近海地区应分析咸水上溯或海水入侵 | 沿海项目不提咸潮/入侵 |
| **潜力口径** | 7.4.1：潜力须同时受**用水总量控制、用水效率控制、限制纳污**三条约束；7.4.2 分析区域节水潜力 | 潜力 = 水资源总量 − 已用水量（只算水量，不算三条红线） |

## 块 6　★用水合理性：工艺与水量平衡（§8.1—8.3）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **工艺合规** | 8.1.1：对照国家鼓励/淘汰的用水技术、工艺、产品和设备目录 | 采用明令淘汰的用水工艺 |
| **冷却水专项** | 8.3.2：冷却水量**超过总取水量 30%** 的，应单独分析冷却水循环量合理性（热量平衡、水质、浓缩倍率） | 冷却水占 60% 却不做专项 |
| **水量平衡图** | 8.3.1：绘制水量平衡图，标明主要用水环节用（耗）水量及设计参数；重要用水单元应**单独**绘制；季节影响大的应分季节+全年；城市公共供水、水利水电工程可省略 | 一张框图无水量数字，无法核 |
| **水量平衡表** | 8.3.5：逐项列出各环节**取（补）水、用水、耗水、回用水、总退水**，并说明各环节水质 | 表中只有"取水"和"退水"两列，耗水缺失 |
| **四量闭合** | 取水 = 用水 + 输水损失（3.9 取水量**含**输水损失）；用水 = 耗水 + 退水（3.10）；⇒ 取水 = 耗水 + 退水 + 损失 | 退水系数拍脑袋（如统一 0.8），与耗水打不平 → 用 `calc_water_balance.py` 核 |
| **回用可行性** | 8.3.3：按污水处理能力、回用环节与水质水量要求评价回用可行性与可靠性，论证排放量与浓度合理性 | 写了"中水回用 50%"但无处理规模、无水质匹配 |
| **零排放** | 8.3.4：污水不外排的，应通过**物料平衡、水量平衡**论证不排水设计的可行性与可靠性 | 只写"实现零排放"，无盐分/浓水出路 |
| **改扩建叠加** | 8.3.6：分析本项目与已建（在建）项目取用退水关系，绘制**整个项目**的水量平衡图 | 只画新建部分，老系统水量不并入 |

## 块 7　★用水水平与节水潜力（§8.4）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **指标齐备** | 8.4.1：按表2 计算具体用水指标，可按特点增减；工业应有**重复利用率**、**万元增加值用水量**，农业应有**灌溉水利用系数**、**亩均用水量** | 只给总水量，一个效率指标都不算 |
| **对标口径** | 8.4.2：对照**区域用水效率控制指标**、国内外同行业先进值、节水标准与**用水定额** | 拿 10 年前的行业平均值当先进值 |

| **节水潜力** | 8.4.4：结合用水水平评价与拟采取措施，分析节水潜力 | 潜力分析结论与后文核定水量无关联 |

## 块 8　★核定取水量（§8.5）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **分施工期/运行期** | 8.5.1：明确施工期与运行期用水量；施工期还应明确**高峰用水量**与**历年取用水量** | 施工期按运行期均摊 |
| **论证前后对比** | 8.5.2：在工艺、过程、节水潜力分析后**重新绘制**水量平衡图，对比说明论证前后水量变化，确定合理用水量 | 论证前后水量一字不差（说明"论证"没起作用） |
| **含输水损失** | 8.5.3：结合**输水过程损失**核定项目总用水量；3.9 取水量含输水损失 | 核定值只到"用水环节"，漏输水损失 → 取水许可量偏小 |
| **与定额互校** | 核定取水量 ÷ 规模 应回到定额量级；差 20% 以上必须解释（利用系数、种结构、工艺） | 定额 480 m³/亩 × 35 万亩 = 1.68 亿，核定却写 1.2 亿而不解释 → `calc_demand_supply --mode quota` 直接抓 |

## 块 9　★取水水源论证 — 地表水（§9.1—9.3）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **三条符合性** | 9.1.1：符合流域/区域水资源综合规划、**水量分配方案（协议）**，满足用水总量控制、限制纳污总量控制、地下水管理要求 | 不引水量分配方案，直接说"水量充足" |
| **生态与水深** | 9.1.2：满足河道内**最小流量或水量**、湖库**最小水深**、通航河道**最小通航水深** | 只算取水量，不算取水后河道剩多少 |
| **来水频率** | 9.3.1.1：按 SL 278 确定设计年径流与设计枯水径流；经验频率按**数学期望公式**，线型**宜用 P-Ⅲ 型或极值分布**；枯水保证程度可用流量（水位）历时曲线 | 频率计算不写公式、不写线型、不写适线结果 |
| **系列插补** | 9.3.1.4：缺长系列时可用水位流量关系、上下游相关、降雨径流、类比法插补延长 | 系列只有 8 年就做 P=97% 设计枯水 |
| **调节计算** | 9.3.1.7：多年调节/完全年调节宜用长系列、以**月**为时段；非完全年调节宜用典型年、以**旬或日**为时段；梯级应**联合**上下游调节；取水占现状可供水 <1% 可简化 | 无调节性能的水源却用年总量相减得可供水量 |
| **已建/规划工程** | 9.3.1.9 已建工程须附**供水协议**；9.3.1.10 规划工程须以**批准**的规划/可研/设计为依据 | 拿一个未批规划水库当水源 |
| **水质** | 9.3.2.1：按 GB 3838 与 SL 395 评价；9.3.2.3 重污染水域应做**底质**评价，富营养化应选参数评价 | 取水口 Ⅳ 类、目标 Ⅲ 类，无达标措施 |
| **取水口高程** | 9.3.3.2：结合实测断面与**设计最低水位**分析取水口高程，附平面与剖面图，标注河底高程、设计最低水位、取水头部尺寸 | 只写高程数值，无设计最低水位对照 |
| **可靠性** | 9.3.4.1：对来水量与用水量的可能变化及**各种组合**做多方案比较，分析供水保证率 | 单点算一个保证率就下结论 |

## 块 10　★取水水源论证 — 地下水 / 公共供水 / 再生水（§9.4—9.6）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **禁止性情形** | 9.2.6：公共供水管网覆盖范围内，建设项目**不应**通过自备井取地下水；**严格控制**深层承压水；**地下水超采区**工农业与服务业**不应**新增取水 | 管网覆盖区内仍批自备井 |
| **水源比选原则** | 9.2.2：合理利用地表水、严格控制地下水、科学使用其他水源；9.2.4 具备条件的钢铁、火电、化工、制浆造纸、印染**应优先使用再生水** | 有再生水条件却选地下水 |
| **水均衡** | 9.4.1.2：按补给量、储存量、排泄量做水均衡，算地下水资源量 | 只给补给量，排泄量缺失 |
| **数值模型** | 9.4.1.3：概化水文地质条件 → 概念模型 → 数学模型 → 用试验与动态观测**识别**参数 → 预测开采条件下动态 | 无模型，直接用"可开采模数×面积" |
| **可开采量与降深** | 9.4.1.5/9.4.1.6：扣除已有与规划用户开采量后确定可供本项目量；明确取水构筑物类型、**开采层位**、开采总量与过程 | 不写开采层位，深浅层混算 |
| **水质评价** | 9.4.2.1/9.4.2.2：地下水水质评价**执行 GB/T 14848**；监测资料须能反映分析范围水质状况**与论证范围水质动态**；水质变化复杂区须**分区、分层**评价 | 只附一张水质检测报告，不分区分层、不评价动态变化 |
| **开采方案合理性** | 9.4.3.1：方案须含目标含水岩组、构筑物类型与结构、数量与间距、平面与剖面布置形式、计划开采量与开采过程；9.4.3.2 据动态预测分析对区域水资源、环境水文地质、**第三者用水户**的影响；9.4.3.3 一级须明确**动态监测方案**（二三级提建议），参见 GB/T 51040、SL 219 | 只给总取水量，无井群布置与开采过程；不提第三者影响 |
| **水源可靠性** | 9.4.4.1：按**特枯年与连续干旱年**补给条件变化分析可靠性；9.4.4.2 资源缺乏或开发程度高的地区，须分析水文要素、含水层渗透系数等的**不确定性** | 只按多年平均补给量论证可靠性，丰枯不分 |
| **特殊水源** | 9.4.1.7 矿坑排水：从矿床充水条件、涌水量、采矿用水论证，并考虑防治水措施、排水变化趋势与周边取水影响；9.4.1.8 地下水热泵：按最大释热/吸热量定合理用水量，明确回灌层位与**回灌率**、水质要求，提供钻孔柱状图与抽灌试验成果表 | 热泵项目不提回灌率；矿坑排水不分析周边影响 |
| **分级深度** | 表4：一级需 1:1万 水文地质图、**群孔**抽水试验、1眼/10km²；二级 1:2.5万~1:5万、多孔抽水、1眼/25km²；三级 1:5万~1:10万、单孔抽水、1眼/50km²；动态观测一级≥1个水文年5日系列 | 一级论证只有单孔抽水、一个枯水期观测 |
| **公共供水** | 9.5.3：保证率要求高的项目，应分析近 **3~5 年**供水范围、人口、总量、能力、日均供水量、**管网漏损率**、高峰月与最高日供水量 | 只写"水厂有余量 2 万 m³/d" |
| **再生水** | 9.6.1：分析污水处理设施**进出水量可靠性**与出水水质稳定性，按近 3 年运行情况估可供水量；**9.6.2**：以污水厂**日出水量监测资料**分析水量可靠性（日变化系数），以出水水质监测资料分析水质变化幅度与稳定性；9.6.4 评价出水水质稳定性 | 按设计规模当实际可供水量；用水量用年总量除 365 代替日变化分析 |

## 块 11　★取水影响（§10）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **最不利时段** | 10.2.1：按取水规模与保证率要求，重点分析**最不利时段**取水对水资源与水文情势的影响 | 只算年均，不算枯水期 |
| **简化判据** | 10.2.3：丰水地区累积取水量 < 取水河段**历年实测最小流量的 10%**，或 < **多年平均最枯月流量的 5%** 时，可简化取水影响论证 | 不满足简化条件却套用简化 |
| **水位/水深** | 10.2.2：水网区、湖泊、水库闸坝取水，应分析对**水位和最小水深**的影响；航运与重要水能河段应分析对航运、水能的影响 | 湖泊取水不算水位降 |
| **地下水影响** | 10.2.4：预测地下水位变化及影响范围，分析对含水岩组结构、循环条件、地表水产汇流的影响；显著影响时应**定量**评价 | 只写"影响较小" |
| **环境地质** | 10.2.8：泉域应分析泉水流量与水位；沿海应分析**海水入侵**；铁路/高速/防洪设施毗邻区应在地灾评估基础上分析 | 沿海项目不提入侵 |
| **生态流量** | 10.4.2：分析取水对**多年平均流量、典型设计保证率流量、生态流量（水位）** 的影响；短缺地区应分析对**基本生态需水量与目标生态需水量**的影响；引蓄水工程应分析**最小生态流量与最小下泄流量** | 只写"下泄生态流量 10%"不给依据；或按多年平均的 10% 一刀切 |
| **纳污能力** | 10.3.1/10.3.2：分析取水导致水文过程改变对**水域纳污能力**的影响；未核定纳污能力的水域按 GB/T 25173 计算 | 取水后水量减少，纳污能力仍按原水量算 |
| **其他用水户** | 10.5.1—10.5.3：明确受影响的其他用水户，量化损失，提出减缓与**补偿方案** | 只写"不影响第三方"，无分水协议/无现状取水口清单 |
| **措施落地** | 10.5.4：减缓措施应有可行性与有效性评价，做**投资估算**，明确资金落实 | 措施无投资、无责任主体 |

## 块 12　★退水影响 + 措施与结论（§11—13）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **退水量核定** | 11.1.1：在退水量与主要污染物**核定**基础上论证；3.10 退水量为对外排放的污水量（不含水轮机排水） | 退水量 = 取水量 × 0.8 一刀切 |
| **叠加累积** | 11.1.2：分析受纳水域内已建、在建、已批拟建项目退水的**叠加与累积**影响 | 只算本项目，不算已批排污口 |
| **事故风险** | 11.1.3：退水条件复杂、污染风险突出的，应分析**非正常工况与事故风险**，提应急要求 | 无事故工况 |
| **纳污能力符合性** | 11.2.3/11.2.5：退水规模、污染负荷、退水方式须符合**水域纳污能力**与**限制排污总量控制方案**；未提总量意见的水域按 GB/T 25173 核算 | 入河量 > 纳污能力仍判可行 |
| **排入污水厂** | 11.2.7：排入污水处理厂须附**同意接纳文件/协议**；依托但负荷不足的应调整方案；排入管网下游无厂的应做**累积影响**论证 | 无接纳协议 |
| **入河排污口** | 11.5.1/11.5.2：按 SL 532 论证设置合理性；须符合防洪规划、水功能区划、水资源保护规划 | 排污口设在饮用水源保护区上游 |
| **已有排污口** | 11.2.8：使用已有排污口的，应论证**扩大排污量**，并附登记或设置同意文件 | 借用老排污口不办手续 |
| **措施针对性** | 12.1.1—12.1.3：从**取、用、耗、退**四环节提节水减污与再生利用措施；提内部用水管理措施；提减缓取退水影响的保护措施 | 措施全是"加强管理、提高意识" |
| **节水措施落地** | 12.2.2 须有**节水措施方案 + 配套节水设施**（改扩建须覆盖整个项目）；12.2.4 须落实节水"**三同时**"与"**四到位**"；12.2.5 须提水平衡测试要求 | 只列设备清单，无制度与配套 |
| **保护措施对号** | 12.3.2 有最小下泄/生态流量要求的，须提**保障措施**（对应 10.4.2 的影响分析）；12.3.3 有退水风险的须提**非正常工况与事故**工程措施；12.3.4/12.3.5 地下水影响大的须提**水位水质动态监测方案**与应急方案 | 影响章节提了风险，措施章节无对应条款 |
| **管理措施可核** | 12.4.1 按 GB 24789、GB/T 28714 配计量器具并定期水平衡测试；12.4.2 **三级计量体系** + 计量器具配备图；12.4.3 按月制定取用水计划 | 只写"安装计量表"，无三级计量与配备图 |
| **结论可追** | 13.1.1：结论须回答"取水是否可行、取多少、什么条件"；13.2 建议应针对未落实事项 | 结论"基本可行"但缺口未落实替代水源 |
| **★不可行情形逐条排除** | **13.1.2**：六种情形之一即应判"取水不可行"——a) 不符产业政策/行业规划/最严格水资源管理制度；b) 不符主体功能区与水功能区管理；c) 不符水资源规划、水量分配方案或用水总量控制；d) 可能引发**重大水事纠纷**；e) 对水资源与水生态可能造成**重大不可逆影响**；f) 对**饮用水源地**等敏感对象造成明显不利影响或潜在威胁 | 报告只写"基本可行"，未逐条排除六种情形；尤其 e)、f) 被"影响较小"一句带过 |
| **重大影响须调方案** | 13.1.3：取水或退水对水资源、水生态造成重大影响且**难以采取补救措施**的，应**调整取水或退水方案**，不是补措施了事 | 影响重大仍靠"加强监测"过关 |

## 第 2 步　跨专业一致性（9 对）

> 单块各自正确 ≠ 报告正确。逐对列出"甲↔乙"必须自洽的数值链，并给出**验算用什么脚本**。

| # | 甲 ↔ 乙 ↔ 丙 | 不自洽的后果 | 验算 |
|---|---|---|---|
| 1 | **取水规模** ↔ **表1 分类等级** ↔ **论证深度（表4~表6）** | 等级定低 → 该做的模型、试验、监测全部缺位，全篇深度不足 | `calc_withdrawal_std.py --mode level` |
| 2 | **取水量** ↔ **用水量** ↔ **耗水量** ↔ **退水量** | 四量不闭合 → 取水许可量、退水影响、纳污核算全部失真 | `calc_water_balance.py --mode balance / sum` |
| 3 | **用水定额** ↔ **规模（面积/产值/人口）** ↔ **需水量** ↔ **水利用系数** | 定额与需水对不上 → 需水量与取水量两条线各说各话 | `calc_demand_supply.py --mode quota` |
| 4 | **取水量** ↔ **设计保证率** ↔ **来水量频率** ↔ **可供水量** | 保证率与频率不匹配 → "97% 保证"却用了 P=75% 的来水 | `calc_demand_supply.py --mode supply` |
| 5 | **地表水资源量** + **地下水资源量** − **重复计算量** = **水资源总量** | 漏扣重复量 → 分母虚高 → 开发利用程度被低估 | `calc_water_resources.py --mode total` |
| 6 | **供水量** ↔ **水资源量/可开采量** ↔ **开发利用程度（表1）** | 分子分母口径错 → 等级错 → 深度错 | `calc_water_resources.py --mode exploit` |
| 7 | **取水后下泄流量** ↔ **生态流量/最小下泄** ↔ **河道内生态需水** | 挤占生态水 → 违反 9.1.2，属实质性不满足 | `calc_demand_supply.py --mode eco` |
| 8 | **退水量 × 浓度** ↔ **污染物入河量** ↔ **纳污能力/限制排污总量** | 入河量超容量 → 退水方案不成立 | `calc_withdrawal_std.py --mode retreat / capacity` |
| 9 | **取水量** ↔ **用水总量控制指标/水量分配方案** ↔ **取水许可** | 超总量 → 不符合 9.1.1，取水许可不予批准 | `calc_withdrawal_std.py --mode alloc` |
