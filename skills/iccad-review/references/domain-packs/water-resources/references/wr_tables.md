### 1.3 取水和退水影响

| 分类指标 | 一级 | 二级 | 三级 |
|---|---|---|---|
| **对水资源利用的影响** | 对流域或区域水资源利用产生显著影响；对第三者取用水影响显著 | （介于两者之间） | 对第三者取用水影响轻微 |
| **对生态的影响** | 现状生态问题敏感；取水对水文情势、生态水量与流量产生明显影响；退水有水温或水体富营养化影响问题 | 现状生态问题较为敏感；取水对生态水量与流量产生一般影响；退水有潜在水体富营养化影响 | 现状无敏感生态问题；取水和退水对生态影响轻微 |
| **对水功能区的影响** | 涉及一级水功能区的保护区、缓冲区，或二级水功能区的饮用水水源区；涉及除饮用水水源区以外其他 **3 个及以上**二级水功能区；涉及水功能区水质管理目标为 **Ⅰ、Ⅱ类** | 涉及一级水功能区的保留区、跨地（市）级的二级水功能区，或涉及 **2 个**二级水功能区；涉及水质管理目标为 **Ⅲ类** | 涉及 **1 个**二级水功能区 |
| **退水污染物类型** | 含有毒有机物、重金属、放射性或持久性化学污染物；含 **三种以上**化学污染物，或含影响水功能区水质保护目标和水域限制排污总量要求的污染物 | 含有 **两种以上**可降解一般污染物 | 含有 **一种**一般可降解污染物 |
| **退水量（缺水地区）** | ≥5000（≥500） m³/d | 5000~1000（500~100） m³/d | ≤1000（≤100） m³/d |

> 括号内数值为**缺水地区**适用值。

### 1.4 表1 三条注（判定口径，常被漏读）

- **注1（开发利用程度定义）**：指多年平均**地表水资源供水量占地表水资源量的百分比**，
  或多年平均**地下水资源供水量占地下水可开采量的百分比**。
  → 两个分母不同！地表水用"地表水资源量"，地下水用"**可开采量**"，不是"地下水资源量"。
- **注2**：**再生水**取水工作等级参照**地表水**分级指标执行；**公共供水**取水以
  **取水影响和退水影响**分类等级确定（不看取水量指标）。
- **注3**：水功能区分类分级参见 **GB/T 50594**。

### 1.5 等级取值与调整规则（5.2.1 / 5.2.2）

```
工作等级 = max(取水水源等级, 取水影响等级, 退水影响等级)     ← "最高级别"= 最严
调整：
  a) 水资源丰沛地区小型灌区        → 可降一级，最低三级
  b) 火(核)电/石化/化工/纺织/造纸/钢铁/食品 中高耗水或重污染 → **应提一级**，最高一级
  c) 仅"开发利用程度"为一级、其他指标均为三级 → 可降为二级
```

> **b) 是"应"，不是"可"** —— 钢铁项目按表1 算出二级也必须提为一级。

## 三、水资源量口径（**不是 GB/T 35580 条款**，是通用定义）

```
水资源总量  W总 = W地表 + W地下 − W重复
    W重复：地表水与地下水相互转化的重复计算量（河川基流、渠系渗漏补给、灌溉入渗等）

水资源可利用量  W可利用 = W总 − W河道内生态需水 − W汛期不可控弃水

开发利用程度  η = W供 / W资源 × 100%
    地表：W资源 = 地表水资源量
    地下：W资源 = 地下水可开采量（= 补给量 − 排泄量中不可夺部分，经水均衡与开采方案确定）

四量链（GB/T 35580 3.8/3.9/3.10）
    W取 = W用 + W损        （取水量含输水损失）
    W用 = W耗 + W退        （退水量不含水轮机排水）
    ⇒ W取 = W耗 + W退 + W损
    耗水率 = W耗/W取；退水系数 = W退/W取；损失率 = W损/W取，三者之和 = 1
```

> **引用纪律**：这套口径来自 SL/T 238《水资源评价导则》与《水资源公报》，
> **GB/T 35580 全文没有"重复计算量"条文**（已实测，见 `norms.md` §五-3）。
> 写判词时说"按水资源总量定义"，不要写"按 GB/T 35580 第 X 条"。

## 四、用水定额反算（8.2.7 / 8.5.3）

```
灌溉：W净 = 定额(m³/亩) × 面积(万亩) / 1e4        [亿m³]
      W毛 = W净 / η灌       η灌 = 渠系水利用系数 × 田间水利用系数
工业：W = 定额(m³/万元) × 产值(万元) / 1e8         [亿m³]
生活：W = 定额(L/(人·d)) × 人口(万人) × 天数 / 1e11 [亿m³]
```

**量级自检（必做）**：大型灌区 η灌 常 **0.55~0.65**。
若由 W毛/W净 反推出的 η > 0.75，基本可判定"定额与取水量至少有一项写错"。

> 例：定额 480 m³/亩 × 35 万亩 = **1.68 亿m³（净）**；
> 报告年取水 1.2 亿m³ → 隐含 η = 1.68/1.2 = **1.40 > 1**，物理上不可能 → 必错。

## 五、水质类别速查 ⚠️

> 数值以 **GB 3838-2002 表1** 原件为准，本表仅作速查，**引用前核原件**。

| 类别 | 适用 | COD (mg/L) | 氨氮 (mg/L) | 总磷（河流/湖库）(mg/L) |
|---|---|---|---|---|
| Ⅰ | 源头水、国家自然保护区 | ≤15 | ≤0.15 | ≤0.02 / ≤0.01 |
| Ⅱ | 集中式饮用水水源地一级保护区、珍稀水生生物栖息地 | ≤15 | ≤0.5 | ≤0.1 / ≤0.025 |
| **Ⅲ** | **集中式饮用水水源地二级保护区**、鱼虾越冬场、游泳区 | ≤20 | ≤1.0 | ≤0.2 / ≤0.05 |
| Ⅳ | 一般工业保护区、非直接接触娱乐用水区 | ≤30 | ≤1.5 | ≤0.3 / ≤0.1 |
| Ⅴ | 农业用水区、一般景观用水区 | ≤40 | ≤2.0 | ≤0.4 / ≤0.2 |

**判定要点**：
- 取水口现状水质类别 **劣于** 项目用水要求 → 须有**达标措施**或另选水源；只写"目标Ⅲ类"不算措施。
- 地下水按 **GB/T 14848** 分 Ⅰ~Ⅴ 类，Ⅲ类及以上可作为集中式饮用水水源。

## 六、纳污能力（零维充分混合简化式）⚠️

```
河流零维：  M = 86.4 × (Cs − C0) × Q
    M  : 纳污能力，kg/d
    Cs : 水质目标浓度，mg/L
    C0 : 现状/来水浓度，mg/L
    Q  : 设计流量，m³/s
```

**适用条件（写在结论里，别省）**：污染物入河后能迅速充分混合的**小型河段**。
大江大河、湖库、一级论证 → 必须用报告自身的二维/三维模型结果，本式只作**量级校核**。

**污染物入河量换算**：
```
年入河量(t/a) = 退水量(万m³/a) × 1e4 × 浓度(mg/L) × 1e-6
日均入河量(kg/d) = 年入河量(t/a) × 1000 / 天数
```

## 七、生态流量参考线 ⚠️（**非规范限值**）

| 方法 | 取值 | 含义 | 性质 |
|---|---|---|---|
| Tennant 法 | 多年平均流量的 **10%** | 最小生态流量（维持基本生存） | **参考线**，非规范硬判据 |
| Tennant 法 | 多年平均流量的 **30%** | 良好生态流量 | **参考线** |

> GB/T 35580 10.4.2 只要求"**分析**取水对生态流量（水位）的影响"，**没有给百分比**。
> 判词写"取水后剩余 X m³/s，低于多年平均的 10%，生态偏紧"，**不要写"按规范应达 10%"**。
> 生态需水评估方法参见 **SL/Z 479**。

## 八、单位换算（本域最易错，务必现算）

| 换算 | 系数 |
|---|---|
| 1 m³/s → 万m³/d | **8.64** |
| 1 万m³/d → m³/s | **0.11574** |
| 1 m³/s → 亿m³/a | **0.31536** |
| 1 亿m³/a → m³/s | **3.171** |
| 1 亿m³/a → 万m³/d | **27.40** |
| 1 万m³/a → 万m³/d | 1/365 = **0.00274** |
| 1 万亩 → 亩 | 1×10⁴ |
| 1 亿m³ → 万m³ | **10 000** |

**常见错法**：把 `m³/s` 的农业取水量直接当 `万m³/d` 填进表1 ——
3 m³/s（三级）被读成 3 万m³/d（二级），**差一级**；20 m³/s（一级）被读成 20 万m³/d（一级），
只是碰巧同级的假安全。

## 九、数值易错点 12 条

1. **地表水农业取水量单位是 m³/s**，其余全是 万m³/d —— 整列套错。
2. **开发利用程度两个分母不同**（地表水/水资源量；地下水/**可开采量**）。
3. **水资源总量漏扣重复计算量** —— 地表+地下直接相加。
4. **取水量漏输水损失** —— 3.9 明确"包括输水损失"。
5. **退水量把水轮机排水算进去** —— 3.10 明确"不含"。
6. **定额与取水量不自洽** —— 反推 η > 1（或灌区 > 0.75）必错。
7. **蒸发皿与 E601 混用** —— 不写折算系数。
8. **地下水资源量当可开采量用** —— 前者是"存量概念"，后者要扣排泄与生态。
9. **频率分析不写线型与适线** —— P-Ⅲ 是"宜"，但不写就无法复核。
10. **P=97% 当灌溉设计保证率** —— 灌溉常见 50%~95%，97% 需特别理由。
11. **入河量单位错** —— t/a 与 kg/d 混用，差 1000 倍再乘天数。
12. **生态流量按 10% 一刀切** —— Tennant 是参考线，不是规范限值。
