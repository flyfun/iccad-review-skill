# 混凝土重力坝工程报告审查

## 定位与适用范围

**审查编排层**：回答"查什么、什么顺序、怎么判、依据谁"。条号与限值从条文库/固化表核对，**不硬编码**。

**用**：混凝土重力坝报告（可研/初设/施工图/安全评价/加固/鉴定）。
**不用**：土石坝、拱坝、水闸、泵站、堤防、河道整治、水保方案、洪评、水资源论证、溢洪道专项、隧洞；纯设计问题、纯条文查询。

## 审查总流程

```
混凝土重力坝报告 (docx/pdf)
 ├─[0]   前置判定 ── 坝型 / 级别 / 阶段 / 规范适用
 ├─[0.5] 取判据 ── spec_lookup 调条文 + 固化限值表 + calc_*.py 复算
 ├─[1]   分块审查（12 块）── 查什么 → 判定标准 → 依据
 ├─[2]   跨专业一致性 ── 9 对交叉校验，数值自洽
 └─[3]   结构化发现 ── 位置 / 问题 / 依据 / 严重度 / 建议
```

**每步该翻哪册，见该步末尾 ▶ 载入。**

## 第 0 步：前置判定

| 判定项 | 取值 | 影响什么 |
|---|---|---|
| **坝型** | 实体 / 宽缝 / 空腹 / RCC / 浆砌石 | RCC → 加 SL 314（层缝面抗滑）；浆砌石 → SL 25，**不属本技能** |
| **坝的级别** | 1 / 2 / 3 级 | 表 4.2.1 安全加高、表 6.4.1-2 K、表 6.4.3 深层 K |
| **坝高 H** | 建基面至坝顶（不含防浪墙） | 7.4.4 帷幕 q 分档、7.4.5 悬挂式帷幕深 |
| **报告阶段** | 可研 / 初设 / 施工图 / 安全评价 / 除险加固 | 章节深度（SL/T 618/619/877）与判据松紧 |
| **地基类型** | 岩基（1/2/3 级） | SL 319 只管**岩基**；土基转 GB 50007 或土石坝技能 |

> 判不出这些 → 报告基本资料有缺项，本身就是一条 ○ 级发现。

## 第 0.5 步：取判据（别跳过）

**报告是 docx → 先用 `scripts/extract_docx_tables.py <报告> --keyword <词>` 把表格还原成网格**
（判据多藏在"荷载组合表""稳定及应力计算成果表""坝基处理工程量表"里，顺序拼字会错行）。
三个来源，**不可混用**：

| 来源 | 怎么取 | 怎么写进意见 |
|---|---|---|
| **规范条文** | `python scripts/spec_lookup.py --spec "SL 319" --q 关键词` | 引条款号（如"SL 319 6.4.1"） |
| **固化限值表** | `gd_tables.md` + `gd_works_tables.md` | 引条款号 + 表号 |
| **强制性条文** | `compulsory-clauses.md`（SL 319 共 **6 条**） | 写"**违反强制性条文**"，最高级 |

> **查条文三纪律**（详见 `norms.md` §一）：① 用规范自己的术语（同义词 0 命中）；② 条号用**纯数字**
> （`--q 7.4.4`，查表块才写 `表6.4.1-1`）；③ 优先词组。库内已做去空白容错。

> 取不到条文的判定项 → 标"依据待核"，只出疑点不出结论。

**能算的不要只靠看** —— 凡报告给出数值结论，用复算脚本自己过一遍：

| 脚本 | 覆盖 | 关键参数（完整见 `norms.md` §一） |
|---|---|---|
| `calc_dam_crest.py` | 坝顶/防浪墙顶高程（Δh=h₁%+h_z+h_c）+ 表 4.2.1 | `--mode crest --grade --case`、`--top` |
| `calc_dam_stability.py` | 抗剪断 K′ / 抗剪 K / 深层 K | `--mode surface\|deep --method --combo` |
| `calc_dam_stress.py` | 坝踵/坝趾应力 + K_c + 拉应力 | `--mode base --w --b --xr --allow-concrete` |
| `calc_dam_seepage.py` | 帷幕 q 分档 + 帷幕深 + 排水孔 | `--mode curtain\|drain --height --q --depth` |

> 退出码：`0` 满足 · `1` 不满足 · `2` 输入错 · `3` 仅参考值。
> ▶ **载入**：`references/norms.md` §一（取条文方法、脚本用法与限制）。

## 第 2 步：跨专业一致性（最容易被漏的一层）

单块正确 ≠ 报告正确。共 **9 对交叉校验**：① 坝顶高程 ↔ 调洪最高库水位；② 断面尺寸 ↔
稳定/应力计算采用尺寸；③ 荷载组合表 ↔ 计算书工况；④ 建基面高程 ↔ 地质剖面；⑤ 帷幕深度 ↔
水头与相对隔水层；⑥ 排水孔深 ↔ 帷幕深度；⑦ 混凝土分区强度 ↔ 应力计算取值；⑧ 温控计算 ↔
施工组织层厚/温度；⑨ 监测布置 ↔ 计算与模型关注部位。

> ▶ **载入**：`references/checklist.md` §第 2 步。自洽性优先用复算脚本验算，不靠眼看。

## 边界

- 只给**条文级判据 + 限值表 + 复算**；不做设计、不替代审批。RCC 并用 SL 314（库内无）、浆砌石归 SL 25、拱坝归 SL 282（已废止）——**均不在范围**。
- 第 8~11 章与附录公式只核"有没有、是否自洽"，不重算模型；产出为**审查发现**非审批结论，责任在人。

> ▶ **载入**：`references/limits.md`（边界与已知局限）。
