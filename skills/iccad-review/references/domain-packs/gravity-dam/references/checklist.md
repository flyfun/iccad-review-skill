## 块 1　前置判定：坝型、级别、阶段与规范适用

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **规范适用边界** | SL 319-2018 适用于**岩基上 1、2、3 级混凝土重力坝**；4、5 级可参照。坝高 >200m 或特别重要的坝，特殊问题应**专门研究** | 砂砾石地基按 SL 319 审；4、5 级坝直接套 1 级指标 |
| **碾压混凝土坝不适用** | SL 319-2018 明文"碾压混凝土重力坝设计已制定专门标准，本标准不包含该部分内容"→ RCC 走 **SL 314** | RCC 报告全篇按 SL 319 判，漏 SL 314 的层间抗滑与防渗要求 |
| **浆砌石坝不适用** | 浆砌石重力坝走 **SL 25**；SL 319 只覆盖混凝土 | 砌石坝套混凝土坝应力指标 |
| **坝高分级** | 坝高 <30m 低坝；30~70m（含）中坝；>70m 高坝。坝高＝建基面最低点（不含局部深槽、井、洞）至坝顶 | 用最大坝高代替坝高；把局部深槽计入坝高 |
| **工程级别与洪水标准** | 级别按 SL 252；洪水标准按 GB 50201 + SL 252，两者不得冲突（取严） | 级别 2 级却用 3 级洪水标准 |
| **设计阶段深度** | 可研按 SL/T 618、初设按 SL/T 619 的章节与深度要求核对；施工图阶段应已有完整计算书 | 初设报告缺稳定/应力计算书，只给结论 |
| **安全评价/除险加固类** | 走 SL 258（安全评价导则）+ SL/T 877（除险加固导则），SL 319 作设计判据 | 安全评价报告直接套初设深度要求 |

## 块 2　总体布置与坝轴线

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **坝轴线** | 3.0.1：宜布置成直线；地形地质不容许时可用折线或曲线，**应论证** | 折线坝轴线无地形地质理由、无折角处结构加强 |
| **枢纽协调** | 3.0.2：泄洪、供水、发电、灌溉、航运、排沙、排漂、**过鱼**统一安排，避免相互干扰；宜**先定泄洪建筑物** | 泄洪与引水口互相顶冲；过鱼设施缺位（2018 新增要求） |
| **生态泄水与分层取水** | 3.0.2 / 3.0.9 / 3.0.10：生态泄水建筑物、分层取水建筑物应纳入布置；取水口高程按供水期引水位、水温、泥沙确定 | 只设一个底层取水口，高温期下泄低温水无解释 |
| **泄水孔设置理由** | 3.0.5：六种情形（泄洪／8 度以上或地质极复杂或需放空／下游供水灌溉／排沙／施工期结合／**生态用水**） | 无放空条件的水库不设放空设施且不论证 |
| **泄水孔选型** | 3.0.6：狭窄河道宜与溢流坝段结合、消能统一考虑；宽阔河道宜分开；排沙孔靠近进水口、船闸闸首且流态不得影响其运行 | 排沙孔出口正对电站进水口 |
| **导流建筑物** | 3.0.7：七项要求，含"施工期生态用水"与"便于回填封堵" | 导流底孔封堵方案缺失 |
| **模型试验** | 3.0.13：大型工程**应**做水工模型试验；中型工程**宜**做 | 大型工程无试验报告，仅数模 |

**▶ 载入**：`gd_works_tables.md` §二（布置要点）。

## 块 3　坝顶高程与坝体断面　★强条

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **坝顶高程（★）** | **4.2.1**：坝顶高程**应高于水库最高静水位**；防浪墙顶高程应高于波浪顶高程 | 坝顶高程＝正常蓄水位+超高，漏校核洪水位控制的工况 |
| **超高计算（★）** | **4.2.1**：Δh = h1% + hz + hc；**正常蓄水位与校核洪水位各算一遍，取防浪墙顶高程的高者** | 只算一个水位；两个水位取了低者 |
| **安全加高（★）** | **表 4.2.1**：正常蓄水位 1/2/3 级＝0.7/0.5/0.4m；校核洪水位＝0.5/0.4/0.3m | 校核工况误用正常蓄水位一列（偏大 0.2m，看似安全实则掩盖坝顶不足） |
| **波高参数** | h1%、hz 按 SL 744 计算；应给风区长度、风速、水深、累积频率 1% | 直接抄邻近工程波高，无风区长度 |
| **防浪墙构造** | §4.2：防浪墙宜与坝体连成整体，横缝处留伸缩缝并设止水；坝顶下游侧设栏杆 | 防浪墙与坝体分期浇筑、无连接钢筋 |
| **非溢流断面** | 4.3.1：基本断面呈三角形，顶点宜在**水库最高静水位附近** | 顶点按正常蓄水位定，超高段做成竖直墙 |
| **坝坡** | 4.3.2：上游坝坡宜 1∶0.2～1∶0；下游坝坡宜 1∶0.8～1∶0.6；折坡点结合进水口、泄水孔定 | 下游坡 1∶0.75 却无稳定/应力论证；折坡点压住进水口 |
| **进水口宽度** | 4.3.3：进水口或引水管道宽度不宜超过坝段宽度的 **1/2**，高坝应论证 | 坝段 15m、进水口宽 9m 无论证 |
| **宽缝坝构造** | 4.3.4～4.3.6：宽缝宽 20%～40% 坝段宽；头部厚度 0.07～0.10 倍水头且 ≥3.0m；尾部 ≥2.0m；宽缝不得贯穿坝顶 | 宽缝贯穿坝顶；头部厚 2.5m |

**▶ 载入**：`gd_tables.md` §一（表 4.2.1 与超高）、`compulsory-clauses.md` 强条 1。

## 块 4　水力设计与消能防冲

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **洪水标准** | 5.1.2：泄水与消能防冲洪水标准按 GB 50201 + SL 252 | 消能防冲按设计洪水、挡水按校核，两者混用 |
| **泄流能力** | 5.2.1：按附录 A.3 计算；应有水位～流量关系曲线与库容曲线同源 | 泄流曲线与库容曲线来自不同版本地形 |
| **水面线** | 5.2.2：Fr>2 应考虑波动与掺气；边墩/导墙顶高程＝计算水面线 + **0.5～1.5m** | 导墙顶低于掺气后水面线 |
| **消能型式选择** | 5.1.5～5.1.10：挑流宜用于坚硬岩基高、中坝；底流宜用于中低坝或软基；坝面台阶消能单宽流量 **<20m³/(s·m)**；联合消能应经模型试验 | 软基上选挑流；台阶消能单宽流量 35 未论证 |
| **挑距与冲坑** | 5.4.2：冲坑最低点距坝趾 **>2.5 倍坑深**；水舌入水宽度不影响岸坡稳定 | 只给冲坑深度，不给距坝趾距离 |
| **空蚀** | 5.3.1～5.3.4：流速 >20m/s 区域应查空蚀；空化数宜大于初生空化数；流速 >30m/s 宜掺气，>35m/s 应减压箱试验 | 溢流面流速 32m/s 无掺气设施 |
| **雾化** | 5.5.1～5.5.2：强雾化区应预测，建筑物与电气设备宜避开或防护 | 坝后式厂房、开关站布置在强雾化区无防护 |
| **闸门与门槽** | 4.4.2：设计洪水位闸门全开负压 ≤3×9.81kPa；校核 ≤6×9.81kPa；4.4.7 门槽不得产生过大负压 | 堰面负压只写"满足"不给数值 |

**▶ 载入**：`gd_tables.md` §五（水力限值）、`error-patterns.md` ●组。

## 块 5　荷载与荷载组合

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **荷载完整性** | 6.1.1：基本 9 项 + 特殊 7 项；**2018 版把"排水失效时的扬压力"列为特殊荷载** | 特殊组合漏"排水失效"工况 |

## 块 6　坝基应力与坝体应力　★强条

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **应力公式** | 6.3.2：σy = ΣW/A ± ΣM·x/J，材料力学法；ΣW **含扬压力** | 用有限元峰值应力直接对材料力学指标 |
| **坝踵不出现拉应力（★）** | **6.3.3-1**：各种荷载组合（地震除外）坝踵垂直应力**不应出现拉应力** | 坝踵 −0.05MPa 写成"基本无拉应力，满足" |
| **坝趾压应力（★）** | **6.3.3-1**：不应大于**坝体混凝土容许压应力**，并**不应大于基岩容许承载力**（两个都要满足） | 只对混凝土容许应力，漏基岩承载力 |
| **施工期（★）** | **6.3.3-2**：施工期坝趾垂直应力可允许 **<0.1MPa** 的拉应力 | 施工期坝踵/坝趾混用运用期指标 |
| **坝体应力（★）** | **6.3.4-1**：上游面垂直应力不出现拉应力（计扬压力）；最大主压应力 ≤ 容许压应力 | 只算坝基面，不算坝体内部截面与折坡截面 |
| **下游面主拉应力（★）** | **6.3.4-2**：施工期下游面主拉应力 ≤**0.2MPa** | 施工期下游面拉应力 0.35MPa 未处理 |
| **容许应力（★）** | **6.3.10**：抗压安全系数 基本 **≥4.0**、特殊（不含地震）**≥3.5**；抗拉 **≥4.0**；地震拟静力 3.5/2.08、动力 2.3/1.0 | 用 3.0 当基本组合抗压安全系数（套了旧版/其他规范） |
| **有限元拉应力区** | 6.3.8：坝踵垂直拉应力区宽度宜小于坝踵至帷幕中心线距离，**且宜小于 0.07 倍坝底宽** | 有限元算出拉应力区 0.12B 仍判满足 |
| **岸坡坝段** | 6.3.6：应计算三向荷载共同作用下的应力，坝踵宜为压应力 | 岸坡坝段只做平面问题 |
| **局部拉应力** | 6.3.4-3：溢流坝堰顶出现拉应力**应配筋**；廊道孔洞周边宜配筋 | 堰顶拉应力 0.6MPa 无配筋 |

**▶ 载入**：`compulsory-clauses.md` 强条 2/3/4、`numeric-checks.md` §一、脚本 `calc_dam_stress.py`。

## 块 7　抗滑稳定（含深层）　★强条

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **抗剪断 K′（★）** | **6.4.1 + 表 6.4.1-1**：K′=(f′ΣW+c′A)/ΣP；基本 **3.0**、特殊(1) **2.5**、特殊(2) **2.3** | 三类组合都用 3.0；把特殊(1) 的 2.5 写成 2.3 |
| **抗剪 K（★）** | **6.4.1 + 表 6.4.1-2**：K=fΣW/ΣP；基本 1.10/1.05/1.05（1/2/3 级）；特殊(1) 1.05/1.00/1.00；特殊(2) 1.00/1.00/1.00 | 抗剪公式套抗剪断的 3.0；不分坝级取 1.10 |
| **公式与参数匹配** | 6.4.1：抗剪断用 **f′、c′**；抗剪用 **f**。两套参数不得混用 | 公式用 f′+c′，限值却套表 6.4.1-2 |
| **参数来源** | 6.4.9：可研及以后阶段**应经现场试验**确定；中型中低坝无条件时可室内试验并参照附录 D | 高坝只用附录 D 经验值，无试验 |
| **静/动取值** | 6.4.8：静力取峰值**小值平均**；动力取峰值**平均** | 地震工况仍用小值平均（偏保守但口径需说明） |
| **深层抗滑（★）** | 6.4.2～6.4.3：存在软弱结构面、缓倾角裂隙**应**核算；抗剪断 K′ 用表 6.4.1-1，抗剪 K 用 **表 6.4.3**（基本 1.35/1.30/1.25） | 有缓倾角夹层但只算坝基面；深层抗滑套表 6.4.1-2 |
| **侧向与相邻坝段** | 6.4.4：缓倾角结构面与水流交角大时可按三维计侧向阻滑；横缝设键槽并灌浆可计相邻坝段 | 未灌浆的横缝也算相邻坝段阻滑 |
| **岸坡坝段** | 6.4.7：较陡岸坡坝段宜按**三向荷载合力方向**分析 | 岸坡坝段按平面滑动算 |
| **有限元稳定** | 6.4.6：宜用变形体极限分析，临界失稳按**塑性区贯通**准则 | 用强度折减系数直接当 K 与规范表比 |

## 块 8　坝基处理　★强条（帷幕）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **建基面** | 7.2.1：坝高 >100m 可建在新鲜～弱风化下部；50~100m 微风化～弱风化中部；<50m 弱风化中部～上部 | 100m 坝建在弱风化上部无专门论证 |
| **建基面形态** | 7.2.2：上、下游高差不宜过大，宜略向上游倾斜；高差大或向下游倾斜应挖成钝角大台阶 | 建基面倾向下游且无齿槽 |
| **地质缺陷** | 7.2.4：夹泥裂隙、风化囊、断层破碎带、岩溶充填物、浅埋软弱夹层应挖除或处理后回填 | 只写"已清理"，无处理图 |
| **固结灌浆** | 7.3.1～7.3.5：孔距排距 **3~4m**；深度 **5~8m**，帷幕上游区按帷幕深加深；压力 有盖重 **0.4~0.7MPa**、无盖重 0.2~0.4MPa | 全坝基统一 5m，帷幕上游未加深 |
| **帷幕防渗标准（★）** | **7.4.4**：坝高 >100m → q=**1~3Lu**；50~100m → **3~5Lu**；<50m → **≤5Lu** | q 按 5Lu 设计 120m 高坝（超标准 2Lu） |
| **帷幕深度** | 7.4.5：封闭式伸入相对隔水层 **3~5m**；悬挂式（非岩溶）**0.3~0.7 倍水头** | 悬挂式帷幕 0.2H 且无渗流计算 |
| **帷幕排数孔距** | 7.4.8：坝高 ≥100m 可两排、<100m 可一排；孔距 **1.0~3.0m**；多排时其余排深取设计深 **1/2~2/3** | 孔距 4m 仍称满足 |
| **灌浆压力** | 7.4.9：第 1 段 **1.0~1.5 倍**坝前静水头，孔底段 **2~3 倍**；不得抬动坝体与基岩 | 全孔一个压力，无分段 |
| **排水** | 7.4.10 / 7.4.13 / 7.4.14：主排水孔距帷幕 ≥**2m**；孔距 **2~3m**；孔深 **0.4~0.6 倍**帷幕深且高、中坝 **≥10m**；辅助 6~12m | 主排水孔 8m（<10m）；排水孔设在帷幕上游 |
| **断层与岩溶** | 7.5.2：混凝土塞深度 **1.0~1.5 倍**断层带宽；7.6：岩溶追索开挖回填或阻浆洞后高压灌浆 | 断层带只做固结灌浆，无混凝土塞 |

**▶ 载入**：`compulsory-clauses.md` 强条 6、`gd_tables.md` §四、脚本 `calc_dam_seepage.py`。

## 块 9　坝体构造（廊道、分缝、止水、排水）

> 本节 2018 版句级条号未逐条核到，**只引到节**（§8.1～§8.4），数值为规范构造要求。

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **廊道设置** | §8.2：高、中坝**必须**设基础灌浆廊道；底板混凝土厚 ≥**3m**；多层廊道层高 **20~40m**，层间设通道 | 中坝不设灌浆廊道 |
| **廊道与孔洞距离** | §8.2：廊道与泄水孔洞距离 **3~5m**，并应通过应力分析；上游壁离上游坝面 **0.05~0.1 倍水头且 ≥3m** | 廊道紧贴上游面 2m |
| **廊道断面** | §8.2：灌浆廊道宽 **2.5~3.0m**、高 **3.0~3.5m**；其他廊道最小 **1.2×2.2m** | 爬梯井兼作灌浆廊道，钻机进不去 |
| **横缝间距** | §8.3：横缝间距一般 **15~20m**；>22m 或 <12m 应论证 | 通仓浇筑 30m 不设纵缝且无温控论证 |
| **灌浆分区** | §8.3：每一灌浆区面积 **200~400m²**、高度 **10~15m**；灌浆压力 **0.1~0.3MPa** | 全坝段一个灌浆区 |
| **止水** | §8.4：高坝上游面横缝**两道止水片**，其间宜设排水井；铜片厚 **1.0~1.6mm**，每侧埋入混凝土 **20~25cm**；埋入基岩 **30~50cm** | 高坝只设一道止水；止水片未与基岩连接 |
| **坝体排水** | §8.4：上游面防渗层下游设竖向排水管系，管距 **2~3m**、内径 **15~25cm**，下部通排水廊道 | 排水管堵塞无检修通道 |
| **分缝与温控衔接** | §8.3：纵横缝划分应结合地形地质、断面尺寸、**温度应力**与施工条件比较确定 | 分缝与温控计算各写一套，缝距不一致 |

**▶ 载入**：`gd_tables.md` §六（构造数值）。

## 块 10　大坝材料与温度控制

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **混凝土分区** | §8.5：按部位分 Ⅰ～Ⅵ 区（水上／水位变动／水下／基础／内部／抗冲刷），分区性能表控制强度、抗渗、抗冻、抗冲耐磨 | 全坝一个强度等级，溢流面与内部同标号 |
| **强度等级表示** | 2018 版改用**设计龄期 150mm 立方体抗压强度**（C＋龄期＋强度），不再用"R90/R28 标号" | 新版报告仍写 R90100 |
| **抗渗等级** | §8.5：坝体内部 W2；其他部位按水力坡降 i：i<10→W4，10≤i<30→W6，30≤i<50→W8，i≥50→W10 | 水位变动区统一 W4 |
| **最大水灰比** | §8.5：严寒寒冷地区 0.45~0.65（分区不同）；温和地区 0.50~0.65；有侵蚀性时水位变动区与水下再减 **0.05** | 全坝 0.55，溢流面也 0.55 |
| **基础温差** | §10.2：基础约束区容许温差按浇筑块长边与距基础高度取 **26~14℃** 区间；超出范围的浇筑块应**论证** | 28℃ 基础温差无温控措施 |
| **上下层温差** | §10.2：上层短间歇均匀上升高度 >0.5 块长时，容许温差 **15~20℃** | 长间歇后直接浇上层，无温差核算 |
| **表面保护** | §10.2：日平均气温 2~3d 内连续下降 **≥6~9℃** 时，未满 28d 暴露面应保护 | 只写"加强保温"，无触发条件 |
| **浇筑层厚与间歇** | §10.3：基础部位层厚 **1.5~2.0m**；夏季可减薄但**不宜 <1.0m**；相邻坝块高差 ≤**10~12m**、间隔 <**30d** | 基础区 3m 通仓一次到顶 |
| **通水冷却** | §10.3：混凝土与冷却水温差 **≤25℃**；坝体降温速度 **≤1℃/d** | 制冷水 4℃ 通入 30℃ 混凝土 |
| **接缝灌浆温度** | §10.3：接缝灌浆温度一般取坝体稳定温度；宜在低温季节灌浆 | 夏季高温灌浆无保温措施 |

**▶ 载入**：`gd_tables.md` §六（材料与温控）、`error-patterns.md` ★组。

## 块 11　安全监测

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **监测范围** | §11.1：坝体、坝基、坝肩，以及对大坝安全有重大影响的近坝区岸坡与相关建筑物设备 | 只设坝体变形，无坝基扬压力 |
| **监测重点** | §11.2：常规项目中以**变形**和**基础渗流**为重点 | 应力应变测点多于渗流测点 |
| **渗流监测布置** | §11.2：纵向监测断面 1~2 个（宜在第一道排水幕线上），每个坝段 1 个测点；横向断面 ≥3 个、间距 50~100m、每断面 ≥3 点 | 横向断面 1 个 |
| **扬压力与渗流量** | §11.2：扬压力、坝基深部渗透压力、绕坝渗流、渗流量、水质分析均属常规项目 | 无渗流量量水堰 |
| **变形监测** | §11.2：水平位移宜用引张线／真空激光／垂线；坝体挠度用垂线；垂直位移用精密水准 | 只设视准线，坝轴线较长时精度不足 |
| **自动化** | §11.1：1、2 级坝重要测点宜设自动化监测系统，同时**应具备人工观测条件** | 全自动化、无人工比测 |
| **基准值与警戒值** | §11.1：首次蓄水前应取得各测点基准值；1、2 级坝重点坝段位移与扬压力宜提**警戒值** | 蓄水后才取基准值 |
| **与计算假定对应** | 设计用有限元算出的拉应力区、深层抗滑控制面，应在对应部位布测点 | 计算关注坝踵拉应力，坝踵无测点 |

## 块 12　加高加固、结论与附件

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **加高设计** | §9.2（2018 新增章）：加高应核算原坝体应力与稳定、新老混凝土结合面抗滑与止水、加高后坝顶高程与超高 | 加高报告只算新增部分，不复核原坝 |
| **加固设计** | §9.3：应按病害成因选措施（坝体裂缝、坝基渗漏、深层抗滑不足、混凝土老化），并核算加固后整体稳定 | 渗漏坝段只做表面修补 |
| **加固后复核** | 加固后抗滑、应力仍须满足 6.3 / 6.4 的现行限值（不得沿用原设计年份的旧标准） | 用 1970 年代标准判"满足" |
| **结论可追** | 结论应回答"坝顶高程多少、断面多大、K′/K 多少、帷幕与排水怎么布"；不得只写"满足规范" | 结论"各项指标满足规范要求"，无一个数值 |
| **强条单列** | 违反强条的事项应在结论中**单独列条**并明确"必须修改" | 强条问题混在一般意见里 |
| **附件完整性** | 应有：水文水利计算书、坝址工程地质报告、稳定与应力计算书、水工模型试验报告（大型）、灌浆试验报告、监测设计图 | 缺稳定计算书，只在正文给结果表 |
| **图纸一致性** | 坝顶高程、坝坡、帷幕深度、排水孔深在**正文／计算书／图纸**三处一致 | 图纸帷幕 45m、正文 40m |
