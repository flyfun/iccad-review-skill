## 二、输入 / 解析边界

- **docx 表格可自助提取**：`scripts/extract_docx_tables.py`（**网格重建**，正确处理横向 gridSpan / 纵向 vMerge）。
  正文段落用 `--text-only`。**PDF / 扫描件不在本技能内**，须另用 OCR / PDF 工具。
- **报告没写的，判不了**：
  - 没给 `f′`、`c′` → 无法复算抗滑，只能判"参数缺失（○）"；
  - 没给坝基面应力或合力作用点 → 无法复算 σ，只能判"计算书缺失"；
  - 没给设计洪水位 / 正常蓄水位 → 无法复算坝顶高程；
  - 没给帷幕设计 q 值 → 无法判 7.4.4 是否达标（只能判"未明确防渗标准"）。
- **附图/影像无法自动审**：坝址地形地质图、坝轴线地质剖面图、坝体横剖面图、
  稳定/应力计算简图、水力计算简图、监测布置图、分缝止水大样图 —— **须人工看图**。
  本技能只能核"图在不在、图号与正文引用是否对得上"。
- **报告属性要先判**：
  - 阶段（可研 / 初设 / 施工图 / 安全评价 / 除险加固 / 蓄水安全鉴定）→ 决定章节深度与判据松紧；
  - 坝型（实体 / 宽缝 / 空腹 / RCC / 浆砌石）→ 决定是否适用 SL 319；
  - 坝级（1/2/3）→ 决定表 4.2.1、表 6.4.1-2、表 6.4.3 取值。
  **三者定错，后续全走错章。**

## 五、复算脚本的能力边界（4 个）

> **统一语义**：每个复算器都做**"复算值 / 规范限值 / 报告值"三方比对**，退出码
> `0` 满足 · `1` 不满足（含违反强条、与报告显著不符）· `2` 输入错 · `3` 仅参考值。
> **判据方向**：下限型（安全系数、超高、深度、距离）与上限型（透水率、应力、孔距、温差）
> —— 方向判反即为错情。

### 5.1 `calc_dam_crest.py` —— 坝顶高程
- **算什么**：Δh = h₁% + h_z + h_c，逐工况算防浪墙顶高程 = 水位 + Δh，取**最高者**；
  坝顶高程 = 防浪墙顶 − 墙高。
- **参数**：`--mode crest|hc`、`--grade`、`--case name,h1%,hz,zw`（可重复，name ∈ normal/check）、
  `--wall-h`、`--top`（报告坝顶高程）、`--parapet`（报告防浪墙顶高程）。
- **不代算什么**：h₁% 与 h_z 本身（须按 SL 744 算或取报告值）、**风浪爬高**（重力坝不控制）、
  地震涌浪（须另按 GB 51247）。
- **已知局限**：只做"两水位取高者"这一条路径；若报告还叠加了**地震涌浪**或**库区滑坡涌浪**，
  须人工补判。

### 5.2 `calc_dam_stability.py` —— 抗滑稳定
- **算什么**：`K′=(f′ΣW+c′A)/ΣP`、`K=fΣW/ΣP`；deep 模式只比对给定 K 与表 6.4.3。
- **参数**：`--mode surface|deep`、`--method shear-strength|shear-friction`、
  `--combo basic|special1|special2`、`--grade`、`--w/--p/--f/--c/--a`、`--value`（deep）。
- **不代算什么**：ΣW / ΣP 本身的荷载组合（须报告给）、**深层抗滑的滑面搜索与力的分解**
  （须报告给 K 值）、三维效应、扬压力折减系数 α 的取值合理性。
- **已知局限**：deep 模式**不重算**，只判"给定 K 是否 ≥ 表 6.4.3"；
  因此报告若没给深层 K，只能判"未评价（●）"，不能自行算。

### 5.3 `calc_dam_stress.py` —— 坝基 / 坝体应力
- **算什么**：`σ_u = ΣW/A·(1−6e/B)`、`σ_d = ΣW/A·(1+6e/B)`，e = B/2 − x_R；
  判 σ_u ≥ 0、σ_d ≤ min(混凝土容许, 基岩容许)、K_c = f_c/σ_d ≥ 4.0/3.5；
  `--mode allow` 反算容许应力。
- **参数**：`--mode base|allow`、`--w/--b/--xr`、`--allow-concrete`（混凝土容许压应力）、
  `--allow-rock`（基岩容许承载力）、`--fc`（设计龄期极限抗压强度）、`--ft`、`--stage operation|construction`、
  `--combo`、`--seismic quasi|dynamic`、`--sigma-u/--sigma-d`（报告值）。
- **不代算什么**：**主应力**（须用材料力学或有限元，本脚本只给垂直正应力）、
  坝体内部应力分布、温度应力、地震动力应力。
- **已知局限**：假定**坝基面为水平面、应力线性分布**（材料力学法）。
  若报告用**有限元**，本脚本结果只能作**量级校核**，不能直接否定有限元结论。

### 5.4 `calc_dam_seepage.py` —— 防渗与排水
- **算什么**：
  - `curtain`：按坝高分档判 q 上限（7.4.4）；判帷幕深度比 0.3~0.7H（悬挂式）或伸入相对隔水层 3~5m（封闭式）；
  - `drain`：判孔距（2~3 / 3~5m）、孔深比（0.4~0.6 倍帷幕深）且高/中坝 ≥10m、与帷幕距离 ≥2m；
  - `uplift`：按四段梯形算单宽扬压力合力 U（**仅参考值，固定 rc=3**）。
- **参数**：`--mode curtain|drain|uplift`、`--height`（坝高）、`--h`（水头）、`--q`、`--depth`、
  `--karst`、`--curtain-depth`、`--drain-depth`、`--type main|aux`、`--spacing`、`--distance`、
  `--b/--h2/--x-grout/--x-drain/--alpha1/--alpha2/--gamma`（uplift）。
- **不代算什么**：**渗流场**（须用二维/三维渗流有限元或流网法）、渗流量、帷幕实际灌浆效果、
  扬压力折减系数 α 的取值合理性（只按给定 α 算）。
- **已知局限**：`uplift` 模式的四段折线是**简化图形**，与规范附录的精确图形可能有差异；
  仅用于快速量级核对，**不得作为判定依据**（故固定 rc=3）。

## 六、判定责任边界

- 本技能产出的是**审查发现**，不是审批结论；最终判定责任在人，**AI 结论须经复核**。
- 涉**行政审批与规划符合性**的，本技能只提供技术审查辅助，**不替代行政许可程序**。
- 涉专业软件的成果（数值模拟、试验）本技能**只核结论间是否自洽、参数是否齐全**，不重算模型。
- 本技能**不做**：造价审查、施工组织进度合理性、移民征地、环境影响评价（转环评技能）。
