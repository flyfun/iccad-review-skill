# 混凝土重力坝工程报告审查 — 常见错情模式

> 出发现前对照本册，**同类问题按模式归并、避免重复计数**，并据此定严重度。
> 每条 = **模式** + **典型表现** + **判定依据** + **默认严重度**。

**严重度**：★ 违反强制性条文 / 关键指标超限影响安全；● 不符规范、方案缺项；
○ 深度不足、专业间不一致、图文不符、附件附图缺失。

---

## ★ 级（9 条）

### ★ E01　坝顶 / 防浪墙顶高程不足
- **表现**：只按正常蓄水位算超高；或把 Δh 直接当坝顶高程（漏减防浪墙高）；或安全加高按错级别/工况；
  或坝顶高程低于水库最高静水位。
- **依据**：SL 319-2018 **4.2.1（强条）** + 表 4.2.1。
- **复核**：`calc_dam_crest.py --mode crest --grade N --case normal,... --case check,... --wall-h ... --top ...`；
  两水位各算一遍取高者，坝顶 = 防浪墙顶 − 墙高。

### ★ E02　运用期坝踵出现拉应力
- **表现**：坝基面垂直应力 σ_u < 0（拉应力），报告却写"满足"或用"局部拉应力允许"辩解。
- **依据**：SL 319-2018 **6.3.3 1 款 1）项（强条）**：坝踵垂直应力**不应出现拉应力**。
- **复核**：`calc_dam_stress.py --mode base --xr ...`；注意 6.3.4 允许的"局部拉应力"
  只适用于**坝体内部**（宽缝坝离上游面较远区域），**不适用于坝基面坝踵**——两者不可混用。

### ★ E03　坝趾压应力超容许压应力或基岩承载力
- **表现**：只核了混凝土容许压应力，漏核基岩容许承载力（或反之）；或用了动态容许应力去核静力工况。
- **依据**：SL 319-2018 **6.3.3 1 款 1）项（强条）**：两个上限**并列**，取小者控制。
- **复核**：`calc_dam_stress.py --mode base --allow-concrete ... --allow-rock ...`；两值都传，分别判、取严者。

### ★ E04　坝基面抗滑稳定安全系数不足
- **表现**：K′ < 3.0（基本组合）仍判合格；或按坝级给 K′ 分档（编造表值）；或特殊(1)/(2) 限值用反。
- **依据**：SL 319-2018 **6.4.1（强条，整条）** + 表 6.4.1-1（**不分坝级**）/ 表 6.4.1-2（按坝级）。
- **复核**：`calc_dam_stability.py --method shear-strength|shear-friction --combo ... --grade ...`

### ★ E05　抗滑计算口径错（漏扬压力 / 参数取错对象）
- **表现**：ΣW 未计扬压力（或只计浮托力不计渗透压力）；f′、c′ 用了**岩体**抗剪指标而非
  **混凝土/岩基接触面**指标；c′ 用 MPa 而 A 用 m²、ΣP 用 kN，量纲不统一。
- **依据**：SL 319-2018 **6.4.1（强条）**原文明确"ΣW 包括扬压力"。
- **复核**：查报告计算书参数表来源；`calc_dam_stability.py` 要求单位统一为 kN / m² / kPa。

### ★ E06　容许应力安全系数不足 / 强度基数取错
- **表现**：K_c < 4.0（基本）或 < 3.5（特殊非地震）；强度用 100mm 试件、85% 保证率、
  或 28d 非设计龄期；地震工况用静态容许应力。
- **依据**：SL 319-2018 **6.3.10（强条，1 款、2 款）**+ 注（150mm 立方体、保证率 80%、动/静 1.2 与 0.1 倍）。
- **复核**：`calc_dam_stress.py --mode base --fc ...`（fc 必须是设计龄期 150mm 立方体 80% 保证率值）。

### ★ E07　施工期应力超限
- **表现**：施工期坝趾拉应力 ≥ 0.1 MPa；或下游面主拉应力 > 0.2 MPa；或根本没做施工期工况。
- **依据**：SL 319-2018 **6.3.3 2 款（强条）**（<0.1MPa）、**6.3.4 2 款 2）项（强条）**（≤0.2MPa）。
- **复核**：`calc_dam_stress.py --stage construction`；注意 0.1 是**严格小于**，等于不放行。

### ★ E08　帷幕体透水率不达标
- **表现**：高坝（>100m）设计 q=4~5Lu；或不分坝高统一按 5Lu；或把 q 的区间上限当目标值。
- **依据**：SL 319-2018 **7.4.4（强条，1 款、2 款）**：>100m 为 1~3Lu；50~100m 为 3~5Lu；<50m ≤5Lu。
- **复核**：`calc_dam_seepage.py --mode curtain --height H --q Q`。

### ★ E09　碾压混凝土坝未算碾压层（缝）面抗滑
- **表现**：报告为 RCC 重力坝，只算坝基面抗滑，未算沿碾压层（缝）面滑动；或用抗剪公式算层缝面。
- **依据**：**SL 314-2018 4.0.3（强条）**：层（缝）面抗滑**应采用抗剪断公式**，安全系数符合 SL 319。
- **复核**：查是否有层缝面抗滑章节；`calc_dam_stability.py --method shear-strength` 可用于层缝面
  （换用层缝面的 f′、c′），但**限值仍按表 6.4.1-1**。

## ● 级（14 条）

### ● E10　荷载组合不全 / 漏"排水失效"
- **表现**：只做基本组合；或特殊组合只做地震、漏校核洪水；或**未按 6.1.1 把"排水失效引起的扬压力"
  作为偶然作用**单独组合。
- **依据**：SL 319-2018 6.1.1、6.1.2。
- **复核**：查荷载组合表行数；正常应有 基本 / 特殊(1) / 特殊(2) 三组，且含排水失效敏感性工况。

### ● E11　深层抗滑未算或限值用错
- **表现**：坝基有缓倾角软弱结构面却只算表层滑动；或深层抗滑用表 6.4.1-1 的 3.0；
  或按单滑面算却未留安全裕度。
- **依据**：SL 319-2018 6.4.3 + 表 6.4.3（基本 1.35/1.30/1.25）；表注"单滑面留安全裕度"；
  **深层抗剪断仍回表 6.4.1-1**。
- **复核**：`calc_dam_stability.py --mode deep --value K --grade N --combo ...`

### ● E12　坝基开挖深度与建基面处理不当
- **表现**：建基面设在强风化岩体；坝基面水平无齿槽；坝踵处形成锐角/尖角未渐变；
  基坑开挖边坡未做稳定验算。
- **依据**：SL 319-2018 §7.2（句级条号待核，只引到节）+ SL/T 386（边坡）。
- **复核**：查地质剖面图与建基面高程；查坝踵体型大样图。

### ● E13　帷幕深度 / 型式判错
- **表现**：悬挂式帷幕深度 < 0.3 倍水头；封闭式帷幕未伸入相对隔水层 3~5m；
  把悬挂式按封闭式论证；帷幕排数、孔距无灌浆试验依据。
- **依据**：SL 319-2018 7.4.5、7.4.8、7.4.9。
- **复核**：`calc_dam_seepage.py --mode curtain --height H --h 水头 --depth D --q Q`
  （悬挂式按 0.3~0.7H 判深度比；封闭式脚本只提示"须核伸入相对隔水层 3~5m"，须人工核）。

### ● E14　排水系统布置不满足
- **表现**：主排水孔与帷幕孔距离 < 2m；主排水孔孔距 > 3m；孔深 < 0.4 倍帷幕深；
  高/中坝孔深 < 10m（漏并列条件）。
- **依据**：SL 319-2018 7.4.10（≥2m）、7.4.13（2~3m / 3~5m）、7.4.14（0.4~0.6 倍且 ≥10m；辅助 6~12m）。
- **复核**：`calc_dam_seepage.py --mode drain --curtain-depth ... --drain-depth ... --spacing ...`

### ● E15　断层破碎带 / 软弱夹层未处理
- **表现**：坝基下断层破碎带只做"加强固结灌浆"处理，未挖除回填混凝土塞、未设传力洞塞；
  缓倾角软弱夹层未评价深层抗滑。
- **依据**：SL 319-2018 §7.5（断层破碎带与软弱结构面处理）+ SL/T 792（地基处理）。
- **复核**：查地质剖面与处理设计图；断层宽度 > 1m 一般应挖除回填。

### ● E16　泄流能力计算漏侧收缩 / 淹没影响
- **表现**：直接用堰流公式 Q=m·b·√(2g)·H^1.5，未乘侧收缩系数、未判淹没出流；
  溢流坝与泄水孔泄量简单相加未考虑相互影响。
- **依据**：SL 319-2018 §5.1 + 附录 A（公式本体为图片，须核原件）。
- **复核**：查泄流能力计算书；与 SL 104 调洪成果对照，反推泄量是否自洽。

### ● E17　消能防冲未验算 / 冲坑影响未评价
- **表现**：只写"采用挑流消能"，无冲坑深度计算、无冲坑上游坡对坝基稳定影响评价；
  或护坦长度无计算依据。
- **依据**：SL 319-2018 §5.3、§5.4。
- **复核**：查水工模型试验报告或计算书；冲坑上游坡应缓于 1:3~1:4（经验值，非规范硬限）。

### ● E18　高坝泄洪雾化未专门论证
- **表现**：坝高 > 100m、挑流泄洪，报告未提雾化影响范围、未评价对两岸边坡与开关站的影响。
- **依据**：SL 319-2018 **§5.5 泄洪雾化**（2018 新增节）。
- **复核**：查是否有序幕化的雾化范围估算或模型试验；高坝大流量必查。

### ● E19　坝身泄水孔构造缺失
- **表现**：未设事故检修闸门；孔内流速 > 40 m/s 未做防空蚀论证；进水口体型突变（形成负压）。
- **依据**：SL 319-2018 §4.5（4.5.1~4.5.11）。
- **复核**：查孔口纵剖面图与闸门布置图；核流速 = Q/A。

### ● E20　坝体分缝灌浆与止水不满足
- **表现**：横缝未设键槽、未灌浆即蓄水；上游面止水只 1 道；未设排水检查廊道。
- **依据**：SL 319-2018 §8.3、§8.4（只引到节）。
- **复核**：查分缝布置图与止水大样图。

### ● E21　混凝土分区与抗渗抗冻不满足
- **表现**：上游面与坝基未设防渗层（Ⅰ 区）；全坝一个抗渗等级；严寒区抗冻等级不足；
  骨料最大粒径超过结构尺寸 1/4。
- **依据**：SL 319-2018 §8.5（只引到节）。
- **复核**：查混凝土分区图与材料表；限值见 `gd_tables.md` 6.2。

### ● E22　温控防裂措施缺失
- **表现**：无温控计算；浇筑层厚 > 3m；夏季浇筑温度无控制；内外温差 > 25℃；无表面保温。
- **依据**：SL 319-2018 **§10**（2018 版第 10 章，2005 版为第 9 章）。
- **复核**：查温控计算书与施工组织；限值见 `gd_tables.md` 6.3。

### ● E23　溢流坝堰顶 / 廊道周边拉应力未配筋
- **表现**：溢流坝堰顶出现拉应力，未配钢筋；廊道周边拉应力区未配筋也无论证。
- **依据**：SL 319-2018 6.3.4 **3 款 2）项**（"应配置钢筋"）、3 款 3）项（"宜配置钢筋"）。
- **复核**：查坝体应力等值线图 + 配筋图。注意 3 款**不属强条**，故列 ●。

## ○ 级（7 条）

### ○ E24　计算书与正文数值不一致
- **表现**：正文写 K′=3.12，计算书附表算得 2.86；或正文引用旧版计算书数据。
- **依据**：报告内部一致性要求。
- **复核**：抽查 3~5 个关键指标，正文 ↔ 计算书 ↔ 结论表三方对齐。

### ○ E25　参数取值无地质 / 试验依据
- **表现**：f′、c′、基岩承载力、变形模量直接给值，无勘察报告或试验成果出处。
- **依据**：GB 50021、SL 319 §7.1。
- **复核**：查参数取值表是否标注来源（钻孔号 / 试验组号 / 类比工程）。

### ○ E26　水位与高程系统不一致
- **表现**：坝顶高程用黄海高程、水位用假设高程；或各章高程基准不同未说明；
  坝顶高程与洪水调节成果的最高库水位矛盾。
- **依据**：报告内部一致性 + SL 104。
- **复核**：核对各章高程基准声明；坝顶高程 − 最高静水位 ≥ Δh。

### ○ E27　附图与附件缺失
- **表现**：缺坝址地形地质图、坝轴线地质剖面图、坝体横剖面图、稳定/应力计算简图、
  水力计算简图、监测布置图。
- **依据**：SL/T 618（可研）、SL/T 619（初设）报告编制规程。
- **复核**：对照编制规程的附图目录逐项点数。

### ○ E28　引用已废止标准
- **表现**：引 SL 319-2005、SL 203、SL 282；或引 SL 319 但用 2005 版条号（如"8.1.1"）。
- **依据**：版本纪律（见 `norms.md` 第四节）。
- **复核**：全文正则扫 `SL\s*319[-—]?2005`、`SL\s*203`、`SL\s*282`；条号对照 2018 版体系。

### ○ E29　章节深度不足
- **表现**：可研阶段缺"坝型比选"；初设阶段缺"坝体分缝与温控"；
  加固类报告缺"现状安全评价"与"加固前后对比"。
- **依据**：SL/T 618、SL/T 619、SL/T 877。
- **复核**：对照 `gd_works_tables.md` 的章节映射表。

### ○ E30　单位与量纲混乱
- **表现**：应力 kPa/MPa 混用；抗滑公式中 c′ 用 MPa、A 用 m²、ΣP 用 kN；
  渗透系数 m/s 与 Lu 混用；扬压力用 m 水头与 kPa 混用。
- **依据**：SL 319 公式量纲；见 `gd_tables.md` 第八节 12 条易错点。
- **复核**：抽查公式代入过程，逐步核单位。

## 附：归并规则

**要归并成一条**（同一根因，只计一次）：
1. **漏扬压力** → 导致 K′ 不足、σ_u 出现拉应力、σ_d 超限 **多项超限** → 归为 **E05 一条**，
   在描述里列出各项数值。不写成 3 条。
2. **坝顶高程不足** → 连带"防浪墙高度不够""坝顶宽度不足" → 归为 **E01 一条**。
3. **参数取错**（如 f′ 用岩体值）→ 导致抗滑、深层抗滑双双不足 → 归为 **E05 一条**。
4. **强度基数错** → 导致抗压、抗拉安全系数同时不足 → 归为 **E06 一条**。
5. **未做某工况**（如未做施工期）→ 该工况下的多项指标缺失 → 归为 **一条"工况缺失"**，
   不逐指标列"未评价"。

**要拆开**（不同根因，分别计数）：
1. 坝踵拉应力（E02）与坝趾压应力超限（E03）—— 一个是下限、一个是上限，根因可能不同。
2. 坝基面抗滑（E04）与深层抗滑（E11）—— 滑动面不同，处理措施不同。
3. 帷幕（E08）与排水（E14）—— 防渗与排水是两套系统，可能一套合格一套不合格。
4. 高程不足（E01）与泄流能力不足（E16）—— 前者是挡水，后者是泄水。
5. 引用废止标准（E28）与条号用错（E28 内）—— 若同时存在，**拆成两条**：
   版本问题与条号问题是两种不同整改动作。

**不计数**：
- 同一句话在不同章节重复出现（如结论章复述正文错误）→ 只计 1 条，定位取**首次出现处**。
- 纯文字笔误、错别字、标点 → 不入错情清单，另附"编辑性意见"。
