## 三、关键构造要求（非数值类）

### 3.1 坝体分缝与坝段长度（§8.3）

| 要求 | 常见违反形态 |
|---|---|
| 横缝间距宜 **15~20m**（常态混凝土），坝段长宽比满足稳定与应力 | 坝段过长（>25m）未论证 |
| 横缝应设**梯形键槽**，并**灌浆**后蓄水 | 只设键槽不灌浆；或灌浆但无检查孔 |
| 纵缝（宽缝坝）应设**键槽 + 灌浆**，缝面设**止水** | 纵缝未灌浆即蓄水 |
| 坝体与岸坡连接处应设**周边缝**并止水 | 直接浇筑、无止水 |

### 3.2 坝体止水与排水（§8.4）

| 要求 | 常见违反形态 |
|---|---|
| 上游坝面横缝**不少于 2 道止水**（铜片 + 橡胶/塑料） | 只设 1 道 |
| 止水应形成**封闭的止水片（止水带）**，并伸入基岩 | 止水未嵌入基岩，形成渗漏通道 |
| 下游坝面设**排水孔**（间距 2~3m），坝体内部设排水管 | 无下游面排水，坝面析钙 |
| 廊道内设**排水沟 + 集水井**，渗水集中排出并计量 | 无集水井、无量水堰 |

### 3.3 坝内廊道与通道（§8.2）

| 要求 | 常见违反形态 |
|---|---|
| 基础灌浆廊道：宽 **1.5~2.5m**、高 **2.2~2.5m**，位于坝基面以上 | 廊道过小，钻机进不去 |
| 廊道间（层间）混凝土/岩体厚度 **≥3m** | 层间过薄，应力集中开裂 |
| 廊道应**连通**（竖向交通、通风、照明） | 各层廊道不连通，无法检修 |
| 廊道周边应**配筋**（拉应力区） | 廊道周边无配筋，出现裂缝 |

### 3.4 坝基处理构造（§7.2 / §7.3 / §7.5）

| 要求 | 常见违反形态 |
|---|---|
| 建基面应开挖至**微风化~新鲜岩体**，承载力满足 | 建基面在强风化带 |
| 坝基面宜**略向上游倾斜**（1:10 左右）或台阶状 | 水平建基面，抗滑不利 |
| **坝踵处应避免锐角/尖角**，做成渐变 | 坝踵形成尖角，应力集中 |
| 断层破碎带应**挖除回填混凝土塞**（宽度大者），并设**传力洞塞** | 只做固结灌浆 |
| 固结灌浆应设**检查孔**，压水检查合格 | 无检查孔、无压水试验 |
| 坝基排水孔应**倾向下游**，孔口设保护 | 垂直孔、孔口无保护 |

### 3.5 溢流面与泄水孔构造（§4.4 / §4.5）

| 要求 | 常见违反形态 |
|---|---|
| 堰面曲线应经**模型试验或规范公式**验证 | 直接套 WES 曲线、未核上游面坡度 |
| 溢流面混凝土应**抗冲耐磨**（≥C30、掺硅粉/纤维） | 用普通大体积混凝土 |
| 闸墩头部宜**流线型**（半圆或尖圆） | 方形墩头，绕流分离 |
| 坝身泄水孔应设**事故检修闸门**（动水关闭） | 只设工作闸门 |
| 孔内流速 > 40 m/s 应**专门论证防空蚀**（掺气坎/抗蚀材料） | 无论证、无掺气设施 |
| 出口应设**消能工**（挑坎/消力池） | 直接跌入河道 |

### 3.6 坝顶构造（§8.1）

| 要求 | 常见违反形态 |
|---|---|
| 坝顶路面应有**排水坡度**（1.5%~2%）和**防渗** | 无坡度、积水 |
| 防浪墙应**连续**，与坝体可靠连接，设**伸缩缝** | 防浪墙断开、无伸缩缝 |
| 坝顶应设**栏杆/护栏**（高度 ≥1.1m） | 无护栏 |
| 坝顶应留**监测点、照明、通信**位置 | 无预埋 |
