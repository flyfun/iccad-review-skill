# 泵站工程报告审查 — 完整检查项清单

配套 `SKILL.md` 第 1 步"分块审查"使用。按 **12 块**展开，每条含 **判定标准** 与 **失败模式**。

> **引用约定见 `norms.md`**（条款号取法、限值出处、强条处置、版本声明）。本文件不再重复。
> 标 **★强条** 者为 `compulsory-clauses.md` 所列强制性条文。
> 数值限值见 `ps_tables.md`；章节结构与报告目录见 `ps_works_tables.md`。
> **★块 = 泵站区别于其他水工建筑物的命门**（特征水位 / 扬程 / 安装高程）。

## 块 1　概述与设计依据

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **报告类型** | 明确属初设 / 可研 / 安全鉴定 / 更新改造；**不同类型对照不同目录**（初设→SL/T 533；可研→SL 560；安全鉴定→SL 316 附录 D/E；更新改造→GB 50265 §13） | 报告按初设目录写却交付安全鉴定，章节错位 |
| **设计依据现行性** | 引 **GB 50265-2022《泵站设计标准》**（注意 2010 版名为《泵站设计**规范**》，2022 改名"标准"）；引旧版 → **引用已废止标准** | 仍引 GB 50265-2010 或写"设计规范" |
| **任务与规模摘要** | 工程任务（灌溉/排水/供水/灌排结合）、设计流量、装机、特征扬程齐备 | 规模数据与后文不一致 |
| **标准清单** | 所列标准均为**现行有效版**；含 SL 316 / GB 50288 / SL 252 / GB 50201 等 | 混引作废版本、漏引等级标准 |

## 块 2　基本资料

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **水文与特征水位原始资料** | 需有**长系列水位/潮位**资料支撑各特征水位；缺则不成立 | 只用一两年资料定特征水位 |
| **水源含沙量与冰情** | 多泥沙 → 须提**抗磨蚀措施**并修正汽蚀余量（10.1.7-1）；寒冷地区冰盖下取水 → 应计**冰盖(含流冰)对水力损失的影响**（4.2.1-6） | 多泥沙水源未修正汽蚀参数 |
| **工程地质** | 地基承载力、抗剪断参数 f/C（附录 A 表 A.0.1~A.0.3）、地震动峰值加速度 | 缺抗剪断参数却做岩基稳定 |
| **地形与供电** | 站址地形、河势、供电电源与负荷等级 | 供电不落实即定电气方案 |

## 块 3　工程规模与等别 ★

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **设计流量** | 灌溉→水量平衡满足保证率的最大平均提水流量（4.1.1）；排水→产汇流/排涝模数/平均排除/调蓄计算（4.1.2）；供水→按设计水平年+保证率+时/日变化系数（4.1.3） | 灌溉站用排涝模数、排水站套灌溉公式 |
| **泵站等别/建筑物级别** | 治涝/排水/灌溉按 **SL 252 表 4.5.3**（设计流量 + 装机功率）；**供水按表 4.7.1**；分属两级取**高者** | 用错表（供水站套 4.5.3）；只用流量不看装机 |
| **防洪(潮)标准** | 按 **SL 252 表 5.5.3**（按级别取设计/校核重现期）；穿堤坝/渠道布置 → **不应低于堤坝(渠道)防洪标准并留安全裕度**（SL 252 5.1.4 ★ / GB 50201 11.8.3 ★） | **等于**堤防标准即判满足；漏"留安全裕度" |
| **合理使用年限** | 按 SL/T 654 定耐久性要求（3.0.3） | 未提耐久性设计 |

## 块 4　特征水位 ★★（本域命门）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **两侧水位齐备** | **站上(出水池) + 站下(进水池)** 各含**防洪(潮)/最高运行/设计运行/平均/最低运行**5 个（§4.2 各站型） | 只给设计水位；缺最高/最低运行水位 |
| **取值规则对站型** | 灌溉（4.2.1/4.2.2）、排水（4.2.3/4.2.4）、供水（4.2.5/4.2.6）**各有专属规则**，不可套用 | 灌溉站套排水取值；供水最低水位保证率写成 95% |
| **扣水力损失** | 各水位**均应扣除从取水口至进水池的水力损失**（4.2.1-6）；河床不稳定须计河床变化 | 直接用取水口水位当进水池水位 |
| **水位顺序自洽** | `最高运行 ≥ 设计运行 ≥ 最低运行`（每侧）；平均水位在运行区间内 | 设计运行水位高于最高运行水位 |
| **最高运行水位口径** | 灌溉站取 **5~10 年一遇**洪水日平均水位（**不是防洪标准重现期**） | 用 100 年/50 年一遇当最高运行水位 |
| **复算** | `calc_water_levels.py --mode order` | — |

## 块 5　特征扬程与水泵选型 ★

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **设计扬程** | = 进出水池**设计运行水位差 + 水力损失**；设计扬程下**满足设计流量**（4.3.1） | 用水位差当总扬程（漏损失） |
| **最高扬程** | = **出水池最高运行水位 − 进水池最低运行水位 + 损失**（4.3.3） | **误取设计水位对设计水位** |
| **最低扬程** | = **出水池最低运行水位 − 进水池最高运行水位 + 损失**（4.3.4） | 漏损失；或与最高扬程对调 |
| **平均扬程** | 加权平均净扬程 **∑(H_i·Q_i·t_i)/∑(Q_i·t_i) + 损失**，或按平均水位差 + 损失（4.3.2） | 简单算术平均 |
| **水泵选型** | 满足设计流量+设计扬程；**平均扬程下在高效区**；**最大/最小扬程下能安全稳定运行、不得汽蚀**（GB 50288 5.4.12） | 只校设计工况点，不校最高/最低扬程 |
| **复算** | `calc_water_levels.py --mode head`（含报告值比对） | — |

## 块 6　水泵安装高程与汽蚀 ★

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **安装高程** | 在**进水池最低运行水位**时满足各工况**允许吸上真空高度或必需汽蚀余量**（10.1.7-1）；转速不同/含沙水源须**修正** | 按设计水位（非最低运行水位）定安装高程 |
| **立式基准面淹没** | 立式轴流泵/混流泵**基准面最小淹没深度应大于0.5 m**（10.1.7-2，★严格大于，等于不满足） | 用底板或叶轮中心代基准面；写"=0.5 m"判不满足 |
| **空化余量** | 设计工况主泵空化余量符合 **GB/T 13006**（GB 50265 13.2） | 未给空化余量 |
| **复算** | `calc_pump_elevation.py --mode install` | — |

## 块 7　总体布置与站址

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **站址选择** | 岩土坚实、水文地质良好，避开活动断裂带与不良地基（5.1.2/5.1.3）；各类站另有专属要求（5.2） | 未论证不良地基 |
| **堤身式/堤后式** | 建于堤防、地基较好、低扬程 → 宜**堤身式**；扬程较高/地基稍差/重要堤防 → 宜**堤后式**（6.2.4） | 重要堤防上采用堤身式未论证 |
| **泵闸合建** | 宜选合适泵型、**适当抬高水泵安装高程**、减小泵闸基底高差（6.2.7） | 合建但未处理基底高差 |
| **枢纽分隔** | 兼泄洪 → 泵房与泄洪建筑物设**分隔设施**；兼通航 → 保证安全距离并设**禁航警示**（6.1.6） | 未设分隔/警示 |
| **拦污清污** | 有漂浮物 → **应设拦污清污设施**，宜设于引渠末端或前池入口（6.1.7） | 无拦污设施 |

## 块 8　泵房（布置 / 高程 / 防渗 / 稳定 / 结构）★

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **挡水部位顶部高程** | ≥ **设计、校核运用情况挡水位 + 波浪壅浪 + 安全加高（取大值）**（7.1.3）；安全加高见**表 7.1.3**（设计 0.7/0.5/0.4/0.3，校核 0.5/0.4/0.3/0.2） | **只算设计运用，漏校核**；安全加高级别取错 |
| **堤坝上泵房** | 挡水顶高程**不应低于堤坝顶部高程**（7.1.4） | 泵房顶低于堤顶 |
| **防渗排水** | 有完整防渗排水系统（7.2.1）；铺盖长度取**最大水位差的 3~5 倍**、厚 ≥0.4 m（7.2.5）；符合 SL 265（7.2.10） | 铺盖长度按经验取值 |
| **抗滑稳定** | 按**表 7.3.5**（土基基本 1.35/1.30/1.25/1.20…）；**K≥允许值** | 分级别/分地基套错栏 |
| **抗浮稳定** | K = ∑G/∑U，**不分级别/地基**，基本 **≥1.10**、特殊 **≥1.05**（7.3.7/7.3.8）| 按抗滑分级别套抗浮 |
| **基底应力不均匀系数** | σ_max/σ_min ≤ 表值（松软 1.5/2.0、中等坚实 2.0/2.5、坚实 2.5/3.0） | 方向判反（当"越大越好"） |
| **荷载组合** | 按表 7.3.3；**地震荷载不应与校核运用水位组合**（7.3.3） | 地震与校核水位组合 |
| **室内地坪** | 高于室外地坪 **0.2 m**（7.1.26） | 未设防淹措施 |
| **复算** | `calc_pump_elevation.py --mode crest` / `calc_stability.py` | — |

## 块 9　进出水建筑物（引渠 / 前池 / 进水池 / 出水池 / 管道 / 流道）★

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **前池** | 正向进水**扩散角单侧 <15°**、底坡**不陡于 1:4**（8.2.1）；侧向进水设导流（8.2.2） | 扩散角过大引发涡流 |
| **进水池水下容积** | **可**按设计流量下**秒换水系数 30~50**（8.2.7，推荐值 → ▲） | 按经验容积拍定 |
| **进水流道** | 进口断面流速 **0.8~1.0 m/s**（10.2.2-3）；**进口上缘应淹没在进水池最低运行水位以下至少0.5 m**（10.2.2-5，★） | 进口上缘淹没不足 |
| **出水流道** | 出口流速 **≤1.5 m/s**（装拍门 ≤2.0）；当量扩散角 **8°~12°**；**出口上缘应淹没在出水池最低运行水位以下 0.3~0.5 m**（10.2.5，★） | 出口淹没用最高运行水位核 |
| **出水管（淹没出流）** | 出口上缘**宜**淹没在出水池最低运行水位以下不小于0.3 m（8.3.3，▲推荐值） | 漏核 |
| **虹吸式出水流道** | 驼峰底**宜略高于出水池最高运行水位**；驼峰真空度 **≤7.5 m 水柱**（10.2.8） | 驼峰高程低于最高运行水位 |
| **喇叭口** | 悬空高度/淹没深度按布置型式取 (0.6~2.0)D 系列、最低悬空 ≥0.5 m（10.3.3） | 悬空/淹没不分型式 |
| **复算** | `calc_pump_elevation.py --mode flowpath` | — |

## 块 10　机电设备与金属结构

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **主泵与电动机** | 主泵选型满足设计流量+设计扬程及不同时期要求（10.1.1）；装置效率 ≥60%/65%（10.1.11） | 效率低于下限 |
| **真空/充水系统** | 虹吸式流道启动不能排气 → **应设抽真空系统**；中高扬程 → 设充水系统（10.5.1） | 虹吸式未设抽真空 |
| **排水系统** | 排水泵**不少于 2 台**（10.6.2）；出口设止回阀+检修阀；冰冻地区出口下缘宜高于最高运行水位（10.6.3） | 排水泵 1 台 |
| **断流方式** | 按出水池水位变幅/扬程/机型选，运行可靠（10.2.6） | 断流方式与水位变幅不匹配 |
| **闸门/拦污栅/启闭机** | 按 SL 74/SL 41 等（第 12 章） | 未提供启闭力计算 |

## 第 2 步　跨专业一致性（9 对）

> 单块各自正确 ≠ 报告正确。逐对列出"甲↔乙"必须自洽的数值链，并给出**验算用什么脚本**。

| # | 甲 ↔ 乙 | 必须自洽的数值链 | 验算 |
|---|---|---|---|
| 1 | **等别 ↔ 建筑物级别 ↔ 防洪标准 ↔ 穿堤要求** | 设计流量+装机 → 级别（SL 252 表4.5.3/4.7.1）→ 洪水标准（表5.5.3）→ 穿堤时**严格高于**堤防标准 | `calc_pump_std.py` |
| 2 | **设计流量 ↔ 特征水位 ↔ 设计扬程 ↔ 装机** | 设计流量决定出水池设计运行水位、进水池设计运行水位 → 设计扬程 → 装机 | `calc_water_levels.py` |
| 3 | **站上/站下水位组合 ↔ 四特征扬程** | H_设/H_max/H_min/H_均 全部由水位组合推出，须与报告逐一吻合；`H_max≥H_设≥H_min` | `calc_water_levels.py --mode head` |
| 4 | **特征扬程 ↔ 水泵选型工况点 ↔ 高效区** | 平均扬程落在水泵高效区；最大/最小扬程在水泵稳定运行区且不汽蚀 | 人工核水泵性能曲线 |
| 5 | **进水池最低运行水位 ↔ 安装高程 ↔ 淹没深度/汽蚀** | 最低运行水位下满足允许吸上真空高度/必需汽蚀余量；立式基准面淹 >0.5 m | `calc_pump_elevation.py --mode install` |
| 6 | **出水池最低运行水位 ↔ 流道/管道出口淹没** | 流道出口淹 0.3~0.5 m、出水管淹 ≥0.3 m（均对最低运行水位） | `calc_pump_elevation.py --mode flowpath` |
| 7 | **挡水顶高程 ↔ 设计/校核运用水位 ↔ 安全加高 ↔ 堤顶高程** | 取设计/校核两运用的大值；堤坝上另 ≥ 堤顶 | `calc_pump_elevation.py --mode crest` |
| 8 | **进水池容积 ↔ 设计流量 ↔ 秒换水系数** | 水下容积 = 设计流量下秒换水系数 30~50 对应容积 | `calc_pump_elevation.py --mode volume` |
| 9 | **荷载组合 ↔ 稳定验算 ↔ 水位组合** | 抗滑/抗浮用相应水位组合；**地震不打校核运用水位** | `calc_stability.py` |
