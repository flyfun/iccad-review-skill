## 一、GB 50265-2022《泵站设计标准》章节结构（14 章 + 附录 A）

| 章 | 章名 | 本域关注要点 |
|---|---|---|
| 1 | 总则 | 适用范围（新建/扩建/**更新改造**的供水、灌溉、排水泵站）；地震动峰值加速度 ≥0.10g 应抗震设计 |
| 2 | 术语和符号 | 特征水位/特征扬程/装置效率/断流方式等定义 |
| 3 | **泵站等级及标准** | **3.0.1 等别与建筑物级别**（转 GB 50201 + SL 252）；**3.0.2 防洪(潮)标准**（穿堤坝泵站"不应低于"）；3.0.3 合理使用年限（转 SL/T 654） |
| 4 | **泵站主要设计参数** | **4.1 设计流量**（灌溉/排水/供水三型）；**4.2 特征水位**（★本域命门）；**4.3 特征扬程**（★四扬程定义） |
| 5 | 站址选择 | 5.1 一般规定（岩土坚实、避断裂带与不良地基）；5.2 各类泵站站址（水库/潮汐/圩区） |

| 报告章 | 内容要点 | checklist 块 |
|---|---|---|
| 水文 | 复核确定工程场址水文成果、特征水位系列 | 块 2 |
| 工程地质 | 泵站工程地质条件、主要地质问题 | 块 2 |
| 工程任务与规模 | 复核工程规模；**直接从河道取水的泵站**应复核/选定**设计引水流量和设计水位**（5.0.9） | 块 3 / 块 4 |

### 2.2 安全鉴定报告（SL 316）

| 报告 | 依据 | 主要内容 |
|---|---|---|
| 《泵站现状调查分析报告》 | SL 316 附录 A | 现状调查、薄弱与隐蔽部位重点检查 |
| 《泵站现场安全检测报告》（建筑物/机电设备/金属结构 三份） | SL 316 附录 B | 检测内容/依据/方法/仪器/结果/结论 |
| **《泵站工程复核计算分析报告》** | **SL 316 附录 D** | 工程概况、基本资料、**工程规模复核**、建筑物复核、机电设备复核、金属结构复核、**安全类别综合评价与建议** |
| 《泵站安全鉴定报告书》 | SL 316 附录 E | 综合安全类别评定结论 |

**安全鉴定工作程序（2.0.1）**：现状调查分析 → 现场安全检测 → **工程复核计算分析** → 安全类别评定 → 安全鉴定工作总结。

**复核计算核心（5.1.1 / 5.2.2 / 5.3.1）**：以**最新规划确定的工程规模数据**为依据，按 GB 50265；**应确定泵站在现行运行条件下承受的各种水位组合、各特征扬程及流量**；建筑物复核内容 = **过流能力、抗渗稳定、抗滑稳定、抗浮稳定、抗倾稳定、地基稳定、结构强度及抗震安全性**。

**全面安全鉴定时机（1.0.5）**：建成投入运行达 **20~25 a**；全面更新改造后运行达 **15~20 a**；其后运行达 **5~10 a**。
**鉴定委员会（2.0.6）**：7~13 人，宜含规划、水文地质、水工、水机、电气、金属结构，高级职称 ≥3/4。

### 2.3 更新改造设计报告（GB 50265 §13）

流程：**安全鉴定**（13.1.1）→ **规划复核**（设计标准/设计流量/特征水位/特征扬程，13.1.2）→ 建筑物/机电/金属结构复核与加固（13.2）→ 完好率目标。

## 三、关键构造要求（非数值）

| 规范号 条号 | 要求 | 常见违反形态 |
|---|---|---|
| GB 50265 6.1.6 | 兼泄洪 → 泵房与泄洪建筑物**设分隔设施**；兼通航 → 保证安全距离并设**禁航警示** | 未设分隔或被航道侵占 |
| GB 50265 6.1.7 | 有漂浮物 → **应设拦污清污设施**，宜设于引渠末端或前池入口；站内交通桥宜结合拦污栅桥 | 无拦污栅/清污机 |
| GB 50265 6.1.8 | 进出水池**设安全防护设施和警示标志** | 缺失 |
| GB 50265 6.2.4 | 堤防处、地基较好、低扬程 → 宜**堤身式**；扬程较高/地基稍差/重要堤防 → 宜**堤后式** | 重要堤防上堤身式未论证 |
| GB 50265 6.2.7 | 泵闸合建 → 适当抬高水泵安装高程，减小基底面高差 | 未处理高差 |
| GB 50265 7.2.1 | 应设置**完整的防渗排水系统** | 防渗不闭合 |
| GB 50265 7.2.9 | 双向扬程灌排结合站 → 防渗排水以**扬程较高的一向**为主 | 按低扬程向布置 |
| GB 50265 8.2.1 | 前池宜**正向进水**；扩散角单侧 <15°；底坡不陡于 1:4 | 斜向进水无导流 |
| GB 50265 8.2.6 | 进水池内**流态良好、便于清淤维护** | 死角淤积 |
| GB 50265 10.2.1 | 进出水流道形式结合**进出水池水位、扬程、泵型、泵房布置、断流方式**选 | 流道与水位变幅不匹配 |
| GB 50265 10.2.6 | 断流方式按出水池水位变幅选，运行可靠、操作灵活 | 高变幅用拍门 |
| GB 50265 10.6.3 | 排水泵出口设**止回阀 + 检修阀**；防倒灌 | 无止回阀 |
| GB 50265 10.6.7 | 排水系统**自动化**：集水井设水位信号与报警 | 无自动排水 |
| GB 50265 13.1.1 | 更新改造前**应开展安全鉴定** | 跳过鉴定直接改造 |
| SL 316 2.0.4 | 现场检测/复核计算须**有相应资质单位**完成 | 无资质单位出报告 |
