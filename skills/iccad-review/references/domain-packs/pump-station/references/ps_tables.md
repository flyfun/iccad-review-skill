## 一、特征水位取值规则（GB 50265 §4.2）

**特征水位分两侧**：**站下 = 进水池（含前池）水位**；**站上 = 出水池水位**。
每侧 5 个：**防洪(潮)水位 / 最高运行水位 / 设计运行水位 / 平均水位 / 最低运行水位**。

### 1.1 灌溉泵站 — 进水池（4.2.1）

| 特征水位 | 取值规则（按水源型式） |
|---|---|
| 防洪(潮)水位 | 按 3.0.2 防洪(潮)标准分析确定 |
| **设计运行水位** | 河流/湖泊→历年灌溉期**满足设计灌溉保证率的日平均或旬平均水位**；水库→结合灌溉保证率与调蓄性能；渠道→**渠道通过设计流量时的水位**（考虑水位降落）；感潮→满足保证率的**灌溉期平均低潮位** |
| **最高运行水位** | 河流/湖泊→**重现期 5~10 年一遇洪水的日平均水位**；水库→按调蓄性能论证；渠道→**通过加大流量时的水位**；感潮→**5~10 年一遇最高日平均潮位** |
| **最低运行水位** | 河流/湖泊/水库→**历年灌溉期水源保证率 95%~97% 的最低日平均水位**；渠道→**最小流量对应水位**；感潮→**95%~97% 的日最低潮位** |
| 平均水位 | 河流/湖泊/水库/感潮→**灌溉期多年日平均水(潮)位**；渠道→**平均流量时水位** |

**第 6 款关键前提（报告最常漏）**：上述水位**均应扣除从取水口至进水池的水力损失**；河床不稳定河道**尚应考虑河床变化影响**；寒冷地区冰盖下取水**应考虑冰盖(含流冰)对水力损失的影响**。

### 1.2 灌溉泵站 — 出水池（4.2.2）

| 特征水位 | 取值规则 |
|---|---|
| 最高水位 | 接输水河道→**河道防洪水位与最高运行水位的高值**；接渠道→**最大流量相应水位**；多泥沙河流**应考虑渠道淤积对水位的影响** |
| 设计/最高/最低运行水位 | 分别按**灌溉设计流量 / 最大运行流量 / 最小运行流量**和**灌区控制高程**要求推算到出水池 |
| 平均水位 | **灌溉期多年日平均水位** |

### 1.3 排水泵站 — 进水池（4.2.3）

| 特征水位 | 取值规则 |
|---|---|
| **最高水位** | 排水区建站后**重现期适当高于治涝标准的内涝水位**（区内有防洪要求时**应同时考虑其影响**） |
| **设计运行水位** | 由**排水区设计排涝水位**推算到站前；有集中蓄涝区/与内排站联合运行→由蓄涝区设计水位或内排站出水池设计水位推算 |
| **最高运行水位** | 按**排水区允许最高涝水位**要求推算；蓄涝区/联合运行→由**蓄涝区最高调蓄水位**或内排站出水池最高运行水位推算 |
| **最低运行水位** | 按**降低地下水埋深**或**蓄涝区允许最低水位**要求推算到站前 |
| 平均水位 | **可取与设计运行水位相同**；蓄涝区泵站设计运行水位取设计低水位并计入渠道损失时→取**设计低水位与设计蓄水位的平均值**并计入损失 |

### 1.4 排水泵站 — 出水池（4.2.4）

- **防洪水位**：按 3.0.2 防洪标准分析确定。
- **设计运行水位**：取**与排水区治涝标准相应的承泄区排水时段平均水位**；感潮河段→**设计排水时段平均高潮位**；重要的排水泵站经论证**可适当提高重现期**。
- 最高/最低运行水位、平均水位按承泄区相应水文条件分析确定。

### 1.5 工业与城镇供水泵站（4.2.5 / 4.2.6）

- **进水池**：设计运行水位按水源型式（河流/湖泊→满足供水保证率日平均或旬平均水位；水库→结合保证率与调蓄性能；渠道→通过设计流量时水位；感潮→供水期平均低潮位）；**最高运行水位**→按设计防洪标准的日平均水位（水库取回水位、渠道取加大流量水位）；**最低运行水位**→**供水期水源保证率 97%~99% 的最低日平均水位**（水库取最低控制水位、渠道取单泵流量水位）；**平均水位**→多年日平均水(潮)位。
- **出水池**：最高水位→**输水渠道校核洪水位**；设计/最高/最低运行水位→分别与**设计流量/最大运行流量/最小运行流量**相应；平均水位→渠道平均流量时水位。

### 1.6 灌排结合泵站（4.2.7）
可按 4.2.1~4.2.4 分析确定；**双向扬程时以扬程较高的一向为主**选防渗排水布置（7.2.9）。

## 二、特征扬程（GB 50265 §4.3；GB 50288 5.4.10 同义）

| 特征扬程 | 定义 | 判定要点 |
|---|---|---|
| **设计扬程 H_设** | **进出水池设计运行水位差 + 水力损失** | 在设计扬程下**应满足设计流量** |
| **平均扬程 H_均** | 加权平均净扬程 **H=∑(H_i·Q_i·t_i)/∑(Q_i·t_i) + 损失**；或进出水池**平均水位差 + 损失** | 在平均扬程下**水泵应在高效区工作** |
| **最高扬程 H_max** | **出水池最高运行水位 − 进水池最低运行水位 + 损失** | 宜按此；两水位**遭遇概率小时**经技术经济比较**可适当降低** |
| **最低扬程 H_min** | **出水池最低运行水位 − 进水池最高运行水位 + 损失** | 宜按此；两水位**遭遇概率小时**经技术经济比较**可适当提高** |

> ⚠ **最高扬程 ≠ 设计水位对设计水位** —— 取**站上最高 − 站下最低**（极值组合）。
> ⚠ **净扬程 = 站上水位 − 站下水位**（同组合）；**总扬程 = 净扬程 + 水力损失**。报告常把两者混为一谈。

**必然成立的顺序关系**（不成立即水位或扬程填错）：
`H_max ≥ H_设 ≥ H_min`；且 `Z_站上最高 ≥ Z_站上设计 ≥ Z_站上最低`、`Z_站下最高 ≥ Z_站下设计 ≥ Z_站下最低`。

## 三、泵房挡水部位顶部安全加高（GB 50265 表 7.1.3）

> 7.1.3：**泵房挡水部位顶部高程不应低于设计、校核运用情况挡水位加波浪、壅浪计算高度与相应安全加高值之和的大值。**

| 运用情况 \ 建筑物级别 | 1 | 2 | 3 | 4、5 |
|---|---|---|---|---|
| **设计**（设计运行水位或设计洪水位） | 0.7 | 0.5 | 0.4 | 0.3 |
| **校核**（最高运行水位或校核洪水位） | 0.5 | 0.4 | 0.3 | 0.2 |

（单位 m。安全加高 = 波浪/壅浪计算顶高程以上至泵房挡水顶部的距离。）

- **7.1.4**：位于**防洪、挡潮堤坝上**的泵房，挡水部位顶高程**不应低于相应堤坝顶部高程**，并考虑两侧堤坝加高的可能。
- **7.1.5**：还应考虑**软弱地基上泵房地基沉降**、上下游河道变化引起水位升降等影响。

## 六、淹没深度与超高（安装高程 / 流道 / 管道）

| 部位 | 要求 | 依据 |
|---|---|---|
| **水泵安装高程** | 在**进水池最低运行水位**时，应满足各工况**允许吸上真空高度或必需汽蚀余量**（必要时计初生汽蚀；转速不同或含沙水源须修正） | 10.1.7-1 |
| **立式轴流泵/混流泵基准面** | 最小淹没深度**应大于0.5 m**（★严格大于，等于不满足） | 10.1.7-2 |
| **进水流道进口上缘** | 淹没在**进水池最低运行水位以下至少0.5 m**（★≥） | 10.2.2-5 |
| **出水流道出口上缘** | **应**淹没在**出水池最低运行水位以下 0.3~0.5 m**（★区间，下限硬要求） | 10.2.5-4 |
| **出水管（淹没出流）出口上缘** | **宜**淹没在**出水池最低运行水位以下不小于0.3 m**（▲推荐值，不作硬判定） | 8.3.3 |
| **虹吸式出水流道驼峰** | 驼峰**底部高程宜略高于出水池最高运行水位**；驼峰顶部**真空度不应超过 7.5 m 水柱** | 10.2.8 |
| **竖井式取水口工作平台** | 高程 = **校核洪水位 + 波浪高度 + 0.5 m 安全加高**；最低取水口下缘距河底按水文泥沙特性定 | 9.2.2 |
| **泵房挡水部位顶部** | ≥ 设计/校核运用挡水位 + 波浪壅浪 + 安全加高（**取大值**）；堤坝上泵房另 ≥ 堤坝顶高程 | 7.1.3 / 7.1.4 |
| **泵房室内地坪** | **高于室外地坪 0.2 m**，并有防淹措施 | 7.1.26 |
| **离心泵进水管截流** | 水泵进口最低点位于**进水池最高运行水位以下**时，**应设截流设施** | 10.3.2-1 |

## 九、地基参数（GB 50265 附录 A）

**土基摩擦系数 f（表 A.0.1）**：黏土 软弱 0.20~0.25 / 中等坚硬 0.25~0.35 / 坚硬 0.35~0.45；壤土、粉质壤土 0.25~0.40；砂壤土、粉砂土 0.35~0.40；细砂、极细砂 0.40~0.45；中砂、粗砂 0.45~0.50；砂砾石 0.40~0.50；砾石、卵石 0.50~0.55；碎石土 0.40~0.50。

**土基摩擦角 φ₀ 与黏结力 C₀（表 A.0.2）**：黏性土 φ₀=0.9φ、C₀=(0.2~0.3)C；砂性土 φ₀=(0.85~0.9)φ、C₀=0。

**岩基抗剪断（表 A.0.3）**：Ⅰ类 f'=1.30~1.50 / C'=1.30~1.50 / f=0.75~0.85；Ⅱ类 1.10~1.30 / 1.10~1.30 / 0.65~0.75；Ⅲ类 0.90~1.10 / 0.70~1.10 / 0.55~0.65；Ⅳ类 0.70~0.90 / 0.30~0.70 / 0.40~0.55；Ⅴ类 0.40~0.70 / 0.05~0.30 / 0.30~0.40。
（参数限硬质岩；软质岩按软化系数折减。选用的 f'/C' **不应超过基础混凝土本身的抗剪断参数**。）

**地基允许变形（7.4.10）**：天然土质地基上泵房**最大沉降量不宜超过 150 mm**。

## 十、防渗排水与铺盖（GB 50265 §7.2）

- **7.2.5**：铺盖长度宜取**上下游最大水位差的 3~5 倍**；混凝土/钢筋混凝土铺盖**最小厚度不宜小于 0.4 m**，顺水流向永久变形缝缝距可用 8 m。
- **7.2.10**：泵房防渗排水设计应符合 **SL 265** 相关规定。
- **7.2.9**：**双向扬程灌排结合泵站**防渗排水以**扬程较高的一向**为主。

## 十一、更新改造专项（GB 50265 §13 / SL 316）

- **13.1.1**：更新改造前**应开展安全鉴定**（按 SL 316 评定综合安全类别及建筑物/机电设备/金属结构安全类别）。
- **13.1.2**：更新改造设计前应做泵站规划复核，**复核内容主要包括泵站设计标准、设计流量、特征水位和特征扬程等**。
- **13.2.2**：更新改造后泵房布置/防渗排水/稳定/变形/地基处理等应符合第 7 章；原泵房**抗渗稳定、抗滑稳定安全系数、应力不均匀系数**不符第 7.2/7.3 节的，**应查明情况、复核计算、采取加固**。
- **完好率**（改造）：建筑物完好率 **≥90%**、设备完好率 **≥95%**（拆除重建为 100%）；按 GB/T 30948 计算。
- **SL 316 5.2.2**：工程规模复核成果应**确定泵站在现行运行条件下承受的各种水位组合、各特征扬程及流量**，为建筑物、机电设备及金属结构复核提供计算依据。
- **SL 316 5.3.1**：建筑物复核内容应包括**过流能力、抗渗稳定、抗滑稳定、抗浮稳定、抗倾稳定、地基稳定、结构强度及抗震安全性**。

## 十二、数值易错点速查（12 条）

1. **最高扬程 ≠ 站上设计−站下设计** —— 是**站上最高 − 站下最低**。
2. **最低扬程**也要**计入水力损失**（且遭遇概率小可论证提高）。
3. **净扬程 vs 总扬程**：净扬程 = 水位差；**总扬程 = 净扬程 + 水力损失**。混用即错。
4. **特征水位未扣取水口至进水池水力损失**（4.2.1-6 硬要求）。
5. **灌溉泵站最高运行水位**取**5~10 年一遇**洪水日平均水位 —— 不是防洪标准重现期。
6. **灌溉泵站最低运行水位**保证率 **95%~97%**；**供水泵站是 97%~99%** —— 两者不同。
7. **排水泵站平均水位可取与设计运行水位相同** —— 不必强凑另一个值。
8. **安全加高"取大值"**：设计运用与校核运用**各算一遍，取大**；不是只算设计。
9. **"不应低于 + 留安全裕度"是严格大于** —— 项目防洪标准等于堤防标准即**不满足**。
10. **抗浮 K 不分级别/地基** —— 一律 1.10/1.05，别按抗滑分级别套。
11. **地震荷载不应与校核运用水位组合**（7.3.3）—— 组合错则稳定验算全错。
12. **立式轴流/混流泵基准面最小淹没深度「应大于0.5 m」**（★严格，等于不满足）是**基准面**（非底板）；流道**进口**淹「至少0.5 m」是**上缘**、**出口**淹 0.3~0.5 m 也是**上缘**（均应）；**出水管**出口淹「宜不小于0.3 m」是**推荐值**（▲）—— 部位、量值与措辞（应/宜）别串。
