# 泵站工程 — 数值判据覆盖矩阵（哪项自动 / 哪项须人工）

> 用途：审查数值时**先查本册**——这 52 项里哪些有复算器可自动三方比对（复算值 / 规范限值 / 报告值），
> 哪些只有固化限值、须人工核。**"自动"不等于"可信"**：自动项也要看输入是否来自报告真实数据。
> 复算器语义见 `limits.md` §五；限值出处见 `ps_tables.md`。

## 三、判据方向纪律（复核前必读）

| 类型 | 例 | 判据 |
|---|---|---|
| **下限型**（越大越安全） | 安全系数、净空、超高、淹没深度、防洪标准、效率、容积 | 用 `≥`（`_check_min`） |
| **上限型**（越小越有利） | 基底应力不均匀系数、流速上限、夹角、坡降 | 用 `≤`（`_check_max`） |
| **区间型** | 出水流道出口淹没 0.3~0.5、喇叭口悬空 (0.6~2.0)D | **下限**作硬要求，上限作提示 |
| **严格大于** | 穿堤泵站防洪标准 vs 堤防（11.8.3 ★ 留安全裕度）；立式泵基准面淹没（10.1.7-2 应大于0.5 m） | 用 `>`，**等于不满足** |
| **措辞分级** | 「应/不应」→ 硬判定（rc=1）；「宜/可」→ ▲ 提示（如 8.3.3 出水管淹没、8.2.7 秒换水系数） | 按条文措辞定，**不一律硬判** |

**方向判反即为错情** —— 尤其"不均匀系数"（上限）最常被当"越大越好"；其次是"应大于"被写成"≥"（等于也放行）。

## 四、脚本不代算（须报告计算书 / 专业软件）

二维三维水流数值模拟、水泵装置模型试验、结构有限元、抗震动力分析、过渡过程计算、水泵全特性曲线、
水文频率分析。本技能**只核结论间是否自洽、参数是否齐全**，不重算模型。
