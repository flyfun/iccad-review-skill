# 泵站工程报告审查

## 这个 Skill 是什么

**审查编排层**，不是设计知识卡。回答：拿到一份泵站工程报告，**按什么顺序查、查哪些点、每条怎么判、依据谁、怎么输出**。条款号、限值一律从条文库 / 固化表核对，**不硬编码**；库内无泵站设计领域技能可路由，判据全落在规范库 + 固化限值表 + 复算脚本上。

## 何时用 / 不适用

- **用**：有一份泵站工程报告，可从报告正文与附表附图出发现。
- **不用**：河道整治/堤防/护岸、洪水影响评价、水闸、土石坝、水土保持方案（各走对应技能）、纯水泵选型/制造咨询、纯设计问题、纯条文查询。

## 审查总流程

```
泵站工程报告 (docx/pdf)
 ├─[0]   前置判定 ── 报告类型 / 任务 / 站型 / 级别与防洪标准 / 水位齐备 / 地基
 ├─[0.5] 取判据 ── spec_lookup 调条文 + 固化限值表 + calc_*.py 复算
 ├─[1]   分块审查（12 块）── 查什么 → 判定标准 → 依据
 ├─[2]   跨专业一致性 ── 9 对数值链自洽
 └─[3]   结构化发现 ── 位置 / 问题 / 依据 / 严重度 / 建议
```

**每步该翻哪册见 ▶ 载入**

## 第 0 步：前置判定

**先定这几样，再翻正文。** 不同前提下判定完全不同——灌溉站与排水站的水位取值规则就不同。

| 判定项 | 常见取值 | 对审查的影响 |
|---|---|---|
| **报告类型** | 可研 / 初设 / 施工图 / 安全鉴定 / 更新改造 | 对照目录：初设→SL/T 533；可研→SL 560；安全鉴定→SL 316 附录 D/E；改造→§13 |
| **泵站任务** | 灌溉 / 排水（治涝）/ 供水 / 灌排结合 | 决定设计流量算法（4.1.1~4.1.3）与级别表（表4.5.3 vs 表4.7.1） |
| **站型与水源** | 堤身式 / 堤后式 / 引水式 / 河床式 / 湖（库）内式 | 站型决定**特征水位取值规则**（4.2.1~4.2.6）与最高运行水位口径 |
| **等别·级别·防洪标准** | SL 252 表4.5.3/4.7.1 + 表5.5.3；是否穿堤 | **级别定错 → 安全加高、抗滑容许值全错**；穿堤须留安全裕度（5.1.4★ / GB 50201 11.8.3★） |
| **特征水位齐备度** | 站上 / 站下 各 5 个（防洪潮·最高运行·设计运行·平均·最低运行） | 缺任一个 → 特征扬程无法复算，直接 ●/○ 发现 |
| **地基类型** | 土基（松软 / 中等坚实 / 坚实）/ 岩基 | 决定抗滑表 7.3.5 取值栏与地基处理要求 |

> 判不出这些 → 报告基本资料有缺项，本身就是一条 ○ 级发现。

## 第 0.5 步：取判据（别跳过）

**报告是 docx → 先 `scripts/extract_docx_tables.py <报告> --keyword <词>` 还原表格网格**（判据多藏在特征水位与扬程表、稳定计算书、水泵性能表，顺序拼字会错行）。

三个来源，**不可混用**：

| 来源 | 怎么取 | 怎么写进意见 |
|---|---|---|
| **规范条文** | `python scripts/spec_lookup.py --spec "GB 50265" --q 关键词` | 引条款号（如"违反 GB 50265 表 X"） |
| **固化限值表** | `ps_tables.md`（水位扬程/级别/加高/抗滑抗浮/淹没/流速）+ `ps_works_tables.md`（章节构造） | 引条款号 + 表号 |
| **强制性条文** | `compulsory-clauses.md` | 写"**违反强制性条文**"，最高严重级 |

> **查条文三条纪律**（详见 `norms.md` §一）：① **用该规范自己的术语**（同义词 0 命中）；
> ② **别带"表"字**（查条号写 `7.2.4`，不写 `表7.2.4`）；③ **优先词组、少用单字**。
> ④ 库内正文来自 PDF/OCR，已做**去空白容错**。取不到条文的判定项 → 标"依据待核"，只出疑点不出结论。

**能算的不要只靠看** —— 数值结论用复算脚本过一遍：

| 脚本 | 覆盖 |
|---|---|
| `calc_water_levels.py` | ★特征水位关系与特征扬程（4×4 水位 → 4 组扬程 + 顺序校验 + 报告值比对） |
| `calc_pump_elevation.py` | 各高程控制点（挡水顶高程+安全加高 / 安装高程淹没 / 流道进出口淹没 / 虹吸驼峰 / 进水池容积） |
| `calc_pump_std.py` | 等别·建筑物级别·防洪标准（表4.5.3/4.7.1/5.5.3 + GB 50201 11.8.3 穿堤留裕度） |
| `calc_stability.py` | 泵房稳定（抗滑表7.3.5 / 抗浮 1.10·1.05 / 基底应力不均匀系数 / 镇墩抗滑抗倾） |

> ▶ **载入**：`references/norms.md` §一（取条文方法、脚本用法与限制）；数值判据该自动还是人工 → `references/numeric-checks.md`（**52 项**覆盖矩阵）。

## 第 2 步：跨专业一致性（最容易被漏的一层）

单块各自正确 ≠ 报告正确。共 **9 对交叉校验**：等别↔级别↔防洪标准↔穿堤、设计流量↔水位↔扬程↔装机、**站上/站下水位组合↔四特征扬程**、特征扬程↔选型工况点、**进水池最低水位↔安装高程↔汽蚀**、**出水池最低水位↔流道出口淹没**、挡水顶高程↔设计/校核水位↔安全加高↔堤顶、进水池容积↔设计流量、荷载组合↔稳定↔水位组合。
> ▶ **载入**：`references/checklist.md` §第 2 步（9 对逐条展开 + 验算脚本）。自洽性优先用复算脚本验算，不靠眼看。

**下判断前先读** `references/norms.md` §四（引用纪律）+ §五（易踩的坑）——唯一权威定义，本入口不重复。

## 边界

- 无泵站工程设计领域技能可路由——只给**条文级判据 + 固化限值表 + 复算**（详见 `limits.md`）。
- 河道整治/堤防/护岸、洪水影响评价、水闸、土石坝、水土保持方案、纯水泵选型/制造咨询、纯条文检索不在范围；产出为**审查发现**非审批结论，责任在人。

> ▶ **载入**：`references/limits.md`（边界与已知局限）。
