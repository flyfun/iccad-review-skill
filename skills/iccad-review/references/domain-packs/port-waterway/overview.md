# 水运工程报告审查

## 定位与适用范围

**审查编排层**：回答"查什么、什么顺序、怎么判、依据谁"。条号与限值从条文库/固化表核对，**不硬编码**。

**用**：港口 / 码头 / 航道 / 防波堤护岸 / 疏浚 / 通航条件影响评价 报告（可研、初设、施工图、安全评价）。
**不用**：土石坝、重力坝、拱坝、水闸、泵站、堤防、河道整治、水保方案、洪评、水资源论证、灌区、隧洞、厂房；纯设计问题、纯条文查询。

> ⚠ 本域**没有单一安全系数 K**。水运用**极限状态分项系数法**（`γ0(γE·EH+γw·Pw+…) ≤ 抗力设计值`）。
> 拿 K≥1.3 去套即编判据——这是与水利域最大的差别。

## 审查总流程

```
水运工程报告 (docx/pdf)
 ├─[0]   前置判定 ── 对象 / 结构型式 / 阶段 / 水位基准 / 规范版本
 ├─[0.5] 取判据 ── spec_lookup 调条文 + 固化限值表 + calc_*.py 复算
 ├─[1]   分块审查（12 块）── 查什么 → 判定标准 → 依据
 ├─[2]   跨专业一致性 ── 9 对交叉校验，数值自洽
 └─[3]   结构化发现 ── 位置 / 问题 / 依据 / 严重度 / 建议
```

**每步该翻哪册，见该步末尾 ▶ 载入。**

## 第 0 步：前置判定

| 判定项 | 取值 | 影响什么 |
|---|---|---|
| **报告对象** | 海港总体 / 码头 / 航道整治 / 疏浚吹填 / 防波堤护岸 / 通航条件影响评价 | 决定 12 块里哪几块必查、哪几块可略（见 `pw_works_tables.md` §四） |
| **结构型式** | 高桩 / 板桩 / 重力式 / 格形钢板桩 / 斜坡 / 浮码头 | 决定走 JTS 167 第 5/6/7/8/9 章哪一章，强条完全不同 |
| **报告阶段** | 可研 / 初设 / 施工图 / 安全评价 | 章节深度（JTS/T 110-4、JTS 120-3）；安全评价另查现状检测 |
| **高程基准** | 理论最低潮面 / 航行基准面 / 85 高程 | 全篇必须同源，且给换算关系（JTS 165 4.5.2.1） |
| **规范版本** | 见 `norms.md` §三换版表 | 引旧版先出"引用已废止标准" |

> 判不出这些 → 报告基本资料有缺项，本身就是一条 ○ 级发现。

## 第 0.5 步：取判据（别跳过）

**报告是 docx → 先用 `scripts/extract_docx_tables.py <报告> --keyword <词>` 把表格还原成网格**
（判据多藏在"主尺度表""水位特征值表""稳定及应力计算成果表""工程量表"里，顺序拼字会错行）。

| 来源 | 怎么取 | 怎么写进意见 |
|---|---|---|
| **规范条文** | `python scripts/spec_lookup.py --spec "JTS 167" --q 7.1.12` | 引条号（"违反 JTS 167 第 7.1.12 条"） |
| **固化限值表** | `pw_tables.md`（水位、富裕深度、船舶荷载、分项系数、γR、f、KD）+ `numeric-checks.md`（50 项矩阵） | 引条款号 + 表号 + 数值 |
| **强制性条文** | `compulsory-clauses.md`（116 条，按 8 部逐条列） | 写"**违反强制性条文**"，最高级 ★ |

> **查条文四条纪律**（详见 `norms.md` §一）：
> ① 用该规范自己的术语——同义词 0 命中；② 查条号写 `7.1.12`，**别带"表"字**；
> ③ 优先词组、少用单字；④ 库内已做去空白容错（`阻 水 比` 也能命中）。

> 取不到条文的判定项 → 标"依据待核"，只出疑点不出结论。

**能算的不要只靠看**：

| 脚本 | 覆盖 | 关键判据 |
|---|---|---|
| `calc_wharf_elevation.py` | 码头前沿设计水深 / 底高程 / 顶高程 | `D=T+Z1+Z2+Z3+Z4`；顶高程两套标准取高 |
| `calc_channel_depth.py` | 航道水深 / 底高程 / 弯曲半径 | 表6.4.5-1/-2；3/4/4 倍取大 |
| `calc_ship_loads.py` | 撞击能量 / 系缆力 / 挤靠力 | 表10.2.5-1 下限；K=1.2/1.3 |
| `calc_pile_capacity.py` | 单桩轴向承载力 / 最小桩距 | `Qa=Qk/γR`；表4.2.2 |
| `calc_wharf_stability.py` | 7 项验算齐全性 / 基床厚度 | 7.1.12 / 7.2.5；**不判 K** |
| `calc_breakwater.py` | 堤顶高程 / 护面块体重量 | k 系数；KD；armor 无报告值 rc=3 |

> ▶ **载入**：`references/norms.md` §一（取条文方法、数据源、脚本用法与限制）。

## 第 2 步：跨专业一致性（最容易被漏的一层）

单块各自正确 ≠ 报告正确。共 **9 对**：① 船型↔全部尺度 ② 水位↔顶/底高程 ③ 通航水位↔航道水深↔保证率
④ 地质参数↔承载力/桩长/边坡 ⑤ 荷载↔结构计算 ⑥ 波高↔护面/顶高程（同频率）⑦ 疏浚量↔断面
⑧ 结构尺寸↔工程量↔概算 ⑨ 平面布置↔通航影响评价结论。
> ▶ **载入**：`references/checklist.md` §第 2 步（每对给"核法"与"常见错"）。自洽性优先用复算脚本验算，不靠眼看。

## 边界

- 条文库覆盖 10 部 JTS 规范；**JTS 146 抗震、JTS 149/150/153/257/310/311 未入库**（详见 `limits.md`）。
- **强条只能标到条/款级**：docx 黑体标记已丢失，不得据此外推"整条强制"。
- 产出为**审查发现**非审批结论，责任在人；不替代行政许可。
