# 技能边界与已知局限

> **本文件是"边界 / 局限"的唯一权威源**。入口 `SKILL.md` 只给指针，不再重复正文。

---

## 一、数据覆盖边界

- **自带条文库 = 10 部 JTS 水运规范 docx 原文自动解析**（含公告明示强条），
  **不是**水利块库 `chunks.pkl`——实测该块库 62 部规范里没有任何 JTS 水运规范
  （`grep "JTS"` 仅 6 次且全是交叉引用）。本技能是本族**首个"docx 原文解析"数据源**。
- **规模**：3,993 块（条文 3,742 + 表 251）；强条 116 条（8 部有、2 部编制规定无）。
- **主规范已入库**：JTS 167-2018《码头结构设计规范》。
- **未入库、只能标"须查原件 / 现行版"的**：
  - **JTS 146 水运工程抗震设计规范**（7.1.15 强条要求按此验算）——库内**没有**，
    报告做地震组合时只能核"是否按 JTS 146 做了"，**不能核它做得对不对**。
  - **JTS 149 港口工程环境保护设计规范**、**JTS 150 港口工程节能设计规范**、
    **JTS 153 水运工程测量规范**、**JTS 257 水运工程质量检验标准**——均未入库。
  - **JTS 310 港口水工建筑物检测与评估技术规范**、**JTS 311 港口水工建筑物修补加固技术规范**
    （安全评价 / 加固改造类报告常用）——未入库。
  - 与结构直接相关的国标：GB 50057（防雷）、GB 50139（内河通航标准）、GB 50009（荷载）、
    GB/T 985.1/.2（坡口）、GB 51142（LPG 供应）——**只在被 JTS 条文引用时出现**，本身未入库。
  - **JTJ 311《通航海轮桥梁通航标准》已废止**（JTS 181 8.3.6 仍引旧号是原文如此），
    遇到报告引 JTJ 311 时既要说"引用已废止标准"，也要说明原文引用关系。
- **管理性文件不是标准**：条例、部令、港口规划、环评批复等**未入库**，引用时写文件名 + 条号/批复号。

## 二、输入 / 解析边界

- **docx 表格可自助提取**：`scripts/extract_docx_tables.py`（**网格重建**，正确处理横向 gridSpan /
  纵向 vMerge）。正文段落用 `--text-only`。**PDF / 扫描件不在本技能内**，须另用 OCR / PDF 工具。
- **报告没写的，判不了**（只能出"深度不足 ○"，不能出"不符合 ●"）：
  - 无设计船型 L/B/T/DWT → 泊位长度、航道宽度、回旋直径、系缆力下限、撞击能量**全都没法核**；
  - 无设计高/低水位、极端高/低水位 → 顶高程两套标准、前沿水深、底高程没法核；
  - 无土层物理力学指标（γ、c、φ、cu、fs、qp）→ 稳定、承载力、桩长没法核；
  - 无基床顶面应力与地基承载力 → 7.2.5 基床厚度无法判（只能看厚度是否 ≥0.5m）；
  - 无护舷型号/反力曲线 → 撞击力只能核能量，不能核护舷选型；
  - 无疏浚断面图 → 方量无法复算。
- **附图 / 影像无法自动审**（须人工看图，本技能只能核"图在不在、图号对不对"）：
  总平面布置图、典型断面图、码头结构图、**桩位图**、地质剖面图、航道平面/断面图、
  疏浚分区图、防雷平面图、系船柱/护舷布置图、CAD 大样图。
- **报告属性要先判**：对象（海港/河港/码头/航道/防波堤/疏浚/通航条件影响评价）×
  阶段（可研/初设/施工图/安全评价）。**属性判错 → 后续章节全走错**：
  例：把"航道整治"按"码头"审，块 4（前沿高程水深）与块 7（码头结构）全是空转；
  把"安全评价"按"初设"审，会漏"现状检测与复核"整章。
- **通航条件影响评价是"分类"的**：JTS 120-3-2018 按码头类 / 修造船类 / 取排水类 /
  整治圈围类 / 孤立构筑物类 / 其他分类，**不同类要求不同章节**，判错类型会漏章。

## 三、公式与表格来源边界

- **表格可靠**：219 张表按网格重建，可直接引数值。已实测可用的关键表：
  表 5.4.8（顶高程富裕高度）、表 5.4.12-1/-2（Z1/Z3）、表 6.4.5-1/-2（航道 Z1/Z2）、
  表 10.4.4-1（靠岸速度）、表 10.2.5-1（系缆力下限）、表 10.2.3（缆绳夹角）、
  表 3.1.5（安全等级）、表 3.2.2（γ0）、表 3.2.6（分项系数）、表 4.2.7（γR）、
  表 4.2.2（桩距）、表 7.1.10（摩擦系数）、表 4.3.7（KD）、表 5.3.3（回旋水域）、
  表 5.4.18（富裕长度 d）、表 5.6.4/5.6.5（防火间距/净距）、表 3.1.7（防波堤安全等级）。
- **公式本体多为嵌入图片，docx 解析拿不到**：
  - 典型：JTS 154 4.3.7 护面块体稳定重量公式、JTS 167 6.3.13 锚碇叉桩公式、
    JTS 144-1 10.4.2 撞击能量公式、JTS 167 7.3.2 抗滑抗倾分项系数表达式。
  - 库里只剩"公式编号"（如 `(6.3.13-1)`）与符号说明，**没有等号左边**。
  - 处理：本技能的复算器按**通行形式落地**（如 Hudson 式），并在输出里标
    "公式本体为图形，须与原版核对"；`calc_breakwater.py --mode armor` 无报告值时返回 **rc=3**。
- **不做复算、只能核"有没有、参数全不全"的**：
  - 波浪场数值模拟、泥沙冲淤模型、潮流数学模型、船舶操纵模拟、系泊分析（Optimoor 类）；
  - 波浪物理模型试验、冰力模型试验、河工模型试验；
  - 结构有限元（桩土相互作用、沉箱内力）、CAD 图审查。
  → 这些只核"报告结论是否与自身参数自洽、是否与其他章一致"。

## 五、复算脚本的能力边界（6 个）

> **统一语义**：每个复算器都做**"复算值 / 规范限值 / 报告值"三方比对**，退出码
> `0` 满足 · `1` 不满足（含违反强条、与报告显著不符）· `2` 输入错 · `3` 仅参考值。
> **判据方向**分下限型（富余深度、超高、堤顶高程、承载力、桩距）与上限型（——本域少）。

| 脚本 | 覆盖什么 | 怎么算 | **不代算什么** |
|---|---|---|---|
| `calc_wharf_elevation.py` | mode=depth：码头前沿设计水深 D；mode=bottom：设计底高程 = 水位 − D；mode=top：前沿顶高程（两套标准取高） | `D=T+Z1+Z2+Z3+Z4`（Z2=K1·H4%−Z1 或 K1·H4%）；`E=DWL+Δ` | 不判"水位本身取得对不对"（那要查 JTS 145）；不代算泊位有效水深（需测深图） |
| `calc_channel_depth.py` | mode=depth：航道设计水深；mode=bottom：航道底高程；mode=radius：最小弯曲半径 | `D=T+Z0+Z1+Z2+Z3+Z4`；半径取 3/4/4 倍之大值 | 不代算 Z0（船体下沉量查图）；不判回淤强度 |
| `calc_ship_loads.py` | mode=impact：撞击能量与护舷所需能量；mode=mooring：系缆力（含下限校核）；mode=berthing：挤靠力 | `E0=ρmVn²/2`；`N=K/n·√(ΣFx²+ΣFy²)`；`F=1.1ΣFy/L` 或 `1.3ΣFy/n` | **不代查护舷反力曲线**（只给能量需求）；不代算风/水流分力（Fx/Fy 须报告给） |
| `calc_wharf_stability.py` | mode=checklist：7 项/5 项验算齐全性；mode=bed：基床厚度 | **只核"做了没有"**，不判 K | **不做分项系数法稳定计算**（水运无单一 K；要算须报告计算书） |
| `calc_pile_capacity.py` | mode=axial：单桩轴向承载力设计值；mode=spacing：最小桩距 | `Qa=Qk/γR`；桩距按表 4.2.2 | 不代算 Qk（须地质参数与桩型）；不代算水平承载力（需 m 法/p-y 曲线） |
| `calc_breakwater.py` | mode=crest：堤顶/护岸顶高程；mode=armor：护面块体稳定重量 | `顶高程=DWL+k·H`；`W=0.1γbH³/[KD(γb/γw−1)³cotα]` | armor 的**公式本体为图形**，无报告值时 rc=3；不代算越浪量（须断面模型或经验公式） |

## 六、判定责任边界

- 本技能产出的是**审查发现**，不是审批结论；最终判定责任在人，**AI 结论须经复核**。
- 涉**行政审批与规划符合性**的（岸线审批、通航许可、环评、海域使用），本技能只提供技术审查辅助，
  **不替代行政许可程序**。
- 涉专业软件的成果（数值模拟、物模试验）本技能**只核结论间是否自洽、参数是否齐全**，不重算模型。
- **强条判定只到条/款级**：docx 黑体标记已丢失，无法定位到句。写"违反强制性条文"时
  必须同时给出条号，**不得**据本技能输出直接下"该条全文强制"的结论。

## 七、与同族技能的关系

| 维度 | 邻域技能 | 本技能 |
|---|---|---|
| 堤防 / 河道整治 | `river-channel-report-review` | 只在水运工程**护岸**（JTS 154 第 7/8 章）范围内接手；纯堤防按河道技能 |
| 洪水影响评价 | `flood-impact-report-review` | 涉河建设项目的水文壅水、阻水比按洪评技能；本技能只管**码头/航道本身的通航与结构** |
| 水闸 / 泵站 | `sluice-report-review` / `pump-station-report-review` | 港口内的闸、泵站按各自技能 |
| 土石坝 / 重力坝 | `earth-dam-report-review` / `gravity-dam-report-review` | 库区码头岸坡涉及坝体稳定时，坝体本身按坝工技能 |
| 水土保持 | `soil-conservation-report-review` | 港口工程的水保方案单独按水保技能，本技能不审水保篇章 |
| 水资源论证 | `water-resources-report-review` | 港口取水/排水的水资源论证按水资源技能 |
| **水运工程** | **本技能** | 港口总平面、码头结构、航道尺度、防波堤护岸、疏浚、通航条件影响评价 |

**边界判据一句话**：**船、泊位、航道、堤（防波堤/护岸）、疏浚** → 本技能；
**坝、闸、泵、堤防（防洪）、水保、水资源** → 邻域技能。
两者交叉时（如库区码头），**结构按本技能、水体与防洪按邻域**，各自出发现，不互相替代。
