# 水运工程报告审查 — 常见错情模式（30 条）

> 出发现前对照本册，**同类问题按模式归并、避免重复计数**，并据此定严重度。
> 每条 = **模式** + **典型表现** + **判定依据** + **怎么核**。

**严重度**：★ 违反强制性条文 / 关键指标超限影响安全；● 不符规范、方案缺项；
○ 深度不足、专业间不一致、图文不符、附件附图缺失。

> 本域和水利域不同：**水运没有"安全系数 K 够不够"这一刀**，用的是极限状态分项系数法。
> 所以 ★ 级错情里，**"漏验算项"比"数值差一点"更常见**——7 项只做 2 项，比 K 差 0.05 严重得多。

## ★ 级（13 条）

### ★ E01　码头前沿设计水深起算水位错 / 基准用错
- **表现**：用平均水位、设计高水位起算；LNG 码头与工作船码头未按**理论最低潮面**起算；
  或把"通航水深 D0"当"设计水深 D"（差一个 Z4）。
- **依据**：JTS 165-2025 **5.4.11（强条）**：按**设计低水位**保证满载吃水安全停靠；5.4.11.2  LNG/工作船从理论最低潮面起算。
- **怎么核**：`calc_wharf_elevation.py --mode depth --t .. --z1 .. --z2 .. --z3 .. --z4 .. --wl .. --report ..`；
  再反算 `底高程 = 起算水位 − D`，与报告底高程比对。

### ★ E02　高桩码头施工期岸坡稳定漏算 / 未组合设计低水位
- **表现**：只算使用期岸坡稳定；施工期只写"满足"，无挖泥、回填、抛石、吹填各工况；
  或施工期未按**设计低水位**组合；打桩震动只字未提。
- **依据**：JTS 167-2018 **5.7.11（强条）**（1 款、2 款）。
- **怎么核**：查计算书目录是否有"施工期岸坡稳定"；逐工况对照 5.7.11.1 列举的四类作业。

### ★ E03　重力式码头只做抗滑抗倾，漏其余 5 项
- **表现**：计算书只有"抗滑、抗倾、基底应力"三张表；缺沿基床底面抗滑、整体稳定、
  合力作用位置、构件承载力；或短暂组合、地震组合整章缺失。
- **依据**：JTS 167-2018 **7.1.12（强条，7 项）**、7.1.13（短暂）、7.1.15（地震）、7.1.16（正常使用）。
- **怎么核**：`calc_wharf_stability.py --mode checklist --type gravity --items 抗倾,抗滑,基床抗滑,承载力,合力位置,整体稳定,构件`。
  **这条是本域最高频的 ★**，几乎每份重力式码头报告都能查到缺项。

### ★ E04　抛石基床厚度不足
- **表现**：基床 0.5~0.8m，而基床顶面应力已大于地基承载力；或厚度"按经验取 1.0m"但无承载力验算。
- **依据**：JTS 167-2018 **7.2.5（强条）**：应力 > 承载力 → 按承载力算且 **≥1.0m**；≤ → **≥0.5m**。
- **怎么核**：`calc_wharf_stability.py --mode bed --stress .. --allow .. --thickness ..`。

### ★ E05　变形缝缺失或位置不合规
- **表现**：只在等间距处设缝；帽梁/导梁/胸墙在**结构形式变化处、水深变化处、土质差别大处、
  新旧结构衔接处**漏设；改扩建工程"新旧衔接处"几乎必漏。
- **依据**：JTS 167-2018 **7.2.18**（墙身）、**6.2.50**（帽梁/导梁/胸墙，四处必须设）、
  **8.2.15**（格形墙上部结构）、**9.2.10**（坡顶挡土墙）、**9.2.20**（固定引桥）——均为强条。
- **怎么核**：对照平面图与纵断面，逐个特殊部位打勾；把"设缝间距"与结构分段图叠看。

### ★ E06　倒滤措施缺失 / 回填料用矿渣炉渣
- **表现**：墙后直接回填不设倒滤层；或写"设土工布"但无等效孔径与渗透系数；
  回填材料表出现矿渣、炉渣。
- **依据**：JTS 167-2018 **7.2.32（强条，必须倒滤）**、**6.1.20（强条，不得用腐蚀性矿渣/炉渣）**、
  6.2.15（细颗粒土接缝防漏土，强条）。
- **怎么核**：查断面图的倒滤层构造 + 材料表；两条一起看，常同时出问题。

### ★ E07　钢管桩 / 钢拉杆防腐缺失或厚度余量不足
- **表现**：有钢管桩但全篇无防腐设计；或只写"涂防锈漆"无腐蚀速率、无设计年限匹配；
  钢拉杆未预留锈蚀厚度。
- **依据**：JTS 167-2018 **4.4.21（强条，必须防腐）**、**6.1.18（强条，拉杆预留锈蚀厚度）**、
  **8.1.5**（前板桩临水面）、JTS 147-7-2022 **6.3.2（强条）**。
- **怎么核**：查"耐久性设计"专节是否存在；查拉杆直径是否标注"含腐蚀余量"。

### ★ E08　板桩码头缺"踢脚"稳定 / 拉杆拉力
- **表现**：只算前墙内力与入土深度，缺前墙"踢脚"稳定；拉杆拉力只写"满足"无计算；
  锚碇叉桩按刚接或计土抗力计算。
- **依据**：JTS 167-2018 **6.1.6（强条）**、**6.3.1（强条，三样必算）**、**6.3.13（强条，两端铰接、不计桩周土）**。
- **怎么核**：查计算书是否单列"踢脚稳定"；核叉桩计算假定与 6.3.13 是否一致。

### ★ E09　桩基漏水平承载力 / 压屈稳定
- **表现**：只算单桩轴向承载力；水平受力桩（靠船桩、系缆墩桩）无水平承载力计算；
  泥面以上自由长度大的桩不验压屈；软土（cu<10kPa）中桩不验压屈。
- **依据**：JTS 167-2018 **4.1.2（强条）**、JTS 147-7-2022 **3.1.3（强条）**、JTS 167 4.3.4。
- **怎么核**：按 4.1.2 的三项逐条打勾；水平力显著的桩必须单列水平承载力。

### ★ E10　6 度区饱和砂土/粉土未做液化判别
- **表现**：抗震设防烈度 6 度，地基有饱和砂土或粉土，报告无液化判别；
  或判为液化但无抗液化措施。
- **依据**：JTS 147-2017 **4.3.13（强条）**："**6 度以上**"**含 6 度**。
- **怎么核**：查地质报告的标准贯入试验与烈度；两者都在 → 必须有液化判别章节。

### ★ E11　一级防波堤 / 一级护岸未做波浪模型试验
- **表现**：安全等级一级的防波堤、一级护岸，只做理论计算，无物模报告；
  或波浪、水流、地形复杂却不做三维整体模型。
- **依据**：JTS 154-2018 **3.1.9（强条）**：一、二级防波堤与一级护岸**应做**；二级护岸**宜做**；复杂条件**应做三维整体模型**。
- **怎么核**：先按表 3.1.7 定安全等级，再查附件里有无模型试验报告。

### ★ E12　危险品泊位防火间距不足 / 折减用错对象
- **表现**：油气化工泊位与客运泊位间距 <300m；与其他货种泊位 <150m（甲/乙类）；
  或把 50% 折减用在 ≥500 吨级泊位。
- **依据**：JTS 165-2025 **5.6.4（强条）** + 表 5.6.4（客运 300m；其他货种甲乙类 150m、丙类 50m；<500 吨级可取 50%）。
- **怎么核**：在总平面图上量**设计船型船舶间**最小净距（不是泊位中心距）。

### ★ E13　防雷用高杆灯杆体替代避雷设施
- **表现**：危险货物堆场、滚装汽车堆场用高杆照明杆体兼作接闪杆，未做防雷校验、未加专用避雷设施；
  或液体散货码头装卸臂、登船梯、钢引桥未与接地系统形成电气通路。
- **依据**：JTS 165-2025 **11.5.5（强条）**、**11.5.4（强条）**、11.5.1（强条）。
- **怎么核**：查防雷平面图的接闪器布置与接地电阻；灯杆兼用时须有滚球法校验。

## ● 级（12 条）

### ● E14　码头前沿顶高程只算一套标准
- **表现**：只按设计高水位算基本标准，不做极端高水位复核；或 Δ 取 0.5m（低于 1.0m 下限）。
- **依据**：JTS 165-2025 5.4.8 + 表 5.4.8（**非强条**，但两套标准取高者是硬性要求）。
- **怎么核**：`calc_wharf_elevation.py --mode top --case basic,.. --case check,..`。

### ● E15　航道水深 Z1 一刀切 / Z2 不乘吨级系数
- **表现**：全航道 Z1 统一 0.3m，不按表 6.4.5-1 分土质与吨级；Z2 不乘"10000 吨级以下 ×1.25"；
  8s<T<10s 不内插。
- **依据**：JTS 165-2025 6.4.5 + 表 6.4.5-1/-2。
- **怎么核**：`calc_channel_depth.py --mode depth --soil .. --dwt .. --angle .. --period ..`。

### ● E16　回旋水域尺度不分掩护条件
- **表现**：一律取 1.5L；掩护条件差的码头也取 1.5L；LNG 码头取 2L 却无"布置困难且流速小"论证。
- **依据**：JTS 165-2025 5.3.3 + 表 5.3.3（掩护好 1.5~2.0L；掩护差 2.5L；LNG ≥2.5L，困难时 ≥2L）。
- **怎么核**：查波浪掩护条件（口门宽度、防波堤遮蔽角）与取值是否对应。

### ● E17　航道弯曲半径只按 3 倍船长
- **表现**：所有航道统一 3L，不考虑顶推船队、拖带船队与困难河段折减。
- **依据**：JTS 181-2016 4.5.5：3×顶推船队长、4×货船长、4×拖带船队最大单船长**取大值**；困难河段 2/3/3；流速>3m/s 宜 5 倍。
- **怎么核**：`calc_channel_depth.py --mode radius --type push/cargo/tow --length .. --difficult`。

### ● E18　系缆力低于规范下限
- **表现**：算出 119kN 直接采用，而该吨级下限为 300kN；或 K 一律取 1.3（n=2 应 1.2）。
- **依据**：JTS 144-1-2010 10.2.1 + 表 10.2.5-1（下限）+ 表 10.2.3（夹角）。
- **怎么核**：`calc_ship_loads.py --mode mooring --dwt .. --n .. --fx .. --fy ..`（脚本内含下限表）。

### ● E19　撞击能量参数取值不当
- **表现**：ρ 取 1.0（应 0.7~0.8）；Vn 不按吨级与掩护条件取；用系缆力代替撞击力选护舷。
- **依据**：JTS 144-1-2010 10.4.2 + 表 10.4.4-1。
- **怎么核**：`calc_ship_loads.py --mode impact --dwt .. --vn .. --rho .. --report ..`。

### ● E20　抗滑直接用 tanφ 当摩擦系数
- **表现**：f 取 0.7~0.8（tan30°~tan38°），而规范给的是**摩擦系数设计值** 0.30~0.65。
- **依据**：JTS 167-2018 表 7.1.10（混凝土-混凝土 0.55、墙底-抛石基床 0.60、黏土 0.30~0.45）。
- **怎么核**：查计算书 f 的取值与依据；偏大即 ●，若因此把不稳定的断面算成稳定 → 升 ★。

### ● E21　γ0 不随安全等级变化
- **表现**：全篇 γ0=1.0；或安全等级定一级仍取 1.0。
- **依据**：JTS 167-2018 3.1.5 + 表 3.2.2（1.1 / 1.0 / 0.9）。
- **怎么核**：查计算书首页的"设计参数表"。

### ● E22　桩距小于 6d 且无持力层论证
- **表现**：桩距 3d~4d，只写"满足"，未说明桩端进入良好持力层。
- **依据**：JTS 167-2018 表 4.2.2（打入/灌注桩轴向 6d，或 3d~6d 且桩端进入良好持力层）。
- **怎么核**：`calc_pile_capacity.py --mode spacing --d .. --s .. --tip-good-soil`。

### ● E23　护面块体 KD 与块体类型不匹配
- **表现**：用四脚空心方块却取 KD=4.0（块石值）；扭王字取 14；KD 与"安放层数/失稳率"不对应。
- **依据**：JTS 154-2018 表 4.3.7（块石 4.0/5.5、四脚锥 8.5、四脚空心方块 14、扭工字/扭王字 15~18）。
- **怎么核**：`calc_breakwater.py --mode armor --block .. --kd .. --h .. --cot .. --gamma-b ..`。

### ● E24　挖槽与主流交角超 15° 无论证
- **表现**：挖槽与中枯水主流向交角 20°~30°，报告不提；或挖槽布置在严重淤积区。
- **依据**：JTS 181-2016 4.11.7（强条范围内，交角"不宜大于 15°"）。
- **怎么核**：在航道平面图上量交角；超限须有泥沙模型或类比工程论证。

### ● E25　疏浚工程量不计超深超宽与回淤
- **表现**：方量 = 净断面×长度；无超深（0.3~0.5m）、超宽（0.5~1.0m）、回淤量；
  与断面图算出的量差 10% 以上。
- **依据**：JTS 181 第 4.11 节 + JTS/T 110-4 3.4.5.2(6)（要求给疏浚工程量、土特性、处置方案）。
- **怎么核**：抽一个分段，用报告断面面积×长度复算，偏差 >5% 追问。

### ● E26　总平面只给单方案
- **表现**：只有一个总平面方案，无方案比选；或写"经比选确定"但无比选内容。
- **依据**：JTS/T 110-4-2025 3.4.5.1：**应提出两个或两个以上方案**；受限时可不比选但**应说明理由**。
- **怎么核**：查章节结构；缺比选且无"受限理由"说明 → ●。

## ○ 级（5 条）

### ○ E27　设计船型在全文不统一
- **表现**：总平面用 5 万吨级船型、荷载章用 3 万吨级、航道尺度又按 7 万吨级校核；
  或"兼顾船型"只在总平面出现一次。
- **依据**：跨专业一致性第 ① 对（`checklist.md` 第 2 步）。
- **怎么核**：把各章出现的设计船型 L/B/T/DWT 列成小表，看是否同一组。

### ○ E28　高程基准混用且无换算
- **表现**：总平面用当地理论最低潮面、结构图用 85 高程、水深图用航行基准面，全篇不给换算关系。
- **依据**：JTS 165-2025 4.5.2.1（应以当地理论最低潮面为基准并给出与国家 85 高程关系）。
- **怎么核**：查"基准与高程系统"专节是否只有一句话；抽 2 个高程点跨图核对。

### ○ E29　主尺度表缺底高程 / 缺参数取值过程
- **表现**：只给"顶高程、设计水深"，不给"设计底高程"；航道只给结果不给 Z1/Z2/Z3/Z4 取值。
- **依据**：JTS/T 110-4-2025 3.4.4、3.5.4.2（要求给计算公式、参数取值和结果）。
- **怎么核**：按块 12 的表逐项打勾，缺项即 ○。

### ○ E30　附图附件缺失
- **表现**：缺桩位图、地质剖面、航道断面、疏浚分区图；正文引用的波浪/泥沙/模型试验报告未附。
- **依据**：JTS/T 110-4-2025 设计图纸卷要求；JTS 120-3-2018 报告附件要求。
- **怎么核**：对照图纸目录与正文引用清单，双向核。

## 附：归并规则（避免同一根因重复计数）

| 情形 | 处理 |
|---|---|
| 同一缺项在多个泊位/多个断面重复出现 | **合并为 1 条**，在"位置"里列全部桩号/泊位号 |
| 变形缝在 5 处特殊部位都漏 | **合并为 1 条**（E05），位置写"帽梁 3 处、胸墙 2 处" |
| 防腐缺失同时涉及钢管桩与拉杆 | **合并为 1 条**（E07），除非两者依据条号不同且结论不同 |
| 缺项导致数值结论偏危险（如漏整体稳定且边坡接近临界） | 由 ● **升 ★**，并在描述里写清"漏项 + 后果" |
| 同一数值在 3 处不一致 | **1 条**（E27 类），写"三处取值分别为…" |
| 强条与普通条同时违反（如 7.1.12 漏项 + 5.4.8 只算一套） | **拆 2 条**，分别标 ★ 与 ●，不要合并降级 |

## 定级口径

1. **先查条号是否在 `compulsory-clauses.md` 的 116 条内** → 在，则 ★（除非明确只是"款内非黑体部分"）。
2. 不在强条内但**结论偏危险**（承载力不足、稳定不够、高程偏低、间距不足）→ ★。
3. 不在强条内且**属方案/内容缺失** → ●。
4. **只是深度、表述、图文不一致、附件缺失** → ○。
5. **拿不准时降一级并写明"依据待核"**，不要凭印象写"违反强条"。
