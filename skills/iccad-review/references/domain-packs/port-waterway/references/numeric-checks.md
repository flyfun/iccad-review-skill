# 水运工程报告审查 — 数值项矩阵（50 项）

> **用途**：审查时按本表逐项打勾，避免"看了结构忘了水位、看了水位忘了荷载"。
> 每项给：**判据 / 出处 / 方向 / 复算器**。
> 方向：`下限`（≥ 才合格）· `上限`（≤ 才合格）· `区间`（落在区间内）· `清单`（只核有没有）。

## 附：不在本表但常被问到的三个数

| 问 | 答 | 为什么不在表里 |
|---|---|---|
| **重力式码头抗滑安全系数 K 取多少？** | **没有这个指标**。水运用分项系数法：`γ0(γE·EH + γw·Pw + …) ≤ 抗力设计值`。硬套 K=1.3 就是编判据 | 见 `norms.md` §四"极限状态不套 K" |
| **越浪量允许值多少？** | 按使用要求定，单位 **L/(s·m)**；JTS 154 2.0.19 只给定义，不给统一限值 | 需按码头面用途（集装箱/件杂/人员通行）分别论证 |
| **桩的竖向承载力特征值怎么算？** | 本技能只核 `Qa = Qk/γR` 的 γR 与 Qk 来源；Qk 需地质参数 + 桩型，属计算书内容 | 见 `limits.md` §五 |

## 使用建议

1. **先扫 ★ 项（表中带 ★ 的 18 项）**——这些是强条，错了直接 ★。
2. **再扫有复算器的 7 项**（#7、#8、#9~16、#28~33、#42、#46、#47、#49、#50）——能算就别靠看。
3. **最后扫"取值型"**（水位、重现期、系数）——这类错在"引错表/引旧版"，查出处最快。
