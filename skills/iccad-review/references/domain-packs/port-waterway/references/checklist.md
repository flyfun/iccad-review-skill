## 块 1　前置条件与设计基础

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **报告属性** | 先定：①对象（海港/河港/码头/航道/防波堤/疏浚/通航条件影响评价）②阶段（可研/初设/施工图/安全评价）③结构型式（高桩/板桩/重力式/格形/斜坡/浮） | 属性判错 → 后面全套章节走错。例：把"航道整治"按"码头"审，块 4/7 全废 |
| **高程基准** | 海港以**当地理论最低潮面**为基准（JTS 165 4.5.2.1）；内河多用航行基准面。必须写明与**国家 85 高程**的换算关系 | 全篇混用两套基准而不给换算；平面图与断面图基准不一致 |
| **设计水位四件套** | 设计高水位、设计低水位、极端高水位、极端低水位**齐全**（JTS 165 4.5.2.3）；极端值取 **50 年**重现期（JTS 145 5.5.7 ★） | 只给设计高/低水位，无极端水位 → 块 4 的复核标准直接无法算 |
| **水位取值口径** | 海岸/感潮常年潮流段：设计高水位 = 高潮累积频率 **10%** 或历时累积频率 **1%**；设计低水位 = 低潮累积频率 **90%** 或历时累积频率 **98%**（JTS 145 5.5.2 ★） | 四个百分数错位（10/1、90/98）；把"平均潮位"当设计高水位 |
| **资料三性** | 水文资料须说明来源、精度、人类活动影响，并做可靠性/一致性/代表性检查（JTS 145 3.0.4、4.4.2、4.4.3 ★） | 直接引邻近站系列不提一致性；建库前后系列拼接使用 |
| **设计船型** | 给出代表船型：总长 L、型宽 B、满载吃水 T、载重吨 DWT；改造工程另给现状船型与目标船型 | 只写"5000 吨级"无 L/B/T，导致块 2/5 无法复核 |
| **地质** | 钻孔布置、土层物理力学指标（γ、c、φ、cu、N、fs、qp）、承载力特征值；软土给灵敏度与固结参数 | 只给柱状图无参数表；参数在块 7 与块 8 取值不一致 |
| **规范版本** | 引用规范**必须现行**。重点核：JTS 165-2013→**2025**、JTS 154-1-2011→**154-2018**、JTS 167 六部合一本、JTS 147-1-2010→**147-2017 + 147-7-2022**、JTS 145-1/145-2→**145-2015(2022版)**、JTS/T 110-4-2008→**2025** | 引旧版且未说明 → ●（涉及强条条号位移时升 ★） |

## 块 2　设计船型与泊位等级

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **泊位长度（单个一字形）** | `L_b = L + 2d`（JTS 165 5.4.18）；富裕长度 d 按表 5.4.18：L<40 → **5m**；41~85 → **8~10**；86~150 → **12~15**；151~200 → **18~20**；201~230 → **22~25**；231~280 → **26~28**；281~320 → **30~33**；>320 → **35~40** | 直接用 L+20 拍数；d 取表中最小值但不说明理由 |
| **泊位长度（连续/端部）** | 端部泊位、中间泊位、连片布置各有公式（JTS 165 5.4.18~5.4.20）；滚装码头另按 5.5.5 | 连续泊位照单个泊位算，重复计 d |
| **泊位等级与吨级** | 设计船型吨级与泊位等级匹配；报告须说明"以 X 万吨级为主、兼顾 Y 万吨级"的论证 | 只写等级不写兼顾船型，导致航道尺度偏小 |
| **通过能力** | 泊位通过能力按装卸工艺、台时效率、年作业天数计算，并说明利用率 | 只给结论数字，无台时效率与作业天数 |
| **作业天数** | 年作业天数须扣除风、浪、雾、雨、冰等不可作业天数，并给出各因素天数 | 直接取 330 天无依据；与块 1 的气象统计矛盾 |

## 块 3　总平面布置

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **码头前沿线** | 位置、方位、长度与地形、水流、主导风向协调；与航道走向夹角合理 | 前沿线顶冲来流；与航道轴线夹角过大导致靠离泊困难 |
| **回旋水域** | 尺度按表 5.3.3：掩护较好、水流不大、有拖船协助 **1.5~2.0L**；掩护较差 **2.5L**；LNG 码头回旋圆 **≥2.5L**（布置困难且流速小时 **≥2L**）（JTS 165 5.3.3） | 一律取 1.5L，不考虑掩护条件；LNG 用 2L 却无"布置困难"论证 |
| **港池与制动水域** | 港池宽度：两侧两泊位以上且港内转头 **≥2.0L**，不转头 0.8~1.0L；连接水域转弯半径 自航 **≥3.0L**、拖船协助 **≥2.0L**（JTS 165 5.3.9/5.3.10） | 港池宽度按 1.5L；连接水域半径小于 3L |
| **锚地** | 锚地位置、水深、底质、面积、锚泊方式与艘数匹配；与航道、管线、保护区不冲突 | 只画位置不给锚泊能力；锚地水深小于设计船型吃水+富余 |
| **口门与防波堤轴线** | 口门数量、宽度、位置、朝向须与波浪玫瑰图、主流向一致；口门宽度满足船舶操纵 | 口门正对强浪向；宽度只按单船宽取 |
| **泊位净距（危险品）** | 油气化工泊位与其他货种泊位防火间距（表 5.6.4）：对**客运泊位** 甲/乙类 **300m**；对其他货种泊位 甲/乙类 **150m**、丙类 **50m**；500 吨级以下可取 **50%**（JTS 165 5.6.4 ★） | 间距不足；折减用于 ≥500 吨级（折减只对 <500 吨级） |
| **相邻油品泊位净距** | 按设计船长查表 5.6.5：L≤110 → 25m；110<L≤150 → 35m；150<L≤182 → 40m；182<L≤235 → 50m；L>235 → 55m | 统一取 35m；与 5.6.4 的防火间距混为一谈 |
| **陆域衔接** | 前沿作业地带宽度、堆场、道路、铁路进线与装卸工艺匹配；集疏运不穿越泊位 | 堆场面积与通过能力不匹配；道路穿越码头前沿 |

## 块 4　码头前沿高程与水深

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **前沿顶高程（基本标准）** | `E = 设计高水位 + Δ`；Δ = 一般取 **10~15 年**重现期波浪波峰面高度且 **≥1.0m**，掩护良好 1.0~2.0m（JTS 165 5.4.8） | 只算一套标准；Δ 取 0.5m；用设计低水位起算 |
| **前沿顶高程（复核标准）** | 以**极端高水位**起算，Δ 取 2~5 年重现期波浪波峰面高度，掩护良好 0~0.5m；**两套取高者** | 缺复核标准 → 越浪风险 |
| **前沿设计水深** | `D = T + Z1 + Z2 + Z3 + Z4`（JTS 165 5.4.12）；Z1 按表 5.4.12-1 查土质（淤泥 0.20 / 含淤泥砂 0.30 / 块状土 0.40 / 岩石 0.60）；Z2 = K1·H4%（良好掩护减 Z1）、K1 顺浪 0.3、横浪 0.5~0.7；Z3 干散/液散 0.15、滚装 ≤1000DWT 0.30 / >1000DWT 0.20；Z4 有淤积 **≥0.4m** | 漏 Z3/Z4；Z2 不减 Z1；横浪仍取 0.3 |
| **设计底高程** | `底高程 = 设计起算水位 − D`（JTS 165 5.4.13）；**LNG 码头与工作船码头从理论最低潮面起算**（5.4.11.2 ★） | 用平均水位起算；LNG 用设计低水位 |
| **开敞式大型码头** | D **不宜小于 1.1T**（JTS 165 5.4.12.2） | 开敞码头 D=1.0T，未做 1.1T 校核 |
| **泊位有效水深** | 停泊水域范围内实际水深（含浚深）≥ D；报告须给"设计水深 vs 现状水深 vs 浚深后水深"三者 | 只给设计值，不核现状测深图 |
| **复算** | `calc_wharf_elevation.py --mode depth/top --t T --z1 .. --k1 .. --h4 .. --report ..` | — |

## 块 5　航道与通航尺度

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **航道设计水深** | `D = T + Z0 + Z1 + Z2 + Z3 + Z4`（JTS 165 6.4.5）；Z1 按表 6.4.5-1（土质 × 6 档吨级，0.20~0.90）；Z2 按表 6.4.5-2（船浪夹角 0~90°），**10000 吨级以下 ×1.25**，8s<T<10s 内插 | 取 Z1=0.3 一刀切；Z2 不乘 1.25；把 D0（通航水深）当 D |
| **航道宽度** | 单线 `W = A + 2c`、双线 `W = 2A + b + 2c`；`A = n(L·sinγ + B)`；b 取设计船宽 B；c 查表 6.4.2-1（JTS 165 6.4.2） | 双线宽度按 2 倍单线；c 取 0 或固定 5m |
| **弯曲半径** | 取 **3×顶推船队长、4×货船长、4×拖带船队最大单船长**之大值；困难河段 2/3/3 倍之大值；山区流速 >3m/s 宜 5 倍（JTS 181 4.5.5） | 只按 3L；困难河段未折减但无"困难"论证 |
| **内河航道水深** | `H = T + ΔH`，ΔH 查表 4.5.2；卵石/岩石河床另加 **0.1~0.2m**；Ⅰ级 5000 吨级以上另加 **0.1~0.2m**（JTS 181 4.5.2） | 直接套海港公式；漏河床附加 |
| **通航水位** | 设计最高/最低通航水位按 JTS 145 5.2.1/5.2.2（★）分河段类型取；枢纽上下游按 5.3.2/5.3.3（★） | 内河套海港潮位频率；枢纽上游只取正常蓄水位 |
| **通航净空** | 跨越建筑物（桥、缆、管）按设计最高通航水位时的最小净空尺度核算（JTS 165 6.4.1、JTS 181 2.0.19） | 用设计水位而非最高通航水位；净空不含波浪/富裕 |
| **通航保证率** | 给出通航保证率与相应水位，说明年通航天数 | 只写"保证率 95%"无水位对应 |
| **复算** | `calc_channel_depth.py --mode depth/radius --t .. --soil .. --dwt .. --angle .. --report ..` | — |

## 块 6　荷载

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **船舶撞击力** | 有效撞击能量 `E0 = ρ·m·Vn²/2`（kJ），ρ **0.7~0.8**；Vn 按表 10.4.4-1 分吨级与掩护条件（海船有掩护 ≤1000t 0.20~0.25 … >100k 0.06~0.08；无掩护更大）；由 E0 反查护舷曲线得撞击力（JTS 144-1 10.4） | 用系缆力代替撞击力；Vn 取 0.3 不分成吨级；ρ 取 1.0 |
| **系缆力** | `N = K/n·√(ΣFx²+ΣFy²)`；K：n=2 → **1.2**，n>2 → **1.3**；夹角 海船 α=30°/β=15°、河船 α=30°/β=0°；结果**不得低于表 10.2.5-1 下限**（1000DWT 150kN … 300000DWT 2000kN）（JTS 144-1 10.2） | 算得 119kN 用于 5000DWT 泊位（下限 300kN）；K 一律 1.3 |
| **挤靠力** | 连续护舷 `F = 1.1·ΣFy/L`（kN/m）；间断护舷 `F' = 1.3·ΣFy/n`（kN）（JTS 144-1 10.3.2/10.3.3） | 两个系数（1.1/1.3）用反 |
| **系船柱数量与间距** | 按泊位长查表 10.2.2：≤100m 2 个 / 101~150 3 / 151~200 4 / 201~250 5~6 / 251~300 7~8；间距多 20~30m | 30 万吨级泊位只设 6 个；间距 40m |
| **堆货荷载** | 按货种/工艺/结构型式综合确定；专业化码头查表 5.1.1-1，一般工艺海港/河港查表 5.1.1-2/-3（JTS 144-1 5.1.1 ★） | 集装箱堆场按 20kPa；堆高与荷载不匹配 |
| **人群荷载** | 按表 5.2.1；人行引桥、浮桥另以**集中力 1.6kN** 验算通道板；栏杆顶部水平荷载 1.0kN/m，经常有人处 **≥1.5kN/m**（JTS 144-1 5.2.1/5.2.2 ★） | 引桥只算均布；客运码头栏杆取 1.0 |
| **起重运输机械荷载** | 按机型与实际起重量、幅度确定（JTS 144-1 6.1.1 ★）；注明轮压/支腿压力分布 | 用额定起重量；未给轮压 |
| **车辆荷载** | 汽车 + 平板挂车**都要算**（8.0.1 ★）；相邻车横向净距 **≥0.4m**、纵向轴距 **≥4.0m**（8.0.4 ★） | 只算汽车；净距 0.3m |
| **风、冰荷载** | 高耸结构自振周期 >0.25s 乘风振系数（11.0.6 ★）；冰荷载按当地冰凌，重要工程做冰力物模（12.0.2 ★） | 北方港口无冰荷载；灯塔不算风振 |
| **复算** | `calc_ship_loads.py --mode impact/mooring/berthing --dwt .. --vn .. --n .. --fx .. --fy .. --report ..` | — |

## 块 7　码头结构选型与稳定计算

> **水运用极限状态分项系数法**，没有单一安全系数 K。
> 判据形式是 `γ0·(γE·EH + γw·Pw + …) ≤ 抗力设计值`，**不要拿 K≥1.3 去套**。
> 因此本块只核"验算项是否齐全 + 分项系数取值是否正确 + 结论是否落在抗力侧"。

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **安全等级与 γ0** | 安全等级按表 3.1.5（JTS 167 3.1.5 ★）；γ0 = 一级 **1.1** / 二级 **1.0** / 三级 **0.9**（表 3.2.2） | 全篇 γ0=1.0；等级定一级但 γ0 取 1.0 |
| **作用分项系数** | 自重 γG **1.2**（有利 ≤1.0、自重为主 ≥1.3）；土压力 γE **1.35**；剩余水压力 γPw **1.05**；可变作用 γQ 五金/散货/机械 **1.5**、汽车铁路件杂 **1.4**；波浪 稳定 **1.3** / 构件 **1.5**；组合系数 ψ 持久 **0.7** / 短暂 **1.0**（表 3.2.6） | 波浪力两档用反；ψ 全取 1.0 |
| **重力式码头持久组合** | **7 项**：①前趾抗倾 ②沿墙底面/墙身水平缝抗滑 ③沿基床底面抗滑 ④基床和地基承载力 ⑤墙底面合力作用位置 ⑥整体稳定 ⑦构件承载力（JTS 167 7.1.12 ★） | 只做抗滑抗倾 → 漏 5 项 |
| **重力式短暂组合** | 施工期：墙后未回填/部分回填时下部结构与胸墙在波浪下稳定；吹填时已建部分稳定（7.1.13 ★） | 沉箱安装期、胸墙未回填期无验算 |
| **摩擦系数** | 混凝土-混凝土 **0.55**；浆砌石-浆砌石 **0.65**；墙底-抛石基床 预制混凝土 **0.60** / 预制浆砌石方块 **0.65**；基床底-地基 细~粗砂 **0.50~0.60** / 粉砂 **0.40** / 砂质粉土 **0.35~0.50** / 黏土 **0.30~0.45**（表 7.1.10） | 直接用 tanφ；取 0.6 不分类 |
| **基床厚度** | 顶面应力 > 地基承载力 → 按承载力算且 **≥1.0m**；≤ → **≥0.5m**（7.2.5 ★） | 0.8m 且应力超限 |
| **板桩码头** | 前墙"踢脚"稳定、锚碇稳定、整体稳定、桩承载力、构件强度（6.1.6 ★）；前墙必算入土深度/内力/拉杆拉力（6.3.1 ★） | 缺踢脚稳定；拉杆拉力只给"满足" |
| **高桩码头** | 承载能力 4 类 + 正常使用 3 类（5.1.20/5.1.21 ★）；岸坡施工期与使用期稳定（5.7.11 ★） | 施工期岸坡不组合设计低水位 |
| **格形钢板桩** | 5 项承载能力（含**内部剪切稳定**、**环向抗拉强度**）+ 2 项正常使用（8.1.7/8.1.8 ★） | 漏内部剪切与环向抗拉（格形墙特有） |
| **斜坡码头/浮码头** | 承载能力 7 项 + 正常使用 4 项（9.1.10/9.1.11 ★）；5000 吨级及以上浮码头设消能设施（9.2.41 ★） | 钢引桥挠度不验 |
| **复算** | `calc_wharf_stability.py --mode checklist --type gravity --items ...`（只核齐全性，不判 K） | — |

## 块 8　桩基与地基处理

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **单桩轴向承载力** | `Qa = Qk/γR`；γR 打入桩 静载 **1.30~1.40** / 经验 **1.45~1.55**；灌注桩 **1.50~1.60** / **1.55~1.65**；嵌岩桩抗压 **1.60~1.70**、抗拔 **1.80~2.00**（JTS 167 表 4.2.7） | 用 2.0 的安全系数当 γR；静载与经验取值混用 |
| **桩距** | 按单桩计算最小桩距：打入/灌注 轴向 **6d**（或 3d~6d 且桩端进入良好持力层）；水平 **6d~8d**；嵌岩桩 轴向 2d/3d（表 4.2.2） | 桩距 3d 无"桩端进入持力层"论证 |

## 第 2 步　跨专业一致性（9 对）

> 单块各自正确 ≠ 报告正确。逐对核"同一条数值链在不同章节是否同源同值"。

**① 设计船型 ↔ 全部尺度**
`L、B、T、DWT` → 泊位长度（L+2d）、航道宽度（A=n(Lsinγ+B)）、回旋直径（1.5~2.5L）、系缆力下限（按 DWT 查表 10.2.5-1）、撞击能量（m 为满载排水量）。
**核法**：先把块 1 的船型表抄出来，逐项代入块 2/3/5/6 的公式，看报告值是否落在同一船型上。常见错：平面用 5 万吨船型、荷载用 3 万吨船型。

**② 设计水位 ↔ 顶高程 / 底高程 / 水深**
设计高水位 → 顶高程基本标准；极端高水位 → 顶高程复核标准；设计低水位 → 前沿设计水深与底高程；理论最低潮面 → LNG/工作船码头。
**核法**：同一张"水位表"必须支撑块 4 全部四个公式。常见错：顶高程用设计高水位、底高程却用平均水位。

**③ 通航水位 ↔ 航道水深 ↔ 通航保证率**
设计最低通航水位 + 航道设计水深 = 航道设计底高程；设计最高通航水位 + 净空 = 桥梁/缆线控制高程。
**核法**：底高程反算水位，与块 1 水位表比对。常见错：航道底高程按设计低水位算，通航保证率却按最低通航水位统计。

**④ 地质参数 ↔ 承载力 / 桩长 / 边坡 / 地基处理**
同一土层的 γ、c、φ、cu、fs、qp 在块 7（稳定）、块 8（桩基）、块 10（挖槽边坡）必须同值。
**核法**：抽查 2~3 个关键土层，把三处的取值列成小表比对。常见错：稳定计算用固结快剪、桩基用直剪，且未说明。

**⑤ 荷载 ↔ 结构计算**
块 6 的堆货、机械、船舶、车辆荷载，必须与块 7 计算书里的荷载图式一一对应（含分项系数与组合系数）。
**核法**：拿计算书的荷载汇总表反查块 6。常见错：荷载章给 30kPa，计算书用 20kPa。

**⑥ 波高 ↔ 护面块体 / 顶高程 / 越浪**
同一个 H 必须同重现期、同累积频率：斜坡堤护面用 H13%，直立堤用 H1%，顶高程用设计高水位时的 H（并按 k 系数）。
**核法**：块 9 的 H 出现几次、是否同一值同一频率。常见错：护面用 H13%、顶高程却用 H1%，两个波高差 20~30%。

**⑦ 疏浚量 ↔ 断面尺度**
方量 = 断面面积 × 长度（或网格法），且含超深（一般 0.3~0.5m）、超宽（一般 0.5~1.0m）、回淤量。
**核法**：任取一个分段，用报告给的断面面积×长度复算，偏差 >5% 即追问。常见错：方量比断面算出的小（漏超深超宽）。

**⑧ 结构尺寸 ↔ 工程量 ↔ 概算**
混凝土方量、钢筋量、基床抛石量、桩长与根数，必须能从断面图与桩位图算出来。
**核法**：抽一个典型断面，按尺寸算混凝土量，与工程量表比对。常见错：桩数按每榀 4 根×榀数，但桩位图多出 6 根。

**⑨ 平面布置 ↔ 通航条件影响评价结论**
口门位置、航道走向、锚地、回旋水域与评价报告的"通航安全影响"结论必须一致；评价提的措施要在设计里落实。
**核法**：把评价结论的措施逐条对照平面图与结构图。常见错：评价要求设导标/警戒，设计图无。
