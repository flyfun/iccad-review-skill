# 洪评报告审查 — 完整检查项清单

配套 `SKILL.md` 第 1 步"分块审查"使用。按 **12 块**展开，每条含 **判定标准** 与 **失败模式**。

> **引用约定见 `norms.md`**（条款号取法、限值出处、强条处置、版本声明）。本文件不再重复。
> 标 **★强条** 者为 `compulsory-clauses.md` 所列强制性条文。
> 数值限值见 `flood_tables.md`；章节结构与报告目录见 `flood_works_tables.md`。
> **块号 ↔ 报告章对照**见 `flood_works_tables.md` §四。

## 块 1　概述与评价依据

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **报告类型与目录** | 与 SL/T 808 附录 B **三套目录**（B.1 综合 / B.2 河道 / B.3 蓄滞洪区）之一对得上 | 缺章、章节顺序与目录不符 |
| **评价依据现行性** | 法律法规 + 技术标准应为**现行有效版本**（**SL/T 808-2025**、GB 50201-2014、SL 252-2017、GB 50286-2013 等） | 引 **SL/T 808-2021** 或 **SL 520-2014** → 引用已废止标准 |
| **影响分析范围** | 按 **SL/T 808 表 1**：山区 **3B** / 丘陵 **(3~5)B** / 平原 **(5~10)B**；**B 为两堤之间河宽**，无堤段取**历史最高洪水位河宽** | 只取"上下游各 500m"不等；B 取值口径错 |
| **技术路线与评价内容** | 覆盖"项目对防洪的影响" + "洪水对项目的影响"两个方面 | 只评一面 |
| **评价对象界定** | 明确是"**河道管理范围内涉河建设项目**"还是"**蓄滞洪区内非防洪建设项目**" | 对象定性错 → 后续全走错章 |
| 与许可/设计文件一致性 | 项目组成、规模、布置与立项批复、设计文件一致 | 报告与主体设计矛盾 |

## 块 2　建设项目基本情况

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **项目概况** | 地理位置、建设规模、性质、总布置清晰 | 概况含混、缺总布置 |
| **工程建设方案** | 平面布置、结构型式、主要尺寸、与河道/堤防的空间关系（**跨/穿/临**）明确 | 未交代与河道、堤防的相对位置 |
| **防洪(潮)方案** | 施工期、运行期防洪（潮）安排；度汛措施 | 缺防洪方案 |
| **施工组织与施工方案** | 施工方法（**定向钻/盾构/顶管/挖沟/围堰/栈桥**）、工期、临时工程布置 | 施工方法不明 → 判不了施工期影响 |
| 数字孪生/地理信息 | 按 3.0.4 提供地理信息数据与主要结构参数 | 缺主要结构参数 |

## 块 3　流域（河湖 / 蓄滞洪区）基本情况

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| 流域·河道概况 | 流域水系、河道总体情况 | 泛泛而谈、无针对性 |
| **所在河段情况** | 河段特征（**山区/半山区/平原/低洼**）、河宽、深泓、滩槽、比降、糙率 | 河段参数缺失 → 影响范围/壅水算不了 |
| **水工程情况** | 范围内堤防、水闸、泵站、水库、水文测站、取用水设施 | 漏现有水工程 → 漏"水工程安全影响评价" |
| **水文监测设施** | 水文站/水位站位置、测验断面（5.1.1 须避让**水文监测环境保护范围**） | 漏水文站 → 违 §5.1.1 |
| **相关规划** | 综合规划、防洪规划、河湖岸线保护与利用规划、蓄滞洪区建设与管理规划、河道整治规划 | 无规划依据 → 规划符合性判不了 |
| 蓄滞洪区基本情况 | 蓄洪容积、进退洪口门、调度运用规则、安全建设工程（安全区/台/避水楼/转移道路） | 漏蓄滞洪区参数 |
| 资料可靠性 | 按 4.1.2 对资料做**可靠性、一致性**分析 | 直接套用未分析 |

## 块 4　河道演变分析

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **历史演变** | 简述历史演变过程与特点（可引用已有成果） | 无历史演变 |
| **近期演变** | 据实测资料分析**深泓、洲滩、汊道、岸线**平面变化 + 断面变化 | 只给结论无实测支撑 |
| **演变趋势** | 据历史+近期，结合规划实施，定性/定量分析趋势 | 无趋势分析 |
| **深度匹配** | 重要河段 / 河势变化剧烈河段 / 影响较大项目，须**数值模拟或河工模型试验**（6.3.5、7.4.3） | 该上模型只做定性 |
| 与治理工程关系 | 演变分析应反映已有控导、护岸工程的实施效果 | 忽略已实施工程 |

## 块 5　洪水影响分析计算（★核心块）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **计算工况** | 按 6.1.2：① **现状及规划防洪标准对应工况**；② **项目设计防洪标准工况**；③ **施工期工况**（另含蓄滞洪运用工况） | 只算一个工况、漏施工期 |
| **水文分析计算** | 各频率水位、流量；多沙河流含泥沙成果；**成果做合理性分析**（6.2.1） | 无合理性分析、直接挪用 |
| **阻水比** | 按 6.4.2 应计算**总阻水比 + 河槽阻水比 + 滩地阻水比 + 占用行洪面积**，四项成果缺一不可；报告以「/」表示未计算即属不符合 | 只给总数、口径不明 |
| **壅水** | 式(A.2.3-1) **ΔZ_M = η(V_M²−V²)**；η 按表 A.2.3-1；V_M 按表 A.2.3-2 分类求得；须给出**壅水高度与壅水长度**的数值成果 | η 拍脑袋、V_M 无依据 |
| **行洪能力** | 壅水后行洪/排涝能力变化定量 | 只给壅水高度、不给能力变化 |
| **河势稳定计算** | 用演变分析 + 冲淤计算支撑河势判断 | 无计算直接定性 |
| **冲刷与淤积** | 冲刷深度 = **演变冲刷 + 一般冲刷 + 局部冲刷叠加**（A.3.3），并据此确定基础埋深 | 只算局部冲刷即定"最大冲刷线" |
| **防洪工程影响计算** | 堤防/岸坡稳定影响计算（按 GB 50286 §9 三工况） | 无稳定影响计算 |
| **蓄滞洪影响计算** | 占用面积/容积及百分比；灌溉供水与排涝面积、流量（6.4.4/6.4.5） | 只定性不给量 |
| **公式适用性** | 按 6.1.3 分析计算公式的**适用性**与**参数来源** | 套公式不论适用条件 |
| 占用库容/湖泊容积 | 占用水库库容/湖泊容积时定量分析对调蓄能力影响（7.5.3） | 漏调蓄能力影响 |

## 块 6　技术要求符合性（SL/T 808 §5 硬指标）

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **总体布置** | 5.1.1 符合河湖岸线保护与利用规划；避开**水文监测环境保护范围**、**蓄滞洪区进退洪口门及行洪通道** | 布置侵入禁入区 |
| **跨越方式与选址** | 5.1.1-3/4 选顺直稳定河段、**不应顺河布置**、穿越**宜下穿** | 顺河布置、上跨穿堤 |
| 影响堤防加高与防汛交通 | 5.1.2 不应影响；背水侧防汛通道**满足三级公路通车标准** | 通道标准不足 |
| **跨河桥梁** | 5.2.2 全线跨越、**主河槽宜一跨**、桥墩夹角 **≤5°**、**阻水比 ≤5%**；5.2.2-5 跨堤**宜立交** | 河道内多支墩、阻水比超限无专门论证 |
| **跨堤/梁底** | 5.2.2-5/6 平交时梁底**高于规划堤顶高程**；梁底满足防洪与漂流物通过 | 梁底低于规划堤顶、净空不足 |
| **相邻桥梁** | 5.2.3 间距 > 壅水长度；否则做工程群累积效应分析 | 漏群效应 |
| **桥墩承台** | 5.2.5 承台顶**不应高于规划河底高程**、不宜高于冲刷线 | 承台顶超高、加剧阻水 |
| **穿河穿堤** | 5.3.2 轴线**宜正交**；**设计防洪标准不应低于穿越处河道及堤防**；定向钻/盾构/顶管/挖沟各按其要求；**管顶埋深在最大冲刷线以下** | 标准偏低、埋深不足 |
| **破堤施工** | 5.3.4 **非汛期**施工、汛前恢复原状或达规划设计标准 | 汛期破堤 |
| **临河临堤** | 5.4.2 不改变河道走向、不束窄行洪断面；**码头/取排水设施阻水比 ≤2%**；5.4.3 码头宜高桩、顺水流 | 临河阻水比超 2%、滩地抬高 |
| **蓄滞洪区项目** | 5.5.1~5.5.9 符合调度安排；口门与主流区无阻水建筑；高速/铁路宜全程高架；**梁底高于设计蓄洪水位**；管道埋深在最大冲刷线以下；架空底高于设计蓄洪水位 | 按 §5.2~5.4 河道要求套蓄滞洪区 |
| 生态与服务设施 | 5.4.6/5.4.12 体育设施**不得建封闭建筑**；服务设施用**移动/可拆结构** | 违禁建设 |
| 复算 | 核对阻水比与净空的**计算成果是否存在**且口径正确（阻水比按 6.4.2 四个口径，净空按 5.2 表2 最小净空） | 报告称满足而实际不足 |

## 块 9　规划符合性与防洪标准评价

| 检查点 | 判定标准 | 失败模式 |
|---|---|---|
| **水利规划符合性** | 7.2.1 符合流域及区域综合规划、防洪规划、河湖岸线保护与利用规划、河道整治规划 | 与规划冲突 / 无规划依据 |

## 第 2 步　跨专业一致性校验（8 对）

**单块各自正确 ≠ 报告正确。** 逐对交叉校验，最容易被漏的一层。

| # | 交叉对 | 校验要点 / 典型错 |
|---|---|---|
| 1 | **保护对象 ↔ 防洪标准 ↔ 堤防级别 ↔ 项目设防标准** | 防洪标准由保护对象定 → 堤防级别 → 项目（尤其堤上建筑物）设防标准；标准定错则全篇连锁错（含强条 11.8.3） |
| 2 | **影响分析范围 B ↔ 河段参数 ↔ 壅水/冲刷计算范围** | B 取值口径（两堤间 / 历史最高洪水位河宽）决定范围；范围错则计算的工况范围错 |
| 3 | **设计洪水 ↔ 水面线 ↔ 梁底/管顶高程 ↔ 净空/埋深** | 设计洪水位是一切高程判据的基准；水位算错 → 净空、埋深判定全错 |
| 4 | **阻水比 ↔ 壅水高度 ↔ 行洪能力变化** | 阻水比大 → 壅水大 → 行洪能力降；三者须自洽（阻水比 5% 而壅水为零 → 可疑） |
| 5 | **冲刷计算 ↔ 最大冲刷线 ↔ 管顶埋深/承台高程** | 冲刷不叠加 → 冲刷线偏浅 → 埋深"假合格"；须逐项核对演变、一般、局部三部分成果 |
| 6 | **项目布置 ↔ SL/T 808 §5 技术要求** | 布置（跨越方式、支墩位置、夹角、码头型式）应逐条对 §5.1~§5.5；口头说"符合"须条条核 |
| 7 | **堤防/岸坡稳定 ↔ 防洪工程影响评价 ↔ 措施** | 稳定计算结论 → 影响评价 → 防冲防渗措施，须一条链自洽 |
| 8 | **报告内部同一参数前后一致** | 正文 / 表格 / 图 / 计算书 中同一数值（设计洪水位、阻水比、壅水高度、冲刷深度、标准、容积）是否一致 |

> 自洽性校验不靠眼看。凡报告给出数值结论（阻水比、壅水、冲刷深度、净空、防洪标准、埋深），
> 先核对**中间量与成果是否齐备**（缺哪一项就判哪一项），再核同一参数在正文/表格/计算书中是否一致。
> 判定口径：报告以「/」表示未计算 → 不符合；相关章节存在但只给定性描述 → 不符合；
> 整块内容缺失 → 缺失。
