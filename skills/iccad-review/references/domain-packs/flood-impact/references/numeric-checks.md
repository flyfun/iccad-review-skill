# 洪评报告审查 — 数值型检查项 · 复算覆盖矩阵

> **用途**：本册回答一个问题 —— **哪些数值型判据有代码复算、哪些必须人工核**。
> 凡下"满足/不满足"判词，数值一律取自 `flood_tables.md` 或用 `scripts/spec_lookup.py`
> 从自带条文库取原文；**两者都不许凭记忆写**。
> **判据方向**：数值型判据分两类，判反了就是错情 ——
> **下限型**（安全系数、净空、超高、埋深、防洪标准）→ 报告值 **≥** 限值才满足；
> **上限型**（阻水比、应力比、夹角、基底应力 vs 承载力）→ 报告值 **≤** 限值才满足。
> 本册每一项都标了方向，脚本输出也带 `≥` / `≤` 与"上限型/下限型"字样。

### 2.2 `calc_backwater.py` — 壅水（下限/比对）

| 数值项 | 依据 | 公式 / 判据 | 用法 |
|---|---|---|---|
| 桥前最大壅水高度 ΔZ_M | SL/T 808 式(A.2.3-1) | **ΔZ_M = η(V_M²−V²)** | `--v 1.8 --vm 2.06 --eta 0.07` |
| 壅水曲线全长 L_Y | 式(A.2.3-4) ★图片式 | ≈ 2ΔZ_M/I₀（**仅量级参考**） | `--i0 0.0002` |
| 相邻桥梁间距 > 壅水长度 | SL/T 808 5.2.3 | 间距 **>** L_Y | `--spacing 10 --ly 100` |
| 报告值比对 | — | 差 > 0.05 m 即提示 | `--report 0.12` |

> **L_Y 取值纪律**：近似式算出的一律不作硬判定（只出 ▲ 提示）；要用它判 5.2.3，

### 2.3 `calc_scour.py` — 冲刷 / 埋深 / 河势（下限型 + 比对）

| 数值项 | 依据 | 公式 | 模式 |
|---|---|---|---|
| 平行岸坡冲刷 h_B | 式(A.3.4-1) | **h_B = h_p[(v_p/v_H)^n − 1]**，n=1/4~1/6 | `--mode parallel` |
| 斜冲岸坡冲刷 Δh_p | 式(A.3.4-2) ★图片式 | 行业通用式还原 → **rc=3 仅参考** | `--mode oblique` |
| 滩地局部冲刷流速 V_j | 式(A.3.4-3) | **V_j = β·Q₁/(B₁·H₁)** | `--mode vj-beach` |
| 无滩地局部冲刷流速 V_j | 式(A.3.4-4) | **V_j = Q/(W − W_P)** | `--mode vj-nobank` |
| 结构埋深 / 承台高程 vs 冲刷线 | 5.2.5 / 5.3.2-3/5 / 5.5.5-1 | 结构底高程 **≤** 最大冲刷线高程 | `--mode check` |
| 河流稳定性指标 K | 式(A.4.4) | **K = D/(hJ)**，越大越稳定 | `--mode regime` |
| 河床稳定性 ζ 系数 | A.4.3 ★OCR 残缺 | 砂河床 1.4 / 一般沙河 2.75 / 极易冲刷细沙 5.5（**待核**） | `--mode regime --bed` |

> **叠加原则（A.3.3）**：最大冲刷线 = **河道演变冲刷 + 一般冲刷 + 局部冲刷**。
> `--mode check` 只核"结构 vs 冲刷线"这一层，**冲刷线本身是否三叠加够**须看报告计算书。
> **不复算**：桥下一般冲刷、桥墩局部冲刷（TB 10017 / JTG C30）、丁坝冲刷（公式含图片+多系数）。

## 四、判词前的三句话自检

1. **方向对不对** —— 这道题是"不得大于"还是"不应小于"？
   （阻水比、应力比、夹角 = 上限；安全系数、净空、超高、埋深、防洪标准 = 下限）
2. **口径对不对** —— 分母是什么？（阻水比的分母是**过水面积**；影响范围的 B 是**两堤间河宽**；
   应力比的分母是 σmin；防洪标准是**重现期**不是频率倒数写反）
3. **版本对不对** —— SL/T 808-**2025**（替换 808-2021 + SL 520-2014）、
   SL/T 386-**2025**（替换 386-2007 + 379-2007）、SL/T 808 的净空表与 JTG D60-2015 一致。
   引旧版 → 先出"引用已废止标准"。
