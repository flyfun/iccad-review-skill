## 五、关键构造与技术要求（正文条文索引，用关键词召回）

| 主题 | 出处 | 要点 |
|---|---|---|
| **涉河项目总体布置** | SL/T 808 5.1.1 | 符合河湖岸线保护与利用规划；避开**水文监测环境保护范围**、**蓄滞洪区进退洪口门及行洪通道**；不应影响行洪通畅、防洪安全 |
| **跨河选址与跨越方式** | 5.1.1-3/4 | 选河道顺直、河势及岸坡稳定河段；**不应顺河布置**；穿越河道及堤防**宜下穿** |
| **影响堤防加高与防汛交通** | 5.1.2 | 不应影响；难以避免时背水侧设防汛通道，**满足三级公路通车标准** |
| **跨河桥梁跨越** | 5.2.2 | 河道管理范围内**全线跨越**；减少支墩、**主河槽宜一跨跨越**；桥墩夹角 ≤5°；**阻水比 ≤5%** |
| **跨堤方式** | 5.2.2-5 | **宜立交跨越**；平交时梁底高于规划堤顶高程、不削弱堤身、做防渗加固；两侧设水平连接段 |
| **梁底高程** | 5.2.2-6/7 | 满足防洪要求，保障流冰·泥石流·漂浮物通过；山区山洪易发区**一跨过河**、留足梁底净空 |
| **相邻桥梁间距** | 5.2.3 | 应大于**桥梁壅水长度**；城区难以满足时须数值模拟/河工模型分析**工程群累积效应** |
| **桥墩承台与墩头** | 5.2.5 | 承台顶**不应高于规划河底高程**、不宜高于冲刷线；墩头宜圆型/流线型 |
| **穿河穿堤轴线与标准** | 5.3.2-1/2 | 轴线**宜正交**；设永久性识别与警示标识；穿堤宜堤基穿越；**设计防洪标准不应低于穿越处河道及堤防** |
| **定向钻穿越** | 5.3.2-3 | 全程穿越；出/入土点在管理范围外；穿越堤防段管顶距堤基线满足堤防安全；**穿越河槽滩地段管顶埋深在最大冲刷线以下** |
| **盾构/顶管** | 5.3.2-4 | 工作井在管理范围外；隧道进出口在河道管理范围外；**通风口高程高于设计洪水位并留足安全超高** |
| **挖沟法** | 5.3.2-5 | **管顶高程低于最大冲刷线或规划河底高程** |
| **管道闸阀** | 5.3.2-6 | 输送流体管道，在堤防**背水侧管理范围外一定距离内设控制闸阀** |
| **破堤施工** | 5.3.4 | **非汛期**施工；**汛前恢复原状或达规划设计标准** |
| **临河临堤布置** | 5.4.2 | 顺应地形地貌；**不应改变河道走向、束窄行洪断面**；不应影响河势·堤岸稳定 |
| **临河阻水比** | 5.4.2-3 | **码头、取排水设施等阻水比不应大于 2%** |
| **码头型式** | 5.4.3 | 顺水流布置、**宜高桩结构**；低水位码头前沿顶高程不宜高于现状滩地平均高程；皮带机栈桥跨堤宜跨堤型 |
| **滩岸整治** | 5.4.5 | 顺应河势、随坡就势；**不应占用行洪断面、大挖大填、修筑围堤、抬高滩地平均高程** |
| **堤顶兼交通** | 5.4.10 | 应充分论证；上/下堤坡道在背水侧加宽堤防，不削弱有效断面 |
| **迎水侧挖入式港池** | 5.4.11 | **不应占用堤防护堤地**；背水侧港池宜设防洪闸门、防洪标准不低于所在河段 |
| **蓄滞洪区项目** | 5.5.1~5.5.9 | 符合洪水调度安排；进退洪口门与主流区不得设阻水建筑；高速/铁路**宜全程高架**；**梁底高于设计蓄洪水位并留安全超高**；低路基+水系连通+穿堤挡水闸门；**管道埋深在最大冲刷线以下**；架空底高于设计蓄洪水位 |
| **计算工况** | 6.1.2 | ≥3 类：① 现状及规划防洪标准对应工况；② 设计防洪标准工况；③ 施工期工况（另含蓄滞洪运用工况） |
| **计算内容** | 6.4.2 | 应计算**总阻水比 + 河槽阻水比 + 滩地阻水比 + 占用行洪面积**，并做壅水及行洪能力分析 |
| **演变分析深度** | 6.3.5 / 7.4.3 | 重要/河势变化剧烈河段、影响较大项目，须**数值模拟或河工模型试验**预测演变趋势 |
| **水工程安全评价** | 7.6.2 | 根据**堤防和岸坡稳定**分析计算结果，评价对堤防/护岸/控导/险工/岸坡稳定的影响 |
| **施工期评价** | 7.9.2~7.9.7 | 施工围堰·栈桥占行洪断面须评价；取土弃土影响；跨汛期须**明确度汛方案**并评价 |
| **消除或减轻措施** | 9.1.2/9.1.3 | 措施设计**满足水工程初步设计深度**；由建设单位组织**与主体工程同步实施、同步验收、同步投入使用** |
| **结论形式** | 10.0.5 | 明确**有影响 / 无影响 / 通过采取措施可减轻影响**三种结论 |
