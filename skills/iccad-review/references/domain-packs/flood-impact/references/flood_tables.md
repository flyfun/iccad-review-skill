## 一、SL/T 808-2025 第 5 章 建设项目技术要求（硬指标）★核心

### 1.1 一般规定（§5.1）

| 条文 | 要求 |
|---|---|
| 5.1.1-1 | 项目布置应符合河湖岸线保护与利用规划与水域岸线管控要求；**避开**水文监测环境保护范围、蓄滞洪区进退洪口门及行洪通道；严格控制占用河湖水域岸线、水库库容和蓄滞洪容积；**不应影响行洪通畅、防洪安全** |
| 5.1.1-3 | 桥梁、管(隧)道、缆线类应选**河道顺直、河势及岸坡稳定**河段跨越；**不应顺河布置**；桥梁互通结构应避开河道管理范围 |
| 5.1.1-4 | 需穿越河道及堤防的，**宜采用下穿方式** |
| 5.1.1-5 | 附属办公、生活设施**不应布置在河道管理范围内** |
| 5.1.1-6 | 选址应避让规划水工程；无法避让且对规划水工程有影响的，须与主体工程**同步实施**影响范围内水工程 |
| 5.1.2 | 不应影响堤防加高加固与**堤顶防汛交通**；难以避免时应在背水侧设防汛通道，**满足三级公路通车标准** |
| 5.1.3 | 避免汛期施工；确需跨汛期施工的须编制**施工度汛方案**并报批；施工临时办公/生活区**不宜布置在河道管理范围内** |

### 1.2 跨河建设项目（§5.2）

| 条文 | 要求（★=数值型硬约束） |
|---|---|
| 5.2.2-1 | 河道管理范围内应**全线跨越**；应减少河道内支墩，**主河槽宜一跨跨越** |
| ★ 5.2.2-2 | 桥梁轴线宜与河道主流方向垂直；桥墩顺水流方向轴线应与中高洪水时主流方向一致，**确实难以满足的，夹角不应大于 5°** |
| ★ 5.2.2-3 | **阻水比应严格控制，不应大于 5%**；确实难以满足的，应对防洪安全影响进行**专门论证** |
| 5.2.2-4 | 支墩**不应布置在堤身设计断面以内**；输电线路迎/背水侧塔基应布置在**堤防工程管理范围以外**、不在主流区内；导线弧垂最低点高程应满足堤顶交通、防汛抢险车船通行及通航安全要求 |
| 5.2.2-5 | **宜立交跨越堤防**；确需平交的，跨堤部分**梁底高程应高于规划堤顶高程**，不应削弱堤身设计断面，并做防渗加固；两侧宜设**长度不小于桥面宽度**的水平连接段 |
| 5.2.2-6 | **梁底最低高程应满足防洪要求**，并保障流冰、泥石流、漂浮物顺利通过 |
| 5.2.2-7 | 山区河道应充分考虑山洪灾害风险；山洪易发区桥梁应**一跨过河**、留足梁底净空 |
| 5.2.3 | **相邻桥梁间距应大于桥梁壅水长度**；城区难以满足时应按数值模拟/河工模型分析工程群累积效应 |
| 5.2.4 | 桥面排水口应**避开堤防、岸坡** |
| 5.2.5 | 桥墩承台顶高程**不应高于规划河底高程**，**不宜高于冲刷线高程**；墩头宜圆型或流线型 |
| 5.2.6 | 浮桥**不应缩窄河槽**；河势变化时应及时调整两端位置 |

### 1.3 穿河、穿堤建设项目（§5.3）

| 条文 | 要求 |
|---|---|
| 5.3.2-1 | 轴线**宜与堤防正交**；河道管理范围内适当位置设**永久性识别和警示标识**；穿堤管道**宜采用堤基穿越**；爬堤敷设涉及沉降段的应专门论证 |
| ★ 5.3.2-2 | **设计防洪标准不应低于穿越处河道及堤防防洪标准** |
| 5.3.2-3 | 定向钻宜**全程穿越**河道堤防；出/入土点应在**堤防工程管理范围之外**；穿越堤防段管顶距堤基线距离应满足堤防安全；**穿越河槽及滩地段管顶埋深应在最大冲刷线以下** |
| 5.3.2-4 | 盾构/顶管法**工作井应布置在堤防工程管理范围以外**；隧道进出口应布置在**河道管理范围之外**，**通风口高程应高于设计洪水位并留足安全超高** |
| ★ 5.3.2-5 | 挖沟法施工的，**管顶高程应低于最大冲刷线或规划河底高程** |
| 5.3.2-6 | 输送流体的穿河/穿堤管道，应在**堤防背水侧管理范围外一定距离内设控制闸阀** |
| 5.3.3 | 爬堤敷设管道/缆线**不应削弱堤身设计断面**；穿越堤身段底部高程**应高于堤防设计洪水位并留足安全超高** |
| 5.3.4 | 破堤施工应在**非汛期**进行，并在**汛前恢复原状或达规划设计标准** |

### 1.4 临河、临堤建设项目（§5.4）

| 条文 | 要求（★=数值型硬约束） |
|---|---|
| 5.4.2-1 | 应顺应原有地形地貌；**不应改变河道走向、束窄或减少行洪断面**，不应影响河势稳定、不应分隔水面、影响堤岸稳定 |
| 5.4.2-2 | 确需地形整理的，**不应抬高河底和滩地高程**，**不宜大面积硬化** |
| ★ 5.4.2-3 | **码头、取排水设施等构筑物阻水比不应大于 2%** |
| 5.4.3 | 码头平台**顺水流方向**布置、**宜高桩结构**；低水位码头前沿顶高程**不宜高于现状河段滩地平均高程**；高水位码头**栈桥梁底高程宜高于设计洪水位**；皮带机栈桥与堤防交叉宜**跨堤型** |
| 5.4.4 | 临河道路**宜平滩地建设**，不应阻碍行洪 |
| 5.4.5 | 滩岸整治应顺应河势、随坡就势；**不应占用行洪断面、降低行洪能力、大挖大填、修筑围堤、抬高现状滩地平均高程** |
| 5.4.6 | 公共体育设施除健身步道、开放式运动场地、水上运动码头外，**不得建设房屋、围栏等封闭式建筑物构筑物** |
| 5.4.7 | 渔业养殖设施**不应布置在行洪通道内** |
| 5.4.8 | 船厂除船台、船坞、滑道、码头外，其他设施不应在河道管理范围内；**不应设围挡等阻水构筑物** |
| 5.4.9 | 必需的水电气油管道缆线跨越/穿越堤防的，应符合 §5.3 |
| 5.4.10 | 堤顶兼作交通道路的应充分论证；上/下堤坡道应在**背水侧加宽堤防**，不应削弱有效设计断面 |
| 5.4.11 | 迎水侧**挖入式港池不应占用堤防护堤地**；背水侧港池宜设**防洪闸门**或保障防洪封闭圈完整，**防洪标准不应低于所在河段** |
| 5.4.12 | 少量公共卫生等服务设施应采用**移动式或可及时拆卸结构** |
| 5.4.13 | 锚地、服务区、待泊区不应影响行洪、河势、岸坡稳定及堤防安全，不应影响河口防潮 |

### 1.5 蓄滞洪区内非防洪建设项目（§5.5）

| 条文 | 要求 |
|---|---|
| 5.5.1 | 应符合洪水调度安排，满足防御洪水方案/洪水调度方案/防洪预案/蓄滞洪区运用预案要求 |
| 5.5.2 | **进退洪(口门、闸)区域及洪水主流区域内不应设置妨碍行洪的建筑物**，不应影响蓄滞洪区调度运用 |
| 5.5.3-1/2 | 高速/铁路宜**全程高架**通过；应减少桥墩数量；**桥梁梁底应高于设计蓄洪水位并留安全超高**，且满足水上救生要求、设警示标识 |
| 5.5.3-6 | 互通枢纽匝道支墩**宜避开主要河道** |
| 5.5.4 | 道路确需路基通过时应**采用低路基**；与河道交叉应设桥梁涵洞等水系连通设施，**不应降低设计行洪排涝能力**；穿堤应设**挡水闸门** |
| ★ 5.5.5-1 | 埋地敷设**不应抬高现状地面高程**，**管道埋深应在最大冲刷线以下** |
| 5.5.5-2 | 架空敷设**架空结构底部应高于设计蓄洪水位**，并满足防汛抢险与水上救生要求 |
| 5.5.6 | 码头及临时堆场**不应减少蓄洪容积**、不应阻碍行洪通道 |
| 5.5.8 | 输变电设施不应影响行洪蓄洪、降低调蓄能力 |

## 四、SL/T 808-2025 表 A.2.3-1　η 系数（壅水计算）

| 河流特征 | 河滩路堤阻挡的流量与设计流量比值 (%) | η |
|---|---|---|
| 河滩很小的山区河流 | ≤10 | **0.05** |
| 河滩较小的半山区河流 | 11~30 | **0.07** |
| 有中等河滩的平原河流 | 31~50 | **0.10** |
| 河滩较大的低洼区河流 | >50 | **0.15** |

> 壅水公式（式 A.2.3-1）：**ΔZ_M = η ( V_M² − V² )**
> ΔZ_M 桥前最大壅水高度(m)；V 断面平均流速(m/s)=设计流量÷全河过水断面（含河滩）；
> V_M 桥下平均流速(m/s)，按表 A.2.3-2 求得。
> 壅水曲线全长（式 A.2.3-4）：**L_Y ≈ 2 ΔZ_M / I₀**（I₀ 天然水面坡度）★公式本体为图片，
> 本册按行业通用近似式记录，正式成果以报告计算书/水面曲线法为准。

## 九、冲刷深度计算式引用关系（SL/T 808-2025 附录 A.3）

| 对象 | 依据 | 是否可复算 |
|---|---|---|
| 水流平行岸坡 | 式(A.3.4-1) **h_B = h_p[(v_p/v_H)^n − 1]**，n 一般取 1/4（1/4~1/6） | ✅ `calc_scour --mode parallel` |
| 水流斜冲岸坡 | 式(A.3.4-2)（GB 50707 附录 B.2.2 / GB 50286 附录 D.2.2）★公式本体为图片 | ⚠ `calc_scour --mode oblique` 仅出参考值 |
| 局部冲刷流速 | 式(A.3.4-3)/(A.3.4-4) | ✅ `calc_scour --mode vj-beach / vj-nobank` |
| 丁坝冲刷 | 式(A.3.4-5)~(A.3.4-8)；GB 50707 附录 C.1.2 / GB 50286 附录 D.2.1 | ❌ 不复算（公式含图片与多修正系数 k₁k₂k₃） |
| 桥下一般冲刷 | TB 10017 / JTG C30；SL/T 808 式(A.3.5-1)~(A.3.5-7) | ❌ 不复算（须报告给计算书） |
| 桥墩局部冲刷 | TB 10017 / JTG C30；式(A.3.5-8)~(A.3.5-14)（非黏性/黏性分列） | ❌ 不复算 |
| 潜坝/锁坝冲刷 | GB 50707 附录 C.2.3 | ❌ 不复算 |

> **叠加原则（A.3.3）**：河道冲刷深度是**河道演变冲刷 + 一般冲刷 + 局部冲刷**的叠加，
> 应分析确定**最大冲刷深度和冲刷线高程**。报告只算局部冲刷而不叠加 → 阻水/埋深判断失真。
> **河势稳定指标（A.4.3/A.4.4）**：ζ 系数公式中 **B/h** 取值 —— 砂河床 1.4、一般沙河 2.75、
> 极易冲刷的细沙河床 5.5；河流稳定性指标 **K = D/(hJ)**（D 代表粒径、h 平均水深、J 比降），
> 越大越稳定（长江汉口段 0.924、黄河秦厂段 0.168）。

## 十四、河道整治防护工程（GB 50707-2011，临河护岸类）

**防护工程稳定安全系数（表 8.2.5 系引用）**：坡式护岸 —— 抗滑 正常 **1.25** / 非常 **1.20**；
墙式防护 —— 抗滑 正常 **1.25** / 非常 **1.20**、抗倾 正常 **1.50** / 非常 **1.40**。

**护脚构造（§8.2.7~8.2.8）**
- 脚槽顶部高程高于设计枯水位 **0.5~1.0 m**；干砌石脚槽断面积 **0.6~1.0 m²**、
  浆砌块石或混凝土 **0.4~0.8 m²**。
- 护脚顶部枯水平台高于设计枯水位 **0.5~1.0 m**，宽 **1~4 m**。
- 抛投体护脚**坡度不宜陡于 1:1.5**，迎流顶冲、重点河段**宜缓于 1:2.0**；
  护脚厚度**不应小于抛投体平均块径的 2 倍**。
- 深泓逼近河岸段宜护至**深泓线**并满足**河床最大冲刷深度**要求；
  岸坡较缓、深泓离岸较远段可护至坡度 **1:3~1:4** 的缓坡河床。

**控导工程（§8.3）**
- 丁坝间距 **可为坝长的 1~3 倍**（潮汐河口段 5~8 倍）；非淹没丁坝可用**下挑式**，
  交角宜 **30°~60°**；淹没丁坝可用上挑式；受潮流倒灌影响可用正挑式。
- 锁坝顶宽 **3~8 m**；护底宽度上游取坝高 1.5 倍、下游取 **3~8 倍**。
- 潜坝坝顶高程**低于设计枯水位**，坝顶宽**不宜小于 3 m**。
- 重要河段/规模较大的锁坝潜坝，应据**河工模型试验**专项设计。
