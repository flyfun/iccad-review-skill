# 洪评报告相关强制性条文（强条）清单

> **强条 = 违反即写"违反强制性条文"，最高严重级 ★，不得降格为"不符规范推荐"。**
> 本清单来自《水利工程建设标准强制性条文》（2020 年版，`spec_lookup.py` 内 `GB-强条汇编`），
> 及各部规范公告明示的强条。**引用前务必在自带条文库召回原文逐字核对。**

**在自带条文库检索强条原文**：
```bash
python scripts/spec_lookup.py --spec "GB-强条汇编" --q 洪水影响评价    # GB 50286 10.1.3
python scripts/spec_lookup.py --spec "GB-强条汇编" --q 11.8.3          # GB 50201 11.8.3
python scripts/spec_lookup.py --spec "GB-强条汇编" --q 滞洪区           # GB 50201 6.1.2/6.2.2/6.5.4
python scripts/spec_lookup.py --spec "GB 50286"   --q 7.2.4            # 压实度原文
```

> ⚠ **特别提示**：**SL/T 808-2025 本身不在 2020 年版强条汇编内**（808-2025 晚于汇编）。
> 洪评的**法定强条约束落在其引用规范上** —— 最直接的是 **GB 50286 10.1.3**（与堤防交叉连接的
> 建筑物应进行洪水影响评价）。**不要把"库里没有 808 的强条"误读成"洪评没有强条约束"。**
> 同理，块库把 SL/T 808 的若干条标成 `level=mandatory`，那只是"含'应'字"的入库启发式标记，
> **不等于** 强制性条文，不可据此写"违反强制性条文"。

## 一、GB 50286-2013《堤防工程设计规范》—— 3 条

### 强条 1 — 10.1.3　与堤防交叉、连接建筑物应做洪水影响评价（★洪评最直接强条）
> 修建与堤防交叉、连接的各类建筑物、构筑物，**应进行洪水影响评价**，
> **不得影响堤防的管理运用和防汛安全**。

**判定要点**：凡穿堤、跨堤、临堤的建筑物/构筑物（桥梁、管道、缆线、码头、泵站、涵闸等），
① 报告**是否做了洪水影响评价**；② 结论**是否影响堤防管理运用与防汛安全**。
> 违反强条 1 的两种形态：**根本没做洪评**；或**做了但结论"不影响"却无计算支撑**。

### 强条 2 — 7.2.4　黏性土土堤填筑压实度
> 黏性土土堤的填筑标准应按**压实度**确定：1 级堤防**不应小于 0.95**；
> 2 级和堤身高度不低于 6m 的 3 级堤防**不应小于 0.93**；堤身高度低于 6m 的 3 级及 3 级以下堤防**不应小于 0.91**。

### 强条 3 — 7.2.5　无黏性土土堤填筑相对密度
> 无黏性土土堤填筑标准应按**相对密度**确定：1 级、2 级和堤身高度不低于 6m 的 3 级堤防**不应小于 0.65**；
> 堤身高度低于 6m 的 3 级及 3 级以下堤防**不应小于 0.60**。有抗震要求的堤防按 SL 203 执行。

**判定要点**：洪评涉及**穿堤恢复/破堤复建**的，其填筑标准须达压实度/相对密度下限（块 8）。

## 二、GB 50201-2014《防洪标准》—— 5 条

### 强条 4 — 11.8.3　堤防上闸涵泵站等建筑物防洪标准（★洪评高频）
> 堤防工程上的**闸、涵、泵站**等建筑物及其他构筑物的设计防洪标准，
> **不应低于堤防工程的防洪标准，并应留有安全裕度**。

**判定要点**：**"不应低于"是下限，但还须"留有安全裕度"→ 取等于堤防标准也不满足**。
用 `calc_flood_std.py --mode check` 复核；等于即判不满足。

### 强条 5 — 5.0.4　工矿企业（毒害物/核工业）
> 遭淹后可能爆炸或致毒液/毒气/放射性大量泄漏时：中、小型工矿企业取**表 5.0.1 中 Ⅰ 等**；
> 特大、大型除取 **Ⅰ 等上限**外尚应采取专门防护措施；**核工业及与核安全有关的厂区、车间及专门设施，
> 应采用高于 200 年一遇的防洪标准**。

### 强条 6~8 — 6.1.2 / 6.2.2 / 6.5.4　穿过行、蓄、滞洪区的铁路 / 公路 / 管道
> 6.1.2 经过行、蓄、滞洪区**铁路**的防洪标准，应结合所在河段、地区的行、蓄、滞洪区要求确定，
> **不得影响行、蓄、滞洪区的正常运用**。
> 6.2.2 同上，**公路**。
> 6.5.4 同上，**管道**。

**判定要点**：涉行蓄滞洪区的交通/管道类洪评项目，标准须结合行蓄滞洪区要求，且**不得影响其正常运用**。

### （配套）6.3.5　河(海)港区陆域防洪工程
> 当河(海)港区陆域的防洪工程是城镇防洪工程的组成部分时，其防洪标准**不应低于该城镇的防洪标准**。

## 四、GB 50707-2011《河道整治设计规范》—— 1 条

### 强条 18 — 4.1.3　整治河段设计标准
> 整治河段的防洪、排涝、灌溉、航运、岸线利用等设计标准，**应符合经审批的防洪、排涝、灌溉、航运、
> 岸线利用规划**；具有两种及以上标准时应**协调各标准间关系**。

**判定要点**：洪评的"水利规划实施影响评价"（块 9）引用河道整治规划时，须核设计标准有规划支撑。
