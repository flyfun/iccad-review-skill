## 二、输入 / 解析边界

- **docx 表格可自助提取**：`scripts/extract_docx_tables.py`（**网格重建**，正确处理横向 gridSpan / 纵向 vMerge 合并单元格）
  —— 把阻水比计算表 / 壅水计算表 / 冲刷计算成果表 / 稳定计算成果表 / 占用容积表还原成可核对的二维表；
  正文段落用 `--text-only`。**PDF / 扫描件不在本技能内**，须另用 OCR / PDF 工具。
- **报告没写的，判不了**：缺影响分析范围、缺设计洪水、缺断面/河宽、缺阻水比计算、缺冲刷计算 → 只能出"深度不足"的发现，判不了对错。
- **附图/影像无法自动审**：地理位置图、工程平面布置图、河道断面图、水面线图、冲刷范围图、监测布置图
  须**人工看图**核对（含是否标出河道管理范围线）。
- **报告属性要先判**：是"河道管理范围内涉河建设项目洪评"还是"蓄滞洪区内非防洪建设项目洪评"，
  决定走附录 B.2 还是 B.3 目录、走 §7 还是 §8 评价。判错对象 → 后续全走错章。

## 五、复算脚本的能力边界（9 个）

> **统一语义**：每个复算器都做**"复算值 / 规范限值 / 报告值"三方比对**，退出码
> `0` 满足 · `1` 不满足（含违反强条、与报告显著不符）· `2` 输入错 · `3` 仅参考值。
> **判据方向**分下限型（安全系数、净空、超高、埋深、防洪标准）与上限型（阻水比、应力比、夹角、σmax vs 承载力）
> —— 方向判反即为错情，逐项见 `numeric-checks.md`。

1. `calc_blockage.py`：按 SL/T 808 5.2.2-3 / 5.4.2-3 机械比对**阻水比**（跨河 ≤5% / 临河 ≤2%），
   并可算**行洪断面缩窄率**与总阻水比的河槽/滩地**分算**。**断面面积、行洪面积仍须人工从报告摘取**。
2. `calc_backwater.py`：按式(A.2.3-1) **ΔZ_M=η(V_M²−V²)** 复算桥前壅水，η 按表 A.2.3-1；
   V_M 可由 `--vm` 直给、或按 `--p`（V_M=V/P）、或 `--vp` 组合。
   5.2.3 桥梁间距判定须用**报告给出的壅水长度**（`--ly`）——近似式 L_Y 只出 ▲ 提示、不作硬判定。
3. `calc_scour.py`：六模式 —— 平行岸坡冲刷 `h_B=h_p[(v_p/v_H)^n−1]`（n 默认 1/4）、斜冲冲刷（**仅参考值，标注待核**）、
   局部冲刷流速 V_j（滩地/无滩地）、埋深校核（结构埋深 vs 最大冲刷线）、**河势稳定 regime**
   （K=D/(hJ)，参考值不作判定；ζ 系数因 A.4.3 原文 OCR 残缺**标待核**）。
   **不代算**桥下一般冲刷、桥墩局部冲刷、丁坝冲刷（须报告计算书）。
4. `calc_impact_area.py`：按表 1 复算**影响分析范围**（山区 3B / 丘陵 (3~5)B / 平原 (5~10)B），
   含上游/下游分段下限校核。**B 的取值（两堤间河宽 / 历史最高洪水位河宽）须人工确认**。
5. `calc_clearance.py`：按表 2 复算**桥类最小净空**（梁底/垫石顶/有铰拱拱脚，对计算水位与最高流冰面双向），
   及无铰拱拱脚淹没 2/3、拱顶净高 ≥1.0m、水库区 0.75×浪高+0.25m、调治构造物顶面 +0.25m。
6. `calc_flood_std.py`：按 GB 50201 表 3.0.1/4.1.1/5.0.1 取**防洪标准**、按 SL 252 表 4.4.1 取**堤防级别**、
   并做**标准符合性校核**（含 ★强条 GB 50201 11.8.3 "不应低于 + 留安全裕度" ⇒ 等于即不满足）。
7. `calc_stability.py`：**九模式**覆盖稳定与构造 —— 安全加高 freeboard（GB 50286 表 3.2.1 + 堤顶高程校核）、
   边坡抗滑 slope（GB 50286 表 3.2.3 / SL/T 386 表 3.3.7，**SL/T 386 区间按下限作要求**）、
   挡墙抗滑 wall-slide（GB 50286 表 3.2.5 / SL/T 386 表 3.4.5、3.4.7，含岩基抗剪断 3.00/2.50/2.30）、
   抗倾覆 overturning（表 3.2.7 / 3.4.10 / 3.4.11）、抗浮 anti-float（表 3.4.12）、
   **基底应力比** base-stress（GB 50286 表 3.2.6 / SL/T 386 表 7.4.6，**上限型**；另核 σmax ≤ 允许承载力
   与 ≤ 1.2×允许承载力、岩基基底不出现拉应力）、**压实度/相对密度** compaction（**7.2.4 / 7.2.5 ★强制性条文**）、
   护堤地 berm（13.2.2，区间型）、防护工程 revetment（GB 50707 表 8.2.5）。
   **只做"报告值 vs 规范限值"比对，不重算稳定系数** —— 稳定系数须报告给出计算方法与参数（含抗剪断强度参数）。
8. `calc_bridge.py`：三模式 —— 桥涵设计洪水频率 freq（JTG D60 表 3.2.9）、
   **涵洞净高 culvert（3.4.4：管涵/拱涵 h≤3m 取 h/4、h>3m 取 0.75m；矩形涵 h≤3m 取 h/6、h>3m 取 0.50m）**、
   河滩流量导流堤 beach-flow（3.2.8-4：单边 ≤15% / 双边 ≤25% 可不设）。
   ⚠ **JTG D60-2015 未入自带条文库**，本脚本输出一律带"**★待核**"。
9. `calc_geometry.py`：三模式 —— 桥墩轴线与主流夹角（**上限 ≤5°**，SL/T 808 5.2.2-2）、
   承台顶高程 vs 规划河底（**不应高于**）/ 冲刷线（不宜，▲提示）、跨堤梁底 ≥ 规划堤顶高程 + 连接段长度（宜，▲提示）。
   **"应/不应"进 `bad`（rc=1）**，**"宜"只出 ▲ 提示**（不构成硬错情，避免假错情）。
10. 脚本不代算：二维水流/泥沙数学模型、河床演变定量预测、河工模型试验、三维渗流、结构有限元、波浪爬高
    —— 这些需专业软件/试验（清单见 `numeric-checks.md` 第三节 18 项）。

## 六、判定责任边界

- 本技能产出的是**审查发现**，不是审批结论；最终判定责任在人，**AI 结论须经复核**。
- 洪评涉**行政审批与规划符合性**（★强条 GB 50286 10.1.3 即要求对交叉建筑物做洪水影响评价），
  本技能只提供技术审查辅助，**不替代行政许可与规划符合性审查程序**。
- 涉专业软件的成果（数值模拟、河工模型试验）本技能**只核其结论间是否自洽、参数是否齐全**，不重算模型。

## 七、与同族技能的关系

| 维度 | 河道工程审查（`river-channel`） | 洪评审查（本技能） |
|---|---|---|
| 对象 | 河道整治/堤防/护岸/清淤**工程本身的设计** | **建设项目对防洪的影响** + 洪水对项目的影响 |
| 主规范 | GB 50707 + GB 50286 | **SL/T 808-2025** |
| 关注点 | 断面/坡比/稳定/工程量 | 阻水比/壅水/冲刷/净空/埋深/蓄洪容积 |
| 报告名 | 可研/初设/施工图/安全评价 | **洪水影响评价报告**（原防洪评价报告） |

- 两者**都**用 GB 50286（堤防稳定）、GB 50707（冲刷公式），**判定口径须一致**（本册与 `rc_tables.md` 已对齐）。
- **纯工程设计问题**走 `river-channel-report-review`；**水土保持方案**走 `soil-conservation-report-review`；
  **水闸/土石坝设计**走对应技能；**洪水影响评价（本项目对防洪的影响）** 才是本技能。
