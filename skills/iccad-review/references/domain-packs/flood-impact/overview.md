# 洪水影响评价报告审查

## 这个 Skill 是什么

**审查编排层**，不是设计知识卡。回答：拿到一份洪评报告，**按什么顺序查、查哪些点、每条怎么判、
依据谁、怎么输出**。条款号、限值一律从条文库 / 固化表核对，**不硬编码**。

**适用**：涉河建设项目 / 蓄滞洪区非防洪建设项目的**洪水影响评价（原防洪评价）报告**。
**不适用**：纯河道设计、水保方案、土石坝/水闸设计、纯条文查询。

## 审查总流程

```
洪水影响评价报告 (docx/pdf)
 ├─[0]   前置判定 ── 类型/对象/跨越型式/河流特性/设防标准/影响范围
 ├─[0.5] 取判据 ── spec_lookup 调条文 + 固化限值表 + calc_*.py 复算
 ├─[1]   分块审查（12 块）── 查什么 → 判定标准 → 依据
 ├─[2]   跨专业一致性 ── 标准↔级别↔范围↔阻水↔壅水↔冲刷↔埋深 数值自洽
 └─[3]   结构化发现 ── 位置 / 问题 / 依据 / 严重度 / 建议
```

---

## 第 0 步：前置判定

**先定这六样，再翻正文。**

| 判定项 | 常见取值 | 影响 |
|---|---|---|
| **报告类型** | 涉河 / 蓄滞洪区两类 | 决定走附录 B 哪套目录、§7 还是 §8 |
| **评价对象** | 涉河建设项目 / 蓄滞洪区非防洪建设项目 | 对象错 → 后续全走错章 |
| **跨越型式** | 跨河 / 穿河穿堤 / 临河临堤 / 蓄滞洪区内 | 决定适用 §5.2/5.3/5.4/5.5 |
| **河流特性** | 山区 / 半山区 / 平原 / 低洼区 | 决定影响范围与壅水 η |
| **设防标准 / 堤防级别** | GB 50201 防护等级、SL 252 表 4.4.1 | **标准定错则全篇连锁错** |
| **影响分析范围** | 山区 3B / 丘陵 (3~5)B / 平原 (5~10)B | 表 1 硬要求；B 为**两堤间河宽**，无堤段取历史最高洪水位河宽 |

> 判不出这六样 → 基本资料缺项，本身就是一条 ○ 级发现。

## 第 0.5 步：取判据（别跳过）

**报告是 docx → 先用 `scripts/extract_docx_tables.py <报告> --keyword <词>` 把表格还原成网格**
（判据多藏在计算表里，顺序拼字会错行）。

三个来源，**不可混用**：

| 来源 | 怎么取 | 怎么写进意见 |
|---|---|---|
| **规范条文** | `python scripts/spec_lookup.py --spec "SL/T 808" --q 阻水比` | 引条款号 |
| **固化限值表** | `flood_tables.md`（阻水比/净空/范围/η/冲刷）+ `flood_works_tables.md` | 引条款号 + 表号 |
| **强制性条文** | `compulsory-clauses.md`（**GB 50286 10.1.3**、**GB 50201 11.8.3**） | 写"**违反强条**"，最高级 |

> **查条文三条纪律**（详见 `norms.md` §一）：① 用该规范自己的术语（"阻水比"是 SL/T 808 的词，
> 拿去查 GB 50707 是 0 命中）；② 别带"表"字（写 `5.2.2` 而非 `表5.2.2`）；
> ③ 优先词组、少用单字（`净空` 命中少，`应` 会带回上千条）；④ 库内正文来自 OCR，
> 已做**去空白容错**（"阻 水 比"也能命中）。

> 取不到条文 → 标"依据待核"，只出疑点不出结论。

**能算的不要只靠看**：凡报告给出数值结论，用复算脚本过一遍：

| 脚本 | 覆盖 |
|---|---|
| `calc_blockage` | **阻水比**（跨河 ≤5% / 临河 ≤2%）+ 缩窄率 + 河槽/滩地分算 |
| `calc_backwater` | **壅水 ΔZ_M=η(V_M²−V²)**（表 A.2.3-1/2）+ 壅水长度 + 桥距核 5.2.3 |
| `calc_scour` | **冲刷**：平行/斜冲岸坡、V_j、埋深核 + **河势 K=D/(hJ)** |
| `calc_impact_area` | **影响分析范围**（表 1：3B / (3~5)B / (5~10)B） |
| `calc_clearance` | **桥下净空**（表 2）+ 无铰拱 + 水库区浪高 + 构造物超高 |
| `calc_flood_std` | **防洪标准 / 堤防级别**核定 + 符合性（含 ★强条 11.8.3） |
| `calc_stability` | **稳定与构造**：安全加高 · 边坡/挡墙抗滑 · 抗倾 · 抗浮 · 基底应力比 · **压实度★** · 护堤地 · 防护工程 |
| `calc_bridge` | **桥涵**：设计洪水频率 · 涵洞净高 · 导流堤（JTG D60，**★待核**） |
| `calc_geometry` | **几何关系**：夹角 ≤5° · 承台顶 ≤ 规划河底 · 跨堤梁底 ≥ 规划堤顶 |

> ▶ **载入**：`references/norms.md` §一（取条文方法、脚本用法与限制）
> + `references/numeric-checks.md`（**39 项数值判据 × 代码覆盖矩阵 + 判据方向**）。

## 第 2 步：跨专业一致性（最容易被漏的一层）

单块各自正确 ≠ 报告正确。共 **8 对交叉校验**（保护对象↔标准↔级别、范围 B↔计算范围、
设计洪水↔净空/埋深、阻水比↔壅水↔行洪能力、冲刷↔最大冲刷线↔埋深、项目布置↔§5 技术要求、
稳定↔影响↔措施、内部数值一致）。
> ▶ **载入**：`references/checklist.md` §第 2 步。自洽优先用复算脚本验算，不靠眼看。

|---|---|---|---|---|---|

**严重度分级**：★ 违反**强制性条文** / 阻水比或设防标准超限 / 净空埋深不足；
● 不符规范、计算不完整、方案缺项；○ 深度不足、专业间不一致、图文不符、附件缺失。

**下判断前先读** `references/norms.md` §四（引用纪律 7 条）+ §五（易踩的坑 10 条）。

## 边界

- 只给**条文级判据 + 固化限值表 + 复算**（详见 `limits.md`）；产出为**审查发现**非审批结论，责任在人。
