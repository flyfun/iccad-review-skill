## 4. 怎么用

**新开一个会话**（技能列表在会话启动时加载），然后直接说：

```
用 $iccad-review 对 <报告目录> 做初步设计内部审查，工程等别 III，基线 送审稿V1
```

单专业也可直接调：

```
用 $iccad-route 列出 M4 水闸在初设阶段的必查项
用 $iccad-floodeval 核对这份防洪评价的壅水与冲刷计算
```

命令行侧（在仓库目录或任意目录，用绝对路径）：

```bash
# 资料清单与哈希
python ~/.workbuddy/skills/iccad-review/scripts/inventory_inputs.py <资料目录> --output inventory.json

# 结构校验 / 文件核验 / 审签准备
python ~/.workbuddy/skills/iccad-review/scripts/validate_review.py review.json
python ~/.workbuddy/skills/iccad-review/scripts/validate_review.py review.json --gate --root <资料根目录>

# 内部工作稿
python ~/.workbuddy/skills/iccad-review/scripts/render_report.py review.json --output report.md
```

退出码：`0` 通过、`2` 记录有错、`3` 结构有效但审签准备仍阻塞。

   `mv iccad-engine iccad-review` 并把 `name:` 改回。

   `git clone` 与 `api.github.com` 正常；下载 ZIP 请用 `codeload.github.com`。

## 6. 更新方式

```bash
cd <你克隆的仓库目录>
git pull
python install.py --target ~/.workbuddy/skills --force    # 覆盖 WorkBuddy 副本
```

同步其他位置（软链未生效，需显式复制）：

```bash
for s in skills/*/; do n=$(basename "$s")
  cp -r "$s" "$HOME/.agents/skills/$n"
  for tgt in .claude .codebuddy .codex .grok .qoder; do
    [ -d "$HOME/$tgt" ] && cp -r "$s" "$HOME/$tgt/skills/$n"
  done
done
```
